# Shapes

TinyCAD supports common shape tools for drawing non-electrical graphic elements,
including:

- rectangles,
- circles and ellipses,
- polygons,
- lines.

Use these to group blocks, highlight areas, and add explanatory notes without
changing circuit connectivity.

## Drawing lines & polygons

You can draw a collection of lines. To end drawing right-click.

You can convert this to a polygon by selecting "Close Polygon" in the context
menu. Once converted to a polygon you can change the fill.
