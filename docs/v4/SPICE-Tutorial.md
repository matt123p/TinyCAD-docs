# SPICE tutorial

Eleven chapters take you from a first DC result to sources, filters, rectifiers, amplifiers and design investigations. The circuits are in **Open Example → SPICE tutorial**; both browser and Desktop can run the analogue examples.

Read [Start here: how to use the tutorials](../Tutorial-Start-Here/) first. Each chapter includes explanations, circuit figures, actual solver results and downloadable drawings/netlists. The original course is included in full.
