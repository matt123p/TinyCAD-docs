# TinyCAD - Getting Started

For help creating symbols, libraries or circuits from written instructions and datasheets, see the [AI assistant](../AI-Assistant/) guide, including provider setup and example prompts.

TinyCAD v4 is available for use in two different ways:

## Desktop app

You may prefer an installed version of TinyCAD when you want to work offline or if you want to ensure
that you will always have access to TinyCAD.

Go to the [Installation Instructions](../TinyCAD-Desktop-App/) for instructions on how to download, install and run this version of TinyCAD.

## Online app

You may prefer the online version when you do not wish to or cannot install TinyCAD - for example in an education or work setting where you are not allowed to install applications.

Go to [TinyCAD Web quick start](../TinyCAD-Web-overview-and-quick-start/) for instructions on how to
start using TinyCAD directly in your web browser without requiring an installation.

## Explore a ready-made drawing

Use [bundled examples](../Bundled-Examples/) to explore a network, sensor station, audio setup, laboratory bench or motor-control project. Open Example is in the browser title bar, or under File in Desktop.

The [bundled libraries](../Bundled-Libraries/) are on the left under **Standard**. Choose a collection, search and drag a preview onto your drawing.

To calculate circuit behaviour, start with [Simulation and SPICE](../Simulation/) or follow the complete [SPICE tutorial](../SPICE-Tutorial/). The integrated engine is included in both products. Use Desktop for the separate [XSPICE digital course](../XSPICE-Tutorial/).
