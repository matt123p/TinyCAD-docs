# Manuale di TinyCAD
{: #tinycad-manual}

TinyCAD v4 è disponibile sia come applicazione desktop sia come applicazione online basata su browser. Esistono solo
poche differenze funzionali tra le due versioni.

Vai alla pagina [Differenze funzionali](Feature-Differences/) se vuoi conoscere le differenze esatte tra le versioni di TinyCAD.

## Avvertenza
{: #warning}

**TinyCAD** è sviluppato e distribuito gratuitamente come progetto open source guidato dalla comunità. È fornito «così com'è» e potrebbe contenere bug o avere funzionalità incomplete.  

È tua responsabilità eseguire il backup del tuo lavoro e prevenire la perdita di dati. È tua responsabilità controllare attentamente i circuiti prima di realizzarli o di stampare i PCB.

## Contribuire a questo manuale
{: #contribute-to-this-manual}

Il manuale di TinyCAD è open source ed è mantenuto su GitHub Pages.
I contributi della comunità sono benvenuti, comprese le correzioni di refusi, una formulazione più chiara,
uove schermate e l'ampliamento degli esempi.
