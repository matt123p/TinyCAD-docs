# Manuale di TinyCAD
{: #tinycad-v4-manual}

TinyCAD v4 è disponibile sia come applicazione desktop sia come applicazione online basata su browser. Le differenze tra le funzionalità delle due versioni sono poche.

Consulta la pagina [Differenze tra le funzionalità](Feature-Differences/) per conoscere le differenze esatte tra le versioni di TinyCAD.

## Avvertenza
{: #warning}

**TinyCAD** è sviluppato e distribuito gratuitamente come progetto open source gestito dalla comunità. È fornito "così com'è" e potrebbe contenere bug o funzionalità incomplete.  

È tua responsabilità eseguire il backup del lavoro e prevenire la perdita di dati. È tua responsabilità verificare attentamente i circuiti prima di realizzarli o stampare i PCB.
