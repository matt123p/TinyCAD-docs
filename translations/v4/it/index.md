# Manuale di TinyCAD
{: #tinycad-manual}

TinyCAD v4 è disponibile sia come applicazione desktop sia come applicazione online basata su browser. Le differenze
funzionali tra le due versioni sono poche.

Consulta la pagina [Differenze funzionali](Feature-Differences/) per conoscere le differenze esatte tra le versioni di TinyCAD.

## Avvertenza
{: #warning}

**TinyCAD** è sviluppato e distribuito gratuitamente come progetto open source gestito dalla comunità. Viene fornito «così com'è» e potrebbe contenere bug o funzionalità incomplete.  

È tua responsabilità eseguire il backup del tuo lavoro e prevenire la perdita di dati. È tua responsabilità effettuare controlli accurati prima di realizzare circuiti o stampare PCB.

## Contribuire a questo manuale
{: #contribute-to-this-manual}

Il manuale di TinyCAD è open source ed è mantenuto su GitHub Pages.
Sono benvenuti i contributi della comunità, tra cui correzioni di refusi, formulazioni più chiare,
nuove schermate ed esempi ampliati.
