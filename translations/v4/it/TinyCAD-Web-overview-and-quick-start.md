# Avvio rapido di TinyCAD Web
{: #tinycad-web-quick-start}

## TinyCAD per il Web
{: #tinycad-for-the-web}

TinyCAD per il Web viene eseguito direttamente nel browser, non richiede installazione
e funziona sui sistemi operativi che supportano un browser compatibile. I formati dei file
sono compatibili con TinyCAD desktop (disegni `.dsn` e librerie `.tclib`).

## Prima di iniziare
{: #before-you-start}

Assicurati di avere quanto segue:

- Chrome o Edge (per la modalità file locale)
- Per la modalità Google Drive, è consigliato Chrome; può funzionare anche Firefox
- Leggi i Termini e condizioni: [Termini e condizioni](https://www.tinycad.net/TCs)

È progettato per funzionare con Windows, Mac, Chromebook e Linux.

## Punti di accesso
{: #entry-points}

- Modalità file locale: <https://online.tinycad.net/fs>
- Modalità Google Drive: <https://online.tinycad.net/ga>
- Supporto: <https://discord.gg/bdXnjhrSYQ>

## Per iniziare (salvataggio dei disegni sul computer locale)
{: #getting-started-saving-drawings-on-local-computer}

Questa modalità si basa su funzionalità del browser disponibili nelle versioni moderne di Chrome o Edge.
Usa la versione più recente di uno dei due browser, quindi apri:

- <https://online.tinycad.net/fs>

## Per iniziare (salvataggio dei disegni su Google Drive)
{: #getting-started-saving-drawings-on-google-drive}

Prima di iniziare, devi avere un account Google.

Configurazione iniziale:

1. Vai a <https://online.tinycad.net/ga>.
2. Se usi un blocco annunci, disattivalo per questo sito (può interferire con
   la procedura di accesso di Google).
3. Se non compare alcuna finestra popup, verifica se il blocco dei popup è attivo e consenti
   i popup per il sito.
4. Accedi al tuo account Google nella finestra popup (se richiesto).
5. Seleziona **tutte** le caselle di consenso per consentire l'integrazione completa con Google Drive.
6. Se la procedura di accesso a Google non riesce dopo aver accettato i termini, ricarica la pagina e riprova.

## Privacy
{: #privacy}

### Modalità file locale
{: #local-file-mode}

TinyCAD viene eseguito interamente nel browser e archivia il lavoro localmente nel browser.
Nessuna parte del tuo lavoro o degli altri file viene inviata ai server di TinyCAD.

### Modalità Google Drive
{: #google-drive-mode}

I disegni vengono archiviati nel tuo Google Drive. Al primo utilizzo, devi concedere a
TinyCAD l'accesso ai tuoi file Google per abilitare l'integrazione.

TinyCAD continua a essere eseguito nel browser e scrive i dati nel tuo Google Drive privato; nessuna
parte del tuo lavoro o degli altri file viene inviata ai server di TinyCAD.

TinyCAD usa Google Analytics per monitorare i volumi di utilizzo del sito.
