# Dimensioni pagina
{: #page-size}

Usa **Dimensioni pagina** per impostare le dimensioni del foglio per tutti i fogli.

<img src="/v4/images/media/image4.png" alt="The page size dialog" />

## Cosa puoi modificare
{: #what-you-can-change}

- **Formato carta**: scegli un formato standard, ad esempio A4.
- **Orientamento**: seleziona **Verticale** per una pagina più alta o **Orizzontale** per una pagina più larga.
- **Larghezza** e **Altezza**: inserisci le dimensioni personalizzate della pagina in millimetri.

Quando scegli un formato carta standard, TinyCAD inserisce automaticamente la larghezza e l'altezza.
Se modifichi l'orientamento, le due dimensioni vengono scambiate.

## Utilizzo tipico
{: #typical-use}

Usa le dimensioni della pagina in base al tipo di output desiderato:

- scegli un formato standard per la stampa o l'esportazione in PDF
- usa l'orientamento orizzontale per gli schemi più larghi
- imposta una larghezza e un'altezza personalizzate quando un formato carta standard non è adatto al disegno

Le dimensioni della pagina selezionate vengono salvate con il foglio come parte del disegno.
