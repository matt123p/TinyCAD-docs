# Cartelle delle librerie
{: #library-folders}

## Panoramica
{: #overview}

Il pannello Le mie librerie supporta le cartelle, così puoi organizzare le librerie installate in gruppi.


<div class="manual-tabset" data-tabset="product-mode" data-tabset-label="Choose your TinyCAD product" data-default-tab="Browser" markdown="1">

### Browser
{: #browser}

Le cartelle delle librerie non sono supportate nella versione Browser di TinyCAD.

### App desktop
{: #desktop-app}

Le cartelle vengono salvate insieme all'elenco delle librerie, quindi la struttura viene mantenuta alla successiva apertura di TinyCAD.

Le cartelle delle librerie sono disponibili solo nell'app desktop.

Le modalità basate su browser continuano a mostrare Le mie librerie, ove supportato, ma non consentono di creare cartelle, raggrupparle o trascinarle.

#### Operazioni disponibili
{: #what-you-can-do}

- Creare cartelle per raggruppare librerie correlate
- Rinominare le cartelle
- Eliminare le cartelle
- Riordinare le cartelle tramite trascinamento
- Spostare le librerie tra le cartelle tramite trascinamento
- Aggiungere più file di libreria esistenti in un'unica operazione
- Aggiungere librerie direttamente alla cartella attualmente selezionata

Le librerie non assegnate a una cartella vengono visualizzate nella sezione Senza categoria.

#### Creare una cartella
{: #create-a-folder}

1. Apri il pannello Librerie.
2. Passa a Le mie librerie.
3. Seleziona il pulsante della cartella nell'intestazione del pannello.
4. Inserisci un nome per la nuova cartella.

La nuova cartella appare nell'elenco delle librerie e può essere selezionata immediatamente.

#### Selezionare una cartella
{: #select-a-folder}

Fai clic sulla riga di una cartella per selezionarla.

La cartella selezionata viene usata quando aggiungi librerie esistenti.

Se fai clic su una libreria, TinyCAD seleziona automaticamente la cartella a cui appartiene. In questo modo è chiaro dove verranno inserite le librerie aggiunte.

#### Aggiungere librerie a una cartella
{: #add-libraries-to-a-folder}

1. Seleziona la cartella di destinazione in Le mie librerie.
2. Seleziona Aggiungi.
3. Scegli uno o più file di libreria esistenti.

Le librerie selezionate vengono aggiunte alla cartella selezionata.

Se non selezioni una cartella personalizzata, le librerie vengono aggiunte a Senza categoria.

#### Spostare librerie tra cartelle
{: #move-libraries-between-folders}

Trascina una libreria dalla posizione corrente e rilasciala su un'altra cartella.

Puoi anche rilasciare una libreria su Senza categoria per rimuoverla da una cartella personalizzata.

Se una cartella è vuota, TinyCAD mostra un'area di rilascio in cui puoi spostare le librerie.

#### Riordinare le cartelle
{: #reorder-folders}

Le cartelle possono essere riordinate direttamente nel pannello.

1. Passa il puntatore sulla cartella che vuoi spostare.
2. Trascina la maniglia di riordinamento.
3. Rilascia la cartella nella posizione di destinazione.

Il nuovo ordine viene salvato automaticamente.

#### Rinominare o eliminare una cartella
{: #rename-or-delete-a-folder}

I pulsanti delle azioni della cartella vengono visualizzati quando il puntatore è sulla cartella o quando questa è selezionata.

- Seleziona Modifica per rinominare la cartella.
- Seleziona Elimina per rimuovere la cartella.

Quando una cartella viene eliminata, tutte le librerie al suo interno vengono spostate in Senza categoria. I file delle librerie non vengono rimossi da TinyCAD.

#### Librerie senza categoria
{: #unfiled-libraries}

Senza categoria è la posizione predefinita per le librerie non assegnate a una cartella personalizzata.

- Le nuove librerie vengono inserite in Senza categoria se non è selezionata una cartella personalizzata
- Le librerie di una cartella eliminata vengono spostate in Senza categoria
- Puoi trascinare le librerie da Senza categoria a qualsiasi cartella personalizzata

Se non esistono cartelle personalizzate, TinyCAD mostra semplicemente l'elenco delle librerie senza un'intestazione Senza categoria.

#### Note
{: #notes}

- Le modifiche all'organizzazione delle cartelle vengono salvate insieme alla configurazione delle librerie
- È possibile aggiungere più librerie alla volta scegliendo file di libreria esistenti
- L'ordine delle cartelle e le assegnazioni delle librerie alle cartelle vengono mantenuti tra le sessioni
