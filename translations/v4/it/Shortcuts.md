# Scorciatoie
{: #shortcuts}

Usare le scorciatoie da tastiera invece di fare clic sulla barra degli strumenti velocizza il disegno.

**Nota:** sono diverse dalle scorciatoie di TinyCAD v3 perché le applicazioni web non gestiscono i tasti funzione allo stesso modo.

| Tasto | Azione |
|---|---|
| `Esc` | Annulla il posizionamento o l’azione di disegno in corso; altrimenti deseleziona |
| `W` | Strumento Filo |
| `N` | Nessuna connessione (No Connect) |
| `P` | Alimentazione |
| `L` | Etichetta |
| `T` | Testo |
| `B` | Bus |
| `S` | Forma (rettangolo/ellisse/linea) |
| `+` | Zoom avanti |
| `=` | Zoom avanti |
| `-` | Zoom indietro |
| `_` | Zoom indietro |
| Tasti freccia | Sposta gli elementi selezionati dell’intervallo della griglia quando lo snap è attivo, oppure a piccoli passi quando è disattivato; esegue una panoramica se non è selezionato nulla |
| `Ctrl` + tasti freccia | Sposta gli elementi selezionati a piccoli passi, oppure esegue una panoramica a passi più piccoli |
| `Ctrl-F` | Trova |
| `Ctrl-P` | Stampa |
| `Ctrl-C` | Copia |
| `Ctrl-X` | Taglia |
| `Ctrl-V` | Incolla |
| `Del` | Elimina |
| `Ctrl-Z` | Annulla |
| `Ctrl-Y` | Ripeti |

Il tasto Esc annulla anche la creazione quando un pulsante della barra degli strumenti è attivo. Quando si digita in un campo di testo o si usa un menu o una finestra di dialogo, completare o chiudere prima il controllo.

Alcune scorciatoie possono essere intercettate dal browser e attivare invece azioni del browser.
