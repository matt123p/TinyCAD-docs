# Istruzioni di installazione
{: #installation-instructions}

Questa pagina descrive l'installazione di TinyCAD.

## Installazione su Windows
{: #install-on-windows}

Per Windows, il metodo consigliato per installare TinyCAD v4 è tramite il
[Microsoft Store](https://apps.microsoft.com/detail/9NZQ1M56NM3V).

Se usi Windows, utilizza la versione del Microsoft Store, a meno che tu non abbia un
motivo specifico per installare il programma da un'altra fonte.

Le [release su GitHub](https://github.com/matt123p/TinyCADv4/releases) includono anche
un programma di installazione per Windows.

## Installazione su macOS
{: #install-on-macos}

Per macOS, scarica TinyCAD v4 dalle
[release su GitHub](https://github.com/matt123p/TinyCADv4/releases).
L'immagine disco di macOS (`.dmg`) è compilata per Apple Silicon (ARM64).

## Installazione su Linux
{: #install-on-linux}

TinyCAD è disponibile tramite lo [Snap Store](https://snapcraft.io/tinycad) per
le principali distribuzioni Linux compatibili con Snap, tra cui Ubuntu, Kubuntu, KDE Neon, Pop!_OS, elementary OS,
Debian, Fedora, openSUSE, Manjaro, Arch Linux, CentOS e Red Hat Enterprise
Linux.

Su Ubuntu e molte distribuzioni basate su Ubuntu, il supporto a Snap è già presente.
In tal caso puoi installare TinyCAD direttamente con:

```bash
sudo snap install tinycad
```
Se non funziona, la pagina di TinyCAD sullo [Snap Store](https://snapcraft.io/tinycad) contiene
collegamenti alle istruzioni di configurazione specifiche per ciascuna distribuzione Linux supportata.

Le [release su GitHub](https://github.com/matt123p/TinyCADv4/releases) includono anche pacchetti Linux `.deb` per x64 e ARM64. Il pacchetto Snap è compilato per
x64. I pacchetti Linux per ARMv7 (ARM a 32 bit) non sono più forniti perché l'attuale
runtime Electron non supporta tale architettura.

## Utilizzo su ChromeOS e Chromebook
{: #use-on-chromeos-and-chromebooks}

Su ChromeOS utilizza [TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/)
anziché installare l'applicazione desktop.
