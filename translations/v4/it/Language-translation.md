# Traduzione della lingua
{: #language-translation}

È possibile impostare TinyCAD in diverse lingue dell'interfaccia.

## Lingue disponibili
{: #available-languages}

Le lingue attualmente disponibili sono:

| Codice | Lingua |
|---|---|
| `en` | Inglese |
| `nl` | Olandese |
| `fr` | Francese |
| `es` | Spagnolo |
| `de` | Tedesco |
| `it` | Italiano |
| `ja` | Giapponese |
| `pl` | Polacco |
| `zh-CN` | Cinese (semplificato) |

## Qualità delle traduzioni e feedback
{: #translation-quality-and-feedback}

Queste traduzioni sono curate dall'IA.

Se noti formulazioni poco naturali, termini tecnici errati o testo non tradotto,
il tuo feedback è molto gradito. Sono benvenuti anche suggerimenti per aggiungere
altre lingue di traduzione.
