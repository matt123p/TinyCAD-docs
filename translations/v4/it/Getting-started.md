# TinyCAD - Guida introduttiva
{: #tinycad---getting-started}

TinyCAD v4 è disponibile in due modalità:

## App desktop
{: #desktop-app}

Potresti preferire una versione installata di TinyCAD se vuoi lavorare offline o assicurarti
di poter sempre accedere a TinyCAD.

Vai a [Istruzioni per l'installazione](../TinyCAD-Desktop-App/) per scoprire come scaricare, installare e avviare questa versione di TinyCAD.

## App online
{: #online-app}

Potresti preferire la versione online se non vuoi o non puoi installare TinyCAD, ad esempio in un contesto scolastico o lavorativo in cui non è consentito installare applicazioni.

Vai a [Avvio rapido di TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) per scoprire come
iniziare a usare TinyCAD direttamente nel browser web senza dover effettuare un'installazione.
