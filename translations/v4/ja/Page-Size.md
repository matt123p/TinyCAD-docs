# ページサイズ
{: #page-size}

**ページサイズ**を使用して、すべてのシートの用紙寸法を設定します。

<img src="/v4/images/media/image4.png" alt="The page size dialog" />

## 変更できる項目
{: #what-you-can-change}

- **用紙サイズ**: A4などの標準用紙サイズを選択します。
- **向き**: 縦長のページには**縦向き**、横長のページには**横向き**を選択します。
- **幅**と**高さ**: カスタムページサイズをミリメートル単位で入力します。

標準用紙サイズを選択すると、TinyCADが幅と高さを自動的に入力します。
向きを変更すると、これらの寸法が入れ替わります。

## 一般的な使い方
{: #typical-use}

目的の出力形式に合わせてページサイズを設定します:

- 印刷またはPDF出力には標準サイズを選択します
- 横幅の広い回路図には横向きを使用します
- 標準用紙サイズでは図面に合わない場合は、幅と高さをカスタム設定します

選択したページサイズは、図面の一部としてシートに保存されます。
