# TinyCAD Web クイックスタート
{: #tinycad-web-quick-start}

## Web 版 TinyCAD
{: #tinycad-for-the-web}

Web 版 TinyCAD はブラウザー上で直接動作し、インストールは不要です。
互換性のあるブラウザーをサポートするオペレーティングシステムで利用できます。ファイル
形式はデスクトップ版 TinyCAD（`.dsn` の図面と `.tclib`
ライブラリ）と互換性があります。

## 始める前に
{: #before-you-start}

以下が必要です。

- Chrome または Edge（ローカルファイルモードの場合）
- Google Drive モードでは Chrome を推奨します。Firefox も利用できる場合があります
- 利用規約をお読みください：[利用規約](https://www.tinycad.net/TCs)

Windows、Mac、Chromebook、Linux での動作を想定しています。

## 利用開始リンク
{: #entry-points}

- ローカルファイルモード：<https://online.tinycad.net/fs>
- Google Drive モード：<https://online.tinycad.net/ga>
- サポート：<https://discord.gg/bdXnjhrSYQ>

## はじめに（図面をローカルコンピューターに保存）
{: #getting-started-saving-drawings-on-local-computer}

このモードでは、最新の Chrome または Edge で利用できるブラウザー機能を使用します。
いずれかのブラウザーを最新バージョンに更新してから、次を開いてください。

- <https://online.tinycad.net/fs>

## はじめに（図面を Google Drive に保存）
{: #getting-started-saving-drawings-on-google-drive}

始める前に、Google アカウントが必要です。

初回セットアップ：

1. <https://online.tinycad.net/ga> にアクセスします。
2. 広告ブロッカーを使用している場合は、このサイトで無効にしてください（Google のログイン処理に
   干渉することがあります）。
3. ポップアップが表示されない場合は、ポップアップのブロックが有効になっていないか確認し、このサイトの
   ポップアップを許可してください。
4. ポップアップで Google アカウントにログインします（必要な場合）。
5. Google Drive との完全な連携を許可するため、**すべて**の同意チェックボックスにチェックを入れます。
6. 利用規約への同意後に Google のログイン処理が失敗した場合は、ページを再読み込みして、もう一度
   試してください。

## プライバシー
{: #privacy}

### ローカルファイルモード
{: #local-file-mode}

TinyCAD はすべてブラウザー内で動作し、作業内容をブラウザー内にローカル保存します。
作業内容やその他のファイルが TinyCAD のサーバーに送信されることはありません。

### Google Drive モード
{: #google-drive-mode}

図面は Google Drive に保存されます。初めて使用する際は、連携を有効にするため、
TinyCAD に Google ファイルへのアクセスを許可する必要があります。

TinyCAD は引き続きブラウザー内で動作し、データをユーザー専用の Google Drive に書き込みます。作業内容やその他のファイルが
TinyCAD のサーバーに送信されることはありません。

TinyCAD は、サイトの利用状況を把握するために Google Analytics を使用しています。
