# 印刷とエクスポート
{: #printing-and-exporting}

<div class="manual-tabset" data-tabset="product-mode" data-tabset-label="Choose your TinyCAD product" data-default-tab="Browser" markdown="1">

### ブラウザー
{: #browser}

**ファイル** メニューから **PDFとしてエクスポート** を選択します。TinyCAD が図面を PDF として新しいタブで開きます。PDF ビューアーの印刷機能で印刷します。

<img src="/v4/Images/media/image12.png" alt="The File menu"  />


### デスクトップアプリ
{: #desktop-app}

**ファイル → 印刷** を選択して **印刷プレビュー** を開きます。左側に図面、右側に印刷設定が表示されます。

<img src="/v4/Images/desktop-print-preview.png" alt="TinyCAD Print Preview showing a drawing, printer settings and sheet selection" />

#### 直接印刷する
{: #print-directly}

1. 図面に複数のシートがある場合は、 **◀ 前へ** と **次へ ▶** でプレビューを切り替えます。最初はすべてのシートが選択されています。印刷しないシートは、 **印刷するページ** でチェックを外します。
2. **プリンター** を選択するか、 **システムの既定のプリンター** のままにします。 **用紙サイズ** 、 **向き** 、 **部数** 、 **カラーモード** 、 **両面印刷** を設定します。 **図面に合わせる** を選択すると、選択した最初のシートの向きに合わせて印刷します。
3. **印刷** を選択すると、選択したシートがプリンターに直接送られます。次回も同じ設定を使う場合は、印刷前に **印刷設定を保存** を選択します。

印刷プレビューの **用紙サイズ** は印刷ジョブに適用されます。図面のシート寸法を変更するには、 **設定** メニューの[ページサイズ](../Page-Size/)を開きます。寸法はミリメートルまたはインチで指定できます。

#### 詳細印刷
{: #advanced-print}

**詳細印刷…** を選択すると、選択したシートを図面の寸法で PDF に変換します。Windows と macOS では、TinyCAD が既定の PDF ビューアーでファイルを開きます。ビューアーの印刷機能でプリンターや追加のオプションを選びます。Linux では、TinyCAD が PDF を開き、システムの印刷ダイアログを表示します。ダイアログをキャンセルしても PDF は開いたままです。

プリンターが見つからない場合も **詳細印刷…** を選べます。後で使う PDF を保存するには、 **ファイル → Export → PDFとしてエクスポート** を選択します。

## SVGエクスポート
{: #svg-export}

SVGにエクスポートすることもできます。SVGは文書やWebページへの埋め込みに便利です。
注記:

- SVGエクスポートには現在のシートのみが含まれます（単ページ形式）
- 無料のSVG-DXF変換ツールがオンラインで利用できます
- 印刷またはエクスポートの前にシート寸法を調整する必要がある場合は、[ページサイズ](../Page-Size/)を参照してください。
- 出力にタイトルブロックの詳細を含める場合は、[設計詳細ボックス](../Design-Details-box/)を参照してください。
- 設計で複数のシートを使用する場合は、[複数シートの図面](../Multiple-Sheet-Drawings/)を参照してください。
