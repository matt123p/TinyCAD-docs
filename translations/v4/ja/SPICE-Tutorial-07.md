# 7. AMP.DSNの再構築とバイアスの確認
{: #rebuilding-ampdsn-and-checking-its-bias}

[前へ](/v4/SPICE-Tutorial-06/) · [目次](/v4/Simulation-Tutorials/) · [次へ](/v4/SPICE-Tutorial-08/)

この章の例はTinyCADに同梱されています。**Open Example → SPICE tutorial**を選び、名前の付いた例を選択してから、**Open Drawing**を選びます。ダウンロードは不要です。

**amp-bias**を開きます。これは、
`D:\Projects\TinyCAD\examples\AMP.DSN`のトポロジーを再構築したものです。タイトルは**Transistor Amplifier**で、原版ではMatt Pyne、1995年と記されています。TinyCADの
SPICE essentialsライブラリの部品と、設定可能なシミュレーション用電源を使用しています。

![シミュレーション用部品を使って再構築したAMP.DSN](/v4/images/simulation-tutorials/spice/amp-bias-circuit.png)

## 元の回路で維持したものとモデル化したもの
{: #what-was-preserved-and-what-was-modelled}

| 元の部品 | 再構築した部品と役割 |
| --- | --- |
| R1、470 Ω、0.5 Wの注記 | Q2のエミッタ抵抗470 Ω。定格はシミュレーション上の熱的制限ではありません |
| R2、1 kΩ | Q1のコレクタ抵抗 |
| R3、100 kΩ、R4、10 kΩ | Q1のベースバイアス分圧回路 |
| R5、220 Ω | Q1のエミッタ縮退抵抗 |
| R6、10 kΩの対数ポテンショメータ | 10 kΩポテンショメータ、電気的な分割 `Wiper = 0.5` |
| C1、100 µF、C2、470 µF | 理想的な入力および出力結合コンデンサ |
| Q1、ZTX650、Q2、BC140 | どちらも埋め込みの汎用`TC_NPN`モデルを使用 |
| J1フォノ入力 | ノード0を基準とする設定可能な電源VIN |
| T1、8 Ωスピーカー | RL = 8 Ω、抵抗性の電気負荷 |
| 12 V / 0 V電源レール | 独立した12 V電源VCCとSPICEノード0 |

元の対数特性を持つ機械式テーパーでは、ノブの位置ごとに抵抗が一意に
分割されるわけではありません。ここでの0.5は**電気的に**5 kΩ/5 kΩに分割する
ことを意味し、元のノブが中間位置にあるという意味ではありません。電源VINの
出力抵抗は理想的です。スピーカーのモデルではインダクタンス、共振、および音響
効率を省略しているため、音圧の予測はできません。

両方のトランジスタ・インスタンスには、ライブラリモデルが埋め込まれています。

```spice
.model TC_NPN NPN(Is=1e-14 Bf=200 Vaf=100 Cje=10p Cjc=5p Tf=500p)
```

これらは説明用のモデルパラメータであり、ZTX650または
BC140のメーカー製モデルではありません。これらを使うのは意図的であり、部品のSPICEプロパティで確認できます。
元のデバイスの性能を正確に得るには、検証済みのデバイスモデルに加えて、ハードウェアとの比較では寄生成分と熱に関する情報が必要です。

## 2つの段を理解する
{: #understand-the-two-stages}

Q1はエミッタ接地段です。コレクタ電流が増えるとコレクタ電圧が低下するため、信号を反転します。R5はエミッタ縮退をもたらします。負帰還により利得の感度が低下し、直線性が向上します。R2は電流の変化をコレクタ電圧の変化に変換します。

Q2はエミッタ・フォロワです。コレクタはVCCに接続され、エミッタはR1と、C2を介してスピーカー負荷を駆動します。さらに大きな電圧利得を得るのではなく、電流駆動を行います。C1とC2は、段間および外部接続との間で直流動作レベルを分離します。

## 信号を加える前にOperating Pointを実行する
{: #run-operating-point-before-applying-a-signal}

27°Cでの基準値は次のとおりです。

| 量 | 基準値 |
| --- | --- |
| BASE、Q1ベース | 1.0235 V |
| Q1エミッタ、Q1とR5の間 | 0.3582 V |
| COLLECTOR、Q1コレクタ / Q2ベース | 10.2800 V |
| EMITTER、Q2エミッタ | 9.5476 V |
| OUT、C2の後 | 0 V |
| VCCから供給される電流 | 22.044 mA |
| 電源電力 | 264.533 mW |

C2がエミッタの直流電圧を遮断し、RLが出力をグラウンドに戻すため、OUTの直流電圧はゼロです。したがって、出力バイアスがゼロでも、アンプに電力が供給されていないという意味ではありません。Q1のエミッタ電流はおよそ`0.3582 / 220 = 1.628 mA`です。
Q2の静止時のエミッタ抵抗電流は`9.5476 / 470 = 20.31 mA`です。

出力段のバイアスは12 V電源レールに対して高く、8 Ωに対する静止電流は控えめです。このことから、信号振幅の上下限が非対称になることがすでに示唆されます。
次の2章では、アンプと呼ばれる回路なら電圧利得が大きい、あるいは音声出力が大きいと決めつけずに、この予測を検証します。
