# KiCADからのシンボルのインポート
{: #importing-symbols-from-kicad}

KiCADのシンボルライブラリからシンボルをインポートする機能は、TinyCAD v4の新機能です。

## KiCadの概要
{: #kicad-background}

[KiCad](https://www.kicad.org/)は、人気の高いオープンソースの電子設計スイートです。そのシンボルエディターは、シンボルライブラリファイルに回路図シンボルを保存します。現在のKiCadリリースでは、これらのシンボルライブラリは通常、最新のS式ベースの`.kicad_sym`形式を使用します。

## TinyCADでインポートできるもの
{: #what-tinycad-can-import}

TinyCADは現在、次のファイルからシンボルをインポートできます:

- `.kicad_sym`ファイル

ファイルは、`kicad_symbol_lib`をルートとするKiCadシンボルライブラリファイルである必要があります。実際には、次のことを意味します:

- 対応: `.kicad_sym`形式で保存された最新のKiCadシンボルライブラリ
- 非対応: 従来のKiCad `.lib`シンボルライブラリ
- 非対応: KiCadのフットプリント、PCBファイル、プロジェクト、回路図、その他のシンボル以外のファイル

## UIでのコマンドの場所
{: #where-the-command-is-in-the-ui}

インポートコマンドの名前は  **Import KiCad Symbols（KiCadシンボルのインポート）**  です。

TinyCADの実行方法によって、次のいずれかの場所にあります:

- デスクトップアプリ（Electron）： **ファイル（File） > インポート（Import） > KiCad Symbols...** 
- ブラウザー／ファイルシステムモード：ツールバーの  **ファイル（File）**  メニューから  **KiCad Symbols のインポート（Import KiCad Symbols）** 

`.kicad_sym` ファイルを選択すると、TinyCAD はそのライブラリ内のすべてのシンボルを読み込み、編集中の対象に応じて2種類のインポートダイアログのいずれかを表示します。

## 2つのインポートモード
{: #two-import-modes}

デザインを編集中かライブラリを編集中かによって、インポートの動作は異なります。

### デザインへのインポート
{: #import-into-a-design}

TinyCAD ライブラリに保存することなく、KiCad のシンボルを現在の回路図に配置する場合に使用します。

動作：

- TinyCAD は  **シンボルのインポート（Import Symbol）**  ダイアログを開きます。
- 選択した `.kicad_sym` ファイルからシンボルを1つ選択できます。
-  **挿入（Insert）**  をクリックすると、TinyCAD はそのシンボルを現在の図面に直接挿入します。
- シンボルは現在のマウス位置に挿入されます。
- この操作では  **追加されません** ：外部の `.tclib` ライブラリにシンボルを追加する操作ではありません。

現在のデザインでシンボルが必要なだけの場合は、これが最も手早い方法です。

### ライブラリへのインポート
{: #import-into-a-library}

インポートした KiCad シンボルを再利用可能な TinyCAD ライブラリシンボルとして保存する場合に使用します。

動作：

- 編集するには、まずTinyCADライブラリを開く必要があります。
- TinyCADで **KiCadシンボルのインポート（Import KiCad Symbols）** ダイアログが開きます。
- インポートするすべてのシンボルがあらかじめ選択されています。
- シンボルの選択／選択解除や、 **すべて選択（Select all）** を使用できます。
-  **選択項目をインポート（Import selected）** をクリックすると、それらのシンボルが現在のTinyCADライブラリに統合されます。
- TinyCADでは、最後にインポートしたシンボルがライブラリエディターで自動的に開きます。
- その後、通常どおりライブラリを保存します。

インポートしたシンボルを複数の図面で再利用する場合は、この方法が適しています。

## 手順：デザインにインポート
{: #step-by-step-import-into-a-design}

1. 作業する回路図デザインを開きます。
2. ファイルメニューから **KiCadシンボルのインポート（Import KiCad Symbols）** を実行します。
3. KiCad `.kicad_sym`ファイルを選択します。
4.  **シンボルのインポート（Import Symbol）** ダイアログで、必要なシンボルをクリックします。
5. 各シンボルについて表示される小さなメタデータ行を確認します。
   - `U?`などのリファレンス接頭辞
   - ユニット分割されたシンボルの場合は、ユニット数
6.  **挿入（Insert）** をクリックします。
7. シンボルが、現在のマウス位置にある現在の図面へ配置されます。
8. 必要に応じて、インポート後にテキスト、ピンの表示設定、または図形を調整します。

## 手順：ライブラリにインポート
{: #step-by-step-import-into-a-library}

1. 編集するTinyCADライブラリを開くか、新規作成します。
2. デスクトップアプリを使用している場合は、一般的な手順は次のとおりです。
   -  **ライブラリ（Libraries）** パネルを開く
   -  **追加（Add）** を使用して既存のライブラリを読み込むか、 **新規（New）** を使用してライブラリを作成する
   - そのライブラリを編集モードで開く
3.  **KiCadシンボルのインポート（Import KiCad Symbols）** を実行します。
4. KiCad `.kicad_sym`ファイルを選択します。
5.  **KiCadシンボルのインポート（Import KiCad Symbols）** ダイアログですべてのシンボルを選択したままにするか、不要なシンボルの選択を解除します。
6.  **選択項目をインポート（Import selected）** をクリックします。
7. ライブラリエディターでインポートされたシンボルを確認します。
8. ライブラリを保存します。

## 対応しているシンボル機能
{: #supported-symbol-features}

TinyCADは現在、KiCadの次のシンボル機能をインポートします。

- シンボル名、リファレンス接頭辞、説明
- TinyCADの属性としての追加シンボルプロパティ
- ValueやReferenceなど、一般的なフィールドの表示／非表示状態
- ピン名、ピン番号、ピン長、電気的タイプ、複数のピン形状を含むピン
- ユニット分割されたシンボル
- KiCadの`extends`機構を使用する継承シンボル
- De Morgan形式のバリエーション。名前に` (De Morgan)`を追加した別シンボルとしてインポートされます
- シンボル本体で使用される基本的な図形：
  - 長方形
  - 円
  - ポリライン
  - 円弧
  - ベジェ曲線
  - テキスト
- TinyCADに相当する機能がある場合の、基本的な線種と塗りつぶし状態

## 正しく動作しない、または完全には一致しない機能
{: #what-will-not-work-or-may-not-match-exactly}

このインポーターは便利ですが、KiCadからTinyCADへの完全な変換エンジンではありません。現在の実装で確認できる主な制限を以下に示します。

### ファイル形式の制限
{: #file-format-limits}

- `.kicad_sym`ファイルのみが受け付けられます。
- ファイルが空、形式が不正、またはKiCadシンボルライブラリでない場合、インポートは失敗します。

### グラフィックとレイアウトの制限
{: #graphics-and-layout-limits}

- 上記に記載された図形プリミティブのみがインポートされます。
- 対応するプリミティブ以外のKiCadシンボルの内容はすべて無視されます。
- インポートされたライブラリシンボルは、余白を設けてTinyCADのページ上に配置され、TinyCADのグリッドに揃うように調整されます。
- KiCadとTinyCADでは内部の描画モデルが異なるため、一部の図形はわずかに異なって見える場合があります。
- KiCadの円弧は、TinyCADの曲線ポイントに近似されます。

### テキストとスタイルの制限
{: #text-and-styling-limits}

- フォントファミリーは保持されません。インポートされたテキストにはTinyCADのフォント設定が使用されます。
- 配置などの細かなテキストレイアウトの詳細は、完全には保持されません。
- テキストの回転は、任意の角度をすべて保持するのではなく、TinyCADのより単純な方向モデルに変換されます。
- ピンのテキスト色は保持されません。

### シンボルの動作の違い
{: #symbol-behavior-differences}

- デザインにインポートすると、シンボルは現在の図面にのみ挿入されます。再利用可能な`.tclib`ライブラリエントリは作成も更新もされません。
- ライブラリにインポートすると、再利用可能なTinyCADライブラリエントリが作成されますが、その後ライブラリを保存する必要があります。
- インポートしたシンボル名がインポート先ライブラリの既存名と競合する場合、TinyCADは数値の接尾辞を付けて新しいエントリの名前を自動変更します。
- KiCadシンボルにDe Morganバリアントが含まれている場合、TinyCADはライブスタイル切り替えとしてではなく、別個のシンボルエントリとしてインポートします。

## 実用上のアドバイス
{: #practical-advice}

- シンボルを一度だけ使う場合は、デザインにインポートしてください。
- シンボルを再利用する予定がある場合は、ライブラリにインポートしてください。
- まず小規模な`.kicad_sym`ライブラリで試し、線画、テキスト、ピンの配置がTinyCADでどのように見えるか確認してください。
- インポート後、複数ユニットの部品とDe Morganバリアントを注意深く確認してください。
- シンボルの表示に問題がある場合は、TinyCADライブラリエディタで開き、テキストの配置、線画、属性を手動で修正してください。

## まとめ
{: #summary}

TinyCADのKiCadインポート機能は、特にピン、テキスト、単純な図形プリミティブで構成された標準的な回路図シンボルなど、新しいKiCadシンボルライブラリをすばやくTinyCADに取り込むことを目的としています。`.kicad_sym`ファイルで最もよく機能し、特に次のような場合に便利です。

- シンボルを現在の図面に直接配置したい場合、または
- 選択したKiCadシンボルを再利用できるようTinyCADライブラリに移行したい場合

より高度な内容については、インポート後に少し手作業で整える必要があると考えてください。
