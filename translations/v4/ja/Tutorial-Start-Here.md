# まずはこちら：チュートリアルの使い方
{: #start-here-how-to-use-these-tutorials}

[目次](/v4/Simulation-Tutorials/) · [次へ：初めてのSPICEシミュレーション](/v4/SPICE-Tutorial-01/)

これらのチュートリアルでは、説明と、TinyCADで実行・変更できる回路を組み合わせています。
**サンプルはすでにTinyCADに同梱されています。** レッスンを進めるために、チュートリアルZIPをダウンロードしたり、ディスク上の図面を探したり、別のSPICEプログラムをインストールしたりする必要はありません。

シミュレーションが初めてなら、SPICEコースから始めてください。電圧、電流、簡単な回路から始まり、波形、フィルター、増幅器、設計の検討へと進みます。別コースのXSPICEでは、イベント駆動型ロジックとミックスドシグナルシミュレーションを扱います。このコースでは**TinyCAD Desktop**を使用してください。ブラウザーエンジンにはXSPICEが含まれていません。

## 同梱の例を探して開く
{: #find-and-open-the-bundled-examples}

1. TinyCAD を開き、ブラウザーのタイトルバー右側にある **Open Example**、またはデスクトップの **File → Open Example** を探します。フォルダーを開くアイコンが目印です。これにより、サンプルブラウザーが開きます。
2. アナログのレッスンには **SPICE tutorial**、デジタルのレッスンには **XSPICE and digital tutorial** を選択します。これらのグループは、ブラウザーのナビゲーション領域にも表示されます。
3. グループの **Drawings** リストから、レッスンで指定されているサンプルを選択します。最初に試すときは、**SPICE tutorial** 内の **divider** を選択します。
4. 説明を読み、回路のプレビューを確認します。サンプルを選択すると詳細が表示されますが、この時点ではまだ図面は置き換わりません。
5. ブラウザー下部の **Open drawing** を選択します。TinyCAD でサンプルの編集可能なコピーが開きます。保存していない作業がある場合は、続行する前に保存の確認に対応してください。

短い指示 **例を開く（Open Example）→ SPICEチュートリアル（SPICE tutorial）→ divider → 図面を開く（Open drawing）** は、これらと同じ手順を意味します。**divider**、**rc-ac**、**logic-counter**のような名前は、このブラウザー内での例の名前であり、探す必要のあるファイル名ではありません。

名前を指定して例を探すには、**グループと例を検索 (Search groups and examples)** を使用します。フィルターによって必要な項目が表示されない場合は、検索をクリアし、**すべてのグループ (All groups)** を使用してグループ一覧に戻ります。例を選択すると、**図面を開く (Open drawing)** が使用可能になります。
**ここから開始 — チュートリアルの使い方 (Start here — using the tutorials)** の項目でもこのガイドが表示され、同じ最初の分圧回路が開きます。

[dividerを開き、実行し、変更する](/v4/videos/simulation-tutorials/spice/first-run.mp4)の字幕付き解説動画で、これらの手順と最初の2つの取得データをご覧ください。

## 回路と並べてレッスンを進める
{: #follow-a-lesson-alongside-its-circuit}

TinyCADで作業している間は、マニュアルまたはMarkdownビューアーで章を開いたままにしてください。例のブラウザーにも、対応するレッスンの説明が表示されます。各章の冒頭には、使用する埋め込み例が記載されています。章によっては複数の例を使用します。たとえば信号発生器の章には、波形を一度に1つずつ調べられるよう、個別のソース例が用意されています。

実験ごとに、次の手順で進めます。

1. **質問を読む。** 調べる対象を特定します。DC電圧、充電時間、カットオフ周波数、論理状態、またはその他の量です。
2. **回路を確認する。** 電源、グラウンド、部品値、名前付き信号を探します。INやOUTなどのラベルは電気的なノードを示し、R1やC1などの参照記号は部品を示します。
3. **保存済みの設定を確認する。** **Simulation**シートを選択し、**Setup**を確認します。各例には、レッスンに必要な解析設定とモデルがすでに含まれています。
4. **結果を予測する。** 章の説明や式を使って予測します。
5. **Runを選択する。** 次に、新しい測定結果を予想値やプロットと比較します。トレースの形だけでなく、数値も確認してください。
6. **レッスンの指示に従って1つ変更する。** その影響を予測して、もう一度実行します。変更した設定と結果を記録してください。

例を開いた後、ブラウザーのタイトルバーで **Explanation（説明）** を選択するか、デスクトップ版で **View（表示） → View Explanation（説明を表示）** を選択すると、図の横に説明を表示できます。説明パネルはシミュレーションチャートの横に表示され、サイズを変更したり、個別に閉じたりできます。ブラウザーのタイトルバーで **Explanation（説明）** を再度選択するか、デスクトップ版で **View（表示） → View Explanation（説明を表示）** を選択すると、再び開けます。

ツールバーのパルス形のアイコンには、マウスを合わせると **Simulation** と表示されます。レッスンに **Simulation → Show charts** または **Simulation → SPICE components** とある場合は、そのアイコンのメニューを開きます。**Simulation sheet** は、図面内の独立したタブで、実験の設定と結果のビューが含まれています。

![最初のdivider回路とシミュレーションチャートパネルを表示したTinyCAD](/v4/Images/simulation-tutorials/spice/tinycad-first-run.png)

このアプリケーションのスクリーンショットには、開いたdividerと、回路の下のシートタブ、右側のチャートパネルが表示されています。主な出発点は、回路、Simulationシート、**Run**です。

## 予想される出力を理解する
{: #understand-the-expected-outputs}

回路図は、確認する配置と接続を示します。結果プロットは、ソルバーで計算された参照データを示します。アプリケーションのスクリーンショットは、TinyCAD内で作業する場所を示します。ウィンドウサイズ、ズーム、チャートの色は異なる場合があります。回路の値、信号、単位、解析設定を比較してください。

変更していない**divider**の例では、ソースは5 V、両方の抵抗は1 kΩです。動作点解析を実行すると、IN = **5 V**、OUT = **2.5 V**、ソース電流`v1#branch` = **−2.5 mA**が予想されます。動作点では信号ごとに値が1つだけなので、時間とともに変化する波形は生成されません。最初のレッスンでは、電流の符号と分圧の計算を説明します。

図面には保持された参照取得データが含まれているため、**Run**を押す前から結果が表示されていることがあります。これは以前の実行で保存された結果です。回路や設定を編集した後は再実行し、新しい取得データを確認してください。数値の小さな差は正常です。大きな差がある場合は、部品値、モデルの前提、単位、測定ウィンドウを確認してください。

## 実験を保存し、元の状態に戻す
{: #keep-experiments-and-return-to-the-original}

埋め込みのサンプルは編集可能なコピーとして開きます。**名前を付けて保存 (Save As)** を使って、下側の抵抗値を変えた分圧回路など、わかりやすい名前で作業内容を保存してください。
コピーを保存しても、同梱されている元のファイルは変更されません。

実験をリセットするには、**Open Example** から名前付きの例をもう一度開きます。
確認が表示されたら、残しておきたい変更を保存します。これにより、例の
元の回路、設定、および保存済みの参照結果が復元されます。章で別の例に移る場合も、
同じ手順を使用します。

通常の保存では、取得した結果を図面とともに保持できます。**結果を含めずに保存**すると、回路と設定は保持されますが、保存済みの結果は省略されます。次回結果が必要になったときに、シミュレーションを再実行してください。

## 現在のCircuit Explorerコントロール
{: #current-circuit-explorer-controls}

Simulationシートを選択し、**Setup**を開いて**Circuit Explorer**までスクロールします。**Add tools**を使って、Measurements、Tune / sweep、Requirements、DC overlay、またはAnalysis labを追加します。設定したツールは左側に表示され、チャートパネルは独立したビューのままです。Simulationシートを選択すると、メインツールバーに**Run**と**Stop**が表示されます。最新のリファレンスについては、[Charts, measurements and Circuit Explorer](/v4/Simulation-Charts-and-Measurements/)をご覧ください。
