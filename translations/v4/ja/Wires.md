# 配線
{: #wires}

配線は、TinyCADの回路図における電気的に有効な接続です。

DRC、ネットリスト作成、SPICE/PCBへのエクスポート、またはシート間の
リンクに接続性が必要な場合は、（注釈線ではなく）配線オブジェクトを使用してください。

## 配線が重要な理由
{: #why-wires-matter}

- 配線は電気的なネットを定義します。
- 配線はシンボルのピンや、その他の有効な接続点にスナップします。
- TinyCADは、ルールチェックや生成される出力に配線の接続性を使用します。

配線の代わりに注釈線を使うと、見た目は正しくても、ツール上では
回路が電気的に接続されません。

## 配線モード
{: #wire-routing-modes}
{: #wire-routing-modes}

TinyCAD v4.0.11では、Wireの横にあるセレクターで、新しいセグメントの描画方法を選択します。

| モード | 動作 |
|---|---|
| **90°** | 水平方向および垂直方向に配線します。 |
| **45°** | TinyCADの45°方向に制約された配線です。 |
| **Free** | 任意の角度で直線セグメントを描画します。 |

モードを選択するとWireが有効になり、作成中の配線プレビューがあればそのまま維持されます。次のセグメントを配置する前にモードを変更できます。グリッドへのスナップは別の設定です。2つの接続点間を自動配線するには、隣にある[Point-to-Point Wireツール](#auto-routing)を使用します。

![90°、45°、Freeの選択肢を表示するWireツールバーのセレクター。](../images/wire-routing-modes.png)

## 配線の配置
{: #placing-wires}
{: #placing-wires}

1. Wireツールを選択します。
2. 有効な接続点をクリックして配線を開始します。ただし、これは必須ではありません。どこにでも配線を配置できます。赤い円が表示されれば、その接続点は有効です。
3. 必要に応じてクリックし、角やセグメントを配置します。
4. 別の有効な接続点で終了するか、または
5. 右クリックして配線モードを終了します。

## Point-to-Point Wireによる自動配線
{: #auto-routing-with-point-to-point-wire}
{: #auto-routing}

**Point-to-Point Wire**は、2つの接続点間の経路を選び、配線セグメントを
自動的に配置します。日常的なマウス操作に便利で、特にタッチスクリーンでは、すべての角を配置するよりも2つの端点をタップする方が簡単です。

1. ツールバーのWireモードセレクターの横にある**Point-to-Point Wire**を選択します。
2. 始点となるシンボルのピンまたは既存の配線をクリックまたはタップします。有効な接続点には赤い円が表示されます。
3. 終点となるピンまたは配線に移動して、自動配線のプレビューを表示します。
4. 終点をクリックまたはタップして、接続全体を配置します。TinyCADは新しい配線セグメントを選択し、配線ツールを終了します。別の接続を作成するには、もう一度**Point-to-Point
   Wire**を選択します。

通常のWireツールとは異なり、両方の端点が有効な接続点である必要があります。空白部分をクリックしても角は配置されません。右クリックすると、未完了の経路をキャンセルできます。角を自分で選びたい場合は、[Wire](#placing-wires)を使用します。

[自動配線のサンプル図面](../examples/Auto-route%20example.dsn)で試せます。抵抗と LED はグリッド上に配置されており、その間の接続だけが未配線です。

まず Point-to-Point Wire を選択し、R1 の右側のピンを始点に指定します。

![1. R1 と D1 の間が未接続の状態から始めます。赤い円が R1 の始点ピンを示します。](../images/wire-auto-route-start.png){: width="435" style="max-width: 50%;"}

次に D1 の上側のピンを指します。確定する前に、経路と曲がり角をプレビューで確認できます。

![2. D1 までの自動配線経路をプレビューします。赤い円が終点のピンを示します。](../images/wire-auto-route.png){: width="435" style="max-width: 50%;"}

最後に D1 のピンをクリックまたはタップします。TinyCAD がすべての区間を一度に配置します。

![3. 終点を確定すると、曲がり角を含む接続全体が配置されます。](../images/wire-auto-route-complete.png){: width="435" style="max-width: 50%;"}

タッチスクリーンでは、2つの端点を直接タップできます。小さなピンや密集したピンの場合は、[ルーペ](../Touch-controls/#precise-placement-with-the-loupe)を使い、各端点に照準を合わせて**クリック**を押します。経路に沿ってドラッグしたり、角をタップしたりする必要はありません。接続が完了したら確認し、必要に応じてセグメントを調整してください。

## スナップと接合点
{: #snapping-and-junctions}

- 配線はピンや既存の配線に吸着します。
- 必要な箇所には接合点が自動的に追加されます。
- 接合点がない交差配線は接続されません。

## 配線の編集
{: #editing-wires}

配線を編集するには、その配線をクリックするだけです。配線自体をドラッグすると配線セグメント全体を移動でき、移動ボックスをドラッグすると配線の端点を移動できます。
