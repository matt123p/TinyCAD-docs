# 配線
{: #wires}

配線は、TinyCADの回路図における電気的に有効な接続です。

DRC、ネットリストの生成、SPICE/PCBへのエクスポート、またはシート間の
リンクに接続性が必要な場合は、注釈線ではなく配線オブジェクトを使用してください。

## 配線が重要な理由
{: #why-wires-matter}

- 配線によって電気的なネットが定義されます。
- 配線は、シンボルのピンやその他の有効な接続点にスナップします。
- TinyCADは、ルールチェックと生成出力に配線の接続性を使用します。

注釈線を配線の代わりに使うと、見た目は正しくても、ツール上では
回路が電気的に接続されていない状態になります。

## 配線の描画モード
{: #wire-routing-modes}

TinyCAD v4.0.11では、配線（Wire）の隣のセレクターで新しい線分の描画方法を選択できます。

| モード | 動作 |
|---|---|
| **90°** | 水平および垂直方向に配線します。 |
| **45°** | TinyCADの45°刻みの方向に制限して配線します。 |
| **自由（Free）** | 任意の角度の直線を描画します。 |

モードを選択すると配線ツールが有効になり、作成中の配線プレビューは保持されます。次の線分を配置する前にモードを変更できます。グリッドへのスナップは別の設定です。隣にあるポイントツーポイント配線ツールは、このセレクターとは独立しています。

![90°、45°、自由（Free）の選択肢を表示した配線ツールバーのセレクター。](../images/wire-routing-modes.png)

## 配線の配置
{: #placing-wires}

1. Wireツールを選択します。
2. 有効な接続点をクリックして開始します（必須ではありません）。配線はどこにでも配置できます。接続点が有効かどうかは、赤い円で接続が示されるかどうかで確認できます。
3. 必要に応じてクリックし、角やセグメントを配置します。
4. 別の有効な接続点で終了する、または
5. 右クリックして配線モードを終了します。

## スナップと接合点
{: #snapping-and-junctions}

- 配線はピンや既存の配線に吸着します。
- 必要に応じて接合点が自動的に追加されます。
- 接合点がない場合、交差する配線は接続されません。

## 配線の編集
{: #editing-wires}

配線を編集するには、配線をクリックします。配線自体をドラッグしてセグメント全体を移動するか、移動ボックスをドラッグして配線の端点を移動できます。
