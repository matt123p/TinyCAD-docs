# 図形
{: #shapes}

TinyCADは、電気的な接続を伴わないグラフィック要素を描画するための一般的な図形ツールをサポートしています。

- 長方形
- 円と楕円
- 多角形
- 線

これらを使ってブロックをまとめたり、領域を強調したり、回路の接続を変更せずに説明用の注記を追加したりできます。

## 線と多角形の描画
{: #drawing-lines--polygons}

一連の線を描画できます。描画を終了するには、右クリックします。

コンテキストメニューで「多角形を閉じる（Close Polygon）」を選択すると、これを多角形に変換できます。多角形に変換した後は、塗りつぶしを変更できます。
