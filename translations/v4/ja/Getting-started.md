# TinyCAD - はじめに
{: #tinycad---getting-started}

TinyCAD v4 は、次の2つの方法で利用できます。

## デスクトップアプリ
{: #desktop-app}

オフラインで作業する場合や、いつでもTinyCADを利用できるようにしたい場合は、インストール版がおすすめです。

このバージョンのTinyCADのダウンロード、インストール、起動方法については、[インストール手順](../TinyCAD-Desktop-App/)をご覧ください。

## オンラインアプリ
{: #online-app}

TinyCADをインストールしたくない、またはインストールできない場合は、オンライン版がおすすめです。たとえば、アプリケーションのインストールが許可されていない教育機関や職場での利用に適しています。

インストールせずにウェブブラウザーから直接TinyCADを使い始める方法については、[TinyCAD Web クイックスタート](../TinyCAD-Web-overview-and-quick-start/)をご覧ください。

## 用意されている回路図を試す
{: #explore-a-ready-made-drawing}

[同梱のサンプル](../Bundled-Examples/)を使って、ネットワーク、センサーステーション、オーディオ構成、実験室の作業台、モーター制御プロジェクトを試してみましょう。「Exampleを開く」はブラウザーのタイトルバー、またはデスクトップ版の「ファイル」メニューにあります。

[同梱ライブラリ](../Bundled-Libraries/)は左側の**Standard**の下にあります。コレクションを選び、検索して、プレビューを回路図にドラッグします。

回路の動作を計算するには、まず[シミュレーションとSPICE](../Simulation/)をご覧いただくか、[SPICEチュートリアル](../SPICE-Tutorial/)を最初から最後までお読みください。統合エンジンは両方の製品に含まれています。別途用意されている[XSPICEデジタルコース](../XSPICE-Tutorial/)には、デスクトップ版をお使いください。
