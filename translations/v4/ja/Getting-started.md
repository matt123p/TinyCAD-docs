# TinyCAD v4 - はじめに
{: #tinycad-v4---getting-started}

TinyCAD v4 は、次の2通りの方法で利用できます。

## デスクトップアプリ
{: #desktop-app}

オフラインで作業したい場合や、いつでもTinyCADを利用できるようにしておきたい場合は、インストール版のTinyCADが適しています。

このバージョンのTinyCADのダウンロード、インストール、起動方法については、[インストール手順](../TinyCAD-Desktop-App/)をご覧ください。

## オンラインアプリ
{: #online-app}

TinyCADをインストールしたくない、またはインストールできない場合（たとえば、アプリケーションのインストールが許可されていない教育機関や職場など）には、オンライン版が適しています。

インストールせずにウェブブラウザーから直接TinyCADを使い始める方法については、[TinyCAD Web クイックスタート](../TinyCAD-Web-overview-and-quick-start/)をご覧ください。
