# TinyCAD - はじめに
{: #tinycad---getting-started}

TinyCAD v4 は、次の2つの方法で利用できます。

## デスクトップアプリ
{: #desktop-app}

オフラインで作業する場合や、いつでも TinyCAD を利用できるようにしたい場合は、インストール版の TinyCAD が適しています。

このバージョンの TinyCAD のダウンロード、インストール、起動方法については、[インストール手順](../TinyCAD-Desktop-App/)を参照してください。

## オンラインアプリ
{: #online-app}

TinyCAD をインストールしたくない、またはインストールできない場合（たとえば、アプリケーションのインストールが許可されていない教育機関や職場など）には、オンライン版が適しています。

インストールせずにウェブブラウザーで直接 TinyCAD を使い始める方法については、[TinyCAD Web クイックスタート](../TinyCAD-Web-overview-and-quick-start/)を参照してください。
