# TinyCAD - はじめに
{: #tinycad---getting-started}

文章の指示やデータシートをもとにシンボル、ライブラリ、回路を作成する際のサポートについては、プロバイダーの設定やプロンプトの例を含む [AI assistant](../AI-Assistant/) ガイドをご覧ください。

TinyCAD v4 は、次の2つの方法で利用できます。

## デスクトップアプリ
{: #desktop-app}

オフラインで作業したい場合や、いつでもTinyCADを利用できるようにしたい場合は、インストール版がおすすめです。

このバージョンのTinyCADのダウンロード、インストール、実行方法については、[インストール手順](../TinyCAD-Desktop-App/)をご覧ください。

## オンラインアプリ
{: #online-app}

TinyCADをインストールしたくない、またはインストールできない場合（たとえば、アプリケーションのインストールが許可されていない教育機関や職場など）には、オンライン版がおすすめです。

インストールせずにウェブブラウザーから直接TinyCADを使い始める方法については、[TinyCAD Web クイックスタート](../TinyCAD-Web-overview-and-quick-start/)をご覧ください。

## 用意された図面を見る
{: #explore-a-ready-made-drawing}

[同梱サンプル](../Bundled-Examples/)を使って、ネットワーク、センサーステーション、オーディオセットアップ、実験台、モーター制御プロジェクトを見てみましょう。「サンプルを開く」は、ブラウザーではタイトルバーに、デスクトップ版では「ファイル」メニューにあります。

[同梱ライブラリ](../Bundled-Libraries/)は左側の **Standard** の下にあります。コレクションを選び、検索して、プレビューを図面にドラッグします。

回路の動作を計算するには、まず[シミュレーションとSPICE](../Simulation/)をご覧いただくか、[SPICEチュートリアル](../SPICE-Tutorial/)を一通りお試しください。統合エンジンは両方の製品に含まれています。独立した[XSPICEデジタルコース](../XSPICE-Tutorial/)を使う場合は、デスクトップ版をご利用ください。
