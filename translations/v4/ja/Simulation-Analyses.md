# シミュレーション解析と設定
{: #simulation-analyses-and-settings}

**Setup** タブの [シミュレーションシート](../Simulation/) で解析を選択します。答えたい問いに応じて選択してください。時間領域の正弦波とAC周波数掃引は、同じソース記号を使用していても、異なる実験です。

| 解析 | 問い | 主な出力 |
| --- | --- | --- |
| **Operating Point** | DCバイアス電圧と電流はいくらか？ | スカラー値 |
| **Transient** | 変化の後、または繰り返し周期の間に何が起きるか？ | 時間に対する信号 |
| **AC** | 小信号は周波数によってどのように変化するか？ | 周波数に対する複素信号 |
| **DC sweep** | 独立ソースを1つ変化させると、DC動作はどのように変化するか？ | ソース値に対する信号 |
| **Noise** | 選択した出力にどのようなノイズが現れるか？ | スペクトルおよび積分ノイズのプロット |
| **Transfer Function** | 指定したソースからの小信号DC伝達はどうなるか？ | ゲインと入力／出力抵抗 |
| **Pole-Zero** | 設定した伝達の極と零点はどこにあるか？ | 複素極／零点の結果 |

## Operating point
{: #operating-point}

動作点解析では、定常DC解を求めます。理想コンデンサはDCでは開放回路、理想インダクタは短絡回路になります。ダイオードやトランジスタなどの非線形デバイスは、バイアス条件で解かれます。トランジスタ増幅器の周波数応答を調べる前に、この解析を確認してください。トランジスタのバイアスが正しくないと、誤った動作状態を中心に線形化されます。

ノード電圧と枝電流には **データ** を使用します。電圧はグラウンド 0 を基準とします。電流の符号は、デバイスで定義された端子の順序に従います。電源電流が負でも、単に電力を供給していることを意味する場合があります。[DCチュートリアル](../SPICE-Tutorial-02/) では、電圧、電流、電力について順を追って説明します。

## Transient: 時間に対する動作
{: #transient-behaviour-over-time}

**Duration** は、イベントと、測定したい応答部分が含まれる長さに設定します。**Maximum step** は、最も速い重要な特徴を解像できるだけ小さく設定します。パルスの場合、繰り返し周期ではなくエッジが条件になることがあります。表示が滑らかに見えても、ソルバーが解像しなかった遷移を復元することはできません。

充電中のRC回路では、時定数は `τ = R × C` です。約5時定数あれば、一次系の整定応答の大部分を確認できます。リップルや実効値を測定するには、定常状態に達するまで十分な周期をシミュレーションし、意図せず起動時の挙動を含めないよう、後半の区間を測定します。

ソルバーは適応タイムステップを使用します。Maximum stepはステップ幅の上限を設定しますが、等間隔のサンプルグリッドを保証するものではありません。測定アルゴリズムは実際のサンプル時刻を考慮します。チャートのズームを変えても表示が変わるだけで、取得時のタイムステップは変わりません。

デフォルトでは、過渡解析の実行時に、まずDC動作点を求めます。この手順を省略する初期条件オプションは、SPICEの **UIC** に相当します。指定した初期状態が実験の一部である場合に、意図して使用してください。回路の接続誤りを一般的に修正する方法ではありません。[RC充電](../SPICE-Tutorial-04/) および [整流とリップル](../SPICE-Tutorial-06/) を参照してください。

## AC: 小信号周波数応答
{: #ac-small-signal-frequency-response}

AC解析では、まず動作点を求め、そこで非線形デバイスを線形化してから、小さな正弦波摂動に対する応答を計算します。大振幅の過渡正弦波をクリッピングさせながら掃引する解析では**ありません**。クリッピング、歪み、大信号変動には過渡解析を使用してください。

開始周波数と終了周波数、およびディケードあたりの点数を設定します。数桁にわたって調べる場合は、対数スイープが便利です。狭い共振や間隔の近いコーナー周波数の周辺では、周波数分解能を上げてください。

ソースの **AC amplitude** と位相は、過渡波形の設定とは別に設定します。位相 **0°**、振幅 **1 V** のAC入力にすると、単一入力の電圧伝達を簡単に解釈できます。過渡正弦波の振幅だけでは、AC信号は有効になりません。一般的な入力では、複素比 `V(out) / V(in)` を計算してください。出力電圧だけではゲインにならない場合があります。

![付属RCフィルターのACスイープ設定](../images/simulation/ac-setup.png)

一次ローパスフィルターで R = 1 kΩ、C = 1 µF の場合、`fc = 1 / (2πRC) ≈ 159.15 Hz`。この周波数では、通過域利得が 1 のフィルターの利得は約 0.707（−3.0103 dB）、位相は約 −45° です。[フィルターのチュートリアル](../SPICE-Tutorial-05/)には、振幅、dB、位相が示されています。

![RCの例を新たにブラウザーで実行して得られた実際のAC解析結果](../images/simulation/ac-charts.png)

## DC sweep
{: #dc-sweep}

**소스 참조**(예: `V1`)를 선택하고 시작값, 종료값 및 간격 값을 입력합니다. 참조는 독립 전압/전류 소스를 식별하며, 네트 라벨이 아닙니다. 시작값에서 종료값을 향해 진행하도록 간격을 선택합니다.

DCスイープでは、一連のバイアス条件を順に解きます。ダイオードのI–V曲線や増幅器の静的伝達曲線を調べるのに便利です。ソースが変化する速さや、ランプ中に蓄積される電荷はモデル化しません。それを調べるには、時間変化する波形を与えて過渡解析を使用します。

この解析は、数値の部品または設定パラメーターを変えながら選択した解析を繰り返し実行する **Circuit Explorerの1変数スイープ**とは異なります。たとえば、AC解析を繰り返しながらR1を5つの値でスイープし、フィルターのコーナー周波数を比較できます。

## Noise
{: #noise}

入力ソースと出力／基準ノードを指定し、周波数範囲と分解能を設定します。出力は電圧差です。選択した基準を確認してください。ノイズ解析では、動作点周辺の小信号ノイズ寄与を使用します。ノイズに対応したデバイスモデルが必要です。理想的でノイズのない動作ブロックに、物理デバイスのノイズスペクトルが自動的に付与されることはありません。

正しい結果プロットを選択してください。**スペクトル**密度と**積分**ノイズは異なる量です。プロットの単位に従ってください。V/√Hzで表される振幅密度は、定義された帯域幅で積分されるまでは電圧ではありません。[設計調査](../SPICE-Tutorial-10/).

## Transfer functionとpole-zero
{: #transfer-function-and-pole-zero}

**Transfer Function**（`.tf`）では、明示的に指定した独立ソースと出力ポートを使用して、小信号DCゲインと入力／出力抵抗を計算します。AC解析の全周波数スイープとは異なります。ソース参照と、出力が正しいノードを基準に測定されているかを確認してください。

**Pole-Zero**解析では、設定した小信号伝達の極と零点を調べます。ポートと伝達の選択が重要です。回路図で考えられるあらゆる動作を探索する解析ではありません。複素平面上の結果は、正しくバイアスされたモデルの代わりとして扱うのではなく、ACおよび過渡解析の結果とあわせて解釈してください。

## 温度、単位、パラメーター
{: #temperature-units-and-parameters}

設定温度の単位は **°C** です。温度依存性を実装したモデルを持つデバイスに影響しますが、理想部品に熱物理を追加するものではありません。名前付き設定パラメーターを使うと、互換性のあるSPICE式や探索バインディングで数値を再利用できます。

数値コントロールでは、`5ms`、`10us`、`1kHz` などの工学表記を使用できます。**SPICEテキスト**では、接尾辞はSPICEの規則に従います。`k` はキロ、`u` はマイクロ、`n` はナノを表し、**`m` または `M` はミリ**を意味します。メガには **`Meg`** を使います。たとえば、1メガオームは `1Meg` です。`1M` が100万を意味すると考えないでください。

時定数やコーナー周波数を単純計算して確認するのは有用です。ただし、負荷の影響を考える代わりにはなりません。信号発生器の出力抵抗、メーターの入力抵抗、または後段によって、実際の応答が変わることがあります。

詳細な解析構文とモデルの動作については、公式の [ngspice マニュアル](https://ngspice.sourceforge.io/docs.html)を参照してください。TinyCADの操作については、[ソースと計測器](../Simulation-Sources-and-Instruments/)または[グラフと測定](../Simulation-Charts-and-Measurements/)に進んでください。
