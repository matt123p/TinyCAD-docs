# 複数シートの図面
{: #mutliple-sheet-drawings}

設計が1ページに収まらない場合や、機能ブロックごとに分けたい場合は、複数のシートを使用します。

## 複数シートを使用する理由
{: #why-use-multiple-sheets}

- 複雑な回路図を読みやすく保つ。
- 関連する部品を機能ごとに整理する。

## 基本的なワークフロー
{: #basic-workflow}

1. 図面に新しいシートを作成します。
2. 各シートにわかりやすい名前を付けます（例: `Power`、`Control`、`I/O`）。
3. 必要に応じて、各シートにシンボルや配線を配置します。
4. ラベルや電源シンボルを使用して、シート間を接続します。
