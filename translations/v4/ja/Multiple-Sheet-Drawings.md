# 複数シートの回路図
{: #multiple-sheet-drawings}

TinyCADの図面には、**1つのファイル**に複数の回路図シートを含めることができます。各シートには独自の作図領域があり、キャンバスの下にタブが表示されます。タブを使って一度に1つのシートを編集します。すべての回路図シートを合わせて1つの回路を表します。

## 複数シートを使う理由
{: #why-use-multiple-sheets}

複数シートを使うと、すべてを混み合った1ページに縮小して詰め込むのではなく、理解しやすいセクションごとに設計を整理できます。たとえば、次のように分けられます。

| シート | 含まれる内容の例 |
| --- | --- |
| **電源** | 入力コネクタ、保護回路、レギュレータ、電源レール |
| **制御** | プロセッサ、クロック、リセット、プログラミング接続 |
| **センサー** | 測定入力とそのインターフェース回路 |
| **出力** | ドライバ、リレー、モーター、ディスプレイ、外部コネクタ |

こうすることで、各セクションを読みやすいサイズで作図、確認、印刷しやすくなります。関連する部品をまとめ、各ページに明確な目的を持たせ、読み進めやすい順序に並べることができます。小規模な設計であれば、1枚のシートの方がわかりやすい場合もあります。

シートは現在の図面の一部であり、別ファイルやブラウザータブではありません。互いに無関係な2つの図面ファイルを開いても、同じラベルが含まれていたとしても、両者は接続されません。

## シートの作成と切り替え
{: #create-and-switch-sheets}

1. 図面を開き、キャンバスの下にあるシートタブを確認します。
2. タブの横にある **+** を選択します。ツールチップには **新しいシートを追加** と表示されます。
3. **シート名**を入力します（例：`Control`）。次に **追加** を選択します。
4. 新しいシートがアクティブになります。そこに部品やワイヤを配置するか、別のシートで項目を選択して［切り取り］と［貼り付け］を使って移動します。
5. シートのタブを選択すると、そのシートに戻れます。シートを切り替えても内容は破棄されません。

回路図を見る人が必要なセクションを見つけやすいように、わかりやすく具体的な名前を付けてください。

## シート名の変更
{: #rename-a-sheet}

1. シートのタブを選択します。
2. シート名の横にある小さな矢印メニューを開きます。
3. **名前の変更**を選択し、新しい**シート名**を入力して、ダイアログで **名前の変更** を選択します。

名前を変更するとページ名が変わります。部品リファレンスやネットラベルは変更されず、電気的接続も変わりません。

## シートの順序を変更する
{: #change-the-sheet-order}

シートタブを別のタブの上にドラッグすると、その位置に移動します。また、タブを選択して矢印メニューを開き、**左へ移動**または**右へ移動**を選択すると、1つずつ移動できます。

順序を変更してもページの並び順が変わるだけで、部品や回路の接続は変わりません。電源セクションを先頭にしたり、関連する機能をまとめたり、補足ページをメイン回路の後に配置したりするために使います。ページの順序を変えるときは**タブ**をドラッグしてください。部品をドラッグすると、その部品が移動します。

## 動画：シートを整理し、ラベルで接続する

このチュートリアルでは、まず **サンプルを開く → SPICE tutorial → divider** を開きます。Circuitシートの名前をPowerに変更し、Controlを作成してタブの順序を入れ替えた後、R2をControlに移動します。OUTという同じ名前のラベルと、0という名前のグラウンド接続によって、2枚の回路図シートにまたがる分圧回路が再接続されます。ネットリストビューで、R1とR2が同じOUTネットを共有していることを確認できます。

## シート間の接続
{: #make-connections-between-sheets}

ワイヤを別のページまで物理的につなげることはできません。代わりに、接続したい点に**同じ名前の、電気的に有効なラベル**を使います。TinyCADは、図面内のすべての回路図シートで、これらの点を1つのネットとして扱います。

たとえば、Power上のレギュレータ出力に`+3V3`というラベルを付け、Control上のプロセッサ入力に`+3V3`というラベルを付けると、両者を接続できます。`RESET`というラベルを付けた信号で、あるシートのリセット回路と別のシートのプロセッサを接続できます。ラベルは、目的のワイヤまたはピンに接続されている必要があります。

### 共通ネットラベルの配置
{: #place-a-shared-net-label}

1. 最初のシートで、通常どおり部品のピンまでローカルワイヤを引きます。
2. **ラベル**ツールを選択し、電気的接続点がそのワイヤまたはピン上に来るように配置します。近くにテキストを描くだけでは不十分です。
3. ラベルのテキストを、`RESET`や`I2C_SDA`のようなわかりやすい名前に編集します。編集するにはラベルのテキストを選択し、既定の`Label`テキストを置き換えます。
4. もう一方のシートに切り替え、同じネットに接続するワイヤまたはピンに別のラベルを配置します。
5. **スペル、スペース、大文字・小文字を含め、完全に同じ名前**を入力します。
6. 同じ電気ネットが必要な他のシートでも繰り返します。

[ラベルツール](../Labels/)を使い、[テキストツール](../Text/)は使わないでください。RESETと書いた注記は図面の説明になりますが、RESETと書いたラベルは電気的接続を作ります。

### 作業例：2枚のシートに分けた分圧回路
{: #worked-example-a-divider-on-two-sheets}

通常の5 V分圧回路を、電源セクションと負荷セクションに分けます。

| シート | 部品 | 共通接続 |
| --- | --- | --- |
| **電源** | V1 = 5 V、R1 = 1 kΩ | R1の出力ワイヤに**OUT**ラベルを付けます。V1の戻り側はグラウンド**0**に接続します。 |
| **制御** | R2 = 1 kΩ | R2の上側ピンに**OUT**ラベルを付け、下側ピンを**0**という名前のグラウンド電源シンボルに接続します。 |

OUTによって、シート間でR1とR2が接続されます。同じグラウンド名によって、R2の戻り側がPower上のグラウンド0に接続されます。ページ間にワイヤは描かれていませんが、電気回路はV1 → R1 → R2 → 戻り側のままです。元の値では、動作点解析の出力は引き続き2.5 Vです。

動画では**切り取りと貼り付け**を使ってR2を移動し、2つ目のR2を作らずに元のリファレンスを維持しています。部品を追加するときは、ネットリストやレポートで目的の部品を特定できるよう、図面内でリファレンスが重複しないようにしてください。

## ラベル名は図面全体に適用される
{: #label-names-apply-to-the-whole-drawing}

共通名は便利ですが、無関係なセクションを誤って接続しやすくもなります。別々のシートにある3つの場所で`OUT`というラベルを使うと、3か所すべてが接続されます。この名前は各ページ内だけで有効なものではありません。信号を分離したままにする場合は、`SENSOR_OUT`や`AUDIO_OUT`のような、より具体的な名前を使ってください。

シート名やタブの順序によって電気的に分離されることはありません。ラベルの形状も視覚的な慣例にすぎません。同じ名前の通常、入力、出力、双方向の各ラベルは、同じネットに属します。信号の意図する方向を読み手に伝えるには形状を使い、接続先を定義するには名前を使ってください。

[電源シンボル](../Power-symbols/)も、共通の名前付き電源接続を提供します。名前に一貫性を持たせてください。`+3V3`と`3V3`は異なる名前です。SPICEでは、ノード**0**への実際の接続を使ってください。GNDという別のネット名が、自動的にシミュレータのグラウンド基準になることはありません。

## シート間接続の確認
{: #check-the-cross-sheet-connections}

下部のリストパネルにあるモードメニューを使い、**シンボル**から**ネットリスト**に切り替えます。共通ラベルを探し、接続されている部品リファレンスとピン番号を確認します。Sheet列には行が表す主な項目が表示されます。Symbols列には、同じネット上にある他のシートの部品が含まれる場合があります。この例では、OUTにR1とR2の両方が含まれています。

接続されていない場合は、ラベルの接続位置と、両方のページにある正確なテキストを確認してください。無関係な部品が同じネットを共有している場合は、図面内の他の場所で同じラベル名が使われていないか確認します。[デザインルールチェック](../Design-Rules-Check/)は電気的な問題の特定に役立ちますが、同じ名前の2つのネットを分離する意図があったかどうかは判断できません。

詳しくは[ネットリストエディター](../Netlist-Editor/)と[ラベル](../Labels/)を参照してください。シミュレーション図面では、回路を変更した後に解析を再実行し、すべての回路図シートの最新の内容を結果に反映させてください。

## 図面全体を保存する
{: #save-the-complete-drawing}

**保存**すると、すべてのシートがまとめて保存されます。通常の図面では`.dsn`を使用し、シミュレーション内容を含む図面では[`.dzn`](../Simulation/#dzn-simulation-drawings)を使用します。シートごとに個別に保存する必要はありません。
