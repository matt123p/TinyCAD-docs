# レイアウトの整頓
{: #layout-tidy-up}

**自動レイアウト (Auto-layout)** は、部品、配線、ラベルの位置を調整して、既存の回路図を整えます。回路が込み入って読みづらい場合や、不要な折れ曲がりを減らしたい場合、リファレンスや値の間隔を改善したい場合に使用します。

ブラウザーとDesktop Appのどちらでも、**現在の回路図シート**に対して動作します。既存の電気的接続は保持されます。描こうとしていた接続を推測したり、回路を一から作成したりする機能ではありません。

## 自動レイアウトを開く
{: #open-auto-layout}

どちらの製品でも、ツールバーの **Simulation** のすぐ隣にある **自動レイアウト (Auto-layout)** を選択します。Desktopでは **Tools → Auto-layout** を選択することもできます。

最初に回路図シートを選択してください。ライブラリの編集中、またはSimulationシートの表示中は、このツールを使用できません。

## 整理する範囲を選ぶ
{: #choose-what-to-tidy}

ダイアログの **適用範囲 (Apply to)** には、次の設定があります。

- **シート全体 (Whole sheet)** — 現在のシート上にある、対応する回路アイテムを整えます。
- **選択したアイテム (Selected Items)** — 選択範囲外のアイテムを固定し、範囲の境界で接続を保持したまま、選択した回路アイテムだけを整えます。

小さな領域で作業するには、ダイアログを開く前に、位置を調整したい部品と配線、ラベルをまとめて選択します。選択範囲に対応する回路アイテムが含まれている場合、デフォルトでは「選択したアイテム」が選ばれます。選択範囲に注記ボックスや図形など対応していないオブジェクトだけが含まれている場合、または何も選択されていない場合は無効になります。

選択範囲には、シンボル、配線、ネットラベル、電源シンボル、未接続マーカー、接続点を含めることができます。選択範囲外の部品は、選択した部品に接続されているだけでは移動しません。

## 強さを選ぶ
{: #choose-the-strength}

**強さ (Strength)** は、部品の配置をどの程度変更できるかを制御します。

| 強さ | 変更可能な内容 |
| --- | --- |
| **低 (Low)** | 大型部品を固定し、小型部品、配線、ラベルの移動を許可します。 |
| **中 (Medium)** | 最大2個の大型部品に加え、小型部品、配線、ラベルの移動を許可します。これがデフォルトです。 |
| **高 (High)** | 配線やラベルとともに、移動可能なすべての部品の移動を許可します。 |

主要な配置を保ちたい場合は、まず「低」を試してください。回路を再配置するために、より広いスペースが必要な場合は「中」または「高」を使用します。「低」はラベルだけを対象にする設定ではありません。小型部品の位置や配線経路も変更されることがあります。

「大型」かどうかは、電気的な重要度ではなく、シンボルの形状とピン数で判断されます。強さを変更しても、部品の回転、サイズ変更、置換は行われず、リファレンス、値、モデル設定も変更されません。

## 実行して結果を確認する
{: #run-and-review-the-result}

1. 図面、または[同梱サンプル](../Bundled-Examples/)の編集可能なコピーを開きます。
2. 操作範囲を限定したい場合は、整える領域を選択します。
3. **自動レイアウト (Auto-layout)** を開き、**適用範囲 (Apply to)** と **強さ (Strength)** を選択してから、**実行 (Go)** を選びます。
4. **レイアウトを配置中… (Arranging layout…)** と表示されている間、処理が終わるまで待ちます。処理が成功すると、結果がすぐに適用され、ダイアログが閉じます。
5. 結果を確認します。元の配置に戻したい場合は、**元に戻す (Undo)** を使うと、整頓全体を一度で取り消せます。

{% include video-player.html src="/v4/videos/simulation/layout-tidy-up.mp4" poster="/v4/videos/simulation/layout-tidy-up.jpg" caption="自動レイアウトを開き、範囲と強さを選んでアンプのサンプルを整えた後、変更を元に戻します。" %}

**キャンセル (Cancel)** を選ぶと計算を停止し、変更を適用せずにダイアログを閉じます。ツールの実行中にシートが変更された場合、結果は破棄されます。現在のシートに対して再実行してください。

**レイアウトの改善が見つかりませんでした (No layout improvements were found)** と表示された場合、選択した範囲と強さでは、許容できる変更が見つからなかったことを意味します。図面は変更されません。ダイアログを閉じ、別の領域を選択するか、強さを変えて試すか、手動で調整してください。

## このツールで改善できること
{: #what-the-tool-improves}

自動レイアウトでは、次のような改善を試みます。

- 部品のリファレンスや値のテキストを読みやすい位置に配置します。フィールドをまとめて配置し、近くの図形、配線、他のテキストと重ならないようにします。
- 通常のネットラベルを接続先の配線に沿った適切な位置に配置し、可能な場合は関連するラベル同士を揃えます。
- 直交配線経路を簡素化し、不要な迂回を短くして、部品ピンからの引き出しを明確にします。
- 接続された部品をよりコンパクトに配置し、繰り返し配置される部品の間隔を整えます。
- 接続関係と使用可能なスペースが許す場合、関連する配線を順序よく並行して配線します。

注記ボックス、バス、形状付きポートフラグ、ライブラリの図形、ページ上の固定要素は再設計しません。密集したシンボルや特殊なシンボルには、手作業での調整が必要な場合があります。ラベル用のスペースを確保したり、接続を明確にしたりできるなら、配線が長くなる方が適切な結果になる場合もあります。

## 整理する前に接続を確認する
{: #check-connections-before-tidying}

自動レイアウトは、**既存の接続状態を出発点**として扱います。変更を確定する前に、電気的なネットへの所属と物理的な配線接続の両方を確認します。これらの確認では、ネット名ラベルによって物理的に切れた配線が見えなくなることはありません。

別の配線の端点やソケットを配線が通過すると、接続点のドットが見えなくても電気的に接続されることがあります。その接触が意図しないものなら、自動レイアウトを実行する前に修正してください。既存の接続が作図ミスかどうかをツールが判断することはできません。また、曖昧な接続点を移動して、以前は別々だったネットを接続することもありません。

整理後は、分岐、ピン接続、未使用ソケットの周囲の配線経路を確認してください。必要に応じて[デザインルールチェック](../Design-Rules-Check/)を実行し、回路を意図した接続と照合してください。シミュレーション図面が変更済みと表示された場合は、以前の結果を現在の図面の測定結果として扱う前に、[再実行してください](../Simulation/)。

## 自動レイアウトとポイント間配線の違い
{: #auto-layout-or-point-to-point-wire}

回路図にすでにある図形配置を整えるには、**自動レイアウト (Auto-layout)** を使用します。2つの端点間に新しい配線経路を作成するには、[ポイント間配線](../Wires/#auto-routing)を使用します。通常の[配線ツール](../Wires/#placing-wires)では、個々の折れ曲がり位置を自分で指定できます。
