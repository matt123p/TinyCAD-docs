# デザインルールチェック
{: #design-rules-check}

v4 では、**デザインルールチェックは v3 と同じように動作します**。

デザインルールチェックを使用して、ネットリストや VHDL などの出力を生成する前に、
回路図の重大な接続上の問題を見つけます。

配線とピンタイプの組み合わせをチェックし、よくある電気的な誤り（たとえば、競合する出力同士の接続）を検出します。ただし、回路が機能的に正しいことを保証するものでは**ありません**。

回路図が正しいという信頼性を高めるため、設計エラーをゼロにすることを目指してください。

## デザインルールチェックを実行する
{: #run-design-rules-check}

1. 設計を開きます。
2. 特殊ツールメニューから **デザインルールをチェック (Check Design Rules)** を実行します。
3. ルールダイアログで、実行するルールチェックを有効または無効にします。
4. **OK** を選択してチェックを実行します。

## 結果を確認する
{: #reading-the-results}

- 検出された各エラーは、回路図上で赤い円でマークされます。
- 設計の横にエラー一覧が表示されます。
- 一覧からエラーを選択すると、図面上の該当箇所が中央に表示されます。

## クリアして再チェックする
{: #clear-and-re-check}

- エラー一覧で **閉じる (Close)** を選択すると、現在のエラーマーカーがすべて削除されます。
- エラーを示す円は一時的な確認用マーカーです。設計と一緒に保存されることはありません。
