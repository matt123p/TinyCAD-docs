# ショートカット
{: #shortcuts}

ツールバーをクリックする代わりにキーボードショートカットを使うと、作図が速くなります。

**注:** ブラウザーアプリケーションではFキーの扱いが異なるため、これらのショートカットはTinyCAD v3のものとは異なります。

| キー | 操作 |
|---|---|
| `Esc` | 現在の配置または作図操作をキャンセルします。操作中でない場合は選択を解除します |
| `W` | 配線ツール |
| `N` | 未接続 |
| `P` | 電源 |
| `L` | ラベル |
| `T` | テキスト |
| `B` | バス |
| `S` | 図形（長方形／楕円／線） |
| `+` | 拡大 |
| `=` | 拡大 |
| `-` | 縮小 |
| `_` | 縮小 |
| 矢印キー | スナップが有効な場合はグリッド間隔で、無効な場合は小刻みに選択項目を移動します。何も選択されていない場合は画面をパンします |
| `Ctrl` + 矢印キー | 選択項目を小刻みに移動するか、より小さな幅で画面をパンします |
| `Ctrl-F` | 検索 |
| `Ctrl-P` | 印刷 |
| `Ctrl-C` | コピー |
| `Ctrl-X` | 切り取り |
| `Ctrl-V` | 貼り付け |
| `Del` | 削除 |
| `Ctrl-Z` | 元に戻す |
| `Ctrl-Y` | やり直し |

ツールバーボタンにフォーカスがある場合、Escapeキーでも作成をキャンセルできます。テキストフィールドへの入力中、またはメニューやダイアログの使用中は、まずその操作を完了するか、コントロールを閉じてください。

一部のショートカットはブラウザーに横取りされ、代わりにブラウザーの操作が実行されることがあります。
