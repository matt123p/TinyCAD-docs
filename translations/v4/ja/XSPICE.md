# XSPICE とデジタルシミュレーション
{: #xspice-and-digital-simulation}

XSPICE は、コードモデルと、アナログソルバーと連携して動作するイベント駆動型シミュレーションシステムによって ngspice を拡張します。ゲート、クロック、記憶素子、アナログ・デジタル混在システムに役立ちます。上流のアーキテクチャについては、公式の [XSPICE 概要](https://ngspice.sourceforge.io/xspice.html)を参照してください。

**XSPICE は TinyCAD Desktop でサポートされていますが、ブラウザ版ではサポートされていません。** Desktop のネイティブエンジンには、バンドルされたコードモデルライブラリが含まれています。

*保存済みの結果の表示:* ブラウザでも、以前に XSPICE のデータ取得を行った図面を開くことができます。保存済みの結果を確認できますが、シミュレーションの実行には Desktop が必要です。

## 適切なロジックモデルを選ぶ
{: #choose-the-right-logic-model}

| 手法 | 動作 | 使用場面 |
| --- | --- | --- |
| バンドルされた **Digital logic** と **Functional blocks** | 電源としきい値を設定した、移植性の高いアナログ動作SPICEモデル | ブラウザと Desktop でのシステムレベルの検討 |
| XSPICE チュートリアルのシンボル／モデル | イベント駆動型ロジック、遅延、記憶素子、および明示的なアナログ・デジタルブリッジ | Desktop のネイティブ混合信号シミュレーション |

見た目が似ているゲートでも、モデリング上の前提は異なる場合があります。外見だけを理由に、一方を他方の代わりに使用しないでください。どちらの手法も、ESP32、Raspberry Pi、Arduino ボードの図を描いただけでファームウェアを実行できるようにするものではありません。TinyCAD の統合機能は、汎用 HDL や組み込みソフトウェアの実行環境ではありません。

## アナログノードとデジタルノード
{: #analogue-and-digital-nodes}

アナログノードは連続値の電圧／電流を伝えます。デジタルイベントノードは状態を伝えます。**ADC ブリッジ**はしきい値を適用してアナログ入力をデジタル状態に変換し、**DAC ブリッジ**はデジタル状態をアナログ出力レベルに変換します。これらのブリッジが表すのはシミュレーター内の領域間の変換であり、必ずしも完全な物理 ADC/DAC デバイスではありません。

しきい値、電源レベル、出力負荷を確認してください。有効なロジックしきい値の範囲に収まらない電圧では、不定状態が発生することがあります。クロック／リセット条件が確定するまで、記憶素子の状態が不定のままになることがあります。不定状態は診断に役立つ情報です。これを仮定上の 0 に置き換えると、実際のタイミングや初期化の問題が見えなくなる場合があります。

伝搬遅延があると、時間が重要になります。経路ごとに遅延の異なるゲートでは、静的な真理値表が正しく見えてもハザードが発生することがあります。アナログ応答と測定したいタイミングを捉えられるよう、過渡解析の最大刻み幅を選んでください。粗い表示だけからイベント遅延を推定しないでください。

## デジタル講座を実行する
{: #run-the-digital-course}

1. Desktop で **File → Open Example → XSPICE and digital tutorial** を選択します。
2. レッスンで指定されている名前の図面を開きます。シンボル、コードモデル宣言、保存済みの結果が含まれています。
3. **View → View Explanation** で説明を読み、Simulation シートを選択します。
4. **Run** を選択して新しいネイティブデータ取得を行い、状態とタイミングをレッスンと比較します。
5. しきい値、遅延、リセット、クロックのタイミングを変更する前に、コピーを保存してください。

[全6章の XSPICE チュートリアル](../XSPICE-Tutorial/)では、ブリッジと最初の実行、ゲートと真理値表、ハザード、フリップフロップ、カウンター、混合信号フィルタを扱います。回路図、ソルバーのプロット、ダウンロード可能な補助資料が含まれています。
