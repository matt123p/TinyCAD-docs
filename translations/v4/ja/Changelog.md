# TinyCAD 変更履歴
{: #tinycad-v4-changelog}


## v4.0.11
{: #v4011}

このリリースでは、書式付きMarkdown注記、SVGによるベクター出力、配線の描画モードを追加しました。

- [Markdownテキストボックス](../Text-and-Annotations/#markdown-text-boxes): リスト、タスクリスト、コードブロックを含む書式付き注記。図面、SVGエクスポート、PDFで同じベクター描画機能を使用します。
- ソース編集中も書式を表示し、編集可能な記号を残します。選択した基本フォントに合わせてカーソル、選択範囲、折り返しを配置します。
- [配線の描画モード](../Wires/#wire-routing-modes): 作成中のプレビューを保持したまま90°、45°、自由な配線を選べるコンパクトなセレクター。
- ルーペボタンは、図面上でタッチ操作を行った後にのみ表示されます。

## v4.0.10 — 2026年11月6日
{: #v4010}

- ライブラリまたは回路図のパネルで縦方向の領域が必要になっても、エディターのツールバーが表示されるようにしました。

## v4.0.9 — 2026年11月4日
{: #v409--4-november-2026}

### 追加
{: #added}

- [タッチ操作](../Touch-controls/)（直接編集、2本指でのパンとピンチズーム、正確な配置のためのクリック、ドラッグ／ドロップ、メニュー、閉じる操作を備えた拡大ルーペを含む）。
- [サイズ変更可能なライブラリパネルとシンボルの並べ替え](../Using-Symbol-Libraries/)（検索結果のアルファベット順表示を含む）。
- [選択したオブジェクトの一時的な非表示](../User-guide/#temporarily-hiding-objects)と、現在のシート上の非表示オブジェクトをすべて再表示するコマンド。
- ポーランド語のインターフェース翻訳、および「シンボルを置換」ダイアログの翻訳テキスト。

### 修正
{: #fixed}

- [グリッドの表示とスナップ](../Snap-to-Grid/)が独立して動作し、スナップが無効な場合はキーボードによる移動にも反映されます。
- 配置したライブラリシンボル内でビットマップ画像が描画されるようになりました。
- [Escapeキーで描画および配置操作をキャンセル](../Shortcuts/)できます。ツールバーのコントロールにフォーカスがある場合も対象です。
- デスクトップ版の未保存の変更に関する確認ダイアログでキャンセルすると、保留中の終了処理が解除されるようになりました。
- キャンバスのピンチズームがブラウザーのページズームと重複しなくなりました。
- タッチルーペの位置、ポインターのフィードバック、ジェスチャー処理、ドラッグ操作を改善しました。
- デスクトップ版およびmacOS版の「TinyCADについて」ダイアログの動作を改善しました。

### パッケージングと保守
{: #packaging-and-maintenance}

- セキュリティ上の脆弱性に対処するため、依存関係を更新しました。
- ElectronランタイムがLinux x64およびARM64に対応しているため、Linux ARMv7パッケージを削除しました。Snapパッケージはx64を対象とし、Debianパッケージはx64およびARM64を対象とします。

## v4.0.6 — 2026年3月29日
{: #v406--29-march-2026}

このリリースには、バージョン4.0.5として行われた開発上の変更が含まれています。個別の4.0.5タグや公開済みGitHubリリースはありません。

### 追加
{: #added-1}

- ワイヤーの自動配線。
- 既存のコンポーネントを別のライブラリシンボルに変更する「シンボルを置換」（Replace Symbol）。
- 図面の端付近をドラッグしている間の自動スクロール。
- ダブルクリックによるワイヤー全体の選択、およびトリプルクリックによる接続点やT字分岐を越えた範囲の選択。
- ラベルの接続インジケーターをオフにするオプション。

### 修正と改善
{: #fixed-and-improved}

- ライブラリフォルダーがデフォルトで開き、検索時に展開されるようになりました。
- 図面にフォーカスがあるときのテキスト編集、クリップボードのショートカット、ナビゲーションキー、キーボードアクセラレーターを改善しました。
- Ctrlキーを押しながらのクリックによる選択、複数の選択オブジェクトのドラッグ、スピンコントロールを修正しました。
- 図面および選択範囲の矩形を、どちらの方向にもドラッグできるようになりました。
- macOSでの終了処理を修正し、ライブラリの重複読み込みを削減しました。
- ラベルの位置、カラーピッカーの翻訳、ネットリストのバックグラウンド処理を修正しました。
- WindowsインストーラーおよびAppXのビルド名を修正しました。
