# TinyCAD 変更履歴
{: #tinycad-changelog}


## 未リリース
{: #unreleased}
{: #unreleased}

### 追加
{: #added}

- [ブラウザーおよび Desktop でローカルの ngspice を使用した統合シミュレーション](../Simulation/)。動作点、過渡、AC、DCスイープ、ノイズ、伝達関数、極零点解析に対応しています。[イベント駆動型 XSPICE](../XSPICE/) は Desktop でサポートされています。
- [オシロスコープ、マルチメーター、ファンクションジェネレーター、ベンチ電源などの信号源、プローブ、仮想計測器](../Simulation-Sources-and-Instruments/)。
- [Circuit Explorer](../Simulation-Charts-and-Measurements/) による、調整、スイープ、名前付き測定、要件、DCオーバーレイ、許容差解析、テストケース、電力・ストレス調査。
- [回路、モデル、シミュレーション設定、オプションの結果をまとめて保存する圧縮`.dzn`図面](../Simulation/#dzn-simulation-drawings)。実行履歴と結果のエクスポートで比較や共有ができ、結果を含めずに保存するとファイルサイズを小さくできます。
- [ネットワークレイアウト、組み込みボード、スマートホームモジュール、オーディオ、実験装置、モーター／モーション、太陽光／バッテリー計画向けの組み込みライブラリ](../Bundled-Libraries/)に加え、モデル化されたSPICE、ロジック、機能、センサーの各コレクション。ライブラリピッカーの「Standard」タブから選択できます。
- [元のトランジスターアンプ、オフィスネットワーク、ESP32気候・表示ステーション、太陽光／バッテリー住宅、ポッドキャストスタジオ、実験室ベンチ、モーター制御ベンチを扱う、編集可能な7つの図面例](../Bundled-Examples/)。シンボルと解説が組み込まれています。
- [SPICEおよびXSPICEのチュートリアル](../Simulation-Tutorials/)：アナログ編11章、デジタル編6章で構成され、実行可能な図面28点、モデル定義、解析設定、保持された基準波形を収録しています。
- [シート全体または選択した項目を対象にしたレイアウト整頓](../Layout-Tidy-Up/)。強度（Low／Medium／High）の指定、キャンセル、接続チェック、1段階のUndoに対応しています。

### 変更
{: #changed}

- ブラウザーでは「サンプルを開く」と「解説」がタイトルバーにあります。デスクトップでは「ファイル」→「サンプルを開く」と「表示」→「解説を表示」を使用します。
- デスクトップの「表示」メニューに「チャートを表示」が追加されました。ツールバーの「シミュレーション」メニューには、引き続きチャートの切り替えがあります。
- 自動レイアウトはツールバーの「シミュレーション」の隣に配置され、デスクトップの「ツール」メニューからも使用できます。

### 修正
{: #fixed}

- 「標準」、「マイライブラリ」、「オンライン」のピッカー検索結果で、ドラッグ可能なコンポーネントのアートワークプレビューを復元。
- 組み込みコントローラー、センサー、ディスプレイのアートワークを実用的なページレイアウトサイズに縮小し、ピンの識別情報と配線位置を維持。
- レイアウト変更によって、配線端点、曲がり、ソケットに意図しない接続が生じないように修正。ピンの引き出しを改善し、不要な迂回を削除。
- 実験装置およびモーション制御のシンボルで、テキストに重なる小さな端子ラベル枠を削除し、該当するサンプルを更新。
- シミュレーションのエラー報告と診断、ブラウザーでのアンプ実行、チャートのポップアウト、独立したサンプル解説パネルを改善。

### マニュアル
{: #manual}

- 同梱ライブラリとサンプルの検索・使用ガイドを追加し、エクスポートのみの SPICE 説明を統合シミュレーションのワークフローに置き換え。
- 解析、モデル、計測器、チャート、測定、トラブルシューティングに関するリファレンスと、ngspice および XSPICE の公式ドキュメントへのリンクを追加。
- 既存のコース一式、ダウンロード可能な図面／ネットリスト、ライブラリ、サンプル、レイアウト整頓、マルチシート接続、SPICEを扱う動画解説10本を収録。
- [機能の違い](../Feature-Differences/)を明確化。`.dzn` と Markdown テキストボックスの互換性、およびブラウザーでの XSPICE サポートなどを含みます。
- ナビゲーション、新しいリファレンスページ、チュートリアルの文章、動画字幕を含め、サポートされる8言語すべてでマニュアルを更新。

## v4.0.11
{: #v4011}
{: #v4011}

このリリースでは、書式付き Markdown ノート、ベクター形式の SVG 出力、配線経路の制御が追加されます。

- [Markdown テキストボックス](../Text/#markdown-text-boxes)：箇条書き、タスクリスト、コードブロックを含む書式付きノートに対応。図面、SVGエクスポート、PDFで同じベクターレンダラーを使用。
- ライブソース書式設定により、編集可能なマーカーを表示したまま、選択した基本フォントに追従。キャレット位置、選択範囲、折り返しも一致します。
- [配線経路モード](../Wires/#wire-routing-modes)：「90°」、「45°」、「自由」を切り替えるコンパクトなセレクター。進行中のプレビューを保持します。
- 拡大鏡ボタンは、図面キャンバスでタッチ入力した後にのみ表示されます。

## v4.0.9 — 2026年11月4日
{: #v409--4-november-2026}

### 追加
{: #added-1}

- [タッチ操作](../Touch-controls/)。直接編集、2本指でのパン
  とピンチズーム、正確な配置のための「クリック」、「ドラッグ／ドロップ」、「メニュー」、「閉じる」
  操作を備えた拡大鏡に対応。
- [サイズ変更可能なライブラリパネルとシンボルの並べ替え](../Using-Symbol-Libraries/)。
  検索結果のアルファベット順表示を含みます。
- [選択したオブジェクトの一時的な非表示](../User-guide/#temporarily-hiding-objects)
  と、現在のシート上の非表示オブジェクトをすべて再表示するコマンド。
- ポーランド語インターフェース翻訳と、「シンボルの置換」ダイアログの翻訳テキスト。

### 修正
{: #fixed-1}

- [グリッドの表示とスナップ](../Snap-to-Grid/)が独立して動作し、
  スナップが無効な場合、キーボードによる移動にも反映されます。
- 配置したライブラリシンボルでビットマップ画像が描画されます。
- ツールバーのコントロールにフォーカスがある場合も含め、[Escape キーで図面作成および配置操作をキャンセル](../Shortcuts/)できます。
- デスクトップの未保存変更の確認画面でキャンセルすると、保留中の終了要求が解除されます。
- キャンバスのピンチズームがブラウザーのページズームと重複しなくなりました。
- タッチ拡大鏡の位置、ポインターの応答、ジェスチャー処理、ドラッグ操作を改善。
- デスクトップ版および macOS の「このアプリについて」ダイアログの動作を改善。

### パッケージングと保守
{: #packaging-and-maintenance}

- セキュリティ脆弱性に対応するため依存関係を更新。
- Electron ランタイムが Linux x64 と ARM64 をサポートするため、Linux ARMv7 パッケージを削除。Snap パッケージは x64 用、Debian パッケージは x64 と ARM64 用です。

## v4.0.6 — 2026年3月29日
{: #v406--29-march-2026}

このリリースには、バージョン4.0.5として行われた開発上の変更が含まれています。
4.0.5の個別タグや公開済み GitHub リリースはありません。

### 追加
{: #added-2}

- 配線の自動経路設定。
- 既存のコンポーネントを別のライブラリシンボルに変更する「シンボルの置換」。
- 図面の端近くでドラッグすると自動スクロール。
- ダブルクリックで配線全体を選択し、トリプルクリックで接合点やT字接続を越えて選択。
- ラベル接続インジケーターをオフにするオプション。

### 修正と改善
{: #fixed-and-improved}

- ライブラリフォルダーは既定で開き、検索時に展開されます。
- 図面にフォーカスがあるときのテキスト編集、クリップボードショートカット、ナビゲーションキー、キーボードアクセラレーターを改善。
- Ctrlキーを押しながらのクリック選択、複数選択オブジェクトのドラッグ、スピンコントロールを修正。
- 図面作成用の矩形と選択用の矩形を、どちら向きにもドラッグ可能に。
- macOS での終了処理を修正し、ライブラリの重複読み込みを削減。
- ラベル位置、カラーピッカーの翻訳、ネットリストのバックグラウンド処理を修正。
- Windowsインストーラーと AppX のビルド名を修正。
