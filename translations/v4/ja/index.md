# TinyCAD マニュアル
{: #tinycad-manual}

TinyCAD v4 はデスクトップアプリとブラウザー版オンラインアプリの両方で利用できます。両バージョンの機能には、わずかな違いしかありません。

TinyCAD のバージョン間の正確な違いを知りたい場合は、[機能の違い](Feature-Differences/)ページをご覧ください。

## 警告
{: #warning}

**TinyCAD** は、オープンソースのコミュニティ主導プロジェクトとして無償で開発・提供されています。「現状有姿」で提供されており、バグや未完成の機能が含まれている場合があります。

作業内容をバックアップし、データの損失を防ぐ責任は利用者にあります。回路の製作や PCB の印刷を行う前に、慎重に確認する責任も利用者にあります。
