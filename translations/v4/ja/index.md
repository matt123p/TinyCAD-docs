# TinyCAD マニュアル
{: #tinycad-manual}

TinyCAD v4 は、デスクトップアプリとブラウザーで動作するオンラインアプリの両方で利用できます。両バージョン間の機能の違いは、わずかです。

TinyCAD のバージョン間の正確な違いを知りたい場合は、[機能の違い](Feature-Differences/) ページをご覧ください。

## 警告
{: #warning}

**TinyCAD** は、オープンソースのコミュニティ主導プロジェクトとして、無償で開発・提供されています。「現状のまま」提供されており、バグや未実装の機能が含まれている場合があります。  

作業内容をバックアップし、データの損失を防ぐことは、ご自身の責任です。回路の製作や PCB の印刷を行う前に、慎重に確認することもご自身の責任です。
