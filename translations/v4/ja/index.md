# TinyCAD マニュアル
{: #tinycad-manual}

TinyCAD v4 はデスクトップアプリとブラウザベースのオンラインアプリの両方で利用できます。両バージョンの機能の違いは
わずかです。

TinyCAD のバージョン間の正確な違いについては、[機能の違い](Feature-Differences/) ページをご覧ください。

## 警告
{: #warning}

**TinyCAD** はオープンソースのコミュニティ主導プロジェクトとして、無償で開発・提供されています。「現状のまま」提供されるため、バグや未完成の機能が含まれている場合があります。  

作業内容をバックアップし、データの損失を防ぐのはご自身の責任です。回路の製作や PCB の印刷を行う前に、十分に確認するのもご自身の責任です。

## このマニュアルへの貢献
{: #contribute-to-this-manual}

TinyCAD マニュアルはオープンソースで、GitHub Pages 上で管理されています。
