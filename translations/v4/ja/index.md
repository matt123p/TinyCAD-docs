# TinyCAD マニュアル
{: #tinycad-v4-manual}

TinyCAD v4 は、デスクトップアプリとブラウザー版のオンラインアプリの両方で利用できます。両バージョン間の機能の違いは、わずかです。

TinyCAD のバージョン間の正確な違いについては、[機能の違い](Feature-Differences/) ページをご覧ください。

## 警告
{: #warning}

**TinyCAD** は、オープンソースのコミュニティ主導プロジェクトとして、無償で開発・提供されています。現状のまま提供されており、バグや未実装の機能がある場合があります。  

作業内容をバックアップし、データの損失を防ぐ責任は利用者にあります。回路の製作や PCB の印刷を行う前に、十分に確認する責任も利用者にあります。

## このマニュアルへの貢献
{: #contribute-to-this-manual}

TinyCAD マニュアルはオープンソースで、GitHub Pages 上で管理されています。
誤字の修正、わかりやすい表現への改善、新しいスクリーンショットの追加、例の拡充など、コミュニティからの貢献を歓迎します。

- [マニュアルへの貢献方法](Contributing-to-the-Manual/)
