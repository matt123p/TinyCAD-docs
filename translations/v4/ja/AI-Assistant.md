# AIアシスタント
{: #ai-assistant}

TinyCADのAIアシスタントは、文章による指示、データシート、回路画像から、編集可能なシンボルや図面を作成します。通常のエディターと連携して動作し、回路の作成、現在開いている図面への部品の追加、シンボルライブラリの構築、既存の接続の説明を依頼できます。

**デスクトップ版のみ：** AIアシスタント（チャットボット）はTinyCAD Desktop Appでのみ利用できます。ブラウザー版では利用できません。

デスクトップアプリのツールバーで **チャット** を開きます。最初のメッセージを送信する前に、以下の手順でAIプロバイダーに接続してください。

## できること
{: #what-it-can-do}

| タスク | アシスタントの支援内容 |
| --- | --- |
| **コンポーネントシンボルを作成する** | 指定したコンポーネントとパッケージから、編集可能な図形、物理ピン番号、ピン名、電気的タイプを生成します。ピン配置が重要な場合は、メーカーのデータシートを添付してください。 |
| **シンボルライブラリを作成または拡張する** | 編集用に開いている `.tclib` ライブラリに、名前、説明、ピンの対応付けを含む複数の再利用可能なコンポーネントを追加します。大規模なコレクションは、複数回に分けて作成できます。 |
| **回路を描く** | 適切なシンボルを探し、部品を配置し、値とリファレンスを設定し、ピンをワイヤやラベルで接続して、説明用の注記を追加します。 |
| **既存の図面を拡張する** | 回路図のほかの部分はそのままに、コネクタ、デカップリングコンデンサ、センサー、ドライバー、または別の機能ブロックを追加する。 |
| **回路を説明または検査する** | 現在の回路図とネットリストを読み取り、信号経路を説明し、ネット上のピンを特定して、接続やデザインルールのエラーを調査する。 |
| **文書から回路図を再構成する** | 添付されたPDFまたは回路画像を読み取り、不明瞭な部分や接続について確認しながら、編集可能な出発点を作成する。 |
| **レイアウトを整える** | TinyCADのレイアウト機能と接続チェックを使用して、シート全体または指定した部分を再配置する。 |
| **結果をエクスポートする** | ファイルを明示的に依頼した場合に、ダウンロード可能な回路図またはシンボルライブラリを作成する。 |

結果はTinyCADオブジェクトであり、選択、編集、配線、保存が可能です。回路図では、新しく作成されたシンボルは接続できる状態で配置されます。ライブラリでは、新しいコンポーネントがそのライブラリのエントリになります。会話からXMLをコピーしたり、別のMCPサーバーを設定したりする必要はありません。

アシスタントはまず [同梱ライブラリ](../Bundled-Libraries/) を検索し、必要に応じて公開されているTinyCAD.netコレクションを検索します。ライブラリ選択ウィンドウで現在選択されていない同梱コレクションも検索できます。公開シンボルの検索には、ローカルAIモデルを使用する場合も含め、インターネット接続が必要です。

再利用可能な部品の場合は、まず [編集するカスタムライブラリを作成または開き](../Custom-symbol-libraries/)、そのライブラリウィンドウで［チャット］を開きます。回路図では、使用する回路図ウィンドウをアクティブにしておきます。対象のシート、部品参照、または機能ブロックをアシスタントに伝えてください。現在のAIによるシンボルの取得と配置は **単一ユニットのシンボル**に対応しています。アシスタントがインポートできない複数ユニットの部品には、通常のシンボルエディターを使用してください。

## 接続を設定する
{: #set-up-a-connection}

### 1. プロバイダーを選択する
{: #choose-a-provider}

1. ツールバーの **チャット** を開きます。
2. **ここをクリックしてサインインし、AIを使用する** をクリックするか、パネル上部の **AI設定** の歯車アイコンをクリックします。
3. **ステップ1 — プロバイダーを選択** でプロバイダーを選び、 **次へ** をクリックします。

![プロバイダーのステップが表示されたAI設定](../images/ai-assistant/setup-provider.png)

一度に接続できるプロバイダーは1つです。

| TinyCADでのプロバイダー | 必要なもの |
| --- | --- |
| **ChatGPT** | 対象となる有料アカウントで **ChatGPTでサインイン** を選ぶか、OpenAIのAPIキーで **APIキーを使用** を選びます。アカウントでのサインインはデスクトップアプリで利用できます。 |
| **Anthropic Claude** | [Claude Console](https://platform.claude.com/settings/keys) で発行したAPIキーが必要です。使用するモデルへのAPIアクセスと課金の設定も必要です。 |
| **Google Gemini** | [Google AI Studio](https://aistudio.google.com/apikey) で発行したAPIキーが必要です。一部のモデルには無料のAPI利用枠があり、利用できるモデルや上限はサービスの条件によって異なります。 |
| **OpenAI互換** | サービスのAPIキー、APIベースURL、およびツール呼び出しに対応したモデル。 |
| **Ollama（ローカルでホスト）** | 起動中のローカルOllamaサーバーと、ツールに対応したインストール済みモデル。ローカルモデルではAPIキーは不要です。 |

プロバイダーの通常のチャットWebサイトのサブスクリプションを契約していても、APIの課金やAPIキーが自動的に提供されるわけではありません。ChatGPTの明示的なアカウントサインインオプションは、別の接続方法です。Geminiの場合、ウィザードではAPIキーを使用します。TinyCADのGoogle Driveストレージへのサインインでは、AIアシスタントには接続されません。

### 2. アカウントまたはAPIキーを接続
{: #connect-an-account-or-api-key}

#### ChatGPTアカウントを使用する
{: #use-a-chatgpt-account}

TinyCAD Desktopで **ChatGPT** を選び、ステップ2で **ChatGPTでサインイン** を選択します。

1. **ChatGPTでサインイン** をクリックし、外部ブラウザーでサインインを完了します。
2. プロンプトが表示されたら、ChatGPTプランの使用を承認してください。プランの使用を有効にせずにサインインしただけでは、AIリクエストを送信できません。
3. ウィザードがステップ3に進んだら、TinyCADに戻ってモデルを選択します。

アカウントが記憶されている場合、画面には **…として続行** または **別のアカウントでサインイン**が表示されます。TinyCADで保持できるアカウントは一度に1つです。接続後は、 **ChatGPTプランの使用** と **使用状況の管理** がメッセージボックスの上に表示されます。初回使用時のメッセージには、リクエストがプランの利用枠または利用可能なクレジットを使用することが説明されています。

![「ChatGPTでサインイン」または「APIキーを使用」を提示するDesktop AI設定](../images/ai-assistant/setup-chatgpt-desktop.png)

ChatGPTでのサインインには対象となる有料アカウントが必要です。アカウント、ワークスペース、アプリの制限は引き続き適用されます。リクエストが拒否された場合に、APIキーによる課金へ暗黙に切り替わることはありません。OpenAI の [ChatGPTでのサインインに関するドキュメント](https://developers.openai.com/siwc/token-sharing-open-source) で、アカウントプランとの連携をご確認ください。

#### APIキーを使用
{: #use-an-api-key}

1. 手順2に表示されるプロバイダーのリンクからキーを作成します。プロジェクトまたはアカウントで、使用するモデルにアクセスできることを確認してください。
2. **ChatGPT** の場合は **APIキーを使用** を選択します。他のホスト型プロバイダーではキーの入力画面が直接表示されます。
3. キーを **APIキー**に貼り付けます。キーはマスクされます。 **APIキーを表示** を有効にすると、必要に応じて入力中にキーを確認できます。
4. **OpenAI互換** の場合は、サービスの **APIベースURL** も入力します。
5. **次へ** をクリックします。TinyCADが接続を確認し、利用可能なモデルを自動的に取得します。

![マスクされたキー入力欄とプロバイダーの案内を表示したChatGPT APIキー入力画面](../images/ai-assistant/setup-api-key.png)

エンドポイントからモデルの一覧を取得できない場合は、ステップ2で **モデルID** の入力が求められます。プロバイダーが指定する正確なIDを入力し、再度 **次へ** をクリックしてください。TinyCADは短いあいさつ文を送って接続を確認します。確認にプロバイダーの利用枠を消費する場合があります。接続に失敗するとステップ2に留まり、エラーが表示されます。

Geminiの場合は、Google AI Studioでプロジェクトを作成または選択し、そのAPIキーをTinyCADにコピーします。Googleの [Gemini APIの料金ページには](https://ai.google.dev/gemini-api/docs/pricing) 無料枠の対象となるモデルと利用条件が記載されています。有料モデルや利用量の増加には、課金が必要になる場合があります。

![Google AI Studioのキーへのリンクを使ったGoogle Geminiの設定](../images/ai-assistant/setup-gemini.png)

### 3. モデルと思考レベルを選択
{: #pick-a-model-and-thinking-level}

接続に成功したら、 **ステップ3 — モデルを選択** でモデルを選び、 **思考レベル** を調整して、 **完了** をクリックします。

![最終設定ステップでのモデル選択と思考スライダー](../images/ai-assistant/setup-model.png)

この図のモデル一覧は一例です。実際の一覧は、プロバイダー、エンドポイント、アカウントによって異なります。ChatGPTには、接続から返された対応モデルのSol、Luna、Astraが表示されます。新しいバージョンが先に表示され、古いモデルは **その他のモデル** の下に表示されます。また、最近選んだモデルが最大6つまで記憶されます。

TinyCADのドキュメントを確認・編集できるように、 **ツール呼び出し** に対応したモデルを選んでください。回路画像や図を含むデータシートを読み取るには、 **画像認識** にも対応したモデルが必要です。一般的なテキストチャット用のエンドポイントでは対応できない作業もあります。

**思考（Thinking）** は **最小** から **最大**まで選べ、初期設定は **中**です。利用できるレベルはプロバイダーによって異なります。設定を高くすると、処理に時間がかかり、利用枠を多く消費することがあります。「最大」は、そのプロバイダーが対応する最高レベルを意味します。メッセージボックスの横にあるモデルアイコンから、返信のたびにモデルと思考レベルを変更できます。

### 代替方法：ローカルのOllamaを使用する
{: #alternative-use-local-ollama}

1. [Ollamaをインストール](https://ollama.com/download) してサーバーを起動します。
2. [ツール呼び出しに対応したモデル](https://docs.ollama.com/capabilities/tool-calling) をダウンロードします。 `ollama pull MODEL_NAME` に実際のモデル名を指定して実行します。画像やPDFを扱う場合は、画像認識への対応状況とコンテキスト容量も確認してください。
3. TinyCADのプロバイダー選択画面で **Ollama（ローカルでホスト）** を選択します。
4. **Ollama API URL** に通常は `http://localhost:11434/v1` を指定します。 **次へ** をクリックすると、インストール済みのモデルが一覧表示されます。
5. モデルと思考レベルを選び、 **完了** をクリックします。

![ローカルAPI URLとブラウザーのオリジンに関するガイダンスを示すOllamaの設定](../images/ai-assistant/setup-ollama.png)

Ollama接続ではlocalhostやその他のループバックURLを使用できます。リモートサーバーに接続する場合は **OpenAI互換** を選びます。ローカルモデルには会話とTinyCADのツールに必要なコンテキスト容量を割り当ててください。詳しくは [Ollamaのコンテキスト設定](https://docs.ollama.com/api/openai-compatibility#setting-the-local-context-size) を参照してください。

ローカルOllamaへのリクエストはローカルサーバーに直接送信されます。ローカルで推論するには、ローカルで動作するモデルを選んでください。Ollamaサーバー経由で設定したクラウドモデルは、クラウドサービスを利用する場合があります。

## 作図中にアシスタントを使う
{: #use-the-assistant-while-drawing}

メッセージ欄に依頼を入力して **送信** をクリックするか、 **Enter** を押します。改行するには **Shift+Enter** を使います。まず範囲を絞った作業を依頼し、結果を確認してから次の変更を依頼してください。

![送信可能なリクエスト例が入力された、接続済みのチャットパネル](../images/ai-assistant/chat-ready.png)

対象のシート、参照番号、値、接続について具体的に指定してください。「配線を直して」よりも、「ControlシートでR2の上端をOUTに接続して」のほうが確認しやすくなります。既存の回路を拡張する場合は、変更せずに残すべき部分も明記してください。

アシスタントは、未保存のエディター内容を確認できます。作業内容を確認した後、通常の方法で図面またはライブラリを保存してください。図面にはシンボルが埋め込まれます。他のプロジェクトでも再利用する定義は、カスタムライブラリに保存してください。

**作業中** は、ツールの処理や途中経過を折りたたみ可能な行にまとめます。開くと、進捗の詳細、ツールの結果、モデルが確認した画像を表示できます。最終回答は別に表示されます。接続先が対応している場合、アシスタントはプロバイダーが提供する思考の要約を表示できます。これは、内部の推論過程をすべて明らかにする設定ではありません。

**停止** を選ぶと、現在のリクエストを取り消せます。適用済みの変更はドキュメントに残ります。AIによる編集でも通常の編集と同様に **元に戻す** と **やり直す** が使えます。複数の手順を含む依頼では、元に戻せる変更が複数作成されることがあります。アシスタントの作業中に図面を編集すると、参照している内容が古くなり、その後の書き込みが拒否されることがあります。図面を読み直して続行するよう依頼してください。

ヘッダーの **新しいチャット** アイコンを押すと、会話、下書き、添付ファイルが消去されます。図面への変更は元に戻りません。モデルを切り替えても会話は保持されますが、別のプロバイダーまたはキーに接続すると、新しいチャットが開始されます。

### データシートと回路画像を添付する
{: #attach-datasheets-and-circuit-images}

メッセージ入力欄の横にある **PDF/画像をインポート** ボタンから、PDF、PNG、JPEG、WebPファイルを添付できます。上限は **6ファイル、合計10 MiB** です。プロバイダー側の上限も適用されます。部品の型番や派生型、パッケージ、関連するPDFページを指定し、ピン図が上面図か下面図かを明記してください。

対応するエンドポイントやOllamaでは、 **PDFページ** にローカルで画像化するページを指定します。 `1-4,12` のように入力します。変換上限の20ページ以内で全ページを処理する場合は空欄にします。変換した画像が10 MiBを超える場合はページ数を減らしてください。ChatGPT/OpenAI、Claude、GeminiにはPDFが直接送信されます。図の読み取り能力はモデルによって異なります。

TinyCADの公開シンボルライブラリの検索は、一般的なWebブラウジングとは独立して利用できます。ネイティブのWeb検索は、対象となる **ChatGPTでサインイン** 接続で、モデルまたはアカウントのポリシーが許可している場合に利用できます。引用は回答内にリンクとして表示されます。APIキー接続やその他のプロバイダーでは、現在、TinyCADを介した一般的なWeb検索は利用できません。アシスタントがメーカーのWebサイトを開けない場合は、データシートまたは関連画像を添付してください。

## プロンプトの例
{: #example-prompts}

これらを出発点として使用してください。プロジェクトに応じて、コンポーネント、パッケージ、ピン番号、電源要件を置き換えてください。

### データシートからシンボルを作成する
{: #create-a-symbol-from-a-datasheet}

対象の図面を開き、データシートを添付します:

> このデータシートに基づいて、8ピンPDIPパッケージのNE555P用のコンパクトなシンボルを作成してください。物理ピン番号、名前、電気的タイプをすべて確認してください。まず既存のシンボルを検索してください。電源ピンを上、グランドを下に配置し、シンボルを検証して、この図面に配線できる状態で配置してください。確認できない項目があれば明示してください。

一般的なICの外形ではなく、物理的なモジュールの場合:

> このセンサーボードの正確なリビジョンのピン図を使って、PCBの外形と、物理的な順序でラベル付けされたヘッダー接点を示す編集可能なシンボルを作成してください。A4の配線図に収まるよう、コンパクトにしてください。接続点をヘッダーパッドに配置し、その機能を示す小さな温度アイコンを使用してください。

### 再利用可能なライブラリを作成する
{: #build-a-reusable-library}

まずカスタム `.tclib` を作成するか、編集用に開きます:

> 単一ユニットのインターフェース部品の小規模なライブラリを追加します。DIP-4のPC817、DIP-16のULN2003A、4極の2.54 mm端子コネクタを作成してください。ICのピン配置には添付のデータシートを使用します。各部品にわかりやすい名前、説明、リファレンス接頭辞を付け、検証して、この開いているライブラリに追加してください。現在編集中のシンボルはそのまま残してください。

最初に作成した部品を確認してから、次の一式に進んでください。 `.tclib` は通常どおり保存できます。ダウンロード用のライブラリが必要な場合は、その旨を明示して依頼してください。

### 回路全体を作成する
{: #create-a-complete-circuit}

> 現在のシートに、PDIP-8部品を使用した5 VのNE555非安定マルチバイブレータを描いてください。約1 Hzを目標にします。タイミング抵抗とコンデンサ、リセット接続、制御ピンのコンデンサ、電源デカップリング、電流制限抵抗付きの出力LEDを含めてください。計算したタイミングを説明し、実際のピン接続を確認して、レイアウトを整えてください。前提条件と未解決の設計規則上の問題を列挙してください。

これは編集可能な設計と計算を求めています。シミュレーションの動作を確認するには、モデルを確認し、 [シミュレーション](../Simulation/) を自分で実行してください。AIによる確信に満ちた説明は、シミュレータの実行記録ではありません。

### SPICEモデルを検索または添付する
{: #find-or-attach-a-spice-model}

SPICEまたはシミュレーションのサポートを明示的に依頼してください。アシスタントは、ウェブ検索なしで[同梱のSPICEモデル](../Bundled-SPICE-Models/)を検索し、そのソース、前提条件、端子の順序を確認できます。該当するモデルがない場合は、ドキュメント化されたドロップイン候補または汎用的な近似モデルを評価するよう依頼してください。パッケージのピン配置は別途確認してください。

> Q1用の同梱SPICEモデルを探し、端子がシンボルにどう対応するか教えてください。ソースと前提条件を確認するまで、図面は変更しないでください。

図面を変更するには、ピン配置を確認したうえでモデルを添付するようアシスタントに依頼してください。SPICE対応の再利用可能なライブラリコンポーネントを作成するよう依頼すると、今後の配置に備えて同梱定義またはカスタム定義を設定できます。

### 回路を描き直さずに部品を追加する
{: #add-parts-without-redrawing-the-circuit}

> U1の電源とグラウンドの間に、U1の近くに100 nFのデカップリングコンデンサを追加してください。配線する前に、実際の電源ピンを特定してください。回路の残りの部分、リファレンス、値は変更せず、影響を受けるネットを確認してください。

> Sensorsシートに、+3V3、GND、SDA、SCL用の4ピンコネクタをラベル付きで追加してください。SDAとSCLを既存のラベル付きネットに接続してください。既存のプルアップがあれば使用し、追加が必要な場合は、追加する前に知らせてください。

### 添付図を再現する
{: #reconstruct-an-attached-diagram}

> 添付PDFの3ページ目の回路を、新しいシート上に編集可能なTinyCAD部品と配線で再現してください。図に示された値とラベルを保持してください。読み取れない値や曖昧な配線の交差については、推測せずに確認してください。再構成したネットを画像と比較し、完成したシートを整えてください。

### 既存の図面について説明、確認、または改善する
{: #explain-inspect-or-improve-an-existing-drawing}

> J1からU2までの信号経路を説明し、OUTに接続された部品と物理ピンを列挙してください。図面は変更しないでください。

> 現在の図面について、接続されていない必須ピン、出力同士の競合、電源ラベルの不整合を確認してください。問題ごとにシートとリファレンスを報告し、適用する前に変更案を提示してください。

> U3とJ4周辺のモータードライバーブロックだけを整えてください。接続と値は変更せず、電源入力ブロックはそのままの位置に残してください。

## 設定、プライバシー、保存
{: #settings-privacy-and-saving}

**AI設定** の歯車アイコンを開くと、現在のプロバイダーと接続方法が表示され、モデルと思考レベルを設定して **保存** できます。APIキーで接続している場合は **APIキーを消去**、ChatGPTアカウントで接続している場合は **サインアウト**、ローカルのOllamaに接続している場合は **Ollamaを切断** が表示されます。別のプロバイダーを設定する前に、現在の接続を解除してください。 **キャンセル** を選ぶと、現在の接続と保存済みの設定が維持されます。

![既存のAPIキー接続のAI設定](../images/ai-assistant/connection-settings.png)

APIキーと会話履歴はアプリケーションのメモリ内に保持されます。キーは設定や図面とともに保存されません。再読み込み／再起動後は、APIキーを再入力する必要があります。機密情報ではないプロバイダー、エンドポイント、モデル、思考に関する設定は記憶させることができます。ChatGPTアカウントの認証はローカルランタイムで個別に管理され、再起動後も保持される場合があります。Desktopでは、利用可能な場合、安全なOS暗号化が使用されます。

ホスト型AIを使用する場合、メッセージ、添付ファイル、およびツールが要求するドキュメントの内容やプレビューは、選択したプロバイダーに送信されます。ホスト型のAPIキー接続では、リクエストは選択したエンドポイントに直接送信されます。TinyCADはプロバイダーへの中継を行いません。互換性のあるサービスでは、ブラウザーからのアクセス（CORS）が許可されている必要があり、通常はHTTPSを使用します（例外はlocalhostです）。完全にローカルなワークフローにするには、ローカルのOllamaモデルと付属のローカル参照ドキュメントを使用し、オンラインでのシンボル検索やクラウドモデルは避けてください。

生成された部品や回路にも、エンジニアリングレビューが必要です。実際のデータシートを参照して、正確なパッケージのピン配置、電力定格、電源電圧、ロジックレベル、動作限界を確認してください。TinyCADの構造検証、設計ルールチェック、レイアウト接続チェックはエラーの発見に役立ちますが、回路が動作することを証明するものではなく、シミュレーションに代わるものでも、ハードウェアが試験済みであることを示すものでもありません。

## トラブルシューティング
{: #troubleshooting}

| 症状 | 確認する項目 |
| --- | --- |
| **チャットを利用できない、または見つからない** | 最新版のTinyCAD v4ビルドを使用してください。目的の図面またはライブラリを開き、ツールバーに「Chat」があるか確認してください。 |
| **ChatGPTアカウントでのサインインを利用できない** | Desktop、またはアカウントランタイムを備えたローカルホスト版を使用してください。公開ホスト版アプリでは、「Use API Key」を選択してください。外部サインインウィンドウを許可し、同意時にChatGPTプランの利用を有効にしてください。 |
| **ステップ2から先に進めない** | 接続エラーの内容を確認してください。キー、モデルへのアクセス権、APIの請求額／利用上限、エンドポイントURL、インターネット接続を確認してください。TinyCADは「Next」をクリックしたときにこの確認を行います。 |
| **モデルが表示されない** | プロバイダーへのアクセスを確認してください。モデルの自動検出に対応していないエンドポイントでは、要求されたModel IDを入力してください。Ollamaに接続する前に、ツールに対応したモデルをインストールしてください。 |
| **ローカルのOllamaに接続できない** | サーバーを起動し、ローカルAPI URLを確認してください。OLLAMA_ORIGINSでTinyCADの正確なオリジンを許可し、Ollamaを再起動してください。要求された場合は、ブラウザーによるローカルネットワークへのアクセスも許可してください。 |
| **アシスタントは応答するが、編集や画像の読み取りができない** | モデルがツール／画像認識に対応しているか確認してください。読みやすい範囲を切り抜いて添付するか、PDFのページ数を減らしてください。 |
| **ツールから図面が変更されたと報告される** | アシスタントに現在の状態を再読み込みさせてから、再試行してください。適用済みの変更は「Undo」で元に戻せます。 |
| **プロバイダーの上限に達して返信が止まる** | 作業を小分けにするか、思考レベルを下げてください。TinyCADは未完了の返信を自動で再試行できます。再試行で追加の利用枠を消費する場合があります。適用済みの変更は元に戻せます。 |
