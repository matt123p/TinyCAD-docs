# 同梱ライブラリ
{: #bundled-libraries}

同梱ライブラリは、ブラウザー版とデスクトップアプリ版の TinyCAD に付属する、すぐに配置できるシンボルのコレクションです。機器の配置図から電子回路まで幅広く収録されています。サインインやライブラリファイルのダウンロード、ライブラリフォルダーの設定を行わずに使用できます。

## コンポーネントを検索して配置する
{: #find-and-place-a-component}

1. 左側のライブラリパネルを開きます。折りたたまれている場合は、展開ボタンを使用します。
2. **Standard** を選択します。**Online** ではオンラインコレクションを検索し、**My Libraries** には独自のライブラリファイルが含まれています。
3. **標準ライブラリを選択 (Choose a standard library)** を使用してコレクションを選択します。TinyCAD は一度に1つの標準ライブラリを読み込み、このデバイスで選択内容を記憶します。
4. リストを参照するか、**ライブラリを検索... (Search libraries...)** に名前または説明を入力します。各検索結果には図柄のプレビューが表示されます。検索結果を選択すると、拡大プレビューと説明を確認できます。
5. コンポーネントのプレビューを図面にドラッグします。グリッド上に配置します。複製の配置を終えたら、**Escape** キーを押すか、右クリックします。

選択中のライブラリを変更しても、すでに配置したコンポーネントは削除されません。定義は図面に埋め込まれるため、図面を開く人が同じライブラリを読み込む必要はありません。標準ライブラリは読み取り専用です。独自のシンボル定義を管理する場合は、[カスタムライブラリ](../Custom-symbol-libraries/) を使用してください。

## 機器およびレイアウトライブラリ
{: #equipment-and-layout-libraries}

これらのライブラリには、機器、基板、端子、ソケットの物理的な配置が示されています。**何と何が接続されるか**を説明するのに役立ちます。実行可能なファームウェア、機械シミュレーション、SPICEモデルは含まれていません。

| ライブラリ | 内容 | 主な用途 |
| --- | --- | --- |
| **ネットワークレイアウト** — 47シンボル | コンシューマー向けルーター、スイッチ、アクセスポイント。同等の19インチラック用スイッチ、ルーター、ファイアウォール、パッチパネル、ブランクパネル | オフィスの配線、ホームネットワーク、ラックの配置図 |
| **組み込みプロセッサーとスマートホーム** — 44シンボル | 10種類のコントローラーボード、26種類のセンサー／アクチュエーターモジュール、8種類のディスプレイ | センサーステーション、ホームオートメーション、組み込みプロジェクトの試作 |
| **オーディオと音楽** — 99シンボル | マイク、ミキサー、インターフェース、楽器、MIDI、コンピューター、コネクター、ヘッドホン、スピーカー、アンプ、ステージ機器 | ライブ、スタジオ、ポッドキャスト、自宅録音、教会、学校 |
| **試験・計測** — 78シンボル | 電源、負荷、オシロスコープ、メーター、RF計測器、プローブ、データ収集装置、ヒーター、リレー、制御装置、ポンプ、ベンチ装置 | 実験室での接続、実験のセットアップ |
| **モーターとモーション** — 66シンボル | DCモーター、ブラシレスモーター、ステッピングモーター、サーボ、ドライバーボード、エンコーダー、リミットスイッチ、ソレノイド、電動／空圧アクチュエーター、機械部品 | ロボット工学、自動化、モーション制御配線 |
| **太陽光発電とバッテリー** — 52シンボル | パネル、アレイ、インバーター、バッテリー、EV充電器、バックアップ機器、保護装置、監視装置、家庭用負荷 | 家庭用エネルギーシステムの概念図と、その電力／制御接続 |

### ネットワークレイアウト
{: #network-layout}

Ethernet接続点はソケットの中央にあります。1つの点は、Ethernetの8本の導体それぞれではなく、**ケーブル全体**を表します。デスクトップスイッチは、PoE対応や銅線／光ファイバー混在の選択肢を含め、銅線ポートが4、5、8、16、24個のものを収録しています。ラックレイアウトには、2個または4個のケージ型SFP+アップリンクを備えた8／16／24／48ポート構成のほか、銅線ポートが10個および32個の汎用的な追加計画用レイアウトがあります。これらは利用可能なシンボルの選択肢として捉え、すべてのレイアウトが同じ程度に一般的だという意味には捉えないでください。必要なポート数とアップリンク構成を選ぶには、シンボル名と前面パネルのラベルを確認してください。

19インチ1Uパネルは共通サイズです。既定の縮尺を保ち、垂直方向に**120 drawing units**間隔で重ねてラックを作成します。[Small office network example](../Bundled-Examples/#equipment-and-layout-examples)では、同じパネルを4枚と、アクセスポイントおよびデスクスイッチまでの長い配線を示しています。各パッチケーブルはソケットの接続点まで描画してください。パネルの図柄によって、異なるソケットが内部で自動的に接続されることはありません。

### 組み込みプロセッサとスマートホーム
{: #embedded-processors-and-smart-home}

コントローラボードには、ESP32 DevKitC V4、ESP32-S3 DevKitC-1、NodeMCU ESP8266、LOLIN D1 mini、Raspberry Pi 3/4/5、Arduino Uno/Nano/Mega各種があります。センサモジュールには、温度、湿度、光、圧力、タッチ、パッシブ赤外線の各センサがあり、ブザーなどの出力も用意されています。PCB、ヘッダーパッド、ピンのラベルは表示されたままで、センサは無地のチップ形状ではなく、小さな機能アイコンで識別できます。

ディスプレイには、I2C LCD1602および128×64 OLED、Waveshare 1.8インチSPI LCDおよび2.8インチ静電容量式タッチLCD、Nextion 2.8インチUARTタッチディスプレイ、Waveshare 2.13/2.9/4.2インチ電子ペーパーアセンブリがあります。各シンボルは、**1つのデバイス**を2つの表示で表しています。左側は画面の正面、右側は背面とヘッダーの接点です。電気的な接続点となるのは背面の接点だけです。ヘッダーが複数ある場合、同じハードウェア信号を公開していることがあります。独立した追加チャンネルではありません。ラベルと指定されたリビジョンを確認してください。

配線する前に、指定されたボードのリビジョンを確認してください。Raspberry Piのヘッダーでは、**物理ピン番号とBCM GPIO名は異なる番号体系**です。ボード上のピン位置は配線図の作成に役立ちますが、図柄はPCBフットプリントでも製造図面でもありません。電源レール、ロジックレベル、電流制限、プルアップについては、実際のモジュールのドキュメントを確認する必要があります。

### オーディオ、実験室およびモーション接続
{: #audio-laboratory-and-motion-connections}

オーディオ図では、ほとんどのソケットはケーブル全体を表します。マイク、ライン、スピーカー、ヘッドホンおよびMIDIの経路には、その用途が明確になるようにラベルを付けてください。コネクタを描いただけでは、2台の機器のレベル、平衡配線、またはファンタム電源の要件に互換性があることは示されません。

実験室およびモーション用のシンボルでは、個々の電線、ケーブル全体、および流体ホースを区別します。たとえば、BNC/USB接続はケーブルを表しますが、モータードライバーの電源、ロジック、およびモーター用端子はそれぞれ別の電線です。機械部品のみの部品には、電気端子がない場合があります。表示されているすべての要素が接続だと決めつけず、ピンラベルとシンボルの説明を参照してください。

**Test & Measurement機器のシンボルは、セットアップ図用の図です。** シミュレーション信号を取得する機器には、**Simulation → Lab Equipment**を使用してください。[ソースと仮想計測器](../Simulation-Sources-and-Instruments/)を参照してください。

太陽光発電のシンボルは、ケーブル全体または論理リンクを表します。これらはシステム構成を示すものであり、個々の設置端子、ケーブル定格、または完全な保護方式を規定するものではありません。
## シミュレーションモデルを備えたライブラリ
{: #libraries-with-simulation-models}

回路シミュレーションを[実行](../Simulation/)する場合は、これらのコレクションを使用してください。

| ライブラリ | 内容 | モデリングの目的 |
| --- | --- | --- |
| **SPICE essentials** — 29個のシンボル | 受動部品、電源、ダイオード、LED、トランジスタ、トランス、共振器、741、LM358、LM324 | [同梱モデルとプリセットされたピン割り当て](../Bundled-SPICE-Models/)を備えたアナログ部品 |
| **Digital logic** — 28個のシンボル | ゲート、カウンター、記憶素子 | 移植性のあるアナログSPICEモデルを使用して実装された、設定可能な論理動作 |
| **Functional blocks** — 17個のシンボル | ADC/DAC、通信インターフェース、状態機械、プログラマブルI/Oブロック | 完全なチップを実装せずに、システムレベルの動作を検討する |
| **Sensors and interfaces** — 10個のシンボル | モデル化されたセンサー、テストポイント、アナログスイッチ、AM変調器 | 設定した刺激と電気出力の関係を確認する |

これらのモデルは、動作を検討するための近似モデルです。特定メーカーのデバイス性能を保証するものではありません。機能ブロックのマイクロコントローラー、PLC、FPGAは、ファームウェアやHDLを実行しません。**Digital logic**ライブラリはアナログ動作モデルを使用し、ブラウザーで実行できます。別の[XSPICEコース](../XSPICE-Tutorial/)では、Desktopのイベント駆動エンジンを使用します。

各モデルのプロパティ、単位、ピン割り当てを確認してください。論理モデルには、**VCC**や**VSS**という名前の非表示電源ピンがある場合があります。対応する電源ネットを用意し、**VSS**をSPICEのグラウンド**0**に接続してください。GNDという語を含むラベルを付けただけでは、ノード0は作成されません。

## 配線を明確にする
{: #make-wiring-unambiguous}

グリッドをオンにし、配線を実際の接続点で終端します。無関係なソケットや別の配線の終端に触れている配線は、電気的な接続を作る場合があります。そうした点を避けて配線してください。見た目が整った線であるだけでは、意図したネットリストが確立されるとは限りません。

使用していない機器のソケットは未接続のままにできます。これらの図では、物理的なパネルの輪郭に配線が入り込んでいることについて、回路チェッカーが通知を出すのは想定内ですが、意図しない短絡や接合点は修正してください。電気的な接続については[配線](../Wires/)を、これらのコレクションを使ったレイアウト例については[同梱のサンプル](../Bundled-Examples/)を参照してください。
