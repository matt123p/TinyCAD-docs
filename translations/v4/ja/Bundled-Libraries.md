# 同梱ライブラリ
{: #bundled-libraries}

同梱ライブラリは、TinyCAD のブラウザー版と Desktop App の両方で提供される、すぐに配置できるシンボルのコレクションです。機器レイアウトから電子回路までを網羅しています。サインインしたり、ライブラリファイルをダウンロードしたり、ライブラリフォルダーを設定したりせずに使用できます。

## コンポーネントを検索して配置する
{: #find-and-place-a-component}

1. 左側のライブラリパネルを開きます。折りたたまれている場合は、展開ボタンを使用します。
2. **Standard** を選択します。**Online** はオンラインコレクションを検索し、**My Libraries** には独自のライブラリファイルが含まれます。
3. **Choose a standard library** を使用してコレクションを選択します。TinyCAD は一度に1つの標準ライブラリを読み込み、このデバイスで選択内容を記憶します。
4. リストを参照するか、**Search libraries...** に名前または説明を入力します。各検索結果にはアートワークのプレビューがあります。検索結果を選択すると、拡大プレビューと説明を確認できます。
5. コンポーネントのプレビューを図面にドラッグします。グリッド上で位置を決めます。複数のコピーの配置が終わったら、**Escape** を押すか右クリックします。

選択中のライブラリを変更しても、すでに配置したコンポーネントは削除されません。定義は図面に埋め込まれるため、図面を開く人が同じライブラリを読み込む必要はありません。標準ライブラリは読み取り専用です。独自のシンボル定義を管理する場合は、[カスタムライブラリ](../Custom-symbol-libraries/)を使用してください。

## 機器およびレイアウトライブラリ
{: #equipment-and-layout-libraries}

これらのライブラリは、機器、基板、端子、ソケットの物理的な配置を示します。**何が何に接続されるか**を説明するのに役立ちます。実行可能なファームウェア、機械シミュレーション、SPICE モデルは含まれません。

| ライブラリ | 内容 | 主な用途 |
| --- | --- | --- |
| **Network layout** — 47 個のシンボル | コンシューマー向けルーター、スイッチ、アクセスポイント、対応する19インチラック用スイッチ、ルーター、ファイアウォール、パッチパネル、ブランクパネル | オフィス配線、ホームネットワーク、ラック計画 |
| **Embedded processors and smart home** — 44 個のシンボル | 10種類のコントローラーボード、26種類のセンサー／アクチュエータモジュール、8種類のディスプレイ | センサーステーション、ホームオートメーション、組み込みプロジェクトの試作 |
| **Audio & Music** — 99 個のシンボル | マイク、ミキサー、インターフェース、楽器、MIDI、コンピューター、コネクター、ヘッドホン、スピーカー、アンプ、ステージ機器 | ライブ演奏、スタジオ、ポッドキャスト、自宅録音、教会、学校 |
| **Test & Measurement** — 78 個のシンボル | 電源、負荷、オシロスコープ、メーター、RF 計測器、プローブ、データ収集、ヒーター、リレー、制御機器、ポンプ、実験台機器 | 実験室の接続と実験セットアップ |
| **Motors & Motion** — 66 個のシンボル | DC モーター、ブラシレスモーター、ステッピングモーター、サーボ、ドライバーボード、エンコーダー、リミットスイッチ、ソレノイド、電動／空圧アクチュエーター、機械部品 | ロボット、オートメーション、モーション制御の配線 |
| **Solar power and batteries** — 52 個のシンボル | パネル、アレイ、インバーター、バッテリー、EV 充電器、バックアップ機器、保護機器、監視機器、家庭内負荷 | 住宅用エネルギーシステムと電力／制御リンクの概念図 |

### Network layout
{: #network-layout}

Ethernet の接続点はソケットの中央にあります。1つの接続点は、Ethernet の8本の導体それぞれではなく、**ケーブル全体**を表します。デスクトップスイッチには、PoE 対応や銅線／光ファイバー混在のオプションを含む、4、5、8、16、24ポートの銅線ポートモデルがあります。ラックレイアウトには、2個または4個のケージ型 SFP+ アップリンクを備えた8／16／24／48ポート構成のほか、銅線ポートが10個および32個の汎用計画用レイアウトもあります。これらは利用可能なシンボルの選択肢であり、すべてのレイアウトが同じように一般的だという意味ではありません。必要なポート数とアップリンク構成を選ぶ際は、シンボル名とフロントパネルのラベルを確認してください。

19インチ1Uパネルは共通のサイズです。デフォルトの縮尺を維持し、垂直方向に **120 drawing units** の間隔で積み重ねるとラックを作成できます。[小規模オフィスネットワークの例](../Bundled-Examples/#equipment-and-layout-examples)では、対応する4つのパネルと、アクセスポイントおよびデスクスイッチまでの長い配線を示しています。各パッチケーブルは、ソケットの接続点まで配線してください。パネルの図柄によって、異なるソケット同士が内部で自動的に接続されることはありません。

### Embedded processors and smart home
{: #embedded-processors-and-smart-home}

コントローラーボードには、ESP32 DevKitC V4、ESP32-S3 DevKitC-1、NodeMCU ESP8266、LOLIN D1 mini、Raspberry Pi 3/4/5、Arduino Uno/Nano/Mega の各種モデルがあります。センサーモジュールには、温度、湿度、光、圧力、タッチ、受動赤外線センサーのほか、ブザーなどの出力が含まれます。PCB、ヘッダーパッド、ピンラベルは表示されたままになり、機能を示す小さなアイコンによって、無名のチップ矩形ではなくセンサーであることが分かります。

ディスプレイの選択肢には、I2C LCD1602 と 128×64 OLED、Waveshare 1.8インチ SPI LCD と 2.8インチ静電容量式タッチ LCD、Nextion 2.8インチ UART タッチディスプレイ、Waveshare 2.13/2.9/4.2インチ電子ペーパーアセンブリーがあります。各シンボルは、**1つのデバイス**を2つの視点で表しています。左側が画面正面、右側が背面／ヘッダー接点です。電気的な接続点は背面の接点だけです。ヘッダーが繰り返し表示されていても、同じハードウェア信号が露出している場合があります。独立した追加チャンネルではありません。ラベルと明記されたリビジョンに従ってください。

配線する前に、明記されたボードのリビジョンを確認してください。Raspberry Pi のヘッダーでは、**物理ピン番号と BCM GPIO 名は異なる番号体系**です。ボード上のピン位置は配線図の作成に役立ちますが、図柄は PCB フットプリントでも製造図面でもありません。電源レール、ロジックレベル、電流制限、プルアップについては、実際のモジュールのドキュメントを確認する必要があります。

### オーディオ、実験室、モーションの接続
{: #audio-laboratory-and-motion-connections}

オーディオ図では、ほとんどのソケットがケーブル全体を表します。マイク、ライン、スピーカー、ヘッドホン、MIDI の経路にラベルを付け、用途が明確になるようにしてください。コネクターを図示しただけでは、2台の機器のレベル、平衡配線、ファンタム電源の要件に互換性があることにはなりません。

実験室およびモーション用のシンボルでは、個々の電気導体、ケーブル全体、流体ホースを区別しています。たとえば、BNC/USB 接続はケーブルを表しますが、モータードライバーの電源端子、ロジック端子、モーター端子はそれぞれ別の導体です。機械専用部品には電気端子がない場合があります。目に見えるものすべてが接続点だと決めつけず、ピンラベルとシンボルの説明を確認してください。

**試験・測定機器のシンボルは、セットアップ図用の画像です。** シミュレーション信号を取得する計測器には、**シミュレーション → ラボ機器**を使用してください。[信号源と仮想計測器](../Simulation-Sources-and-Instruments/)を参照してください。

太陽光発電のシンボルは、ケーブル全体または論理リンクを表します。システムアーキテクチャを説明するものであり、個々の設置端子、ケーブル定格、完全な保護方式を規定するものではありません。

## シミュレーションモデルを含むライブラリ
{: #libraries-with-simulation-models}

回路シミュレーションを[実行する](../Simulation/)場合は、これらのコレクションを使用してください。

| ライブラリ | 内容 | モデル化の目的 |
| --- | --- | --- |
| **SPICE essentials** — 27 個のシンボル | 受動部品、ソース、ダイオード、LED、トランジスタ、トランス、741型アンプ | モデル化されたアナログコンポーネントの基本セット |
| **Digital logic** — 28 個のシンボル | ゲート、カウンター、記憶素子 | 移植性のあるアナログ SPICE モデルで実装された、設定可能なロジック動作 |
| **Functional blocks** — 17 個のシンボル | ADC/DAC、通信インターフェース、状態機械、プログラマブル I/O ブロック | 完全なチップを実装せずにシステムレベルの動作を検討 |
| **Sensors and interfaces** — 10 個のシンボル | モデル化されたセンサー、テストポイント、アナログスイッチ、AM 変調器 | 設定した刺激と電気出力の関係を確認 |

これらのモデルは動作を検討するための近似モデルです。特定メーカーの製品性能を保証するものではありません。機能ブロックとしてのマイクロコントローラー、PLC、FPGA は、ファームウェアや HDL を実行しません。**Digital logic** ライブラリはアナログのビヘイビアモデルを使用し、ブラウザーで実行できます。別の [XSPICE コース](../XSPICE-Tutorial/)では、Desktop のイベント駆動エンジンを使用します。

各モデルのプロパティ、単位、ピン割り当てを確認してください。ロジックモデルには、**VCC** と **VSS** という名前の非表示電源ピンがある場合があります。対応する電源ネットを用意し、**VSS** を SPICE グラウンド **0** に接続してください。GND という語を含むラベルを付けても、それだけではノード0は作成されません。

## 配線を明確にする
{: #make-wiring-unambiguous}

グリッドをオンにし、実際の接続点で配線を終端してください。無関係なソケットや別のワイヤーの端点に触れているワイヤーは、電気的な接続を作る場合があります。それらの点を避けて配線してください。見た目が整っているだけでは、意図したネットリストが作成されたことにはなりません。

使用していない機器のソケットは未接続のままにできます。これらの図面では、物理パネルの外形にワイヤーが入ることについて回路チェッカーが通知する場合がありますが、これは想定内です。ただし、意図しない短絡や接合点は修正する必要があります。電気的な接続については[ワイヤー](../Wires/)を、これらのコレクションを使ったレイアウト例については[同梱例](../Bundled-Examples/)を参照してください。
