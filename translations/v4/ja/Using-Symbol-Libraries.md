# シンボルライブラリの使用
{: #using-symbol-libraries}

## シンボルライブラリとは？
{: #what-is-a-symbol-library}

回路設計において、**シンボルライブラリ**とは、1つのファイルに保存された回路図シンボルの集まりです。各シンボルは、抵抗器、コンデンサ、IC、コネクタ、トランジスタなどの電子部品、あるいはその他の部品を、定義済みの電気的接続点を備えた標準化された図形で表します。

TinyCADのシンボルライブラリは、`.tclib`ファイル形式を使用します。1つのライブラリファイルには、通常、カテゴリや用途ごとに分類された、関連する数十から数百のシンボルを格納できます。たとえば、受動部品用、ロジックIC用、コネクタ用に、それぞれ別のライブラリを用意できます。

## シンボルライブラリの用途
{: #what-are-symbol-libraries-used-for}

シンボルライブラリは、回路図作成において次のような重要な役割を果たします。

- **設計間での再利用。** シンボルをライブラリに定義しておけば、作り直すことなく、どの回路図にも配置できます。これにより時間を節約し、プロジェクト間で一貫性を保てます。
- **標準化された表現。** ライブラリによって、各部品の共通の視覚的スタイルとピン構成が統一されます。555タイマーやオペアンプは、どのインスタンスも同じ外観とピン定義になるため、誤解が減ります。
- **電気的な正確性。** 各シンボルには、ピン名、ピン番号、電気的な種類（入力、出力、電源、受動など）といったピン情報が含まれています。このデータは、ネットリストの生成、デザインルールチェック、PCBレイアウトツールへのエクスポートなど、後続の処理に使用されます。
- **整理。** シンボルを機能、メーカー、またはプロジェクトごとにライブラリにまとめると、適切な部品を簡単に見つけられます。TinyCADでは、設計ごとに必要なライブラリだけを読み込めます。
- **共有と共同作業。** ライブラリファイルは、チームメンバー間で共有したり、コミュニティからダウンロードしたりできるため、全員が検証済みの同じシンボル定義を使用できます。

## 組み込みライブラリとカスタムライブラリ
{: #built-in-and-custom-libraries}

TinyCADには、一般的な部品ファミリーを網羅した組み込みライブラリが付属しています。含まれていない部品については、次のことができます。

- 独自の[カスタムシンボルライブラリ](../Custom-symbol-libraries/)を作成する
- [KiCADからシンボルを](../Importing-Symbols-from-KiCAD/)インポートする
- TinyCAD.netのウェブサイトから追加のライブラリをダウンロードする

## 一般的なワークフロー
{: #typical-workflow}

実際には、シンボルライブラリを使う作業は、通常、次のような流れで進めます。

1. 現在のTinyCADセッションで使用するライブラリを読み込むか、追加します。
2. それらのライブラリからシンボルを参照、検索、プレビューします。
3. シンボルを図面に配置します。
4. シンボル定義を変更する必要がある場合は、配置済みのインスタンスではなくライブラリを編集します。

このページでは手順1～3を説明します。ライブラリファイルの管理については、[カスタムシンボルライブラリ](../Custom-symbol-libraries/)を参照してください。シンボル定義自体の変更については、[シンボルの編集](../Editing-a-Symbol/)を参照してください。

## ライブラリの読み込み
{: #loading-libraries}

シンボルを配置するには、そのライブラリをTinyCADで利用できる状態にする必要があります。

- 組み込みライブラリはTinyCADの一部として利用できます。
- カスタムライブラリは、参照する前に追加または開く必要があります。
- 正確な手順は、TinyCAD Webとデスクトップアプリケーションで異なります。

ライブラリファイルの追加、オープン、更新、作成、編集に関する製品ごとの手順については、[カスタムシンボルライブラリ](../Custom-symbol-libraries/)を参照してください。

## 参照、検索、プレビュー
{: #browsing-searching-and-previewing}

ライブラリのシンボルを使用するには、まずTinyCADセッションにライブラリを読み込む必要があります。読み込み後は、次の操作を行います。

1. シンボル選択画面を開きます。
2. ライブラリを展開して内容を参照するか、検索ボックスを使って名前または説明からシンボルを検索します。
3. シンボルをクリックしてプレビューします。
4. シンボルを選択してアクティブな配置ツールにし、図面内をクリックしてインスタンスを配置します。

シンボルを選択した後の配置と設定について詳しくは、[シンボル](../Symbols/)を参照してください。

## ライブラリパネルのサイズ変更
{: #resizing-the-library-panel}

ライブラリパネルの右端をドラッグすると、幅を広げたり狭めたりできます。幅を広げると、長いシンボル名や説明を確認しやすくなります。ローカルストレージが利用できる場合、TinyCADはこのデバイス上でパネルの幅を記憶します。

## シンボルの並べ替え
{: #sorting-symbols}

**My Libraries**では、ライブラリの操作ボタンの横にある並べ替えボタンを使って、**ライブラリ順**、**AからZ**、**ZからA**を切り替えます。ボタンのツールチップには現在のモードが表示されます。
並べ替えは、ライブラリ内のシンボルと検索結果（オンラインの検索結果を含む）に適用されます。ライブラリファイルやフォルダーの並べ替えは行いません。ローカルストレージが利用可能な場合、TinyCADはこのデバイスで並べ替えモードを記憶します。

ブラウザーのファイルシステム版ではオンライン検索のみが表示され、**My Libraries**の並べ替えボタンは表示されません。

## 図面へのシンボルの配置
{: #placing-symbols-in-a-drawing}

ライブラリブラウザーでシンボルを選択すると、そのシンボルがアクティブな配置ツールになります。

選択後のシンボルの動作を含む、実際の配置手順については、[シンボル](../Symbols/)を参照してください。

図面にシンボルを配置しても、ライブラリ定義は編集され**ません**。今後の使用に備えてグラフィック、ピン、または属性を変更する必要がある場合は、代わりにライブラリ内のシンボルを編集してください。[シンボルの編集](../Editing-a-Symbol/)を参照してください。
