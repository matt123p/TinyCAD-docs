# シンボルライブラリの使用
{: #using-symbol-libraries}

## シンボルライブラリとは？
{: #what-is-a-symbol-library}

回路設計において、**シンボルライブラリ**とは、1つのファイルに保存された回路図シンボルの集合です。各シンボルは、抵抗器、コンデンサ、IC、コネクタ、トランジスタなどの電子部品や、その他の部品を、電気的な接続点を定義した標準化された図形として表します。

TinyCADのシンボルライブラリは、`.tclib`ファイル形式を使用します。1つのライブラリファイルには、通常はカテゴリや用途ごとにまとめられた、関連するシンボルを数十個から数百個含めることができます。たとえば、受動部品用、ロジックIC用、コネクタ用のライブラリをそれぞれ作成できます。

## シンボルライブラリの用途
{: #what-are-symbol-libraries-used-for}

シンボルライブラリは、回路図作成において、次のような重要な役割を果たします。

- **設計間での再利用。** シンボルを一度ライブラリに定義すれば、作り直すことなく、どの回路図にも配置できます。これにより時間を節約し、プロジェクト間の一貫性を保てます。
- **標準化された表現。** ライブラリによって、各部品の共通の外観とピン構成が維持されます。555タイマーやオペアンプのすべてのインスタンスが同じ外観と同じピン定義を持つため、誤解を減らせます。
- **電気的な正確性。** 各シンボルにはピン情報（ピン名、番号、電気的な種類（入力、出力、電源、受動など））が含まれます。このデータは、ネットリスト生成、デザインルールチェック、PCBレイアウトツールへのエクスポートなど、後続の処理に使用されます。
- **整理。** 機能、メーカー、プロジェクト別にシンボルをライブラリにまとめると、目的の部品を簡単に見つけられます。TinyCADでは、設計ごとに必要なライブラリだけを読み込めます。
- **共有と共同作業。** ライブラリファイルはチームメンバー間で共有したり、コミュニティからダウンロードしたりできるため、全員が検証済みの同じシンボル定義を使用できます。

## 組み込みライブラリとカスタムライブラリ
{: #built-in-and-custom-libraries}

TinyCADには、機器レイアウトやモデル化された電子回路用の[同梱ライブラリ](../Bundled-Libraries/)が付属しています。左側の選択欄で**Standard**を選択し、次に**Choose a standard library**からコレクションを選択してください。別途ライブラリをインポートする必要はありません。含まれていない部品については、次の方法があります。

- 独自の[カスタムシンボルライブラリ](../Custom-symbol-libraries/)を作成する
- [KiCADの](../Importing-Symbols-from-KiCAD/)ライブラリからシンボルをインポートする
- TinyCAD.netのウェブサイトから追加のライブラリをダウンロードする

## 一般的なワークフロー
{: #typical-workflow}

実際にシンボルライブラリを使用する際は、通常、次の順序で作業します。

1. 現在のTinyCADセッションで使用するライブラリを読み込むか、追加します。
2. それらのライブラリからシンボルを参照、検索、プレビューします。
3. シンボルを図面に配置します。
4. シンボル定義を変更する必要がある場合は、配置済みのインスタンスではなく、ライブラリを編集します。

このページでは、手順1から3までを説明します。ライブラリファイルの管理については、[カスタムシンボルライブラリ](../Custom-symbol-libraries/)を参照してください。シンボル定義そのものの変更については、[シンボルの編集](../Editing-a-Symbol/)を参照してください。

## ライブラリの読み込み
{: #loading-libraries}

シンボルを配置する前に、そのライブラリをTinyCADで使用できる状態にする必要があります。

- 組み込みライブラリはTinyCADの一部として使用できます。
- カスタムライブラリは、参照する前に追加または開く必要があります。
- 手順はTinyCAD Webとデスクトップアプリケーションで異なります。

ライブラリファイルの追加、読み込み、更新、作成、編集に関する製品別の手順は、[カスタムシンボルライブラリ](../Custom-symbol-libraries/)を参照してください。

## 参照、検索、プレビュー
{: #browsing-searching-and-previewing}

ライブラリのシンボルを使用するには、まずTinyCADのセッションでライブラリを読み込む必要があります。読み込み後は、次の操作を行います。

1. 左側のシンボル選択ツールで **Standard**、**Online**、または **My Libraries** を選択します。
2. Standard では同梱ライブラリを1つ選択し、My Libraries では独自のライブラリを開くか展開します。名前または説明でシンボルを探すには、**Search libraries...** を使用します。
3. 結果一覧で図柄を確認し、シンボルを選択して拡大プレビューと説明を表示します。
4. プレビューを図面にドラッグし、グリッド上に配置します。複数のコピーの配置を終了するには、Escape キーを押すか右クリックします。

選択後のシンボルの配置と設定について詳しくは、[シンボル](../Symbols/)を参照してください。

## ライブラリパネルのサイズ変更
{: #resizing-the-library-panel}

ライブラリパネルの右端をドラッグすると、幅を広げたり狭めたりできます。幅を広げると、長いシンボル名や説明を表示しやすくなります。ローカルストレージが利用可能な場合、TinyCADはこのデバイスでパネル幅を記憶します。

## シンボルの並べ替え
{: #sorting-symbols}

**My Libraries**では、ライブラリコントロールの横にある並べ替えボタンを使用して、**ライブラリ順**、**AからZ**、**ZからA**を切り替えます。ボタンのツールチップには現在のモードが表示されます。
並べ替えはライブラリ内のシンボルとオンライン検索結果を含む検索結果に適用されます。ライブラリファイルやフォルダの順序は変更されません。ローカルストレージが利用可能な場合、TinyCADはこのデバイスで並べ替えモードを記憶します。

ブラウザーとデスクトップの選択欄には、**Standard**、**Online**、**My Libraries**タブがあります。ソースと標準ライブラリの選択は、このデバイスに記憶されます。

## 図面へのシンボルの配置
{: #placing-symbols-in-a-drawing}

ライブラリブラウザーからシンボルを選択すると、そのシンボルがアクティブな配置ツールになります。

実際の配置手順や、選択後のシンボルの動作については、[シンボル](../Symbols/)を参照してください。

図面にシンボルを配置しても、ライブラリ定義は**編集されない**ことに注意してください。グラフィック、ピン、または属性を今後の使用に備えて変更する必要がある場合は、ライブラリ内のシンボルを編集してください。[シンボルの編集](../Editing-a-Symbol/).

## 関連する作業
{: #related-tasks}

- 追加、開く、作成、管理には [Custom Symbol Libraries](../Custom-symbol-libraries/) を使用して、`.tclib` ファイルを操作します。
- シンボルのグラフィック、ピン、属性の変更には [Editing a Symbol](../Editing-a-Symbol/) を使用します。
- シンボルを選択した後の配置の詳細については [Symbols](../Symbols/) を参照してください。
