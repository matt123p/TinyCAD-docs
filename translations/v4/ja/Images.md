# 画像
{: #images}

ロゴ、参考画像、スキャンした図面などを図面に追加できます。画像はクリップボードから貼り付けるか、TinyCAD Desktop とブラウザーアプリのどちらでも **File → Import → Image…** を使ってファイルを選択できます。

画像はシート上の図形です。コンポーネント、ピン、電気的接続は作成されません。回路画像を編集可能なシンボルと配線に変換するには、代わりに Desktop の [AI assistant](../AI-Assistant/) を使用してください。

## コピーと貼り付け
{: #copy-and-paste}

1. 別のアプリケーションで、ファイル名やリンクではなく画像そのものをコピーします。たとえば、ブラウザーで **Copy image** を使用するか、画像編集ソフトで選択範囲をコピーします。
2. TinyCAD に戻り、テキストフィールドを編集中でないことを確認して、描画領域をクリックします。
3. **Ctrl+V**（macOS では **Cmd+V**）を押します。
4. 貼り付けた画像を選択し、目的の位置までドラッグします。

PNG または JPEG 形式のクリップボード画像に対応しています。画像を貼り付けられない場合は、ファイルとして保存してから「インポート」を使用してください。TinyCAD の図面に配置済みの画像をコピーして貼り付けることもできます。

## ファイルからインポート
{: #import-from-a-file}

1. **File → Import → Image…** を開きます。ブラウザーアプリでは、ツールバーのドキュメントアイコンを使って **File** メニューを開きます。
2. 画像ファイルを選択し、ファイル選択ダイアログで確定します。
3. 画像が現在のシートに表示されます。画像を選択して、移動、サイズ変更、またはクリッピングを行います。

PNG および JPEG ファイルはそのまま埋め込まれます。GIF、WebP、BMP、SVG など、ブラウザーでデコード可能なその他の形式は PNG に変換されます。インポートした画像は静止画であり、アニメーションは保持されません。形式の対応状況は、ブラウザーまたは TinyCAD Desktop に含まれるブラウザーエンジンによって異なります。読み取り不能または非対応のファイルを指定すると、エラーが表示されます。

PNG または JPEG ファイルを描画領域にドラッグして、ドロップした位置に配置することもできます。

## 移動とサイズ変更
{: #move-and-resize}

画像をクリックして選択します。画像本体をドラッグすると移動でき、角または辺のハンドルをドラッグするとサイズを変更できます。

画像を選択すると、下部のプロパティバーに **Image** セクションが表示されます。サイズ変更時に現在の幅と高さの比率を維持するには、**Fixed aspect ratio** を有効にします。幅と高さを個別に変更するには、無効にします。画像を移動しても縦横比は変わりません。

**Reset aspect ratio** は、クリッピングを考慮した表示画像の元の縦横比に戻します。現在の幅と左上の位置を保ち、高さを調整します。「Fixed aspect ratio」チェックボックスの現在の設定は維持されます。リセットは元に戻すことができます。

## 端をクリッピングする
{: #clip-the-edges}

Image プロパティの **Left clipping (px)**、**Right clipping (px)**、**Top clipping (px)**、**Bottom clipping (px)** を使って、不要な余白や画像の一部を非表示にします。

- 値は元画像上のピクセル単位の整数で、表示サイズや図面のグリッドとは無関係です。
- たとえば、**Left clipping (px)** を **20** に設定すると、元画像の左端から20ピクセルが非表示になります。
- クリッピングしても、残りのピクセルの倍率と位置は変わりません。画像を引き伸ばすのではなく、表示境界が内側に移動します。
- 各方向に少なくとも1ピクセル残す必要があります。各辺の設定可能な値は、それに応じて制限されます。
- 辺を元に戻すには、値を **0** に設定します。クリッピングによって、埋め込まれた元画像のピクセルが削除されることはありません。

画像の挿入やプロパティの変更も、移動やサイズ変更と同様に **Undo** と **Redo** の対象です。

## 保存と出力
{: #saving-and-output}

画像は図面ファイルに埋め込まれるため、インポート元の場所に元ファイルを残しておく必要はありません。画像、縦横比固定の設定、クリッピングを保持するには、通常どおり図面を保存します。これらの設定は、ファイルを再度開いたときにも保持され、圧縮された `.dzn` 図面にも保存されます。

クリッピングは配置した画像ごとに設定されるため、同じ画像のコピーごとに異なる部分を表示できます。表示されている画像は、印刷、PDF、SVG 出力に含まれます。
