# タッチ操作
{: #touch-controls}

タッチスクリーンでは、図面を直接編集するか、拡大鏡を使ってより正確に配置できます。これらの操作は、ブラウザー版とデスクトップエディターで使用できます。

## 直接タッチ
{: #direct-touch}

- タップすると、アクティブなツールでオブジェクトを選択または配置できます。
- マウスと同様に、1本の指でドラッグすると、オブジェクトを移動したり範囲選択したりできます。
- 指を約1秒間動かさずに置くと、図面のコンテキストメニューが開きます。
- 2本の指を同じ方向に動かすと図面をパンできます。2本の指を広げたり閉じたりすると、ジェスチャーを中心にキャンバスがズームします。
- ライブラリーパネルからシンボルのプレビューを図面にドラッグして配置できます。

## 拡大鏡を使った正確な配置
{: #precise-placement-with-the-loupe}

拡大鏡は照準十字の周囲を拡大するため、指で隠さずに接続点を狙うことができます。

1. 必要に応じて図面をタップして **Show Loupe** を表示し、図面下部にあるそのボタンをタップします。
2. キャンバス上で指を滑らせて照準十字を合わせます。細かく操作できるよう、指の動きよりもゆっくり移動します。指を離すと照準位置が固定されます。
3. レンズの下にあるラベル付きコントロールを使用します。

   | コントロール | 操作 |
   |---|---|
   | **Click** | 照準十字の位置をクリックして、オブジェクトを選択するか、アクティブなツールで点を配置します。 |
   | **Drag** | 照準十字の位置からドラッグを開始します。キャンバス上で指を滑らせてポインターを移動します。 |
   | **Drop** | ドラッグを終了します。ドラッグ中は **Drag** の代わりに表示されます。 |
   | **Menu** | 照準十字の位置でコンテキストメニューを開きます。 |
   | **Close** | 拡大鏡を閉じ、直接タッチに戻ります。 |

4. **Hide Loupe** をタップして、直接タッチに戻ります。

![接続部を拡大し、照準十字とClick、Drag、Menuの各コントロールを表示したタッチ用拡大鏡。](../images/touch-loupe.png)

たとえば、ワイヤーを描くには、**Wire** を選択して始点のピンに照準を合わせ、**Click** をタップします。指を滑らせて次の点に照準を合わせ、もう一度 **Click** をタップします。操作を終了またはキャンセルする場合は、**Menu** を使ってツールのコンテキストコマンドを選択します。

拡大鏡を開いた状態でも、2本指でのパンとピンチズームを使用できます。表示を変更する前に、**Drop** で実行中のドラッグを終了してください。
