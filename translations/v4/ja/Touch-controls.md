# タッチ操作
{: #touch-controls}

タッチスクリーンでは、図面を直接編集するか、ルーペを使ってより正確に配置できます。これらの操作はブラウザー版とデスクトップエディターで使用できます。

## 直接タッチ
{: #direct-touch}

- タップすると、アクティブなツールでオブジェクトを選択または配置します。
- マウスと同じように、1本の指でドラッグするとオブジェクトを移動したり、範囲選択したりできます。
- 指を約1秒間動かさずに押さえると、図面のコンテキストメニューが開きます。
- 2本の指を同じ方向に動かすと図面をパンします。指を開いたり閉じたりすると、ジェスチャーの中心を基準にキャンバスをズームします。
- ライブラリパネルからシンボルのプレビューを図面上にドラッグして配置します。

## 2回のタップでワイヤーを自動配線
{: #auto-route-wires-with-two-taps}
{: #auto-route-wires}

ツールバーの **ポイント間ワイヤー (Point-to-Point Wire)** を使うと、各コーナーを配置せずに、2つのピン、またはピンと既存のワイヤーを接続できます。始点となる接続点をタップし、次に終点をタップします。TinyCADが経路を選択し、ワイヤーセグメントを配置します。
これはマウスでも便利ですが、正確な配置回数を減らせるため、特にタッチスクリーンで役立ちます。

端点が小さい場合や密集している場合は、ピンを直接タップする代わりに、各端点でルーペの **クリック (Click)** コントロールを使います。手順と例については、[ワイヤーの自動配線](../Wires/#auto-routing)
を参照してください。

## ルーペで正確に配置
{: #precise-placement-with-the-loupe}
{: #precise-placement-with-the-loupe}

ルーペは照準十字の周辺を拡大するため、操作したい接続点を指で覆わずに済みます。

1. 必要に応じて図面をタップして **ルーペを表示 (Show Loupe)** を表示し、図面下部のそのボタンをタップします。
2. キャンバス上で指を1本スライドさせて照準十字を合わせます。細かく操作できるよう、動きは指より遅くなります。指を離しても照準位置はそのままです。
3. レンズの下にあるラベル付きコントロールを使います。

   | コントロール | 操作 |
   |---|---|
   | **クリック (Click)** | 照準十字の位置をクリックし、オブジェクトを選択するか、アクティブなツールで点を配置します。 |
   | **ドラッグ (Drag)** | 照準十字の位置からドラッグを開始します。キャンバス上で指をスライドさせてポインターを移動します。 |
   | **ドロップ (Drop)** | ドラッグを終了します。ドラッグ中は **ドラッグ (Drag)** の代わりに表示されます。 |
   | **メニュー (Menu)** | 照準十字の位置でコンテキストメニューを開きます。 |
   | **閉じる (Close)** | ルーペを閉じて直接タッチに戻ります。 |

4. **ルーペを隠す (Hide Loupe)** をタップして、直接タッチに戻ります。

![接続領域を拡大したルーペ。照準十字と、クリック、ドラッグ、メニューの各コントロールが表示されています。](../images/touch-loupe.png)

たとえば、ワイヤーを描くには、**ワイヤー (Wire)** を選択し、始点のピンに照準を合わせて **クリック (Click)** をタップします。指をスライドさせて次の点に照準を合わせ、もう一度 **クリック (Click)** をタップします。ツールのコンテキストコマンドを使って終了またはキャンセルするには、**メニュー (Menu)** を使います。

ルーペを開いた状態でも、2本指でのパンとピンチズームを使用できます。表示を変更する前に、アクティブなドラッグを **ドロップ (Drop)** で終了してください。
