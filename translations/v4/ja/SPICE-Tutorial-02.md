# 2. DC電圧、電流、電力の測定
{: #measuring-dc-voltage-current-and-power}

[前へ](/v4/SPICE-Tutorial-01/) · [目次](/v4/Simulation-Tutorials/) · [次へ](/v4/SPICE-Tutorial-03/)

この章の例はTinyCADに同梱されています。**Open Example → SPICE tutorial**を選択し、名前が示された例を選んでから、**Open Drawing**を選択してください。ダウンロードは不要です。

**divider**を開きます。公称5 Vの電源と2つの1 kΩ抵抗はそのままにします。ここでは、ノード電圧、デバイス両端の電圧、デバイスを流れる電流、デバイスが吸収する電力を区別することを目的とします。

## 電圧測定
{: #voltage-measurements}

`out`は、ノード0を基準としたOUTの電圧を意味します。R1両端の電圧は`VIN − VOUT`で、ここではこれも2.5 Vです。この一致は偶然です。R2を2 kΩに変更すると、R1の電圧は1.667 V、R2の電圧は3.333 Vになります。

ノード電圧を測定するには、**Simulation → SPICE → Insert Probe**を使用します。差動プローブは、正端子の電圧から負端子の電圧を差し引いて測定します。R1を測定するには、正の先端をINに、負の先端をOUTに接続します。先端を逆にすると、測定結果の符号も逆になります。差動プローブは、結合コンデンサやブリッジ出力のように、どちらの端子も接地されていない場合に特に便利です。

## 電流測定
{: #current-measurements}

直列電流プローブを使うには、配線を切断してプローブを経路に挿入します。プローブは0 Vの電圧源としてモデル化されるため、理想的な電圧降下なしに電流が流れます。代わりに電源の両端へ接続すると、電源が短絡します。プローブ電流の正方向は、プローブの正端子から負端子への向きです。`v1#branch`のような電源の枝電流も、直接利用できます。

この分圧回路では、電流はV1からR1、R2を通ってグラウンドへ流れます。両抵抗を流れる電流は2.5 mAです。V1は正端子から電流を供給するため、その枝電流は−2.5 mAになります。

## 電力とエネルギー収支の確認
{: #power-and-an-energy-balance-check}

受動符号規約を使用します。`P = V × I`は、電圧が正と定義されている端子に電流が流入する向きです。正の電力は吸収、負の電力は供給を表します。

| デバイス | 計算 | 公称結果 |
| --- | --- | --- |
| R1 | `(2.5 V)² / 1 kΩ` | +6.25 mW |
| R2 | `(2.5 V)² / 1 kΩ` | +6.25 mW |
| V1 | `5 V × (−2.5 mA)` | −12.5 mW |
| 合計 | 電源と負荷の合計 | 0 W |

この収支はデバッグに役立ちます。1000倍の違いがある場合、単位接頭辞の間違いが原因であることがよくあります。符号が正しくない場合は、プローブの向きが逆になっていることがよくあります。説明のつかない余分な負荷は、意図しない接合や計器の接続が原因かもしれません。

TinyCADの**Measurements**コントロールでは、モデルが対応している場合、部品の電圧、電流、電力を選択できます。対応しているはずの電流ベクトルが見つからない場合は、利用不可として報告されます。消費電流がゼロだと解釈してはいけません。

## 電源をスイープする
{: #sweep-the-supply}

**dc-sweep**を開きます。保存済みの**DC sweep**では、V1を使用し、開始値は0 V、終了値は10 V、増分は0.5 Vです。実行してOUTをプロットします。

![計算されたDC伝達曲線](/v4/images/simulation-tutorials/spice/dc-sweep-results.png)

横軸はスイープする電源の値であり、時間ではありません。電源値が0 V、5 V、10 Vのとき、予想される値はそれぞれ0 V、2.5 V、5 Vです。傾きは0.5 V/Vです。このテストは、時間変化する刺激を追加する前に、バイアス回路やセンサーインターフェースを確認するのに役立ちます。

## 負荷の影響を調べる
{: #investigate-loading}

OUTからグラウンドへ、別の1 kΩ抵抗を追加します。R2と新しい負荷は並列になるため、合成抵抗は500 Ωです。予想される出力は`5 × 500 / (1000 + 500) = 1.667 V`になります。分圧器は理想電圧源ではありません。電流を供給すると出力が変化します。

測定のチェックリストとして、ノード名、基準方向、単位、電源設定、解析内容を記録してください。こうした情報があれば結果を再現でき、回路の変更とプロットの変更を別の読者が区別できます。
