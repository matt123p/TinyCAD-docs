# シミュレーションとSPICE
{: #simulation-and-spice}

TinyCADでは、作図画面を離れずに電子回路シミュレーションを実行し、結果をプロットして回路の動作を測定できます。統合エンジンは **ngspice** です。ブラウザー版とDesktop Appのどちらにもエンジンが含まれているため、統合ワークフローに別途ngspiceをインストールする必要はありません。

シミュレーションが初めてですか？ [ガイド付きSPICEコース](../SPICE-Tutorial/) から始めてください。まず結果をすぐに確認するには、以下の分圧回路の手順に従ってください。このリファレンスでは、各種コントロールと結果の解釈方法について説明します。

## 回路シミュレーターが計算するもの
{: #what-a-circuit-simulator-calculates}

SPICEは *Simulation Program with Integrated Circuit Emphasis* の略です。シミュレーターは、接続された回路の数学的モデルを解きます。抵抗器は電圧と電流の関係を表し、コンデンサーとインダクターはエネルギーを蓄え、半導体モデルは非線形動作を記述します。DCバイアスの算出、時間に対する波形の計算、小信号周波数応答の解析ができます。

回路図が示すのは **接続**、SPICEモデルが示すのは **動作**、解析が指定するのは **何を計算するか** です。この3つすべてが正しくなければなりません。アンプやプロセッサーをリアルに描いても、シミュレーションモデルが含まれているとは限りません。反対に、単純な三角形や長方形でも、役に立つビヘイビアモデルを含めることができます。

シミュレーションは、アイデアの確認、部品値の比較、予想外の応答の理解に役立ちます。結果は、指定したモデルと条件に左右されます。理想配線には、意図しない抵抗やインダクタンスはありません。また、汎用トランジスタモデルは、あらゆるトランジスタの完全な仕様を表すものではありません。負荷、電源インピーダンス、許容差、温度が結果に反映されるのは、選択したモデルがそれらを表現している範囲に限られます。

## ブラウザー版とDesktopのエンジン
{: #browser-and-desktop-engines}

| 機能 | ブラウザー版 | Desktop App |
| --- | --- | --- |
| アナログSPICE、チャート、測定、探索 | worker内にWebAssembly版ngspiceを同梱 | ヘルパープロセスを介してネイティブ版ngspiceを同梱 |
| 移植可能なモデルベースのDigital logic / Functional blocks / Sensors and interfacesライブラリー | はい | はい |
| イベント駆動型XSPICEコードモデル | 非対応¹ | 対応、ネイティブコードモデルライブラリーを同梱 |
| チャートのポップアウトウィンドウ | はい | はい |
| 仮想計測器のポップアウトウィンドウ | いいえ | はい |

¹ ブラウザー版では、保存済みのXSPICE結果を含む図面を開いて表示できます。XSPICEの実行にはDesktopが必要です。

計算はブラウザーまたはDesktopのエンジン内でローカルに実行されます。オンラインライブラリー検索は別の機能です。現在同梱されているエンジンはngspice 47をベースとしており、実行履歴には取得に使用したエンジン／ビルドが記録されます。モデル構文やエンジン間の違いを確認する際は、対応する上流のマニュアルを参照してください。

## 最初のシミュレーションを実行する
{: #run-your-first-simulation}

1. ブラウザーのタイトルバーにある **Open Example**、またはDesktopの **File → Open Example** を開きます。
2. **SPICE tutorial → divider → Open drawing** を選択します。
3. 回路を確認します。5 Vの電源から直列に接続された2個の1 kΩ抵抗に電流が流れます。**OUT** はその中点で、下側の配線はグラウンド **0** です。
4. シートタブで **divider Simulation sheet** を選択します。時計のようなアイコンで回路図シートと区別できます。**Setup** を開き、**Operating Point** が選択された状態のままにします。
5. **Run** を選択します。完了したら **History** を開き、新しく完了した取得を選択します。
6. **Data** を開きます。中点の電圧は **2.5 V** です。電源電流は **−2.5 mA** です。ngspiceでは電圧源の電流基準方向が正端子に流れ込む向きなので、この回路で電力を供給する電源の電流は負になります。
7. 抵抗を変更して、もう一度実行します。新しい結果と元の取得結果を比較します。

{% include video-player.html src="/v4/videos/simulation/first-simulation.mp4" poster="/v4/videos/simulation/first-simulation.jpg" caption="同梱の分圧回路を開き、設定を確認して、ブラウザー版ngspiceで新しい取得を実行してください。Dataテーブルで、OUTが2.5 V、電源を流れる電流が−2.5 mAであることを確認できます。" %}

この例には、保持された参照用の取得結果が含まれています。開いた直後に結果が表示されても、新たな計算が実行されたとは限りません。**History** では、保存済みの結果と、Runで作成する取得結果を区別できます。

## 新しいシミュレーションを作成する
{: #build-a-new-simulation}

1. **Standard → SPICE essentials** からモデル付き部品を配置するか、ツールバーの **Simulation → SPICE components** サブメニューを使用します。**More…** を選ぶと、SPICE essentialsの全コレクションが開きます。
2. ピンを配線で接続し、重要なノードには読みやすいラベルを付けます。グラウンド **0** に実際に接続してください。正しい電源シンボルを配置するには、**Simulation → SPICE → Insert Ground** を使用します。
3. **Simulation → SPICE → Insert Source** で励振源を追加します。電圧／電流の種類と波形を設定します。便利なチャートを使いたい場合は、[プローブ](../Simulation-Sources-and-Instruments/#probes-and-ground) を追加します。
4. **Simulation → Simulate** を選択して **Simulation sheet** を追加します。
5. **Setup** で解析と設定を選択します。回路で必要な場合は、パラメーターを設定するか、カスタムモデルテキストを添付します。
6. 信号を選択して実行し、**Simulation charts** パネルに加えて、シートの **Data**、**History**、**Diagnostics** ビューを確認します。報告された配線エラーやモデルエラーを修正してから、値を信頼してください。

Simulation sheetでは、メインツールバーに **Run** と **Stop** が表示されます。シートを開くと **Setup** が表示されます。実行後は **History** と **Diagnostics** が表示され、数値データが利用可能になると **Measurements** と **Data** が表示されます。Circuit ExplorerツールはSetupの解析設定の下にあります。**Add tools** から必要なツールだけを追加してください。

図面内のすべての回路図シートは **1つの回路** を構成します。各Simulation sheetは、解析、パラメーター、添付モデル、信号選択、指示、実行履歴からなる独自の設定を持ちます。2つ目のSimulation sheetを追加しても、独立した2つ目の回路図回路が作成されるわけではありません。同じ回路を別の方法で調べるために使用します。たとえば、過渡解析と並べてAC解析を実行できます。

調査ごとに異なる設定名を使用してください。設定を複製すると定義はコピーされますが、取得結果はコピーされません。一度に実行できる取得は1つだけです。スイープとスタディのケースは順次実行されます。

## グラウンド、接続、モデル
{: #ground-connections-and-models}

SPICEの電圧基準ノードは **0** です。この値を正確に指定した電源シンボルまたはネットラベルによって基準が確立されます。**GND** という名前だけでは通常のネット名であり、ノード0にも接続しない限りグラウンドにはなりません。フローティング回路、電源が供給されていないモデルの電源ピン、未接続の電源リターンは、最初の実行でよくある問題です。

配線は接続点でピンに接続する必要があります。近くにあるテキストは接続ではありません。配線が別の配線の端点や部品ソケットに触れると、意図していなくても接合点ができる場合があります。曖昧な図面を解決するには、[配線の接続](../Wires/) と生成されたネットリストを確認してください。

シミュレーションする各部品には、有効なテンプレート、モデル、ピンマッピングが必要です。配置した部品の **SPICE** プロパティで確認できます。ベンダーモデルを添付したり、作図専用のシンボルを変更したりする前に、[SPICEモデルとネットリスト出力](../SPICE-output/) を参照してください。

## Setup、Run、Stop
{: #setup-run-and-stop}

**Run** は、現在の回路と設定を使用して新しい取得を開始します。データの到着に伴ってチャートが更新されることがあります。**Stop** は取得を終了し、到着済みのデータを保持します。実行の状態と利用可否で、何が保持されたか確認できます。これは一時停止／再開のコントロールではありません。再計算するには、もう一度実行してください。

回路、モデル、設定を編集すると、以前の結果は履歴上のものになります。TinyCADは、再実行が必要な結果を示し、編集後の回路の測定値として古い値を表示し続けることはありません。履歴には、回路／設定の識別情報、バックエンド、時刻、結果が記録されます。以前の取得を選択すると以前の結果が選ばれますが、取り消し操作のように古い回路図が復元されるわけではありません。

## 結果の保存と共有
{: #save-and-share-results}

回路、モデル、設定、取得済み結果を保持するには、図面を保存してください。シミュレーション部品、設定、または結果が図面に含まれている場合、TinyCADは **`.dzn`** を自動的に使用します。**Save without results** は、シミュレーション定義と取得したスカラー値／レポートのメタデータを保持しつつ、数値波形配列を省略します。これらの配列を必要とするチャートは、その後新たに取得し直す必要があります。

保持される数値データの上限は、1回の実行あたり64 MiB、図面あたり256 MiBで、1設定あたり最大1,000回の実行が保存されます。長時間かつ細かいタイムステップのスタディでは、上限に達することがあります。重要なプロットとCSVデータをエクスポートし、不要になった結果は削除してください。受信者がローカルのファイルパスを必要としないよう、モデルの添付ファイルも図面と一緒に保存してください。

## `.dzn` シミュレーション図面
{: #dzn-simulation-drawings}
{: #dzn-simulation-drawings}

**`.dzn` はTinyCAD v4以降でサポートされる、TinyCADの圧縮図面形式です。** 回路図、埋め込みシンボル、Simulation sheet、ソース設定、添付モデルテキスト、保持されている取得結果を、ZIPベースの1つのファイルにまとめます。数値波形データは、複素数のAC結果を含め、コンテナー内に効率よく保存されます。通常の **File → Open**、**Save**、**Save As** コマンドで開いて保存でき、手動で展開する必要はありません。

通常の図面にはXML形式の **`.dsn`** が使われます。シミュレーション内容がある場合、TinyCADは自動的に`.dzn`を選択します。対象には、ソース、プローブ、仮想計測器、SPICE属性、`0`という名前のグラウンド、Simulation sheet、結果が含まれます。シミュレーション設定を保持する場合、**Save without results** でも`.dzn`が使用されます。削除されるのは大容量の波形配列であり、実験の定義ではありません。

受信者がシミュレーションを再実行できる場合は、共有用の小さなファイルを作成するために **Save without results** を使用してください。受信者が再実行せずに取得結果、測定値、エンジンの詳細を確認できるようにするには、結果を保持してください。保存された取得結果が示すのは、実行時点の回路です。編集後に再実行する代わりにはなりません。

TinyCAD v3では`.dzn`ファイルを開けません。拡張子を`.dsn`に変更しても、形式は変換されず、新しいシミュレーション記録がv3で使えるようになることもありません。古いバージョンのTinyCADとデザインをやり取りする場合は、元のコピーを保管してください。`.cir`エクスポートはシミュレーター用のSPICEテキストであり、どちらのTinyCAD図面形式とも異なります。
