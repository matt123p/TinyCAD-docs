# ソース、プローブ、仮想計測器
{: #sources-probes-and-virtual-instruments}

ツールバーの **Simulation** メニューには、**SPICE** 挿入ツールと **Lab Equipment** があります。ツールを選択し、回路図上に配置します。右クリックするか Escape キーを押すと、配置をキャンセルできます。Simulation シートから選択したツールは、配置のため回路図に切り替わります。定義は図面に埋め込まれます。

## 独立ソース
{: #independent-sources}

**Simulation → SPICE → Insert Source** を選択します。配置前にエディターが開きます。電圧または電流と、信号タイプを選択します。配置したソースの本体を選択すると、下部のエディターが再び開きます。

| 信号タイプ | 用途 | 確認する設定 |
| --- | --- | --- |
| DC | バイアスと定常電源 | DC 値と極性 |
| Sine | 周期的なアナログ入力 | オフセット、ピーク振幅、周波数、位相、遅延、減衰 |
| Square/pulse | スイッチングとタイミング | 低／高レベル、遅延、立ち上がり／立ち下がり時間、パルス幅、周期 |
| Triangle | 繰り返しランプ | レベル、周期、ランプのタイミング |
| Piecewise-linear (PWL) | 指定した系列 | 時間／値のペアを昇順で、1 行につき 1 ペア |
| Exponential | 形状を指定した遷移 | レベル、遅延、時定数 |
| FM | 周波数変調 | 搬送波と変調の設定 |

![正弦波ソースエディターと波形プレビュー](../Images/simulation/source-settings.png)

プレビューには数値で設定した波形が反映されます。実行前に、予期しないオフセット、ピーク、タイミングがないか確認してください。設定が無効な場合、起動できません。ソースのアイコンは波形に応じて変わり、電流ソースには方向矢印が表示されます。

**AC 振幅と位相は別個の設定**であり、小信号周波数解析に使用します。これらは過渡解析における正弦波の振幅とは独立しています。ソースの DC バイアスと過渡波形も、意図して選択する必要があります。[解析](../Simulation-Analyses/) および[ソースのチュートリアル](../SPICE-Tutorial-03/)を参照してください。

新しいソースとプローブの端子間隔は、コンパクトな 8 mm です。以前の大型コントロールでは、下部エディターに **Use compact symbol** があります。変換では最初の端子を固定し、既存の接続をサイズ変更後の端子まで延長します。これは 1 回で取り消せる編集として行われます。サイズ変更後は接続を確認してください。

## プローブとグラウンド
{: #probes-and-ground}

| **Simulation → SPICE** のツール | 接続 | 意味 |
| --- | --- | --- |
| **Insert Probe** | 先端を 1 つのネットに接続 | グラウンド 0 を基準とする電圧 |
| **Insert Differential Probe** | + と − を 2 つのネットに接続 | `V(+) − V(−)` |
| **Insert Current Probe** | 分岐に直列接続 | + から − に向かう電流 |
| **Insert Ground** | 回路の基準ネットに接続 | 値 0 の Earth 電源シンボルを接続 |

プローブ／グラウンドの挿入では、ワイヤにスナップし、接続点でワイヤを分割します。先端の実際の位置と極性を確認してください。電流プローブは**理想的な 0 V 電圧源**であるため、直列に接続する必要があります。電源に並列に接続すると短絡します。直列測定用に挿入するときは、元の並列ワイヤを削除するか切断してください。

プローブパネルでは、取得モードと表示モードを選択できます。動作点信号はスカラー値として表示でき、複素 AC 結果は実数、絶対値、dB、位相で表示できます。必要な結果がない場合や、編集された回路の結果である場合、パネルに利用できない理由、または再実行が必要な理由が表示されます。

### 制御ソース
{: #controlled-sources}

**Insert Controlled Source** では、電圧制御電圧源（**E**）または電圧制御電流源（**G**）を使用できます。出力ピンは +／− で、番号は 1／2 です。制御ピンは C+／C− で、番号は 3／4 です。制御入力の両側を接続し、エディターで伝達特性を確認してください。制御ポートは出力電源端子ではありません。

## 仮想実験室機器
{: #virtual-laboratory-equipment}

これらは **Simulation → Lab Equipment** から選択します。取得コントロールを備えた動作モデルです。**Standard → Test & Measurement** にある似た名前の図は、物理的なベンチ配置図用であり、シミュレーション測定は行いません。

配線済みの回路を使用するには、[Virtual laboratory.dzn](../examples/simulation/virtual-laboratory.dzn)をダウンロードし、**File → Open** を使用してください。これは付属のサンプルブラウザーに名前付き項目として含まれるものではなく、関連するデモファイルです。

### オシロスコープ
{: #oscilloscope}

オシロスコープには 2 つの差動チャンネルがあります。**1 A+**、**2 A−**、**3 B+**、**4 B−** です。正入力と同様に、各負入力も接続してください。デフォルトの入力負荷は **1 MΩ** であり、高インピーダンス回路に影響することがあります。

10 横目盛り×8 縦目盛りの表示を使い、time/div と volts/div を設定します。トリガーモードは **Auto**、**Normal**、**Single** です。**Acquire** は、最大ステップ幅をおよそ time/div の 1/100 として、過渡データを 10 時間目盛り分要求します。実行後に表示スケールを変更しても、新しい取得は行われず、欠落したエッジも解決されません。

AC 結合では、表示信号から時間加重平均が除去されます。これは物理的なアナログ高域通過入力モデルではありません。GND 結合では、計測器の負荷を接続したままゼロが表示されます。オシロスコープの時間／レベルコントロールはデータの確認に役立ちますが、サンプリング不足の実行を有効なタイミング測定に変えることはできません。

### マルチメーター
{: #multimeter}

電圧または抵抗には **VΩ と COM** を、電流には **A と COM** を使用します。電流測定は直列に行う必要があります。デフォルトの電圧入力は **10 MΩ** です。電流モードでは **1 Ω の負担抵抗**と 0 V の検出源を使用します。そのため、モードを変更すると回路負荷も変化し、再実行が必要です。

DC では該当する定常値／平均値が表示されます。AC では DC 成分を除去した時間加重 RMS 値が使用されます。測定範囲外の値は **OL** と表示されます。これらはモデル化された計測器の動作であり、ヒューズ切れや熱破壊のシミュレーションはありません。

抵抗測定は、電源を切った状態で一時的に行う別個のテストです。テスト中は独立ソースが抑制され、計測器の接続は切り離されます。対応するネットワークは R/C/L とプローブです。コンデンサーは DC で開放、インダクターは短絡として扱われます。能動部品や未対応のテンプレートがある場合、抵抗測定は利用できません。これを、任意の通電中電子機器における回路内抵抗の測定値として解釈しないでください。

### ファンクションジェネレーター
{: #function-generator}

ジェネレーターは、振幅、オフセット、周波数、タイミングのコントロールを備え、正弦波、パルス／方形波、三角波、PWL 波形を出力します。プレビューは**開放回路**の波形です。デフォルトの**出力抵抗 50 Ω**により、負荷を接続すると端子振幅が低下することがあります。

Output Off は、漏れ抵抗 **1 TΩ** の開放ポートを近似します。小信号 AC 振幅は過渡振幅とは別個です。設定した波形を測定値と比較する前に、必要な振幅がピーク値、ピーク間値、RMS 値のどれかを確認してください。

### ベンチ電源
{: #bench-supply}

電圧、電流制限、出力抵抗、出力の有効／無効、オプションのランプ時間を設定します。このモデルでは滑らかな動作電流制限と有限の抵抗を使用し、パネルに測定 V/I と **CV/CC** 動作が表示されます。電流制限を負荷の要求より低くすると、供給電圧が低下します。

同じ電流制限内で電流を供給したり吸収したりできます。これは特定メーカーのスイッチング電源モデルでも、熱モデルでもありません。出力無効時は、1 TΩ の漏れ抵抗で近似します。ランプは過渡解析に影響します。DC 動作点では、設定された最終電圧が使用されます。

ジェネレーターと電源の数値プロパティは、[Circuit Explorer](../Simulation-Charts-and-Measurements/)にバインドして、一時的な調整やテスト条件の設定に使用できます。Desktop では計測器パネルを別ウィンドウにポップアウトできます。チャートのポップアウトはどちらの製品でも利用できます。

## 負荷も実験の一部
{: #loading-is-part-of-the-experiment}

理想的な電圧プローブと、入力負荷のあるオシロスコープでは、同じ回路結果になりません。結果を比較する前に、ジェネレーターのインピーダンス、メーターの負担、オシロスコープの入力負荷、共通リターンを考慮してください。信号のどちらの端もグラウンドでない場合は、差動測定を使用してください。計測器を追加した後に実行が失敗した場合は、ソルバー設定を変更する前に、配線とモードを確認してください。
