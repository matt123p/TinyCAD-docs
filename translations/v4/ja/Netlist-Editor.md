# ネットリストエディター
{: #netlist-editor}

`Netlist Editor` は TinyCAD v4 の新機能です。

次のような場合に使用します。

- ワイヤーとラベルがどのようにネットにまとめられているか確認する
- 図面内でネットが使われている場所を探す
- ネットにタイプを割り当てる
- ネットのグループの表示方法を変更する

## Netlist ビューとは
{: #what-the-netlist-view-is}

`Netlist Editor` は、図面内のネットをリアルタイムで表示する一覧です。

ネットとは電気的な接続です。TinyCAD は次の要素から接続を判断します。

- ワイヤー
- ピン
- ラベル
- 電源シンボル

回路図の編集中も一覧は自動的に更新されます。

## 開き方
{: #how-to-open-it}

1. エディター下部のパネルを確認します。
2. `Symbols` が表示されている場合は、モードボタンで `Netlist` に切り替えます。

選択中のオブジェクトによって別のパネルが開いている場合は、先に選択を解除してください。

## 各列の意味
{: #what-each-column-means}

- `Net`：ネット名、または内部ネット番号
- `Sheet`：その行の主な項目が見つかったシート
- `Connections`：そのネットに接続されているピンの数
- `Labels`：そのネットにあるラベル
- `Type`：そのネットに割り当てられたネットリストタイプ
- `Symbols`：そのネットに接続されている部品とピン

## Netlist ビューの使い方
{: #how-to-use-the-netlist-view}

### ネットを検索する
{: #find-a-net}

検索ボックスで一覧を絞り込みます。

次の情報で検索できます。

- ネット名
- シート名
- ラベルの文字列
- シンボルの参照番号
- タイプ名

### 図面内のネットを強調表示する
{: #highlight-a-net-in-the-drawing}

行にマウスポインターを合わせます。

TinyCAD が回路図内の該当するネットの項目を強調表示するため、ネットの位置を確認できます。

### 図面内のネットへ移動する
{: #jump-to-a-net-in-the-drawing}

行をクリックします。

TinyCAD が該当するシートを開き、関連する項目へ移動します。

## ネットにタイプを割り当てる
{: #how-to-assign-a-type-to-a-net}

各行には `Type` フィールドがあります。

タイプを割り当てるには、次の手順を実行します。

1. ネットの `Type` フィールドをクリックします。
2. 一覧から既存のタイプを選ぶか、新しい名前を入力します。
3. フィールドの外をクリックして変更を適用します。


## ネットタイプとは
{: #what-a-net-type-is}

ネットタイプは、ネットのグループに付ける再利用可能なラベルです。

次のような用途に使用できます。

- ネットを分類する
- 同じ分類のネットに同じ色を設定する
- 特定のネットを図面上で太く表示する
- 追加のメモを属性として保存する

タイプ名には、たとえば次のような名前を使用できます。

- `power`
- `control`
- `logic`
- `analog`
- `high_current`

## Netlist Types を開く
{: #how-to-open-netlist-types}

1. 下部バーの `Netlist` ビューを開きます。
2. `Netlist Types` をクリックします。

使用可能なすべてのタイプ定義を編集するエディターが開きます。

## Netlist Types でできること
{: #what-you-can-do-in-netlist-types}

`Netlist Types` ウィンドウでは、次の操作ができます。

- 新しいタイプを追加する
- 既存のタイプを複製する
- タイプの名前を変更する
- タイプを削除する
- ワイヤーの色を変更する
- ラベルの色を変更する
- 電源シンボルの色を変更する
- ワイヤーの太さを変更する
- 独自の属性を追加する
- 保存前に結果をプレビューする

## デフォルトのタイプ
{: #the-default-type}

`default` タイプは常に存在します。

次の点に注意してください。

- 名前は変更できません
- 削除できません
- このタイプの色は図面の通常の色です

`default` 行の色を変更すると、図面で使用する通常のネットの色が変わります。

## 新しいタイプを作成する
{: #how-to-create-a-new-type}

1. `Netlist Types` を開きます。
2. `Add` をクリックします。
3. 名前を入力します。
4. 色とワイヤーの太さを設定します。
5. `OK` をクリックして保存します。

その後、下部の `Netlist` ビューから新しいタイプをネットに割り当てられます。

## タイプを複製する
{: #how-to-duplicate-a-type}

既存のタイプに似たタイプを作成するときに便利です。

1. タイプの行を選択します。
2. `Duplicate` をクリックします。
3. 新しい名前に変更します。
4. 必要な色や設定を変更します。
5. `OK` をクリックします。

## 色を変更する
{: #how-to-change-colors}

各タイプでは、次の要素の色を個別に設定できます。

- ワイヤー
- ラベル
- 電源項目

色を変更するには、次の手順を実行します。

1. 行内の色のセルをクリックします。
2. 色のダイアログで色を選択します。
3. 色のダイアログを閉じます。
4. `OK` をクリックします。このボタンはメインの `Netlist Types` ウィンドウにあります。

デフォルト以外のタイプでは、独自の色を使用するか、図面のデフォルト色を使用できます。

## ワイヤーの太さを変更する
{: #how-to-change-wire-thickness}

1. タイプの行を探します。
2. `Wire Thickness` の値を変更します。
3. `OK` をクリックします。

そのタイプのネットに含まれるワイヤーの描画方法が変わります。

## 属性を追加する
{: #how-to-add-attributes}

属性は、タイプとともに保存する名前と値の組です。

次の手順で追加します。

1. タイプの `Attributes` セルをクリックします。
2. 属性の名前と値を追加または編集します。
3. 属性を保存します。
4. `OK` をメインのダイアログでクリックします。

現在、これらの属性は主に図面とともに保存されます。すべての出力形式で使用されるわけではありませんが、タイプに関する追加情報の保存に役立ちます。
