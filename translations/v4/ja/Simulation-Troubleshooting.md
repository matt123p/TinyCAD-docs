# シミュレーションのトラブルシューティング
{: #simulation-troubleshooting}

設定を変更する前に、取得ステータスと診断出力を確認してください。**実行に失敗した場合**、**予期しない動作を示す有効な実行結果**、**選択した結果から測定できない項目**を区別してください。それぞれ確認すべき内容が異なります。

## シミュレーションを開始できない
{: #the-simulation-will-not-start}

| 症状 | 確認事項 |
| --- | --- |
| グラウンドがない／回路が浮いている | 電源シンボルまたは値が **0** のラベルを接続してください。独立した GND ラベルは、自動的にノード 0 になるわけではありません。電源の戻り線と絶縁されたサブサーキットを確認してください。 |
| コンポーネントモデルがない | モデル化されたライブラリ部品を使用するか、テンプレートとモデルを指定してください。機器の図はシミュレーションモデルではありません。 |
| 属性が不足している、またはピン割り当てが無効 | コンポーネントの SPICE プロパティと、実際のモデル端子の順序を確認してください。インスタンスのオーバーライドによって既定値が変更される場合があります。 |
| モデル／インクルードファイルが見つからない | モデルのテキストとその依存ファイルを、論理ファイル名を一致させて Simulation シートに添付してください。ローカルの絶対パスや Web URL は自動的には取得されません。 |
| コンポーネント内に解析指示がある | コンポーネント属性から、従来の `.op`、`.tran`、`.ac`、`.end` および実行制御テキストを削除してください。解析設定は統合された Simulation シートで管理します。 |
| ブラウザーで XSPICE モデルを利用できない | 新たにネイティブ実行するには、図面を Desktop で開いてください。保存済みの結果をブラウザーで確認することは引き続き可能です。 |
| ソースまたは範囲が無効 | 波形フィールド、単調増加する PWL 時刻、開始値／終了値、掃引方向、正の周波数／時間量を確認してください。 |

## 結果が正しくない、またはソルバーが収束しない
{: #a-result-is-wrong-or-the-solver-does-not-converge}

**まず回路を確認してください。** ワイヤ端点を越えて引かれた線や未使用のソケットによって、意図しない接続が生じることがあります。T 字接続、実際のピン先端、ネットラベル、非表示の電源を確認してください。電流プローブやメーターを電源の両端に置くと、短絡する場合があります。生成されたネットリストを使って、シミュレーターに渡された回路を確認してください。

モデルの向きと端子順を確認してください。ダイオードの極性、BJT のコレクタ／ベース／エミッタ、オペアンプの電源ピン、サブサーキットのピン順を確認します。意味のある一意の参照番号を使用し、スイープ／ノイズ／伝達特性の設定で指定したソース参照が、意図したソースを指していることを確認してください。

AC を調べる前に、Operating Point（動作点）で DC バイアスを確認してください。理想電源のループ、浮遊ノード、急峻な理想遷移、妥当でないモデルパラメーターは、回路の解析を困難または不可能にすることがあります。実際の実験を表す場合は、物理的に妥当な抵抗値や有限のエッジ時間を加えてください。数値オプションを変更する前に、複雑な回路を、失敗する最小限の部分まで簡略化してください。

数値の接頭辞を確認してください。**SPICE テキストの 1M は 1 ミリ単位であり、1 メガ単位ではありません**。メガには `1Meg` を使用してください。温度、ソースの DC 値、過渡／AC 設定をそれぞれ個別に確認してください。ソースの過渡振幅が、小信号 AC 振幅として自動的に使われるわけではありません。

## 波形が途中までしか表示されない
{: #the-waveform-looks-incomplete}

- 起動過渡が収束していない場合や、必要な周期が実行範囲外の場合は、過渡解析の時間を延長してください。
- 速いエッジや狭いパルスを分解できるよう、最大ステップ幅を小さくしてください。表示のズームでは、欠落したサンプルを再現できません。
- 選択した設定、取得データ、結果プロット、凡例の表示状態、単位、軸範囲を確認してください。
- AC 解析では、狭い共振付近に十分なポイントを設け、正しい入力／出力比を使用してください。
- 実行が停止または失敗した場合は、実際にデータが取得されているか確認してください。部分的なトレースは、完了した実験ではありません。

## チャートやプローブの読み取り値が古い
{: #charts-or-probe-readings-are-stale}

配線、値、モデルテキスト、設定を編集した後は、再度 **Run（実行）** してください。保存済みの取得データは、元の入力条件を示します。履歴の選択によって図面が元に戻ることはありません。バンドルされたチュートリアルは、自分で何も実行する前に、保持された参照結果とともに開く場合があります。

パネルが非表示の場合は、**Simulation → Show charts（チャートを表示）**、または Desktop の **View → Show Charts（チャートを表示）** を使用してください。自動生成されたプローブチャートを削除すると、明示的に再度追加するまで削除されたままになります。チャートのポップアウトウィンドウを閉じると、チャートはパネルに戻ります。

## 測定できない
{: #a-measurement-is-unavailable}

信号の割り当て、単位、時間窓、しきい値、明示的な初期値／最終値を確認してください。タイミング測定には、完全な交差または周期が必要です。整定測定は、宣言された最終帯域内で終了する必要があります。遮断周波数測定には指定された交差点と利得基準が必要であり、帯域幅測定には 2 つの交差点が必要です。掃引範囲の境界にある共振は確定できません。サポートされていないデバイス電流／電力ベクトルを推測して補うことはありません。

測定要件が利用できない場合、それは合格ではありません。スタディレポートには条件と失敗ステータスを含め、非収束の許容差ケースも表示したままにしてください。評価可能な要件がないスタディには、歩留まりの推定値がありません。

## 調査内容の保存と再現
{: #saving-and-reproducing-an-investigation}

図面、モデルの添付ファイル、解析設定、ソース設定、温度、関連する取得データをまとめて保持してください。数値結果を保存せずに終了した場合や、ファイルサイズを小さくするために結果を削除した場合は、チャートを復元するために再実行してください。保持されたスカラー値やレポートのスナップショットから、欠落した波形配列を復元することはできません。

再現可能なレポートには、モデルの前提、エンジン、測定窓、条件を記載してください。シミュレーター言語に関する問題を切り分ける際は、[チュートリアルの想定値](../Simulation-Tutorials/) および公式の [ngspice マニュアル](https://ngspice.sourceforge.io/docs.html) と比較してください。
