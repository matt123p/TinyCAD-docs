# 8. アンプのゲインと帯域幅の測定
{: #measuring-amplifier-gain-and-bandwidth}

[前へ](/v4/SPICE-Tutorial-07/) · [目次](/v4/Simulation-Tutorials/) · [次へ](/v4/SPICE-Tutorial-09/)

この章の例はTinyCADに同梱されています。**Open Example → SPICE tutorial**を選択し、名前の付いた例を選んでから、**Open Drawing**を選択してください。ダウンロードは不要です。

**amp-ac**を開きます。これは、VINのAC振幅を1に設定し、1 Hz～100 MHzを1桁あたり60点でACスイープするよう再構築されたアンプです。
広い上限範囲により、汎用トランジスタモデルのロールオフが見えるようになります。ただし、元のハードウェアがRF帯域で正確に動作することを示すものではありません。

保存済みのOUT/IN派生トレースである**Voltage gain**を選択します。振幅をdB、位相を表示します。メモではノード電圧と無次元のゲインを区別してください。

![計算されたアンプのゲインと位相](/v4/Images/simulation-tutorials/spice/amp-ac-results.png)

## 説明する前に結果を読み取る
{: #read-the-result-before-explaining-it}

RL = 8 Ω、R6 の電気的分割比を 0.5 とした場合、1 kHz での基準ゲインは
約 **0.892 V/V**、すなわち **−0.995 dB** で、位相はおよそ反転します。
サンプリングされたピーク振幅も約 0.892 です。このピークを基準とした半電力点は、
**24 Hz** と **2.9 MHz** 付近です。これらの丸めた値は、サンプリングされたスイープと選択した汎用モデルを反映しています。

これはユニティゲイン交差ではありません。−3 dB帯域幅はアンプの通過帯域ゲインまたはピークゲインを基準に測定するもので、必ずしも1 V/Vを基準にするわけではありません。TinyCADの名前付き帯域幅測定では、このようなバンドパス形状の応答を調べる際にOUTとINを選択し、基準ゲインを`peak`に設定します。帯域幅の測定では、取得した周波数範囲内に両方の交差点が必要です。

## 全体の電圧ゲインが1未満である理由
{: #why-the-overall-voltage-gain-is-below-one}

VINはボリュームポテンショメータの手前で測定されます。そのワイパ電圧は、アンプの有限な入力インピーダンスによってさらに低下します。Q1は反転電圧ゲインを提供します。Q2はC2を介して非常に重い8 Ω負荷を駆動し、その有限な出力インピーダンスによってさらに減衰が生じます。全体の比には、すべての段が含まれます。

BASE/IN、COLLECTOR/BASE、OUT/COLLECTORを、それぞれ別の派生比として比較してください。それぞれ異なる問いに答えるものです。段単体では電圧ゲインが得られても、入力から負荷までの経路全体ではゲインが1未満になることがあります。エミッタフォロワは、電圧ゲインが1未満でも有用な電流ゲインを得られます。

## 低周波と高周波の限界の原因を調べる
{: #find-the-causes-of-the-low--and-high-frequency-limits}

C1とC2は直列結合コンデンサです。低周波ではリアクタンスが増加し、信号が減衰します。C2の実効抵抗には負荷と段の出力インピーダンスの両方が含まれます。`1/(2π × 8 Ω × C2)`だけでは、負荷が接続された回路を十分に表せません。高周波では、トランジスタの容量とモデルの遷移時間により、応答が低下して位相が変化します。

次の変更を一つずつ試し、変更のたびに元に戻してください。

1. RLを8 Ωから80 Ωに変更します。通過帯域ゲインと低域コーナーを比較します。
2. C2を2倍にします。C2が支配的なら低域コーナーが予想どおりに移動するか確認します。C1や負荷の影響も考えられます。
3. R6の電気的分割比を変更します。ボリュームによる減衰とトランジスタ段のゲインを混同しないよう、INからのゲインとBASEからのゲインを別々に記録します。
4. 交差点付近の1桁あたりの点数を増やし、桁数を増やして示す前に、報告されるコーナー周波数が安定したことを確認します。

AC解析は、バイアス点周辺の十分に小さな摂動に対する応答を予測します。出力振幅を利用可能な電源電圧の振幅範囲に制限するものではありません。次の章では、有限振幅の過渡入力を用いて、小信号予測が実際の波形を記述できなくなる点を調べます。
