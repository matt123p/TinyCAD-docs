# 設計詳細ボックス
{: #design-details-box}

各設計には、タイトル、作成者、その他の関連情報などのドキュメントメタデータが保存されます。これらの値は、**設計詳細**コマンドから編集できます。

設計詳細ボックスは、図面の左下に表示されることがあります。

<img src="/v4/images/media/image15.png" alt="Design details box displayed on the schematic page with title and document metadata fields" style="width: 4.65625in; height: 2.20833in;" />

## 設計詳細を編集する
{: #edit-design-details}

1. 回路図を開きます。
2. ファイルメニューまたはツールから**設計詳細**を開きます。
3. 変更するフィールド（タイトルや作成者など）を更新します。
4. 設計を保存します。

設定メニューから**設計詳細**を選択して編集します。

<img src="/v4/images/media/image16.png" alt="Menu showing the Design Details command used to edit document metadata" />

設計を保存すると、これらの詳細も一緒に保存されます。

## 詳細ボックスを表示
{: #display-details-box}

**詳細ボックスを表示**オプションでは、図面上に詳細パネルを表示するかどうかを設定します。

- 有効にすると、回路図上に詳細が表示されます。
- 詳細ボックスは設計とともに印刷されます。
- 詳細ボックスは図面の右下に表示されます。

## 設計ガイド
{: #design-guides}

ボックスの表示を切り替え、設計ガイド（ページ端の文字や数字）を設定できます。

設計ガイドは次のように表示されます。

<img src="/v4/images/media/image18.png" alt="Schematic page showing border guide markers around the sheet" style="width: 6.26806in; height: 4.44028in;" />

## 注記
{: #notes}

設計詳細はシートごとに設定されます。複数シートの図面では、シートごとに異なる設計詳細を設定できます。

- 設計が複数ページにわたる場合は、[複数シートの図面](../Multiple-Sheet-Drawings/)を参照してください。
- 詳細ボックス周辺のシートレイアウトを設定するには、[ページサイズ](../Page-Size/)を参照してください。
- 印刷またはPDF出力で詳細ボックスがどのように表示されるかについては、[印刷](../Printing/)を参照してください。
