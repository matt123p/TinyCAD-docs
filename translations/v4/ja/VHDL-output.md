# VHDL出力
{: #vhdl-output}

TinyCAD v4でのVHDL出力は、v3と同じように機能します。TinyCADは、回路図の接続情報、シンボルのピン定義、およびVHDL向けシンボルを使用して、設計のVHDL記述を生成します。

VHDLのエクスポートはデスクトップアプリで利用できます。ブラウザー版では現在、VHDLファイルは作成できません。

## VHDLの用途
{: #what-vhdl-is-used-for}

VHDLは、Very High Speed Integrated Circuit Hardware Description Language（超高速集積回路ハードウェア記述言語）の略です。論理ゲート、カウンター、ステートマシン、バス、さらに大規模な再利用可能ブロックなどのデジタルハードウェアを記述するために使用されます。

VHDLは一般に、次の用途に使用されます。

- ハードウェアを構築する前にデジタル論理をシミュレーションする
- 入出力が定義された再利用可能な設計ブロックを記述する
- 小さなモジュールから階層型FPGAまたはASIC設計を構築する
- 設計を後工程の合成ツールや検証ツールに渡す

実際には、VHDL設計では通常、次のものを定義します。

- **エンティティ**: ブロックの外部ポート
- **アーキテクチャ**: 内部の論理または構造

TinyCADのVHDLサポートは、デジタル設計の構造を回路図として作成し、その構造をVHDL形式でエクスポートしたい場合に最も役立ちます。

## 回路図の準備
{: #preparing-the-schematic}

VHDL出力を作成するには、VHDLライブラリのシンボルを使って回路図を作成します。これらのシンボルは、どのピンが入力、出力、名前付き接続であるかをTinyCADが認識できるように設計されています。

[tinycad.net](https://www.tinycad.net/Search?key=%23vhdl)でもVHDL向けシンボルを見つけることができます。

シンボルは他のTinyCADシンボルと同様に使用できますが、特に名前に注意してください。

- トップレベルの入力と出力には、VHDLライブラリのシンボルを使い、それぞれに必要な信号名を付けます。
- 同じ信号を接続する必要がある箇所では、内部配線に一貫した名前を付けます。
- カスタムシンボルのピン名、方向、ピン番号は正しく設定してください。

TinyCADは接続された配線に自動で名前を付けますが、エクスポートする信号名を明確に制御するには、ラベルを明示的に付けるのが最適です。

## TinyCADによるシンボルとVHDLの対応付け
{: #how-tinycad-pairs-symbols-with-vhdl}

TinyCADでは、TinyCADの複数ファイル対応の階層型回路図機能に頼らずに、階層的なVHDL向け設計を行うことができます。

想定される作業手順は次のとおりです。

1. 再利用可能なブロックの動作を定義するVHDLファイルを作成するか、集めます。
2. プロジェクトライブラリに、それらのブロックに対応するTinyCADシンボルを作成します。
3. 各シンボルに、対応するVHDLファイルまたは設計単位と同じ名前を付けます。
4. 各シンボルのピン名、方向、固有のピン番号が正しいことを確認します。

これらのシンボルを回路図に配置するたびに、TinyCADはシンボルのインスタンスを同じ名前のVHDLブロックに対応付けることができます。

これにより、トップレベルの構造を回路図として描きながら、小さなVHDL定義モジュールを組み合わせて、より大規模な設計を実用的に構築できます。

## バスの操作
{: #working-with-buses}

VHDL出力では、TinyCADのバス描画機能をバスの論理的な定義として使用しないでください。代わりに、配線に直接名前を付けてバスを定義します。

例:

- `A(7:0)`は、`A`という名前の8ビットバスを定義します。
- `A(3)`は、そのバスの1ビットを指します。
- `A(7:4)`は、そのバスのスライスを指します。

バスを表す場合は、入力シンボルと出力シンボルにも同じ命名規則を使用します。

`A(i:j)`形式のバス範囲では、`i`を`j`より大きい値にしてください。

見やすさのためにバス接続を描画してもかまいませんが、VHDLエクスポートで重要なのは、視覚的なバスの図形ではなく配線名です。

## VHDLファイルの生成
{: #generating-the-vhdl-file}

回路図の準備ができたら、TinyCADで「VHDLの作成」(Create VHDL)コマンドを実行します。

TinyCADはエクスポート処理の一環として、設計ルールチェックを自動的に実行します。出力を生成する前に配線やシンボルの問題を見つけたい場合は、あらかじめ設計ルールチェックを実行することもできます。

## 実用チェックリスト
{: #practical-checklist}

エクスポートする前に、次の点を確認してください。

- トップレベルの入力と出力に、VHDLで使用したい名前が正確に付いている
- カスタムシンボルのピン方向が正しい
- すべてのシンボルでピン番号が一意である
- 接続されるべき共通ネットに、実際に同じ名前が付いている
- バスに`DATA(15:0)`などのVHDL形式の範囲名が付いている

生成されたVHDLが期待どおりでない場合、原因はたいてい、ピン定義の誤り、配線名の欠落、またはバス名の不一致です。
