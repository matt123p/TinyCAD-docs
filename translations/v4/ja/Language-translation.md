# 言語翻訳
{: #language-translation}

TinyCAD は、複数のインターフェース言語に切り替えることができます。

## 利用可能な言語
{: #available-languages}

現在選択できる言語は次のとおりです。

| コード | 言語 |
|---|---|
| `en` | 英語 |
| `nl` | オランダ語 |
| `fr` | フランス語 |
| `es` | スペイン語 |
| `de` | ドイツ語 |
| `it` | イタリア語 |
| `ja` | 日本語 |
| `pl` | ポーランド語 |
| `zh-CN` | 中国語（簡体字） |

## 翻訳の品質とフィードバック
{: #translation-quality-and-feedback}

これらの翻訳は AI によって管理されています。

不自然な表現、技術用語の誤り、または未翻訳のテキストに気づいた場合は、
ぜひフィードバックをお寄せください。翻訳言語の追加に関するご提案も
歓迎します。
