# グラフ、測定、Circuit Explorer
{: #charts-measurements-and-circuit-explorer}

[シミュレーションを実行](../Simulation/)した後、グラフで波形を確認し、名前付き測定で再現可能な量を記録します。Circuit Explorer では、一時的な調整、繰り返し実行、要件、スタディレポートを利用できます。

**Simulation sheet → Setup** を開き、**Circuit Explorer** までスクロールします。必要に応じて **Add tools** を使い、Measurements、Tune / sweep、Requirements、DC overlay、Analysis lab を追加します。設定済みのツールは左側のリストに表示されます。**Hide tool** を使うと、保存済みの設定を保持したままコントロールを非表示にできます。グラフは右側の独立したパネルに表示されます。

## グラフの表示と配置
{: #show-and-arrange-charts}

ブラウザー版、Desktop のいずれでも、ツールバーの **Simulation → Show charts** を選択します。Desktop では **View → Show Charts** からも表示できます。右側の **Simulation charts** パネルの左端をドラッグして、パネルの幅を調整します。セットアップと取得データを選び、回路図を離れずに **Run** または **Stop** を使います。

プローブのグラフは自動的に追加されます。プローブがない場合は、セットアップに出力グラフが追加されます。別のプローブやカスタム表示を追加するには **Add chart** を使い、続いて **Choose signals** を選択します。グラフのタイトルは編集できます。ノイズなどの複数プロット解析には、結果プロットの選択項目があります。

凡例項目をクリックすると、波形の表示を切り替えられます。電圧、電流などの単位はラベル付きの軸に表示されます。電圧の目盛りから電流を読み取らないでください。複素ACデータは、実部／虚部、絶対値、dB、位相で表示できます。入力が適切に正規化されていない限り、出力の絶対値をdB表示しても、自動的に伝達利得を示すわけではありません。

ホイール／ピンチでズームし、ドラッグでパンします。**Shift-ドラッグ**で範囲を選択し、**Fit** で表示を元に戻します。数値カーソルでサンプル位置を確認できます。大きな結果データでは、表示を滑らかにするために表示用データを間引いて全体を示します。ズームすると表示が精細になります。互換性のあるピン留め済みベースラインは、破線のオーバーレイとして表示されます。

### 別ウィンドウ表示とエクスポート
{: #pop-out-and-export}

**Pop out chart** を使うと、どちらの製品でも独立したウィンドウにグラフを表示できます。複数のグラフを切り離して表示できます。ポップアウトを閉じるとパネルに戻ります。ドッキングされたグラフの × を押すと、グラフが削除されます。切り離したグラフは現在の結果データを共有し、別のシミュレーションは開始しません。

**Download CSV** は、選択した信号とそのスケールについて、虚数部を含む保持済みの全サンプルをエクスポートします。表示のズームやサンプリング設定には左右されません。メインのグラフでは **PNG** もダウンロードできます。データがどの実験を表しているかが分かるように、レポートには選択したセットアップ、取得データ、単位も記載してください。

## 用意されたRCの検討例を試す
{: #try-the-prepared-rc-investigation}

[RC low-pass.dzn](../examples/simulation/rc-low-pass.dzn) をダウンロードし、**File → Open** から開いて実行します。この付属ファイルは、同梱の **rc-ac** チュートリアル例とは別のファイルです。測定、要件、調整の定義があらかじめ用意されています。

R1 = 1 kΩ、C = 1 µF の場合、公称遮断周波数は約159.15 Hzです。**Measurements** には遮断周波数、100 Hzでの利得、理想的な遮断周波数での位相が含まれます。**Requirements** では、遮断周波数が150～170 Hzの範囲内かどうかを確認します。

![RC付属回路図のCircuit Explorer調整コントロール](../images/simulation/explorer-tuning.png)

## 保存した回路を変更せずに調整する
{: #tune-without-changing-the-saved-circuit}

**Tune / sweep** でコンポーネントと数値プロパティを選び、**Add tuning control** を選択します。回路図上のコンポーネントを選択すると、選択画面でそのコンポーネントがあらかじめ選択されます。対応するソース／計測器の設定や、名前付きセットアップパラメーターにバインドすることもできます。任意のテキスト、式、モデルファイルの内容はスライダーの対象になりません。

コントロールでは、単位、範囲、線形／対数スケール、E12/E24/E96の標準値へのスナップに対応しています。値を変更すると、約500 ms後に実行がスケジュールされます。一時的な値は、保存されたコンポーネント値とは別に管理されます。

- **Undo tuning** は、ひとつ前の一時的なオーバーライドに戻します。
- **Reset** は、元の値と取得設定を復元します。
- **Apply** は、オーバーライドをひとつの取り消し可能な編集として回路図に書き込みます。

数値プロパティが回路に影響するのは、そのコンポーネントのSPICEテンプレートが実際にその値を使用している場合だけです。使用されていない属性を変更しても、モデルが変わるとは限りません。

### 1変数スイープ
{: #one-variable-sweeps}

**One-variable sweep** を展開し、コントロールを選択します。線形／対数の2～100点、または空白かセミコロンで区切った1～100個の明示的な値を指定します。**Run sweep** は、各値について選択した解析を実行します。**Cancel** は、それ以降のケースのスケジュールを停止し、完了済みの結果を保持します。

RC付属例では、1 kΩ、2.2 kΩ、4.7 kΩ、6.8 kΩ、10 kΩを用意しています。それぞれの理想的な遮断周波数は約159.15、72.34、33.86、23.41、15.92 Hzです。オーバーレイ、または名前付きの測定値をパラメーター値と比較します。これは、DC解析内で独立ソースを変化させる[DCスイープ解析](../Simulation-Analyses/#dc-sweep)とは異なります。

スイープの定義、値、単位、実行状況、取得した測定値は`.dzn`に保存されます。**Saved sweep** を使うと、グループを再確認できます。生の結果を削除すると波形のオーバーレイは消えますが、取得済みのスカラー値の表やレポートのメタデータは残る場合があります。通常の取得データおよびデータ量の制限内で、最大100個のスイープグループが保持されます。

## 名前付き測定を定義する
{: #define-named-measurements}

**Measurements** で名前を追加し、信号／コンポーネントを選択して設定を展開します。意味のある時間／周波数ウィンドウと、必要なレベルや基準値を設定します。コンポーネント／プローブのバインドにはシートの識別情報とリファレンスが使用されるため、ファイルを再度開いた後も維持できます。

![あらかじめ設定された遮断周波数、利得、位相の測定](../images/simulation/explorer-measurements.png)

| 測定 | 解釈 |
| --- | --- |
| 値、最小値、最大値、ピーク・ツー・ピーク | ある位置での信号値、または選択したウィンドウ内の極値 |
| 平均、RMS、リップルRMS | 時間重み付きの過渡量。リップルRMSでは平均値を除去 |
| 積分 | 時間に対する面積。Wを積分するとJになる |
| 立ち上がり／立ち下がり時間 | 指定した低／高レベル間の、最初の完全な10～90%遷移 |
| 周期、周波数、デューティ比、パルス幅 | 明示的なしきい値、またはウィンドウの中間レベルを使った、最初の完全な周期／パルス |
| 遅延 | 出力の最初の立ち上がりしきい値交差から、同じしきい値における基準信号の最初の交差を引いた値 |
| オーバーシュート／アンダーシュート | 指定した初期／最終レベルとステップ幅に対する逸脱 |
| 整定時間 | ウィンドウ開始から測定した、最終値の許容帯への最後の進入までの時間 |
| 時定数 | ウィンドウ開始から測定した、初期値 + (最終値 − 初期値) × (1 − 1/e) への最初の到達時間 |
| AC利得／位相 | 選択した周波数における複素出力／入力比 |
| 遮断周波数／帯域幅 | 選択した利得基準に対する半電力点（−3.0103 dB）の交差周波数 |
| 共振 | 内部にある絶対値の最大ピーク。端点での最大値は、共振が確認されたことを意味しない |
| その他の応答測定 | 通過帯域リップル、阻止帯域減衰量、ポートインピーダンスの絶対値、群遅延 |

過渡積分では、不等間隔のタイムステップと補間したウィンドウ端点が考慮されます。RMSにはDC成分が含まれ、リップルRMSではDC成分が除去されます。出力の交差が基準信号より先なら、遅延は負になることがあります。タイミングの測定には、対象の遷移や周期がウィンドウ内に十分含まれている必要があります。

ステップ測定では、初期／最終レベルを指定します。最終レベルが正しくないと、整定時間やオーバーシュートが誤解を招く値になります。最終サンプルが整定していない、交差がない、バインドが曖昧、単位が一致しない、またはウィンドウが無効な場合、値を作り出して0とするのではなく **unavailable** と表示されます。

遮断周波数の測定には、明示的な線形基準利得または **peak** を使用します。単純なRCフィルターには利得1の基準が適していますが、利得20のアンプには別の基準が必要です。帯域幅の測定には、有効な交差が2つ必要です。周波数の補間は対数的に行われます。スイープ端の任意のピークだけでは、共振を確認したことにはなりません。

## 要件とDCオーバーレイ
{: #requirements-and-dc-overlays}

**Requirements** を使うと、名前付き測定値が **at least**、**at most**、または両端を含む **between** の範囲を満たすかテストできます。単位は一致している必要があります。結果は **pass**、**fail**、**unavailable** のいずれかです。値を取得できない測定は、要件を満たしたことにはなりません。

![許容範囲を明示したRC遮断周波数の要件](../images/simulation/explorer-requirements.png)

利用可能な測定を選択すると、測定の根拠と、適用可能な回路図上のハイライトを確認できます。エクスポートする結果には、測定の定義、ウィンドウ、しきい値を含めてください。プローブ間の双方向ハイライトは、すべての種類の信号やモデルに完全対応しているわけではありません。

DC回路図オーバーレイには、最新の完了済み動作点取得データが必要です。電圧は0基準で表示されます。電流の向きは、設定された端子の順序に従います。消費電力は正の値で表されるため、電力を供給するソースの電力は負になる場合があります。理想抵抗の電流はV/Rから算出できます。対応していないデバイス電流は、値を作り出さずに省略されます。

## Analysis lab
{: #analysis-lab}

![Circuit ExplorerのAnalysis labワークフロー](../images/simulation/analysis-lab.png)

### 周波数特性とアンプの応答
{: #frequency-and-amplifier-response}

入力／出力、周波数範囲、読み取り周波数を選択します。ACを実行して、利得、位相、遮断周波数、帯域幅、共振、バンドパスのQ、群遅延を確認します。バンドパスのQは`f₀ / half-power bandwidth`を意味します。伝達関数の計算には、明示的に名前を付けた信号源を使用します。ポートインピーダンスを測定するには、意図的に設定した電圧／電流テスト構成が必要です。任意のノード比はループ利得の測定ではありません。

### 許容差とコーナー
{: #tolerance-and-corners}

モンテカルロスタディでは、設定されたコンポーネント分布を使って実行を繰り返します。分布には、許容差を指定した有界一様分布、または標準偏差を指定した非有界正規分布を使用できます。符号なしの乱数シードと2～100件のケースを設定します。同じシードとセットアップを再利用すると、サンプリングを再現できます。完全に正の相関を持つグループでは標準化された乱数が共有され、分布の種類も統一する必要があります。

物理的な抵抗、容量、インダクタンス、周波数のサンプル値が正でない場合、そのケースは失敗になります。失敗を黙って除外せず、内容を確認してください。平均、標本標準偏差、ヒストグラムはサンプル結果を示すものであり、製造される部品すべての特性を示すものではありません。

コーナー探索では、最大6個の独立変数、つまり最大64コーナーを列挙します。モンテカルロの相関グループは考慮されません。観測された最悪値の報告は、コーナー間における全体の最悪値を証明するものではありません。歩留まりは、入力されたモデル／分布の仮定に基づく参考値です。評価可能な要件がないスタディでは、歩留まりを推定できません。

### テストケース
{: #test-cases}

解析、パラメーター、トレース／測定／要件の定義、バインドをケースとして記録します。ケースごとに温度や、パラメーター、信号源、負荷のオーバーライドを変えてから、スイートを実行します。ケースで共有されるのは**現在の回路図とモデル**です。過去の回路図リビジョンが個別に保存されるわけではありません。各実行では入力の識別情報が記録されます。

JSONレポートには、条件、結果、スタディの履歴が含まれます。スタディは順次実行され、キャンセルできます。失敗したケースや収束しなかったケースも表示されます。定義、シード、ケース条件、グループの参照情報は`.dzn`に保持されます。通常の結果制限の範囲内で、直近100個のスタディグループが保持されます。

### 電力、効率、ストレス
{: #power-efficiency-and-stress}

対応するコンポーネントの電力信号を選択し、ピーク電圧、電流、電力の上限を明示的に設定します。平均／RMS／積分の測定により、平均電力、実効電流、エネルギーを求められます。効率の測定には、符号を正しく設定した電力供給側の境界と、有効負荷を消費側として設定した境界が必要です。対応していない、または曖昧なデバイス電流では、結果を取得できません。

小信号AC解析は、大信号ストレス試験ではありません。TinyCADで数値上限を設定しても、パッケージの熱モデル、パルス定格、保護機構が追加されるわけではありません。検討内容に適した過渡条件とモデルを使用し、その前提条件をレポートに記載してください。

## 現在の制限
{: #current-limits}

実装済みのワークフローには、FFT／高調波ひずみ解析、自動故障注入、無制限の多次元スイープ、自動最適化、協調型のLive／Pauseは含まれていません。結果を確認する際は、完了／停止／失敗の実行状況と、実際のデータの有無を確認してください。測定値や取得データが利用できない場合は、[トラブルシューティング](../Simulation-Troubleshooting/)を参照してください。
