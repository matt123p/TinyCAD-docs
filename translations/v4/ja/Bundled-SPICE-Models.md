# 同梱のSPICEモデル
{: #bundled-spice-models}

TinyCADには、オフラインで利用できるSPICEモデルのカタログが含まれています。同梱モデルを使用すると、ngspiceでコンポーネントをシミュレーションしたり、候補デバイスを比較したり、動作実績のある定義をもとにCustomモデルを作成したりできます。モデルはTinyCAD WebとDesktop Appの両方で利用できます。モデル選択ツールは、アプリケーションの読み込み後にローカルで動作します。

## モデル付きシンボルから始める
{: #start-with-a-modelled-symbol}

サイドパネルで **Standard → SPICE essentials** を開くか、ツールバーの **Simulation → SPICE components** を使用します。シンボルライブラリ全体を参照するには **More…** を選択します。SPICE essentialsの29個のシンボルにはすべて同梱モデルとプリセットのピン割り当てがあります。ほとんどは **TinyCAD Basic** モデルを使用します。LM358とLM324は、完全なOpenJellyBeanパッケージモデルを使用します。

シンボルを配置し、図面上で選択して、下部の **Symbol** パネルにある **SPICE** を開きます。**Bundled** には、リンクされたモデルとそのソースが表示されます。**Value**、**Wiper**、**Initial Voltage** などの通常のシンボルフィールドは、これらのフィールドを使用するTinyCAD Basicモデルを引き続き制御します。たとえば、抵抗器の **Value** を`10k`に設定すると、デフォルトの **Ideal resistor** モデルを使用して10 kΩをシミュレーションできます。

![配置したシンボルのSPICEタブでBundledが選択され、TinyCAD Basicの黄色LEDモデルへのリンクが表示されています。](/v4/Images/simulation/bundled-spice-properties.png)

回路全体で試すには、**Open Example → SPICE tutorial → divider** を選択し、いずれかの抵抗器を選択します。その **SPICE** タブに **Ideal resistor** のリンクが表示されます。抵抗値を変更してから、例のOperating Point設定を再実行します。保持されている結果は、編集前の回路を表しています。

## モデルを選択して割り当てる
{: #choose-and-attach-a-model}

1. シンボルの **SPICE** タブを開きます。**Bundled** を選択し、続いて **Find SPICE model…** を選択します。
2. 部品番号、別名、モデルID、またはデバイスファミリーを入力します。検索欄を空にすると、そのシンボルで利用できる選択肢が表示されます。
3. 行を選択します。表の下にある詳細には、モデルの説明、ソース、端子の順序、調整可能なパラメーターが表示されます。**View SPICE definition** を展開すると、インスタンステンプレートと、使用されるモデルカードやサブサーキットを確認できます。元の定義、または上流のアーカイブとメンバーのファイル名を確認するには、ソースリンクを選択します。
4. ピンの割り当てを確認し、必要に応じてパラメーターのオーバーライドを設定します。**Select SPICE model** を選択します。図面上では、選択中の配置が変更され、元に戻すこともできます。

![黄色LED用のFind SPICE modelダイアログ。選択されたcircsimモデルにはソースと、確認済みのアノードおよびカソードのピン番号が表示されています。](/v4/Images/simulation/bundled-spice-picker.png)

**SPICE essentialsシンボル** には、そのシンボルのピン配置について割り当てが確認済みのモデルのみが表示されます。シンボルによっては、デフォルトのBasicモデルのみが用意されています。たとえば黄色LEDでは、Basicモデルとcircsimの黄色LEDモデルを選べます。標準のNPNトランジスターは、汎用モデルのほか、OpenJellyBeanの`2N3904_OJ`などの代替モデルを使用でき、コレクター、ベース、エミッターはそれぞれピン3、1、2に割り当て済みです。

ライブラリIDのない古い配置を含む **その他のシンボル** では、そのエディションのカタログ全体を参照できます。候補として表示された一致項目を確認し、モデル端子ごとに異なる物理ピンを選択してください。回路図上で非表示の場合でも、電源ピンを含めます。シンボルの確認済みパッケージピン配置と、モデルの端子順序を使用してください。モデルで省略されている物理ピンは割り当て対象外にします。ピンの数や機能が誤っている一時的なシンボルは、デバイスを表す前に修正が必要です。

![カスタムライブラリ内の741シンボルに対する手動ピン割り当て。circsim LM741の5つの端子が物理ピン3、2、6、7、4に割り当てられています。](/v4/Images/simulation/bundled-spice-pin-mapping.png)

この例では、ピン3（非反転）、2（反転）、6（出力）、7（正電源）、4（負電源）を使用して、circsim `LM741`モデルを741シンボルに割り当てています。このモデルはオフセットヌルピンを省略しています。マルチパートのライブラリシンボルでは、TinyCADはテンプレートを使用するパーツ間で共通のピン番号を提示します。シンボルとシミュレーションの両方でパッケージ全体が必要な場合は、完全なパッケージモデルを選択してください。

選択ツールに **No models match this search** と表示された場合は、検索語を消すか、より広い検索語を試してください。タグ付きシンボルでは、確認済みの選択肢のみが表示される場合があります。別のモデルを使用するには、デバイスのピン配置を確認し、適切な[カスタムライブラリシンボル](../Custom-symbol-libraries/)またはCustom定義を使用してください。

## 適切な詳細度を選ぶ
{: #choose-the-right-level-of-detail}

| 知りたいこと | 最初に使用するモデル |
| --- | --- |
| 分圧回路、RC時定数、または基本的な回路動作を確認する | TinyCAD Basicを使用します。寄生成分や許容差が検討対象でない場合は、理想モデルが便利です。 |
| 特定の部品でバイアス、利得、ダイオードの順方向電圧降下、またはスイッチングを調べる | 正確な部品番号または文書化された同等品を検索します。使用する電圧、電流、温度、周波数での説明とモデルの前提を確認してください。 |
| 正確なモデルが入手できない場合に代替品を検討する | 文書化されたドロップイン候補、またはデバイスファミリーの汎用モデルを使用します。パッケージのピン機能、電源の極性、動作限界を個別に確認してください。近似する動作を記録します。 |
| ノイズ、入力同相範囲、熱ドリフト、プロセスコーナーなどの限界を調べる | モデルがその効果を明示的に扱っているか確認します。必要に応じて、適切なメーカーまたはプロセスモデルを[Custom定義](../SPICE-output/#models-templates-and-pin-order)として使用してください。 |

同梱モデルは標準的な動作を表します。たとえば、circsim 741は公称利得、帯域幅、スルーレート、オフセット、電源電流を表現します。高入力インピーダンスの入力段を使用しています。circsim黄色LEDモデルは、20 mAにおける2.10 Vのフィット値周辺の電気的動作をモデル化します。光出力、デバイス定格、最悪条件での動作には、それぞれ別の根拠が必要です。

## ライブラリのデフォルトを設定する、またはCustomコピーを編集する
{: #set-a-library-default-or-edit-a-custom-copy}

- **今後の配置に適用するには**、編集可能な`.tclib`ライブラリを開き、シンボルを選択します。その **SPICE** タブを開いて、同じモデル選択ツールを使用します。ライブラリを保存します。選択した定義が、そのエントリーから今後配置するシンボルのデフォルトになります。既存の配置には、保存済みの定義がそのまま残ります。
- **単一の配置に適用するには**、回路図上でそのシンボルを選択し、**SPICE** プロパティを変更します。同じ図面内で2つのモデルを並べて比較する場合に便利です。
- **モデルテキストを編集するには**、リンク済みシンボルで **Custom** を選択します。TinyCADは、割り当てられたピンとともに、インスタンステンプレートと必要な定義を編集可能なフィールドにコピーします。定義を含むモデルの場合、ローカルコピーでは配置ごとにスコープされた名前が使用されるため、同梱の元モデルと並行して実行できます。理想抵抗器では、インスタンステンプレートだけで十分です。

**Bundled** に戻すと、リンクされたモデルが復元されます。再び **Custom** に切り替えると、編集内容を取得できます。選択中のモードによって使用する定義が決まり、どちらの設定も保存と再オープン後に保持されます。**Remove attached model** を選択するとリンクが削除され、保存済みのテンプレートがあれば復元されます。

サポート対象の[KiCad SPICEインポート](../Importing-Symbols-from-KiCAD/#import-spice-models-with-symbols)は **Custom** の下に表示されます。インポートした定義を今後の配置にも使用するには、編集可能なライブラリにインポートして保存してください。

## 実行、保存、共有
{: #run-save-and-share}

1. 割り当て済みのピンと電源を接続し、SPICEグラウンド **0** への接続も含めます。
2. [Simulationシート](../Simulation/)を作成または開き、**Setup** で解析を選択して、**Run** を選択します。有効な同梱モデルは自動的に解決されます。Customモデルに必要な追加ファイルを割り当てるには、**Setup → SPICE models** を使用します。
3. 展開後のインスタンス行とモデル参照を確認するには、**Diagnostics → Generate circuit text** を開きます。結果が正しくないように見える場合は、ピンの順序と電源ネットを確認してください。

図面には各モデルのリビジョン、割り当て済みピン、パラメーター設定が保持され、参照された各パックのコピーも1つずつ保存されます。回路とモデル定義を共有するには、図面を保存します。Desktop専用のXSPICEモデルの実行にはDesktopエンジンが必要です。**Generate Spice NetList** は、参照されている同梱定義をSPICE出力に埋め込みます。エクスポートの選択肢とシミュレーションデッキと図面の違いについては、[SPICEモデルとネットリスト出力](../SPICE-output/#inspect-and-export-a-spice-netlist)を参照してください。

## カタログの内容とソース
{: #catalog-contents-and-sources}

TinyCAD Webには97個のカタログモデルが含まれています。Desktop Appでは、ネイティブXSPICEを必要とする定義が3つ追加されます。正確なモデルソースについては、各モデルの詳細にあるリンクを使用してください。TinyCADはライセンス通知をパックとともに配布しており、**About TinyCAD** からも確認できます。

| パック | モデル数 | 例 |
| --- | ---: | --- |
| TinyCAD Basic | 20 | 理想抵抗器、コンデンサー、インダクター、独立電源、可変抵抗器と変圧器のテンプレート、汎用半導体、741、共振器 |
| OpenJellyBean | 42 | BJT、MOSFET、JFET、信号用ダイオードとショットキーダイオード、ツェナーダイオード、LED、オペアンプのチャネルとパッケージ、可変抵抗器 |
| circsim | 15 | LM741、黄色LED、LM393、LM339、NE5532、NE555、フォトカプラー、レギュレーター、パワーMOSFET |
| Spice_Files | 14 | 汎用ダイオードとLED、ブリッジ整流器、フォトカプラー、スイッチ、リレー、16 MHz水晶振動子、10:1変圧器 |
| ngspice special models | 1 | ICL8038波形発生器 |
| ngspice special models (Desktop) | 3 | LTC1044HV電圧インバーター、LR8レギュレーターとその補助オペアンプ |
| SkyWater SKY130 | 1 | 基板端子付きの公称集積PNPトランジスター |
| GlobalFoundries GF180MCU | 3 | 公称MIMコンデンサー（1.0、1.5、2.0 fF/µm²） |
| IHP SG13G2 | 1 | 公称pnpMPA集積PNPトランジスター |

ファウンドリーのエントリーは、公称モデルを選択したものです。完全なプロセスキットには、個別のモデルツリー、コーナー、シミュレーター設定が含まれます。ソース一覧、ライセンス、SPICE essentialsで確認済みの代替モデルについては、[カタログリファレンス](https://github.com/matt123p/TinyCADv4/blob/main/docs/bundled-spice-models.md#catalog-sources)を参照してください。

## Desktop AIアシスタントに依頼する
{: #ask-the-desktop-ai-assistant}

SPICEのサポートを明示的に依頼すると、[Desktop AIアシスタント](../AI-Assistant/)はローカルカタログを検索し、モデルテキストとソースを調べ、シンボルへの割り当てを確認できます。配置済みコンポーネントへのモデルの割り当てや、新しいライブラリパーツを追加する際のデフォルトモデルとしての保存もできます。既存のCustomテンプレートを置き換える前には確認を求めます。通常の回路図またはシンボルの作業では、指定されたデフォルト設定を保持します。

読み取り専用で比較するには、次のように依頼してください。「Q1用の同梱SPICEモデルを探してください。端子順序と制限事項を、使用予定の部品と比較してください。図面は変更しないでください。」

編集を依頼するには、次のように指示してください。「物理ピンの割り当てを確認してから、同梱の2N3904モデルをQ1に割り当ててください。ソースと前提条件を表示してください。」
