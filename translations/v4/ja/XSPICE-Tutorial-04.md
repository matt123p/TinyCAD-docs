# 4. Dフリップフロップ、クロック、リセット
{: #d-flip-flops-clocks-and-reset}

[前へ](/v4/XSPICE-Tutorial-03/) · [目次](/v4/Simulation-Tutorials/) · [次へ](/v4/XSPICE-Tutorial-05/)

この章の例はTinyCADに同梱されています。**Open Example → XSPICE and digital tutorial**を選び、指定された例を選択してから、**Open Drawing**を選びます。ダウンロードは不要です。

**logic-dff**を開きます。D、CLK、RESETそれぞれに独立したアナログ
刺激信号が用意されています。X1の内部では、ブリッジがXSPICEのDフリップフロップに接続され、
QとNQはプロット用にアナログ出力へ変換されます。

![Dフリップフロップのテスト回路](/v4/Images/simulation-tutorials/xspice/logic-dff-circuit.png)
![計算されたクロック、データ、リセット、Q](/v4/Images/simulation-tutorials/xspice/logic-dff-results.png)

8 µsの過渡解析を実行します。クロックの立ち上がりエッジごとにQはDを取り込み、その状態を
エッジ間で保持します。伝搬が落ち着くと、NQはその反転出力になります。
最初のクロック立ち上がりエッジは約0.5 µsです。DはすでにHighなので、
モデルのクロックから出力までの遅延後にQがHighになります。この正エッジトリガーの例では、
クロックの立ち下がりエッジで新しいデータは取り込まれません。

## 実際のモデルインターフェースを確認する
{: #read-the-actual-model-interface}

内部インスタンスは次のとおりです。

```spice
Aff dd dc NULL dr dq dn flip
.model flip d_dff(ic=0 clk_delay=20n reset_delay=20n
+ rise_delay=5n fall_delay=5n)
```

ポートは、データ、クロック、非同期セット、非同期リセット、出力、反転出力です。`NULL`では、オプションのセット入力は未使用のままです。初期状態は
明示的に0に設定されています。ポートの順序はモデルの仕様です。表示ブロック上のピンの
位置だけでポート順序が決まるわけではありません。

## 非同期リセットをテストする
{: #test-asynchronous-reset}

RESETは約6 µsでHighになり、約0.5 µs継続します。Qは次の
クロック立ち上がりを待たずにクリアされます。リセットがアサートされている間は、
クロックの動作を解釈する前に出力を確認してください。リセット解除後は、その後のクロック
エッジでデータの取り込みが再開します。この例では、通常のD波形とは独立してリセットを検証します。

最初の取り込みエッジの前後に短い測定ウィンドウを設定し、2.5 Vでの
クロックからQまでの遅延を測定します。測定されたアナログ遅延にはブリッジも含まれ、
`clk_delay`だけの遅延ではありません。別のウィンドウをリセットの前後に設定して、非同期
クリアを調べます。複数の異なるトリガーイベントを、単一の最初のエッジの測定で
まとめて評価しようとしないでください。

## 初期状態とセットアップ／ホールドの前提
{: #initial-state-and-setuphold-assumptions}

`ic=0`を設定すると、このチュートリアルを再現可能にできます。実際の電源投入時
状態が未定義の設計で、都合のよい初期値0を前提とすると、リセット要件の欠落が見えなくなる
ことがあります。起動時に明示的なリセットパルスを試し、モデルの初期条件設定に
依存する場合と比較してください。

次に、データの遷移をクロックエッジの近くに移動します。機能モデルがイベントをどのように
順序付けるかを観察します。ただし、デジタル結果が正常だからといって、実デバイスがセットアップ時間と
ホールド時間を満たす証明にはなりません。この単純な機能モデルはトランジスタレベルの
メタスタビリティモデルではなく、メタスタビリティの解消確率を示すものでもありません。メーカーのタイミング制約と適切なデバイス
モデルは、電気的タイミング解析において別途必要な入力です。

記録に残すテストケースには、データ波形、クロックエッジの規約、
リセットの極性とタイミング、初期状態の前提、期待される取り込みシーケンス、
測定しきい値を含めると有用です。Qだけのスクリーンショットよりも多くの情報が得られます。
