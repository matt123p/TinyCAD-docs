# Controles táctiles
{: #touch-controls}

En una pantalla táctil, puede editar el dibujo directamente o usar la lupa para
colocar objetos con mayor precisión. Estos controles funcionan en el navegador y en el editor de escritorio.

## Tacto directo
{: #direct-touch}

- Toque para seleccionar o colocar un objeto con la herramienta activa.
- Arrastre con un dedo para mover objetos o realizar una selección, como con el ratón.
- Mantenga un dedo quieto durante aproximadamente un segundo para abrir el menú contextual del dibujo.
- Mueva dos dedos juntos para desplazar el dibujo; sepárelos o júntelos para
  ampliar o reducir el lienzo alrededor del gesto.
- Arrastre una vista previa de un símbolo desde el panel de bibliotecas hasta el dibujo para colocarlo.

## Colocación precisa con la lupa
{: #precise-placement-with-the-loupe}

La lupa amplía el área alrededor de una cruz de mira, para que el dedo no
cubra el punto de conexión al que intenta llegar.

1. Toque el dibujo, si es necesario, para mostrar **Mostrar lupa (Show Loupe)**; luego toque ese botón
   en la parte inferior del dibujo.
2. Deslice un dedo por el lienzo para orientar la cruz de mira. El movimiento es más lento
   que el de su dedo, para ofrecer un control más preciso; al levantar el dedo, la mira permanece en su lugar.
3. Use los controles con etiquetas que aparecen debajo de la lente:

   | Control | Acción |
   |---|---|
   | **Clic (Click)** | Haga clic en la cruz de mira para seleccionar un objeto o colocar un punto con la herramienta activa. |
   | **Arrastrar (Drag)** | Inicie un arrastre en la cruz de mira. Deslice un dedo por el lienzo para mover el puntero. |
   | **Soltar (Drop)** | Finalice el arrastre. Este control sustituye a **Arrastrar (Drag)** mientras haya un arrastre activo. |
   | **Menú (Menu)** | Abra el menú contextual en la cruz de mira. |
   | **Cerrar (Close)** | Cierre la lupa y vuelva al tacto directo. |

4. Toque **Ocultar lupa (Hide Loupe)** para volver al tacto directo.

![Lupa táctil que muestra un área de conexión ampliada, una cruz de mira y los controles Clic, Arrastrar y Menú.](../images/touch-loupe.png)

Por ejemplo, para dibujar un cable, elija **Cable (Wire)**, oriente la mira hacia el pin inicial y toque
**Clic (Click)**. Deslice el dedo para orientar la mira hacia el siguiente punto y toque **Clic (Click)** de nuevo.
Use **Menú (Menu)** para acceder a los comandos contextuales de la herramienta cuando quiera finalizar o cancelar.

El desplazamiento con dos dedos y el zoom mediante pellizco también funcionan con la lupa abierta. Finalice un
arrastre activo con **Soltar (Drop)** antes de cambiar la vista.
