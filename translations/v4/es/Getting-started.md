# TinyCAD: primeros pasos
{: #tinycad---getting-started}

TinyCAD v4 está disponible de dos maneras:

## Aplicación de escritorio
{: #desktop-app}

Puede que prefiera una versión instalada de TinyCAD si quiere trabajar sin conexión o asegurarse
de tener siempre acceso a TinyCAD.

Consulte las [Instrucciones de instalación](../TinyCAD-Desktop-App/) para saber cómo descargar, instalar y ejecutar esta versión de TinyCAD.

## Aplicación en línea
{: #online-app}

Puede que prefiera la versión en línea si no desea o no puede instalar TinyCAD; por ejemplo, en un entorno educativo o laboral donde no se permite instalar aplicaciones.

Consulte [Inicio rápido de TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) para saber cómo
empezar a usar TinyCAD directamente en el navegador web, sin necesidad de instalarlo.

## Explore un dibujo prediseñado
{: #explore-a-ready-made-drawing}

Use los [ejemplos incluidos](../Bundled-Examples/) para explorar una red, una estación de sensores, una configuración de audio, un banco de laboratorio o un proyecto de control de motores. En el escritorio, «Abrir ejemplo» está en la barra de título del navegador o en el menú Archivo.

Las [bibliotecas incluidas](../Bundled-Libraries/) están a la izquierda, en **Estándar**. Elija una colección, busque y arrastre una vista previa al dibujo.

Para calcular el comportamiento del circuito, empiece con [Simulación y SPICE](../Simulation/) o siga el [tutorial completo de SPICE](../SPICE-Tutorial/). El motor integrado está incluido en ambos productos. Use la aplicación de escritorio para el [curso de XSPICE digital](../XSPICE-Tutorial/) independiente.
