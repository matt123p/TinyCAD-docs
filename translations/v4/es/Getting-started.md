# TinyCAD: primeros pasos
{: #tinycad---getting-started}

Para obtener ayuda para crear símbolos, bibliotecas o circuitos a partir de instrucciones escritas y hojas de datos, consulta la [guía del asistente de IA](../AI-Assistant/), que incluye la configuración del proveedor y ejemplos de indicaciones.

TinyCAD v4 está disponible de dos formas distintas:

## Aplicación de escritorio
{: #desktop-app}

Quizá prefieras una versión instalada de TinyCAD si quieres trabajar sin conexión o asegurarte
de tener siempre acceso a TinyCAD.

Consulta las [instrucciones de instalación](../TinyCAD-Desktop-App/) para saber cómo descargar, instalar y ejecutar esta versión de TinyCAD.

## Aplicación en línea
{: #online-app}

Quizá prefieras la versión en línea si no quieres o no puedes instalar TinyCAD; por ejemplo, en un entorno educativo o laboral en el que no se permite instalar aplicaciones.

Consulta la [guía de inicio rápido de TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) para saber cómo
empezar a usar TinyCAD directamente en el navegador web, sin necesidad de instalarlo.

## Explora un dibujo listo para usar
{: #explore-a-ready-made-drawing}

Usa los [ejemplos incluidos](../Bundled-Examples/) para explorar un proyecto de red, estación de sensores, configuración de audio, banco de laboratorio o control de motores. En el escritorio, «Open Example» está en la barra de título del navegador o en el menú File.

Las [bibliotecas incluidas](../Bundled-Libraries/) están a la izquierda, bajo **Standard**. Elige una colección, busca y arrastra una vista previa hasta el dibujo.

Para calcular el comportamiento de un circuito, empieza por [Simulación y SPICE](../Simulation/) o sigue el [tutorial completo de SPICE](../SPICE-Tutorial/). El motor integrado está incluido en ambos productos. Usa la aplicación de escritorio para el [curso independiente de XSPICE sobre lógica digital](../XSPICE-Tutorial/).
