# TinyCAD v4 - Primeros pasos
{: #tinycad-v4---getting-started}

TinyCAD v4 está disponible de dos maneras distintas:

## Aplicación de escritorio
{: #desktop-app}

Puede preferir una versión instalada de TinyCAD si desea trabajar sin conexión o asegurarse
de tener siempre acceso a TinyCAD.

Consulte [Instrucciones de instalación](../TinyCAD-Desktop-App/) para saber cómo descargar, instalar y ejecutar esta versión de TinyCAD.

## Aplicación en línea
{: #online-app}

Puede preferir la versión en línea si no desea o no puede instalar TinyCAD, por ejemplo, en un entorno educativo o laboral donde no se permite instalar aplicaciones.

Consulte [Inicio rápido de TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) para saber cómo
empezar a usar TinyCAD directamente en el navegador web sin necesidad de instalarlo.
