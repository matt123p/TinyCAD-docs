# TinyCAD: primeros pasos
{: #tinycad---getting-started}

TinyCAD v4 está disponible de dos maneras distintas:

## Aplicación de escritorio
{: #desktop-app}

Quizá prefiera una versión instalada de TinyCAD si desea trabajar sin conexión o asegurarse de
que siempre tendrá acceso a TinyCAD.

Consulte las [Instrucciones de instalación](../TinyCAD-Desktop-App/) para saber cómo descargar, instalar y ejecutar esta versión de TinyCAD.

## Aplicación en línea
{: #online-app}

Quizá prefiera la versión en línea si no desea o no puede instalar TinyCAD; por ejemplo, en un entorno educativo o laboral en el que no se permite instalar aplicaciones.

Consulte [Inicio rápido de TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) para obtener instrucciones sobre cómo
empezar a usar TinyCAD directamente en el navegador web, sin necesidad de instalarlo.
