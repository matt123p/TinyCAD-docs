# Traducción de idiomas
{: #language-translation}

TinyCAD puede cambiarse entre varios idiomas de interfaz.

## Idiomas disponibles
{: #available-languages}

Las opciones de idioma actuales son:

| Código | Idioma |
|---|---|
| `en` | Inglés |
| `nl` | Neerlandés |
| `fr` | Francés |
| `es` | Español |
| `de` | Alemán |
| `it` | Italiano |
| `ja` | 日本語 |
| `pl` | Polaco |
| `zh-CN` | 中文 (简体) |

## Calidad de la traducción y comentarios
{: #translation-quality-and-feedback}

Estas traducciones se mantienen mediante IA.

Si observa expresiones poco naturales, términos técnicos incorrectos o texto sin traducir,
agradecemos mucho sus comentarios. También agradecemos las sugerencias de idiomas adicionales
para la traducción.
