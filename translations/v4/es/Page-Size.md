# Tamaño de página
{: #page-size}

Use **Tamaño de página** para establecer las dimensiones de todas las hojas.

<img src="/v4/images/media/image4.png" alt="The page size dialog" />

## Qué puede cambiar
{: #what-you-can-change}

- **Tamaño del papel**: elija un tamaño de papel estándar, como A4.
- **Orientación**: seleccione **Vertical** para una página más alta o **Horizontal** para una página más ancha.
- **Ancho** y **Alto**: introduzca un tamaño de página personalizado en milímetros.

Al elegir un tamaño de papel estándar, TinyCAD completa el ancho y el alto por
usted. Al cambiar la orientación, se intercambian esas dimensiones.

## Uso habitual
{: #typical-use}

Use el tamaño de página que corresponda al tipo de salida que desea:

- elija un tamaño estándar para imprimir o exportar a PDF
- use la orientación horizontal para esquemas más anchos
- use un ancho y un alto personalizados cuando ningún tamaño de papel estándar se ajuste al dibujo

El tamaño de página seleccionado se guarda con la hoja como parte del dibujo.
