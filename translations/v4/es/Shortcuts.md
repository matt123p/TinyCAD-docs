# Atajos de teclado
{: #shortcuts}

El uso de atajos de teclado en lugar de hacer clic en la barra de herramientas agiliza el dibujo.

**Nota:** Estos atajos difieren de los de TinyCAD v3 porque las aplicaciones web
no exponen las teclas F de la misma manera.

| Tecla | Acción |
|---|---|
| `Esc` | Cancelar la acción de colocación o dibujo actual; si no, quitar la selección |
| `W` | Herramienta de cableado |
| `N` | Sin conexión (No Connect) |
| `P` | Alimentación (Power) |
| `L` | Etiqueta (Label) |
| `T` | Texto (Text) |
| `B` | Bus (Bus) |
| `S` | Forma (rectángulo/elipse/línea) |
| `+` | Ampliar |
| `=` | Ampliar |
| `-` | Reducir |
| `_` | Reducir |
| Teclas de flecha | Mover los elementos seleccionados según el espaciado de la cuadrícula cuando el ajuste está activado, o en pequeños incrementos cuando está desactivado; desplazar la vista cuando no hay nada seleccionado |
| `Ctrl` + Teclas de flecha | Mover los elementos seleccionados en pequeños incrementos, o desplazar la vista en incrementos menores |
| `Ctrl-F` | Buscar (Find) |
| `Ctrl-P` | Imprimir (Print) |
| `Ctrl-C` | Copiar (Copy) |
| `Ctrl-X` | Cortar (Cut) |
| `Ctrl-V` | Pegar (Paste) |
| `Del` | Eliminar (Delete) |
| `Ctrl-Z` | Deshacer (Undo) |
| `Ctrl-Y` | Rehacer (Redo) |

Escape también cancela la creación cuando un botón de la barra de herramientas tiene el foco. Al escribir en un
campo de texto o usar un menú o cuadro de diálogo, primero termine o cierre ese control.

Algunos atajos pueden ser interceptados por el navegador y activar acciones del
navegador en su lugar.
