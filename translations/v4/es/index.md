# Manual de TinyCAD
{: #tinycad-manual}

TinyCAD v4 está disponible tanto como aplicación de escritorio como aplicación en línea basada en navegador. Solo hay
unas pocas diferencias de funciones entre las dos versiones.

Visite la [página de diferencias entre funciones](Feature-Differences/) si desea conocer las diferencias exactas entre las versiones de TinyCAD.

## Advertencia
{: #warning}

**TinyCAD** se escribe y distribuye de forma gratuita como un proyecto de código abierto impulsado por la comunidad. Se proporciona «tal cual» y puede contener errores o tener funciones incompletas.  

Es su responsabilidad hacer copias de seguridad de su trabajo y evitar la pérdida de datos. Es su responsabilidad comprobar todo cuidadosamente antes de construir circuitos o imprimir PCBs.

## Contribuir a este manual
{: #contribute-to-this-manual}

El manual de TinyCAD es de código abierto y se mantiene en GitHub Pages.
Se agradecen las contribuciones de la comunidad, incluidas las correcciones de errores tipográficos, una redacción más clara,
nuevas capturas de pantalla y ejemplos ampliados.

- [Cómo contribuir al manual](Contributing-to-the-Manual/)
