# Instrucciones de instalación
{: #installation-instructions}

Esta página describe la instalación de TinyCAD.

## Instalar en Windows
{: #install-on-windows}

En Windows, la forma recomendada de instalar TinyCAD v4 es desde la
[Microsoft Store](https://apps.microsoft.com/detail/9NZQ1M56NM3V).

Si usas Windows, utiliza la versión de Microsoft Store, a menos que tengas un
motivo concreto para instalarlo desde otra fuente.

Las [versiones de GitHub](https://github.com/matt123p/TinyCADv4/releases) también
incluyen un instalador para Windows.

## Instalar en macOS
{: #install-on-macos}

Para macOS, descarga TinyCAD v4 desde las
[versiones de GitHub](https://github.com/matt123p/TinyCADv4/releases).
La imagen de disco de macOS (`.dmg`) está compilada para Apple Silicon (ARM64).

## Instalar en Linux
{: #install-on-linux}

TinyCAD está disponible a través de la [Snap Store](https://snapcraft.io/tinycad) para 
distribuciones Linux populares compatibles con Snap, incluidas Ubuntu, Kubuntu, KDE Neon, Pop!_OS, elementary OS,
Debian, Fedora, openSUSE, Manjaro, Arch Linux, CentOS y Red Hat Enterprise
Linux.

En Ubuntu y muchas distribuciones basadas en Ubuntu, la compatibilidad con Snap ya está disponible.
En ese caso, puedes instalar TinyCAD directamente con:

```bash
sudo snap install tinycad
```
Si esto no funciona, la página de TinyCAD en la [Snap Store](https://snapcraft.io/tinycad) incluye 
enlaces a instrucciones de configuración específicas para cada distribución Linux compatible.

Las [versiones de GitHub](https://github.com/matt123p/TinyCADv4/releases) también
incluyen paquetes de Linux `.deb` para x64 y ARM64. El paquete Snap está compilado para
x64. Ya no se proporcionan paquetes para Linux ARMv7 (ARM de 32 bits), porque el entorno de ejecución actual de
Electron no admite esa arquitectura.

## Usar en ChromeOS y Chromebooks
{: #use-on-chromeos-and-chromebooks}

En ChromeOS, usa [TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/)
en lugar de instalar la aplicación de escritorio.
