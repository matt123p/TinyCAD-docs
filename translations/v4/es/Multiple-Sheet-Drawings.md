# Esquemas de varias hojas
{: #mutliple-sheet-drawings}

Utilice varias hojas cuando el diseño sea demasiado grande para una sola página o cuando quiera separar los bloques funcionales.

## Por qué utilizar varias hojas
{: #why-use-multiple-sheets}

- Mantenga legibles los esquemas complejos.
- Organice las partes relacionadas según su función.

## Flujo de trabajo básico
{: #basic-workflow}

1. Cree una hoja nueva en el esquema.
2. Asigne un nombre claro a cada hoja (por ejemplo: `Power`, `Control`, `I/O`).
3. Coloque los símbolos y los cables en cada hoja según sea necesario.
4. Utilice etiquetas y símbolos de alimentación para establecer conexiones entre hojas.
