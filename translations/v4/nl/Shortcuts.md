# Sneltoetsen
{: #shortcuts}

Tekenen gaat sneller met sneltoetsen dan met klikken op de werkbalk.

**Opmerking:** Deze sneltoetsen verschillen van die van TinyCAD v3, omdat browsertoepassingen F-toetsen niet op dezelfde manier beschikbaar stellen.

| Toets | Actie |
|---|---|
| `Esc` | Annuleert de huidige plaatsings- of tekenactie; maakt anders de selectie ongedaan |
| `W` | Draadgereedschap |
| `N` | Geen verbinding (No Connect) |
| `P` | Voeding |
| `L` | Label |
| `T` | Tekst |
| `B` | Bus |
| `S` | Vorm (rechthoek/ellips/lijn) |
| `+` | Inzoomen |
| `=` | Inzoomen |
| `-` | Uitzoomen |
| `_` | Uitzoomen |
| Pijltoetsen | Verplaatst geselecteerde items met de rasterafstand wanneer uitlijnen op raster is ingeschakeld, of in kleine stappen wanneer dit is uitgeschakeld; verschuift het beeld wanneer niets is geselecteerd |
| `Ctrl` + pijltoetsen | Verplaatst geselecteerde items in kleine stappen, of verschuift het beeld in kleinere stappen |
| `Ctrl-F` | Zoeken |
| `Ctrl-P` | Afdrukken |
| `Ctrl-C` | Kopiëren |
| `Ctrl-X` | Knippen |
| `Ctrl-V` | Plakken |
| `Del` | Verwijderen |
| `Ctrl-Z` | Ongedaan maken |
| `Ctrl-Y` | Opnieuw uitvoeren |

Escape annuleert ook het aanmaken wanneer een werkbalkknop de focus heeft. Als u in een tekstveld typt of een menu of dialoogvenster gebruikt, voltooi of sluit u dat eerst.

Sommige sneltoetsen kunnen door de browser worden onderschept en in plaats daarvan browseracties activeren.
