# Installatie-instructies
{: #installation-instructions}

Deze pagina behandelt de installatie van TinyCAD.

## Installeren op Windows
{: #install-on-windows}

Voor Windows is de aanbevolen manier om TinyCAD v4 te installeren via de
[Microsoft Store](https://apps.microsoft.com/detail/9NZQ1M56NM3V).

Als u Windows gebruikt, gebruik dan de versie uit de Microsoft Store, tenzij u een
specifieke reden hebt om de installatie via een andere bron uit te voeren.

De [GitHub-releases](https://github.com/matt123p/TinyCADv4/releases) bevatten ook
een Windows-installatieprogramma.

## Installeren op macOS
{: #install-on-macos}

Download TinyCAD v4 voor macOS via de
[GitHub-releases](https://github.com/matt123p/TinyCADv4/releases).
De macOS-schijfkopie (`.dmg`) is gebouwd voor Apple Silicon (ARM64).

## Installeren op Linux
{: #install-on-linux}

TinyCAD is beschikbaar via de [Snap Store](https://snapcraft.io/tinycad) voor 
veelgebruikte Linux-distributies met Snap-ondersteuning, waaronder Ubuntu, Kubuntu, KDE Neon, Pop!_OS, elementary OS,
Debian, Fedora, openSUSE, Manjaro, Arch Linux, CentOS en Red Hat Enterprise
Linux.

Op Ubuntu en veel op Ubuntu gebaseerde distributies is Snap-ondersteuning al aanwezig.
In dat geval kunt u TinyCAD rechtstreeks installeren met:

```bash
sudo snap install tinycad
```
Als dit niet werkt, bevat de TinyCAD-pagina in de [Snap Store](https://snapcraft.io/tinycad) 
koppelingen naar distributiespecifieke installatie-instructies voor elke ondersteunde Linux-distributie.

De [GitHub-releases](https://github.com/matt123p/TinyCADv4/releases) bevatten ook
Linux-`.deb`-pakketten voor x64 en ARM64. Het Snap-pakket is gebouwd voor
x64. Linux ARMv7-pakketten (32-bits ARM) worden niet langer aangeboden, omdat de huidige
Electron-runtime die architectuur niet ondersteunt.
