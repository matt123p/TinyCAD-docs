# Taalvertaling
{: #language-translation}

TinyCAD kan worden ingesteld op verschillende interfacetalen.

## Beschikbare talen
{: #available-languages}

De huidige taalopties zijn:

| Code | Taal |
|---|---|
| `en` | Engels |
| `nl` | Nederlands |
| `fr` | Frans |
| `es` | Spaans |
| `de` | Duits |
| `it` | Italiaans |
| `ja` | 日本語 |
| `pl` | Pools |
| `zh-CN` | 中文 (简体) |

## Kwaliteit van de vertaling en feedback
{: #translation-quality-and-feedback}

Deze vertalingen worden onderhouden met behulp van AI.

Als u onhandige formuleringen, onjuiste technische termen of onvertaalde tekst opmerkt,
stellen we uw feedback zeer op prijs. Suggesties voor aanvullende vertalingstalen
zijn ook welkom.
