# Skróty klawiaturowe
{: #shortcuts}

Korzystanie ze skrótów klawiaturowych zamiast klikania przycisków paska narzędzi przyspiesza rysowanie.

**Uwaga:** Skróty te różnią się od skrótów w TinyCAD v3, ponieważ aplikacje przeglądarkowe
nie udostępniają klawiszy funkcyjnych F w ten sam sposób.

| Klawisz | Działanie |
|---|---|
| `Esc` | Anuluj bieżące umieszczanie lub rysowanie; jeśli nie jest ono wykonywane, wyczyść zaznaczenie |
| `W` | Narzędzie przewodu |
| `N` | Brak połączenia (No Connect) |
| `P` | Zasilanie |
| `L` | Etykieta |
| `T` | Tekst |
| `B` | Magistrala |
| `S` | Kształt (prostokąt/elipsa/linia) |
| `+` | Powiększ |
| `=` | Powiększ |
| `-` | Pomniejsz |
| `_` | Pomniejsz |
| Klawisze strzałek | Przesuń zaznaczone elementy o odstęp siatki, gdy przyciąganie jest włączone, lub małymi krokami, gdy jest wyłączone; gdy nic nie jest zaznaczone, przesuń widok |
| `Ctrl` + klawisze strzałek | Przesuń zaznaczone elementy małymi krokami lub przesuń widok mniejszymi krokami |
| `Ctrl-F` | Znajdź |
| `Ctrl-P` | Drukuj |
| `Ctrl-C` | Kopiuj |
| `Ctrl-X` | Wytnij |
| `Ctrl-V` | Wklej |
| `Del` | Usuń |
| `Ctrl-Z` | Cofnij |
| `Ctrl-Y` | Ponów |

Klawisz Escape anuluje również tworzenie, gdy fokus znajduje się na przycisku paska narzędzi. Podczas wpisywania tekstu
w polu tekstowym lub korzystania z menu albo okna dialogowego najpierw zakończ wprowadzanie lub zamknij ten element sterujący.

Niektóre skróty mogą być przechwytywane przez przeglądarkę i zamiast tego uruchamiać jej działania.
