# Tłumaczenie języka
{: #language-translation}

TinyCAD można przełączyć na jeden z kilku języków interfejsu.

## Dostępne języki
{: #available-languages}

Obecnie dostępne są następujące języki:

| Kod | Język |
|---|---|
| `en` | Angielski |
| `nl` | Niderlandzki |
| `fr` | Francuski |
| `es` | Hiszpański |
| `de` | Niemiecki |
| `it` | Włoski |
| `ja` | 日本語 |
| `pl` | Polski |
| `zh-CN` | 中文 (简体) |

## Jakość tłumaczenia i opinie
{: #translation-quality-and-feedback}

Tłumaczenia są opracowywane przez AI.

Zachęcamy do przesyłania opinii, jeśli zauważysz niezręczne sformułowania, nieprawidłowe terminy techniczne lub nieprzetłumaczony tekst.
Chętnie przyjmiemy także propozycje dodania kolejnych języków tłumaczenia.
