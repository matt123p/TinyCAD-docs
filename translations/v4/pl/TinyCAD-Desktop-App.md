# Instrukcja instalacji
{: #installation-instructions}

Ta strona zawiera informacje o instalacji TinyCAD.

## Instalacja w systemie Windows
{: #install-on-windows}

W systemie Windows zalecanym sposobem instalacji TinyCAD v4 jest użycie
[Microsoft Store](https://apps.microsoft.com/detail/9NZQ1M56NM3V).

Jeśli używasz systemu Windows, skorzystaj z wersji dostępnej w Microsoft Store, chyba że masz
konkretny powód, aby instalować program z innego źródła.

[Wydania w serwisie GitHub](https://github.com/matt123p/TinyCADv4/releases) zawierają również
instalator dla systemu Windows.

## Instalacja w systemie macOS
{: #install-on-macos}

W systemie macOS pobierz TinyCAD v4 ze strony
[wydań w serwisie GitHub](https://github.com/matt123p/TinyCADv4/releases).
Obraz dysku macOS (`.dmg`) jest przeznaczony dla komputerów Apple Silicon (ARM64).

## Instalacja w systemie Linux
{: #install-on-linux}

TinyCAD jest dostępny w [Snap Store](https://snapcraft.io/tinycad) dla
popularnych dystrybucji Linuksa obsługujących snap, w tym Ubuntu, Kubuntu, KDE Neon, Pop!_OS, elementary OS,
Debian, Fedora, openSUSE, Manjaro, Arch Linux, CentOS i Red Hat Enterprise
Linux.

W Ubuntu i wielu dystrybucjach opartych na Ubuntu obsługa snap jest już dostępna.
W takim przypadku możesz zainstalować TinyCAD bezpośrednio za pomocą polecenia:

```bash
sudo snap install tinycad
```
Jeśli to nie zadziała, strona TinyCAD w [Snap Store](https://snapcraft.io/tinycad) zawiera
łącza do instrukcji konfiguracji dla poszczególnych dystrybucji Linuksa.

[Wydania w serwisie GitHub](https://github.com/matt123p/TinyCADv4/releases) zawierają również
pakiety Linux `.deb` dla x64 i ARM64. Pakiet Snap jest przeznaczony dla
x64. Pakiety Linux dla ARMv7 (32-bit ARM) nie są już udostępniane, ponieważ obecne
środowisko uruchomieniowe Electron nie obsługuje tej architektury.

## Korzystanie z systemu ChromeOS i Chromebooków
{: #use-on-chromeos-and-chromebooks}

W systemie ChromeOS skorzystaj z [TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/)
zamiast instalować aplikację na komputer.
