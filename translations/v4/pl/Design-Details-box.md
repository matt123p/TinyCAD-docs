# Ramka Szczegółów projektu
{: #design-details-box}

Każdy projekt przechowuje metadane dokumentu, takie jak tytuł, autor i powiązane
informacje. Wartości te można edytować za pomocą polecenia **Szczegóły projektu**.

Ramka Szczegółów projektu może pojawić się w lewym dolnym rogu rysunku:

<img src="/v4/images/media/image15.png" alt="Design details box displayed on the schematic page with title and document metadata fields" style="width: 4.65625in; height: 2.20833in;" />

## Edytowanie szczegółów projektu
{: #edit-design-details}

1. Otwórz schemat.
2. Otwórz **Szczegóły projektu** w menu Plik/narzędziach.
3. Zaktualizuj wybrane pola (na przykład tytuł i autora).
4. Zapisz projekt.

Możesz je edytować w menu ustawień za pomocą polecenia **Szczegóły projektu**:

<img src="/v4/images/media/image16.png" alt="Menu showing the Design Details command used to edit document metadata" />

Po zapisaniu projektu te informacje zostaną zapisane razem z nim.

## Wyświetlanie ramki Szczegółów
{: #display-details-box}

Opcja **Wyświetl ramkę Szczegółów** określa, czy panel szczegółów jest widoczny
na rysunku.

- Po włączeniu szczegóły są wyświetlane na schemacie.
- Ramka szczegółów jest drukowana razem z projektem.
- Ramka szczegółów pojawia się w prawym dolnym obszarze rysunku.
