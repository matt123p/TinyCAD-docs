# Encadré des détails du dessin
{: #design-details-box}

Chaque dessin stocke des métadonnées du document, telles que le titre, l’auteur et les informations associées. Vous pouvez modifier ces valeurs à l’aide de la commande **Détails du dessin (Design Details)**.

L’encadré des détails du dessin peut apparaître en bas à gauche du dessin :

<img src="/v4/images/media/image15.png" alt="Design details box displayed on the schematic page with title and document metadata fields" style="width: 4.65625in; height: 2.20833in;" />

## Modifier les détails du dessin
{: #edit-design-details}

1. Ouvrez votre schéma.
2. Ouvrez **Détails du dessin (Design Details)** depuis le menu/fichier ou les outils.
3. Mettez à jour les champs souhaités (par exemple, le titre et l’auteur).
4. Enregistrez le dessin.

Vous pouvez les modifier dans le menu des paramètres à l’aide de **Détails du dessin (Design Details)** :

<img src="/v4/images/media/image16.png" alt="Menu showing the Design Details command used to edit document metadata" />

Lorsque le dessin est enregistré, ces détails le sont également.

## Afficher l’encadré des détails
{: #display-details-box}

L’option **Afficher l’encadré des détails** détermine si le panneau des détails est affiché sur le dessin.

- Lorsqu’elle est activée, les détails s’affichent sur le schéma.
- L’encadré des détails est imprimé avec le dessin.
- L’encadré des détails apparaît dans la zone en bas à droite du dessin.

## Remarques
{: #notes}

Les détails du dessin sont propres à chaque feuille : dans les dessins comportant plusieurs feuilles, chacune peut avoir ses propres détails.

- Consultez [Dessins à plusieurs feuilles](../Multiple-Sheet-Drawings/) si votre dessin s’étend sur plusieurs pages.
- Consultez [Format de page](../Page-Size/) pour contrôler la mise en page de la feuille autour de l’encadré des détails.
- Consultez [Impression](../Printing/) pour savoir comment l’encadré des détails apparaît à l’impression ou dans le fichier PDF.
