# Raccourcis
{: #shortcuts}

L’utilisation des raccourcis clavier plutôt que des clics dans la barre d’outils accélère le dessin.

**Remarque :** ces raccourcis diffèrent de ceux de TinyCAD v3, car les applications
web n’exposent pas les touches F de la même manière.

| Touche | Action |
|---|---|
| `Esc` | Annuler le placement ou l’action de dessin en cours ; sinon, désélectionner |
| `W` | Outil Fil |
| `N` | Non connecté (No Connect) |
| `P` | Alimentation (Power) |
| `L` | Étiquette (Label) |
| `T` | Texte (Text) |
| `B` | Bus |
| `S` | Forme (rectangle/ellipse/ligne) |
| `+` | Zoom avant |
| `=` | Zoom avant |
| `-` | Zoom arrière |
| `_` | Zoom arrière |
| Touches fléchées | Déplacer les éléments sélectionnés selon l’espacement de la grille lorsque l’alignement sur la grille est activé, ou par petits incréments lorsqu’il est désactivé ; faire défiler la vue si aucun élément n’est sélectionné |
| `Ctrl` + touches fléchées | Déplacer les éléments sélectionnés par petits incréments, ou faire défiler la vue par incréments plus petits |
| `Ctrl-F` | Rechercher (Find) |
| `Ctrl-P` | Imprimer (Print) |
| `Ctrl-C` | Copier (Copy) |
| `Ctrl-X` | Couper (Cut) |
| `Ctrl-V` | Coller (Paste) |
| `Del` | Supprimer (Delete) |
| `Ctrl-Z` | Annuler (Undo) |
| `Ctrl-Y` | Rétablir (Redo) |

La touche Échap annule également la création lorsqu’un bouton de la barre d’outils a le focus. Lorsque vous saisissez du texte dans un
champ ou utilisez un menu ou une boîte de dialogue, terminez ou fermez d’abord ce contrôle.

Certains raccourcis peuvent être interceptés par le navigateur et déclencher des actions
propres à celui-ci.
