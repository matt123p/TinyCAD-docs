# Dossiers de bibliothèques
{: #library-folders}

## Vue d’ensemble
{: #overview}

Le panneau Mes bibliothèques prend en charge les dossiers afin de vous permettre d’organiser les bibliothèques installées en groupes.


<div class="manual-tabset" data-tabset="product-mode" data-tabset-label="Choose your TinyCAD product" data-default-tab="Browser" markdown="1">

### Navigateur
{: #browser}

Les dossiers de bibliothèques ne sont pas pris en charge dans la version Navigateur de TinyCAD.

### Application de bureau
{: #desktop-app}

Les dossiers sont enregistrés avec votre liste de bibliothèques, de sorte que la structure est conservée à la prochaine ouverture de TinyCAD.

Les dossiers de bibliothèques sont uniquement disponibles dans l’application de bureau.

Les modes basés sur le navigateur affichent toujours Mes bibliothèques lorsqu’ils le prennent en charge, mais ne permettent ni de créer des dossiers, ni de regrouper des bibliothèques dans des dossiers, ni de les déplacer par glisser-déposer.

#### Actions possibles
{: #what-you-can-do}

- Créer des dossiers pour regrouper les bibliothèques associées
- Renommer des dossiers
- Supprimer des dossiers
- Réorganiser les dossiers par glisser-déposer
- Déplacer des bibliothèques d’un dossier à un autre par glisser-déposer
- Ajouter plusieurs fichiers de bibliothèque existants en une seule opération
- Ajouter des bibliothèques directement dans le dossier actuellement sélectionné

Les bibliothèques qui ne sont affectées à aucun dossier apparaissent dans la section Sans dossier.

#### Créer un dossier
{: #create-a-folder}

1. Ouvrez le panneau Bibliothèques.
2. Passez à Mes bibliothèques.
3. Sélectionnez le bouton de dossier dans l’en-tête du panneau.
4. Saisissez un nom pour le nouveau dossier.

Le nouveau dossier apparaît dans la liste des bibliothèques et peut être sélectionné immédiatement.

#### Sélectionner un dossier
{: #select-a-folder}

Cliquez sur la ligne d’un dossier pour le sélectionner.

Le dossier sélectionné est utilisé lorsque vous ajoutez des bibliothèques existantes.

Si vous cliquez sur une bibliothèque, TinyCAD sélectionne automatiquement le dossier auquel elle appartient. Cela indique clairement où seront placées les bibliothèques nouvellement ajoutées.

#### Ajouter des bibliothèques à un dossier
{: #add-libraries-to-a-folder}

1. Sélectionnez le dossier cible dans Mes bibliothèques.
2. Sélectionnez Ajouter.
3. Choisissez un ou plusieurs fichiers de bibliothèque existants.

Les bibliothèques sélectionnées sont ajoutées au dossier sélectionné.

Si vous ne sélectionnez pas de dossier personnalisé, les bibliothèques sont ajoutées à Sans dossier.

#### Déplacer des bibliothèques entre des dossiers
{: #move-libraries-between-folders}

Faites glisser une bibliothèque depuis son emplacement actuel et déposez-la sur un autre dossier.

Vous pouvez également déposer une bibliothèque sur Sans dossier pour la retirer d’un dossier personnalisé.

Si un dossier est vide, TinyCAD affiche une cible de dépôt qui vous permet d’y déplacer des bibliothèques.

#### Réorganiser les dossiers
{: #reorder-folders}

Les dossiers peuvent être réorganisés directement dans le panneau.

1. Survolez le dossier que vous souhaitez déplacer.
2. Faites glisser la poignée de réorganisation.
3. Déposez le dossier à l’emplacement cible.

Le nouvel ordre est enregistré automatiquement.

#### Renommer ou supprimer un dossier
{: #rename-or-delete-a-folder}

Les boutons d’action du dossier s’affichent lorsque vous le survolez ou le sélectionnez.

- Sélectionnez Modifier pour renommer le dossier.
- Sélectionnez Supprimer pour retirer le dossier.

Lorsqu’un dossier est supprimé, toutes les bibliothèques qu’il contient sont déplacées vers Sans dossier. Les fichiers de bibliothèque eux-mêmes ne sont pas supprimés de TinyCAD.

#### Bibliothèques sans dossier
{: #unfiled-libraries}

Sans dossier est l’emplacement par défaut des bibliothèques qui ne sont affectées à aucun dossier personnalisé.

- Les nouvelles bibliothèques sont placées dans Sans dossier si aucun dossier personnalisé n’est sélectionné
- Les bibliothèques d’un dossier supprimé sont déplacées vers Sans dossier
- Vous pouvez faire glisser des bibliothèques de Sans dossier vers n’importe quel dossier personnalisé

Lorsqu’il n’existe aucun dossier personnalisé, TinyCAD affiche simplement la liste des bibliothèques sans en-tête Sans dossier.

#### Remarques
{: #notes}

- Les modifications apportées à l’organisation des dossiers sont enregistrées avec la configuration de vos bibliothèques
- L’ajout simultané de plusieurs bibliothèques est pris en charge lors du choix de fichiers de bibliothèque existants
- L’ordre des dossiers et l’affectation des bibliothèques aux dossiers sont conservés d’une session à l’autre
