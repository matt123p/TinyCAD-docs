### Navigateur
{: #browser}

Pour imprimer depuis un navigateur, utilisez l’option Exporter en PDF (Export to PDF). Vous pouvez ensuite imprimer directement le PDF.

<img src="/v4/images/media/image12.png" alt="The File menu"  />


### Application de bureau
{: #desktop-app}

Utilisez l’option **Imprimer (Print)** du menu de la barre d’outils.

L’application de bureau ouvre une boîte de dialogue d’impression pour votre système d’exploitation.
Sélectionnez votre imprimante, vérifiez les paramètres de page, puis imprimez le dessin.

## Exportation SVG
{: #svg-export}

Vous pouvez également exporter au format SVG. Le format SVG est utile pour intégrer des dessins dans des documents ou des pages Web.
Remarques :

- L’exportation SVG ne contient que la feuille active (format une seule page)
- Des convertisseurs SVG vers DXF gratuits sont disponibles en ligne
- Consultez [Format de page](../Page-Size/) si vous devez ajuster les dimensions de la feuille avant l’impression ou l’exportation.
- Consultez [Zone de détails de conception](../Design-Details-box/) si vous souhaitez inclure les détails du cartouche dans le résultat.
- Consultez [Dessins à feuilles multiples](../Multiple-Sheet-Drawings/) si votre conception utilise plusieurs feuilles.
