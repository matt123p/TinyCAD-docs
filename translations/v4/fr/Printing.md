# Impression et exportation
{: #printing-and-exporting}

<div class="manual-tabset" data-tabset="product-mode" data-tabset-label="Choose your TinyCAD product" data-default-tab="Browser" markdown="1">

### Navigateur
{: #browser}

Dans le menu **Fichier**, choisissez **Exporter en PDF**. TinyCAD ouvre le dessin au format PDF dans un nouvel onglet. Utilisez les commandes d’impression de la visionneuse PDF pour l’imprimer.

<img src="/v4/images/media/image12.png" alt="The File menu"  />


### Application de bureau
{: #desktop-app}

Choisissez **Fichier → Imprimer** pour ouvrir l’**Aperçu avant impression**. Le dessin apparaît à gauche et les réglages d’impression à droite.

<img src="/v4/images/desktop-print-preview.png" alt="TinyCAD Print Preview showing a drawing, printer settings and sheet selection" />

#### Imprimer directement
{: #print-directly}

1. Si le dessin comporte plusieurs feuilles, utilisez **◀ Préc.** et **Suiv. ▶** pour les prévisualiser. Toutes les feuilles sont sélectionnées au départ. Dans **Pages à imprimer**, décochez les cases des feuilles à exclure.
2. Choisissez une **Imprimante** ou laissez **Imprimante par défaut du système** sélectionnée. Réglez **Format papier**, **Orientation**, **Copies**, **Mode couleur** et **Impression recto verso**. Choisissez **Selon le dessin** pour reprendre l’orientation de la première feuille sélectionnée.
3. Sélectionnez **Imprimer** pour envoyer directement les feuilles sélectionnées à l’imprimante. Pour retrouver vos réglages la prochaine fois, cliquez sur **Enregistrer les réglages d’impression** avant d’imprimer.

Le **Format papier** de l’aperçu s’applique au travail d’impression. Pour modifier les dimensions des feuilles du dessin, ouvrez [Taille de page](../Page-Size/) dans le menu **Paramètres**. Vous pouvez saisir les dimensions en millimètres ou en pouces.

#### Impression avancée
{: #advanced-print}

Sélectionnez **Impression avancée…** pour créer un PDF des feuilles sélectionnées aux dimensions du dessin. Sous Windows et macOS, TinyCAD ouvre le PDF dans votre visionneuse par défaut. Utilisez les commandes d’impression de la visionneuse pour choisir l’imprimante et les options supplémentaires. Sous Linux, TinyCAD ouvre le PDF et affiche la boîte de dialogue d’impression du système. Si vous annulez dans cette boîte de dialogue, le PDF reste ouvert.

**Impression avancée…** est également disponible si TinyCAD ne trouve aucune imprimante. Pour enregistrer un fichier PDF en vue d’une utilisation ultérieure, utilisez **Fichier → Export → Exporter en PDF**.

## Exportation SVG
{: #svg-export}

Vous pouvez également exporter au format SVG. Le format SVG est utile pour intégrer des éléments dans des documents ou des pages Web.
Remarques :

- L’exportation SVG ne contient que la feuille actuelle (format une page)
- Des convertisseurs SVG vers DXF gratuits sont disponibles en ligne
- Consultez [Taille de page](../Page-Size/) si vous devez ajuster les dimensions de la feuille avant l’impression ou l’exportation.
- Consultez [Zone Détails de conception](../Design-Details-box/) si vous souhaitez inclure les détails du cartouche dans la sortie.
- Consultez [Dessins à feuilles multiples](../Multiple-Sheet-Drawings/) si votre conception utilise plusieurs feuilles.
