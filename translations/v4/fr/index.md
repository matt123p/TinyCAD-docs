# Manuel de TinyCAD
{: #tinycad-manual}

TinyCAD v4 est disponible à la fois comme application de bureau et comme application en ligne dans un navigateur. Il n’existe que
quelques différences de fonctionnalités entre les deux versions.

Consultez la page [Différences entre les fonctionnalités](Feature-Differences/) si vous souhaitez connaître les différences exactes entre les versions de TinyCAD.

## Avertissement
{: #warning}

**TinyCAD** est développé et fourni gratuitement en tant que projet communautaire open source. Il est fourni « en l’état » et peut comporter des bogues ou des fonctionnalités incomplètes.  

Il vous incombe de sauvegarder votre travail et d’éviter toute perte de données. Il vous incombe de vérifier soigneusement vos circuits avant de les construire ou d’imprimer des PCB.

## Contribuer à ce manuel
{: #contribute-to-this-manual}

Le manuel de TinyCAD est open source et maintenu sur GitHub Pages.
Les contributions de la communauté sont les bienvenues, notamment les corrections de fautes de frappe, les formulations plus claires,
les nouvelles captures d’écran et les exemples détaillés.

- [Comment contribuer au manuel](Contributing-to-the-Manual/)
