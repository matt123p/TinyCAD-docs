# Commandes tactiles
{: #touch-controls}

Sur un écran tactile, vous pouvez modifier directement le dessin ou utiliser la loupe pour
placer les éléments avec plus de précision. Ces commandes fonctionnent dans le navigateur et dans l’éditeur de bureau.

## Toucher directement
{: #direct-touch}

- Touchez pour sélectionner ou placer un objet avec l’outil actif.
- Faites glisser un doigt pour déplacer des objets ou effectuer une sélection, comme avec la souris.
- Maintenez un doigt immobile pendant environ une seconde pour ouvrir le menu contextuel du dessin.
- Déplacez deux doigts ensemble pour faire défiler le dessin ; écartez-les ou rapprochez-les en les pinçant pour
  zoomer autour du geste sur le canevas.
- Faites glisser un aperçu de symbole depuis le panneau de bibliothèque vers le dessin pour le placer.

## Placement précis avec la loupe
{: #precise-placement-with-the-loupe}

La loupe agrandit la zone autour d’un réticule de visée, afin que votre doigt ne
masque pas le point de connexion que vous essayez d’atteindre.

1. Touchez le dessin si nécessaire pour afficher **Afficher la loupe (Show Loupe)**, puis touchez ce bouton
en bas du dessin.
2. Faites glisser un doigt sur le canevas pour viser avec le réticule. Le déplacement est plus lent
   que celui de votre doigt pour un contrôle plus précis ; lever le doigt conserve la visée en place.
3. Utilisez les commandes libellées sous la lentille :

   | Commande | Action |
   |---|---|
   | **Cliquer (Click)** | Cliquez au niveau du réticule pour sélectionner un objet ou placer un point avec l’outil actif. |
   | **Faire glisser (Drag)** | Commencez un glissement au niveau du réticule. Faites glisser un doigt sur le canevas pour déplacer le pointeur. |
   | **Déposer (Drop)** | Terminez le glissement. Cette commande remplace **Faire glisser (Drag)** pendant un glissement. |
   | **Menu** | Ouvrez le menu contextuel au niveau du réticule. |
   | **Fermer (Close)** | Fermez la loupe et revenez au toucher direct. |

4. Touchez **Masquer la loupe (Hide Loupe)** pour revenir au toucher direct.

![Loupe tactile montrant une zone de connexion agrandie, un réticule et les commandes Click, Drag et Menu.](../images/touch-loupe.png)

Par exemple, pour tracer un fil, choisissez **Fil (Wire)**, visez la broche de départ et touchez
**Cliquer (Click)**. Faites glisser votre doigt pour viser le point suivant et touchez de nouveau **Cliquer (Click)**.
Utilisez **Menu** pour accéder aux commandes contextuelles de l’outil lorsque vous souhaitez terminer ou annuler.

Le déplacement à deux doigts et le zoom par pincement fonctionnent également lorsque la loupe est ouverte. Terminez un glissement actif avec **Déposer (Drop)** avant de modifier la vue.
