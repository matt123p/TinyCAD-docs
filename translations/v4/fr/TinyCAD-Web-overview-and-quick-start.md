# Démarrage rapide de TinyCAD Web
{: #tinycad-web-quick-start}

## TinyCAD pour le Web
{: #tinycad-for-the-web}

TinyCAD pour le Web s’exécute directement dans votre navigateur, ne nécessite aucune installation
et fonctionne sur les systèmes d’exploitation prenant en charge un navigateur compatible. Les formats de fichier
sont compatibles avec TinyCAD pour ordinateur (dessins `.dsn` et bibliothèques `.tclib`).

## Avant de commencer
{: #before-you-start}

Assurez-vous de disposer des éléments suivants :

- Chrome ou Edge (pour le mode fichiers locaux)
- Pour le mode Google Drive, Chrome est recommandé ; Firefox peut également fonctionner
- Lisez les conditions générales : [Conditions générales](https://www.tinycad.net/TCs)

Le logiciel est conçu pour fonctionner sous Windows, Mac, Chromebook et Linux.

## Points d’accès
{: #entry-points}

- Mode fichiers locaux : <https://online.tinycad.net/fs>
- Mode Google Drive : <https://online.tinycad.net/ga>
- Assistance : <https://discord.gg/bdXnjhrSYQ>

## Premiers pas (enregistrement des dessins sur l’ordinateur local)
{: #getting-started-saving-drawings-on-local-computer}

Ce mode repose sur des fonctionnalités de navigateur disponibles dans les versions récentes de Chrome ou Edge.
Utilisez la dernière version de l’un ou l’autre de ces navigateurs, puis ouvrez :

- <https://online.tinycad.net/fs>

## Premiers pas (enregistrement des dessins sur Google Drive)
{: #getting-started-saving-drawings-on-google-drive}

Avant de commencer, vous devez disposer d’un compte Google.

Configuration initiale :

1. Accédez à <https://online.tinycad.net/ga>.
2. Si vous utilisez un bloqueur de publicités, désactivez-le pour ce site (il peut interférer avec
   le processus de connexion de Google).
3. Si aucune fenêtre contextuelle ne s’affiche, vérifiez si le blocage des fenêtres contextuelles est activé et autorisez-les
   pour ce site.
4. Connectez-vous à votre compte Google dans la fenêtre contextuelle (si nécessaire).
5. Cochez **toutes** les cases de consentement pour autoriser l’intégration complète de Google Drive.
6. Si le processus de connexion Google échoue après l’acceptation des conditions, rechargez la page et réessayez.

## Confidentialité
{: #privacy}

### Mode fichiers locaux
{: #local-file-mode}

TinyCAD s’exécute entièrement dans votre navigateur et stocke votre travail localement dans celui-ci.
Aucune partie de votre travail ni aucun autre fichier n’est envoyé aux serveurs de TinyCAD.

### Mode Google Drive
{: #google-drive-mode}

Les dessins sont stockés dans votre Google Drive. Lors de la première utilisation, vous devez autoriser
TinyCAD à accéder à vos fichiers Google pour activer l’intégration.

TinyCAD s’exécute toujours dans le navigateur et écrit les données dans votre Google Drive privé ; aucune
partie de votre travail ni aucun autre fichier n’est envoyé aux serveurs de TinyCAD.

TinyCAD utilise Google Analytics pour mesurer le volume d’utilisation du site.
