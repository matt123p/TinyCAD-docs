# Format de page
{: #page-size}

Utilisez **Format de page** pour définir les dimensions de toutes les feuilles.

<img src="/v4/images/media/image4.png" alt="The page size dialog" />

## Éléments modifiables
{: #what-you-can-change}

- **Format de papier** : choisissez un format de papier standard, tel que A4.
- **Orientation** : sélectionnez **Portrait** pour une page plus haute ou **Paysage** pour une page plus large.
- **Largeur** et **Hauteur** : saisissez un format de page personnalisé en millimètres.

Lorsque vous choisissez un format de papier standard, TinyCAD renseigne la largeur et la hauteur
pour vous. Changer l’orientation inverse ces dimensions.

## Utilisation courante
{: #typical-use}

Utilisez le format de page adapté au type de sortie souhaité :

- choisissez un format standard pour l’impression ou l’exportation en PDF
- utilisez l’orientation paysage pour les schémas plus larges
- définissez une largeur et une hauteur personnalisées lorsqu’aucun format de papier standard ne convient à votre dessin

Le format de page sélectionné est enregistré avec la feuille et fait partie du dessin.
