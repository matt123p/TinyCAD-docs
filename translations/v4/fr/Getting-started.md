# TinyCAD - Premiers pas
{: #tinycad---getting-started}

TinyCAD v4 est disponible de deux manières différentes :

## Application de bureau
{: #desktop-app}

Vous préférerez peut-être une version installée de TinyCAD si vous souhaitez travailler hors ligne ou vous assurer
d’avoir toujours accès à TinyCAD.

Consultez les [Instructions d’installation](../TinyCAD-Desktop-App/) pour savoir comment télécharger, installer et exécuter cette version de TinyCAD.

## Application en ligne
{: #online-app}

Vous préférerez peut-être la version en ligne si vous ne souhaitez pas ou ne pouvez pas installer TinyCAD, par exemple dans un contexte scolaire ou professionnel où l’installation d’applications n’est pas autorisée.

Consultez le [Démarrage rapide de TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) pour savoir comment
commencer à utiliser TinyCAD directement dans votre navigateur Web sans installation.

## Découvrir un schéma prêt à l’emploi
{: #explore-a-ready-made-drawing}

Utilisez les [exemples inclus](../Bundled-Examples/) pour découvrir un réseau, une station de capteurs, une configuration audio, un banc de laboratoire ou un projet de commande de moteur. La commande « Ouvrir un exemple » (Open Example) se trouve dans la barre de titre du navigateur ou, dans l’application de bureau, sous Fichier.

Les [bibliothèques incluses](../Bundled-Libraries/) se trouvent à gauche, sous **Standard**. Choisissez une collection, effectuez une recherche et faites glisser un aperçu sur votre schéma.

Pour calculer le comportement d’un circuit, commencez par [Simulation et SPICE](../Simulation/) ou suivez le [tutoriel complet sur SPICE](../SPICE-Tutorial/). Le moteur intégré est inclus dans les deux produits. Utilisez l’application de bureau pour suivre le [cours distinct sur XSPICE et le numérique](../XSPICE-Tutorial/).
