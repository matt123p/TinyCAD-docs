# TinyCAD - Premiers pas
{: #tinycad---getting-started}

TinyCAD v4 est disponible de deux façons différentes :

## Application de bureau
{: #desktop-app}

Vous pouvez préférer une version installée de TinyCAD si vous souhaitez travailler hors ligne ou vous assurer
d’avoir toujours accès à TinyCAD.

Consultez les [Instructions d’installation](../TinyCAD-Desktop-App/) pour savoir comment télécharger, installer et lancer cette version de TinyCAD.

## Application en ligne
{: #online-app}

Vous pouvez préférer la version en ligne si vous ne souhaitez pas ou ne pouvez pas installer TinyCAD, par exemple dans un cadre scolaire ou professionnel où vous n’êtes pas autorisé à installer des applications.

Consultez le [Guide de démarrage rapide de TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) pour savoir comment
commencer à utiliser TinyCAD directement dans votre navigateur Web, sans installation.
