# TinyCAD v4 - Bien démarrer
{: #tinycad-v4---getting-started}

TinyCAD v4 peut être utilisé de deux façons différentes :

## Application de bureau
{: #desktop-app}

Vous préférerez peut-être une version installée de TinyCAD si vous souhaitez travailler hors ligne ou vous assurer
d’avoir toujours accès à TinyCAD.

Consultez les [Instructions d’installation](../TinyCAD-Desktop-App/) pour savoir comment télécharger, installer et lancer cette version de TinyCAD.

## Application en ligne
{: #online-app}

Vous préférerez peut-être la version en ligne si vous ne souhaitez pas ou ne pouvez pas installer TinyCAD, par exemple dans un contexte scolaire ou professionnel où l’installation d’applications n’est pas autorisée.

Consultez le [Démarrage rapide de TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) pour savoir comment
commencer à utiliser TinyCAD directement dans votre navigateur Web, sans installation.
