# TinyCAD - Bien démarrer
{: #tinycad---getting-started}

Pour obtenir de l’aide afin de créer des symboles, des bibliothèques ou des circuits à partir d’instructions écrites et de fiches techniques, consultez le [guide de l’assistant IA ](../AI-Assistant/), qui comprend la configuration du fournisseur et des exemples de requêtes.

TinyCAD v4 est disponible de deux façons différentes :

## Application de bureau
{: #desktop-app}

Vous préférerez peut-être une version installée de TinyCAD si vous souhaitez travailler hors ligne ou vous assurer
d’avoir toujours accès à TinyCAD.

Consultez les [instructions d’installation](../TinyCAD-Desktop-App/) pour savoir comment télécharger, installer et exécuter cette version de TinyCAD.

## Application en ligne
{: #online-app}

Vous préférerez peut-être la version en ligne si vous ne souhaitez pas ou ne pouvez pas installer TinyCAD, par exemple dans un contexte éducatif ou professionnel où l’installation d’applications est interdite.

Consultez le [guide de démarrage rapide de TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) pour savoir comment
commencer à utiliser TinyCAD directement dans votre navigateur Web, sans installation.

## Découvrez un schéma prêt à l’emploi
{: #explore-a-ready-made-drawing}

Utilisez les [exemples fournis](../Bundled-Examples/) pour découvrir un réseau, une station de capteurs, une installation audio, un banc de laboratoire ou un projet de commande de moteur. La commande Open Example (Ouvrir un exemple) se trouve dans la barre de titre du navigateur ou, dans la version Desktop, sous File (Fichier).

Les [bibliothèques fournies](../Bundled-Libraries/) se trouvent à gauche, sous **Standard**. Choisissez une collection, effectuez une recherche et faites glisser un aperçu sur votre schéma.

Pour calculer le comportement d’un circuit, commencez par [Simulation et SPICE](../Simulation/) ou suivez le [tutoriel SPICE complet](../SPICE-Tutorial/). Le moteur intégré est inclus dans les deux produits. Utilisez Desktop pour suivre le [cours XSPICE sur le numérique](../XSPICE-Tutorial/) séparé.
