# Traduction de l’interface
{: #language-translation}

TinyCAD peut être utilisé dans plusieurs langues d’interface.

## Langues disponibles
{: #available-languages}

Les langues actuellement disponibles sont :

| Code | Langue |
|---|---|
| `en` | Anglais |
| `nl` | Néerlandais |
| `fr` | Français |
| `es` | Espagnol |
| `de` | Allemand |
| `it` | Italien |
| `ja` | Japonais |
| `pl` | Polonais |
| `zh-CN` | Chinois (simplifié) |

## Qualité des traductions et retours
{: #translation-quality-and-feedback}

Ces traductions sont maintenues par l’IA.

Vos retours sont les bienvenus si vous remarquez des formulations maladroites, des termes techniques incorrects ou du texte non traduit.
Les suggestions d’ajout de langues de traduction sont également les bienvenues.
