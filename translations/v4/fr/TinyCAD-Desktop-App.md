# Instructions d’installation
{: #installation-instructions}

Cette page explique comment installer TinyCAD.

## Installation sous Windows
{: #install-on-windows}

Sous Windows, la méthode recommandée pour installer TinyCAD v4 consiste à passer par le
[Microsoft Store](https://apps.microsoft.com/detail/9NZQ1M56NM3V).

Si vous utilisez Windows, privilégiez la version du Microsoft Store, sauf si vous avez une
raison précise de l’installer depuis une autre source.

Les [versions publiées sur GitHub](https://github.com/matt123p/TinyCADv4/releases) comprennent également
un programme d’installation pour Windows.

## Installation sous macOS
{: #install-on-macos}

Sous macOS, téléchargez TinyCAD v4 depuis les
[versions publiées sur GitHub](https://github.com/matt123p/TinyCADv4/releases).
L’image disque macOS (`.dmg`) est conçue pour Apple Silicon (ARM64).

## Installation sous Linux
{: #install-on-linux}

TinyCAD est disponible sur le [Snap Store](https://snapcraft.io/tinycad) pour les 
distributions Linux courantes compatibles avec Snap, notamment Ubuntu, Kubuntu, KDE Neon, Pop!_OS, elementary OS,
Debian, Fedora, openSUSE, Manjaro, Arch Linux, CentOS et Red Hat Enterprise
Linux.

Sous Ubuntu et de nombreuses distributions basées sur Ubuntu, la prise en charge de Snap est déjà disponible.
Dans ce cas, vous pouvez installer TinyCAD directement avec :

```bash
sudo snap install tinycad
```
Si cela ne fonctionne pas, la page TinyCAD sur le [Snap Store](https://snapcraft.io/tinycad) contient des 
liens vers les instructions de configuration propres à chaque distribution Linux prise en charge.

Les [versions publiées sur GitHub](https://github.com/matt123p/TinyCADv4/releases) comprennent également des
paquets Linux `.deb` pour x64 et ARM64. Le paquet Snap est conçu pour
x64. Les paquets Linux pour ARMv7 (ARM 32 bits) ne sont plus proposés, car l’environnement d’exécution
Electron actuel ne prend pas en charge cette architecture.

## Utilisation sous ChromeOS et sur les Chromebook
{: #use-on-chromeos-and-chromebooks}

Sous ChromeOS, utilisez [TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/)
plutôt que d’installer l’application de bureau.
