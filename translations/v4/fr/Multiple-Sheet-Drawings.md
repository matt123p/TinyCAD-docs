# Schémas à plusieurs feuilles
{: #mutliple-sheet-drawings}

Utilisez plusieurs feuilles lorsque votre conception est trop grande pour tenir sur une seule page ou lorsque vous
souhaitez séparer les blocs fonctionnels.

## Pourquoi utiliser plusieurs feuilles
{: #why-use-multiple-sheets}

- Garder les schémas complexes lisibles.
- Organiser les composants associés par fonction.

## Procédure de base
{: #basic-workflow}

1. Créez une nouvelle feuille dans votre dessin.
2. Donnez un nom clair à chaque feuille (par exemple : `Power`, `Control`, `I/O`).
3. Placez les symboles et les fils sur chaque feuille selon vos besoins.
4. Utilisez des étiquettes et des symboles d’alimentation pour établir des connexions entre les feuilles.
