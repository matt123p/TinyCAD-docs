# Feld „Konstruktionsdetails“
{: #design-details-box}

Jeder Entwurf speichert Dokumentmetadaten wie Titel, Autor und weitere
Details. Diese Werte bearbeiten Sie mit dem Befehl **Konstruktionsdetails (Design Details)**.

Das Feld „Konstruktionsdetails“ kann unten links in der Zeichnung erscheinen:

<img src="/v4/images/media/image15.png" alt="Design details box displayed on the schematic page with title and document metadata fields" style="width: 4.65625in; height: 2.20833in;" />

## Konstruktionsdetails bearbeiten
{: #edit-design-details}

1. Öffnen Sie Ihren Schaltplan.
2. Öffnen Sie **Konstruktionsdetails (Design Details)** im Menü „Datei“ bzw. über die Werkzeuge.
3. Aktualisieren Sie die gewünschten Felder (zum Beispiel Titel und Autor).
4. Speichern Sie den Entwurf.

Bearbeiten Sie die Details über das Einstellungsmenü mit **Konstruktionsdetails (Design Details)**:

<img src="/v4/images/media/image16.png" alt="Menu showing the Design Details command used to edit document metadata" />

Beim Speichern des Entwurfs werden diese Details mitgespeichert.

## Feld „Details anzeigen“
{: #display-details-box}

Mit der Option **Feld „Details anzeigen“ (Display Details box)** wird festgelegt, ob das Detailfeld
in der Zeichnung angezeigt wird.

- Ist die Option aktiviert, werden die Details im Schaltplan angezeigt.
- Das Detailfeld wird zusammen mit dem Entwurf gedruckt.
- Das Detailfeld erscheint im unteren rechten Bereich der Zeichnung.

## Hinweise
{: #notes}

Konstruktionsdetails gelten für jedes Blatt einzeln – bei Zeichnungen mit mehreren Blättern kann jedes Blatt eigene Konstruktionsdetails haben.
