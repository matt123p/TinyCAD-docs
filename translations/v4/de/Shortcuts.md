# Tastenkombinationen
{: #shortcuts}

Mit Tastenkombinationen statt Symbolleistenklicks können Sie schneller zeichnen.

**Hinweis:** Diese unterscheiden sich von den Tastenkombinationen in TinyCAD v3, da Browseranwendungen
F-Tasten nicht auf dieselbe Weise bereitstellen.

| Taste | Aktion |
|---|---|
| `Esc` | Aktuelle Platzierungs- oder Zeichenaktion abbrechen; andernfalls die Auswahl aufheben |
| `W` | Werkzeug „Draht“ |
| `N` | Keine Verbindung (No Connect) |
| `P` | Stromversorgung |
| `L` | Beschriftung |
| `T` | Text |
| `B` | Bus |
| `S` | Form (Rechteck/Ellipse/Linie) |
| `+` | Vergrößern |
| `=` | Vergrößern |
| `-` | Verkleinern |
| `_` | Verkleinern |
| Pfeiltasten | Ausgewählte Elemente bei aktiviertem Einrasten um den Rasterabstand verschieben oder bei deaktiviertem Einrasten in kleinen Schritten; schwenken, wenn nichts ausgewählt ist |
| `Ctrl` + Pfeiltasten | Ausgewählte Elemente in kleinen Schritten verschieben oder in kleineren Schritten schwenken |
| `Ctrl-F` | Suchen |
| `Ctrl-P` | Drucken |
| `Ctrl-C` | Kopieren |
| `Ctrl-X` | Ausschneiden |
| `Ctrl-V` | Einfügen |
| `Del` | Löschen |
| `Ctrl-Z` | Rückgängig |
| `Ctrl-Y` | Wiederholen |

Escape bricht die Erstellung ebenfalls ab, wenn eine Symbolleistenschaltfläche den Fokus hat. Wenn Sie in ein
Textfeld tippen oder ein Menü oder Dialogfeld verwenden, schließen Sie zunächst die Eingabe ab oder schließen Sie das Steuerelement.

Einige Tastenkombinationen können vom Browser abgefangen werden und stattdessen Browseraktionen auslösen.
