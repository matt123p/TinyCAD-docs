# Touch-Steuerung
{: #touch-controls}

Auf einem Touchscreen können Sie die Zeichnung direkt bearbeiten oder die Lupe für eine präzisere Platzierung verwenden. Diese Steuerungen funktionieren im Browser und im Desktop-Editor.

## Direkte Touch-Bedienung
{: #direct-touch}

- Tippen Sie, um mit dem aktiven Werkzeug ein Objekt auszuwählen oder zu platzieren.
- Ziehen Sie mit einem Finger, um Objekte zu verschieben oder eine Auswahl zu erstellen, wie mit der Maus.
- Halten Sie einen Finger etwa eine Sekunde lang still, um das Kontextmenü der Zeichnung zu öffnen.
- Bewegen Sie zwei Finger gemeinsam, um die Zeichnung zu verschieben; ziehen Sie sie auseinander oder zusammen, um die Leinwand um die Geste herum zu vergrößern oder zu verkleinern.
- Ziehen Sie eine Symbolvorschau aus dem Bibliotheksbereich auf die Zeichnung, um sie zu platzieren.

## Präzise Platzierung mit der Lupe
{: #precise-placement-with-the-loupe}

Die Lupe vergrößert den Bereich um ein Fadenkreuz, sodass Ihr Finger nicht den Anschlusspunkt verdeckt, den Sie ansteuern möchten.

1. Tippen Sie bei Bedarf auf die Zeichnung, um **Lupe anzeigen (Show Loupe)** einzublenden, und tippen Sie dann auf diese Schaltfläche am unteren Rand der Zeichnung.
2. Bewegen Sie einen Finger über die Leinwand, um das Fadenkreuz auszurichten. Die Bewegung ist langsamer als die Ihres Fingers und ermöglicht so eine feinere Steuerung; wenn Sie den Finger anheben, bleibt die Ausrichtung erhalten.
3. Verwenden Sie die beschrifteten Steuerelemente unter der Linse:

   | Steuerelement | Aktion |
   |---|---|
   | **Klicken (Click)** | Klicken Sie am Fadenkreuz, um ein Objekt auszuwählen oder mit dem aktiven Werkzeug einen Punkt zu platzieren. |
   | **Ziehen (Drag)** | Beginnen Sie das Ziehen am Fadenkreuz. Bewegen Sie einen Finger über die Leinwand, um den Zeiger zu verschieben. |
   | **Ablegen (Drop)** | Beenden Sie das Ziehen. Während eines aktiven Ziehvorgangs ersetzt dies **Ziehen (Drag)**. |
   | **Menü (Menu)** | Öffnen Sie das Kontextmenü am Fadenkreuz. |
   | **Schließen (Close)** | Schließen Sie die Lupe und kehren Sie zur direkten Touch-Bedienung zurück. |

4. Tippen Sie auf **Lupe ausblenden (Hide Loupe)**, um zur direkten Touch-Bedienung zurückzukehren.

![Touch-Lupe mit vergrößertem Anschlussbereich, Fadenkreuz und den Steuerelementen Click, Drag und Menu.](../images/touch-loupe.png)

Um beispielsweise eine Leitung zu zeichnen, wählen Sie **Leitung (Wire)**, richten Sie das Fadenkreuz auf den Startanschluss aus und tippen Sie auf **Klicken (Click)**. Bewegen Sie Ihren Finger, um den nächsten Punkt anzusteuern, und tippen Sie erneut auf **Klicken (Click)**. Verwenden Sie **Menü (Menu)** für die Kontextbefehle des Werkzeugs, wenn Sie den Vorgang beenden oder abbrechen möchten.

Das Verschieben mit zwei Fingern und das Vergrößern bzw. Verkleinern durch Zusammen- oder Auseinanderziehen funktionieren auch bei geöffneter Lupe. Beenden Sie einen aktiven Ziehvorgang mit **Ablegen (Drop)**, bevor Sie die Ansicht ändern.
