# TinyCAD – Erste Schritte
{: #tinycad---getting-started}

TinyCAD v4 steht auf zwei verschiedene Arten zur Verfügung:

## Desktop-App
{: #desktop-app}

Eine installierte Version von TinyCAD ist möglicherweise vorzuziehen, wenn Sie offline arbeiten möchten oder sicherstellen wollen,
dass Sie jederzeit Zugriff auf TinyCAD haben.

Unter [Installationsanleitung](../TinyCAD-Desktop-App/) finden Sie Anweisungen zum Herunterladen, Installieren und Ausführen dieser TinyCAD-Version.

## Online-App
{: #online-app}

Die Online-Version ist möglicherweise vorzuziehen, wenn Sie TinyCAD nicht installieren möchten oder können – beispielsweise in einer Bildungs- oder Arbeitsumgebung, in der Sie keine Anwendungen installieren dürfen.

Unter [Schnellstart für TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) finden Sie Anweisungen, wie Sie
TinyCAD ohne Installation direkt in Ihrem Webbrowser verwenden können.

## Eine vorgefertigte Zeichnung erkunden
{: #explore-a-ready-made-drawing}

Mit [beigefügten Beispielen](../Bundled-Examples/) können Sie ein Netzwerk, eine Sensorstation, eine Audioanlage, einen Laborarbeitsplatz oder ein Motorsteuerungsprojekt erkunden. „Beispiel öffnen“ befindet sich in der Titelleiste des Browsers oder in der Desktop-Version unter „Datei“.

Die [beigefügten Bibliotheken](../Bundled-Libraries/) befinden sich links unter **Standard**. Wählen Sie eine Sammlung aus, suchen Sie nach einem Element und ziehen Sie eine Vorschau auf Ihre Zeichnung.

Um das Schaltungsverhalten zu berechnen, beginnen Sie mit [Simulation und SPICE](../Simulation/) oder absolvieren Sie das vollständige [SPICE-Tutorial](../SPICE-Tutorial/). Die integrierte Engine ist in beiden Produkten enthalten. Verwenden Sie die Desktop-Version für den separaten [XSPICE-Digitalkurs](../XSPICE-Tutorial/).
