# TinyCAD – Erste Schritte
{: #tinycad---getting-started}

Hilfe zum Erstellen von Symbolen, Bibliotheken oder Schaltungen anhand schriftlicher Anweisungen und Datenblätter finden Sie im [Leitfaden zum KI-Assistenten](../AI-Assistant/), einschließlich der Einrichtung des Anbieters und Beispiel-Prompts.

TinyCAD v4 kann auf zwei verschiedene Arten verwendet werden:

## Desktop-App
{: #desktop-app}

Eine installierte Version von TinyCAD ist möglicherweise besser geeignet, wenn Sie offline arbeiten möchten oder sicherstellen wollen,
dass Sie jederzeit Zugriff auf TinyCAD haben.

Die [Installationsanleitung](../TinyCAD-Desktop-App/) enthält Informationen zum Herunterladen, Installieren und Ausführen dieser TinyCAD-Version.

## Online-App
{: #online-app}

Die Online-Version ist möglicherweise besser geeignet, wenn Sie TinyCAD nicht installieren möchten oder können – zum Beispiel in einer Bildungseinrichtung oder am Arbeitsplatz, wo die Installation von Anwendungen nicht erlaubt ist.

In der [Schnellstartanleitung für TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) erfahren Sie, wie Sie TinyCAD direkt in Ihrem Webbrowser verwenden können, ohne etwas installieren zu müssen.

## Eine fertige Zeichnung erkunden
{: #explore-a-ready-made-drawing}

Erkunden Sie mithilfe der [mitgelieferten Beispiele](../Bundled-Examples/) ein Netzwerk-, Sensorstations-, Audio-, Laborbank- oder Motorsteuerungsprojekt. „Beispiel öffnen“ (Open Example) befindet sich in der Browser-Titelleiste oder in der Desktop-App unter „Datei“ (File).

Die [mitgelieferten Bibliotheken](../Bundled-Libraries/) befinden sich links unter **Standard**. Wählen Sie eine Sammlung aus, suchen Sie nach einem Element und ziehen Sie eine Vorschau auf Ihre Zeichnung.

Um das Schaltungsverhalten zu berechnen, beginnen Sie mit [Simulation und SPICE](../Simulation/) oder folgen Sie dem vollständigen [SPICE-Tutorial](../SPICE-Tutorial/). Die integrierte Engine ist in beiden Produkten enthalten. Verwenden Sie die Desktop-App für den separaten [XSPICE-Digitalkurs](../XSPICE-Tutorial/).
