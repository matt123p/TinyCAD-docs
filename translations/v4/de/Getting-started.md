# TinyCAD – Erste Schritte
{: #tinycad---getting-started}

TinyCAD v4 kann auf zwei verschiedene Arten verwendet werden:

## Desktop-App
{: #desktop-app}

Eine installierte Version von TinyCAD ist möglicherweise vorzuziehen, wenn Sie offline arbeiten möchten oder sicherstellen wollen,
dass Sie jederzeit Zugriff auf TinyCAD haben.

Unter [Installationsanleitung](../TinyCAD-Desktop-App/) finden Sie Anweisungen zum Herunterladen, Installieren und Ausführen dieser Version von TinyCAD.

## Online-App
{: #online-app}

Die Online-Version ist möglicherweise vorzuziehen, wenn Sie TinyCAD nicht installieren möchten oder können – beispielsweise in einer Bildungs- oder Arbeitsumgebung, in der Sie keine Anwendungen installieren dürfen.

Unter [Schnellstart für TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) finden Sie Anweisungen dazu,
wie Sie TinyCAD direkt in Ihrem Webbrowser verwenden können, ohne etwas installieren zu müssen.
