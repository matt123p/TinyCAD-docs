# TinyCAD – Erste Schritte
{: #tinycad-v4---getting-started}

TinyCAD v4 kann auf zwei verschiedene Arten verwendet werden:

## Desktop-App
{: #desktop-app}

Möglicherweise bevorzugen Sie eine installierte Version von TinyCAD, wenn Sie offline arbeiten möchten oder sicherstellen wollen,
dass Sie jederzeit Zugriff auf TinyCAD haben.

Unter [Installationsanleitung](../TinyCAD-Desktop-App/) finden Sie Anweisungen zum Herunterladen, Installieren und Ausführen dieser Version von TinyCAD.

## Online-App
{: #online-app}

Möglicherweise bevorzugen Sie die Online-Version, wenn Sie TinyCAD nicht installieren möchten oder können – zum Beispiel in einer Bildungs- oder Arbeitsumgebung, in der Sie keine Anwendungen installieren dürfen.

Unter [Schnellstart für TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/) finden Sie Anweisungen dazu,
wie Sie TinyCAD direkt in Ihrem Webbrowser verwenden können, ohne es installieren zu müssen.
