# TinyCAD-Handbuch
{: #tinycad-manual}

TinyCAD v4 ist sowohl als Desktop-App als auch als browserbasierte Online-App verfügbar. Zwischen den beiden Versionen gibt es nur
eine geringe Anzahl von Funktionsunterschieden.

Auf der Seite [Funktionsunterschiede](Feature-Differences/) finden Sie die genauen Unterschiede zwischen den TinyCAD-Versionen.

## Warnung
{: #warning}

**TinyCAD** wird als Open-Source-Projekt von der Community entwickelt und kostenlos bereitgestellt. Die Software wird „wie besehen“ bereitgestellt und kann Fehler oder unvollständige Funktionen enthalten.  

Es liegt in Ihrer Verantwortung, Ihre Arbeit zu sichern und Datenverlust zu verhindern. Vor dem Bau von Schaltungen oder dem Drucken von PCBs müssen Sie sorgfältig prüfen.

## Zu diesem Handbuch beitragen
{: #contribute-to-this-manual}

Das TinyCAD-Handbuch ist Open Source und wird auf GitHub Pages gepflegt.
Beiträge aus der Community sind willkommen, darunter Korrekturen von Tippfehlern, verständlichere Formulierungen,
neue Screenshots und ausführlichere Beispiele.
