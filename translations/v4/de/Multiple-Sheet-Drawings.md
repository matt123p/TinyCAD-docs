# Zeichnungen mit mehreren Blättern
{: #mutliple-sheet-drawings}

Verwenden Sie mehrere Blätter, wenn Ihr Entwurf zu groß für eine einzelne Seite ist oder wenn Sie
Funktionsblöcke voneinander trennen möchten.

## Warum mehrere Blätter verwenden?
{: #why-use-multiple-sheets}

- Halten Sie komplexe Schaltpläne übersichtlich.
- Organisieren Sie zusammengehörige Teile nach Funktion.

## Grundlegender Arbeitsablauf
{: #basic-workflow}

1. Erstellen Sie ein neues Blatt in Ihrer Zeichnung.
2. Benennen Sie jedes Blatt eindeutig (zum Beispiel: `Power`, `Control`, `I/O`).
3. Platzieren Sie Symbole und Leitungen nach Bedarf auf den einzelnen Blättern.
4. Verwenden Sie Beschriftungen und Stromversorgungssymbole, um Verbindungen zwischen den Blättern herzustellen.
