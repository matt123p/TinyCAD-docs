# Stückliste
{: #bill-of-materials}

Das Werkzeug erstellt eine Liste aller Teile, die im aktuellen Entwurf verwendet werden. Die Ausgabe
wird nach Symbolreferenz sortiert, wobei gleiche Teile zusammengefasst werden.

## Wozu dient die Ausgabe?
{: #what-the-output-is-for}

- Sie ist im Wesentlichen eine Einkaufs- und Fertigungsliste für den Entwurf.
- Sie hilft dabei, vor der Fertigung Referenzen und gruppierte Bauteiltypen zu überprüfen.

## Stückliste erstellen
{: #generate-a-bom-parts-list}

Sie können die Stückliste erstellen, indem Sie die entsprechende Menüoption auswählen. Anschließend können Sie sie
als CSV-Datei herunterladen. Wenn Sie fertig sind, wählen Sie „Schließen“.
