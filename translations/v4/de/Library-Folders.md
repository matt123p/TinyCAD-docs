# Bibliotheksordner
{: #library-folders}

## Übersicht
{: #overview}

Im Bereich „Meine Bibliotheken“ können Sie Ordner verwenden, um installierte Bibliotheken in Gruppen zu organisieren.


<div class="manual-tabset" data-tabset="product-mode" data-tabset-label="Choose your TinyCAD product" data-default-tab="Browser" markdown="1">

### Browser
{: #browser}

Bibliotheksordner werden in der Browser-Version von TinyCAD nicht unterstützt.

### Desktop-App
{: #desktop-app}

Ordner werden zusammen mit Ihrer Bibliotheksliste gespeichert, sodass die Struktur beim nächsten Öffnen von TinyCAD erhalten bleibt.

Bibliotheksordner sind nur in der Desktop-App verfügbar.

Browserbasierte Modi zeigen „Meine Bibliotheken“ weiterhin an, sofern unterstützt, bieten jedoch keine Funktionen zum Erstellen von Ordnern, Gruppieren in Ordnern oder Verschieben per Drag-and-drop.

#### Was Sie tun können
{: #what-you-can-do}

- Ordner erstellen, um zusammengehörige Bibliotheken zu gruppieren
- Ordner umbenennen
- Ordner löschen
- Ordner per Drag-and-drop neu anordnen
- Bibliotheken per Drag-and-drop zwischen Ordnern verschieben
- Mehrere vorhandene Bibliotheksdateien in einem Vorgang hinzufügen
- Bibliotheken direkt zum aktuell ausgewählten Ordner hinzufügen

Bibliotheken, die keinem Ordner zugewiesen sind, werden im Bereich „Nicht abgelegt“ angezeigt.

#### Ordner erstellen
{: #create-a-folder}

1. Öffnen Sie den Bereich „Bibliotheken“.
2. Wechseln Sie zu „Meine Bibliotheken“.
3. Wählen Sie die Ordnerschaltfläche in der Kopfzeile des Bereichs.
4. Geben Sie einen Namen für den neuen Ordner ein.

Der neue Ordner wird in der Bibliotheksliste angezeigt und kann sofort ausgewählt werden.

#### Ordner auswählen
{: #select-a-folder}

Klicken Sie auf eine Ordnerzeile, um sie auszuwählen.

Der ausgewählte Ordner wird verwendet, wenn Sie vorhandene Bibliotheken hinzufügen.

Wenn Sie auf eine Bibliothek klicken, wählt TinyCAD automatisch den Ordner aus, zu dem diese Bibliothek gehört. So ist klar, wo neu hinzugefügte Bibliotheken abgelegt werden.

#### Bibliotheken zu einem Ordner hinzufügen
{: #add-libraries-to-a-folder}

1. Wählen Sie in „Meine Bibliotheken“ den Zielordner aus.
2. Wählen Sie „Hinzufügen“.
3. Wählen Sie eine oder mehrere vorhandene Bibliotheksdateien aus.

Die ausgewählten Bibliotheken werden dem ausgewählten Ordner hinzugefügt.

Wenn Sie keinen benutzerdefinierten Ordner auswählen, werden Bibliotheken unter „Nicht abgelegt“ hinzugefügt.

#### Bibliotheken zwischen Ordnern verschieben
{: #move-libraries-between-folders}

Ziehen Sie eine Bibliothek von ihrem aktuellen Speicherort auf einen anderen Ordner.

Sie können eine Bibliothek auch auf „Nicht abgelegt“ ziehen, um sie aus einem benutzerdefinierten Ordner zu entfernen.

Wenn ein Ordner leer ist, zeigt TinyCAD ein Ablageziel an, sodass Sie Bibliotheken dorthin verschieben können.

#### Ordner neu anordnen
{: #reorder-folders}

Ordner können direkt im Bereich neu angeordnet werden.

1. Bewegen Sie den Mauszeiger über den Ordner, den Sie verschieben möchten.
2. Ziehen Sie den Ziehgriff zum Neuordnen.
3. Legen Sie den Ordner an der gewünschten Position ab.

Die neue Reihenfolge wird automatisch gespeichert.

#### Ordner umbenennen oder löschen
{: #rename-or-delete-a-folder}

Die Ordneraktionsschaltflächen werden angezeigt, wenn sich der Mauszeiger über einem Ordner befindet oder dieser ausgewählt ist.

- Wählen Sie „Bearbeiten“, um den Ordner umzubenennen.
- Wählen Sie „Löschen“, um den Ordner zu entfernen.

Beim Löschen eines Ordners werden alle darin enthaltenen Bibliotheken nach „Nicht abgelegt“ verschoben. Die Bibliotheksdateien selbst werden nicht aus TinyCAD entfernt.

#### Nicht abgelegte Bibliotheken
{: #unfiled-libraries}

„Nicht abgelegt“ ist der Standardspeicherort für Bibliotheken, die keinem benutzerdefinierten Ordner zugewiesen sind.

- Neue Bibliotheken werden unter „Nicht abgelegt“ abgelegt, wenn kein benutzerdefinierter Ordner ausgewählt ist
- Bibliotheken aus einem gelöschten Ordner werden nach „Nicht abgelegt“ verschoben
- Sie können Bibliotheken aus „Nicht abgelegt“ in jeden benutzerdefinierten Ordner ziehen

Wenn keine benutzerdefinierten Ordner vorhanden sind, zeigt TinyCAD die Bibliotheksliste einfach ohne die Überschrift „Nicht abgelegt“ an.

#### Hinweise
{: #notes}

- Änderungen an der Ordnerstruktur werden mit Ihrer gespeicherten Bibliothekskonfiguration abgelegt
- Beim Auswählen vorhandener Bibliotheksdateien können mehrere Bibliotheken auf einmal hinzugefügt werden
- Die Ordnerreihenfolge und die Zuordnung von Bibliotheken zu Ordnern bleiben zwischen den Sitzungen erhalten
