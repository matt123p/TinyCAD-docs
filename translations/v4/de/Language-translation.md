# Sprachübersetzung
{: #language-translation}

TinyCAD kann zwischen mehreren Oberflächensprachen umgeschaltet werden.

## Verfügbare Sprachen
{: #available-languages}

Die derzeit verfügbaren Sprachen sind:

| Code | Sprache |
|---|---|
| `en` | Englisch |
| `nl` | Niederländisch |
| `fr` | Französisch |
| `es` | Spanisch |
| `de` | Deutsch |
| `it` | Italienisch |
| `ja` | Japanisch |
| `pl` | Polnisch |
| `zh-CN` | Chinesisch (vereinfacht) |

## Übersetzungsqualität und Feedback
{: #translation-quality-and-feedback}

Diese Übersetzungen werden mithilfe von KI gepflegt.

Wenn Ihnen eine ungelenke Formulierung, falsche Fachbegriffe oder nicht übersetzter Text auffallen,
freuen wir uns über Ihr Feedback. Auch Vorschläge für zusätzliche Übersetzungssprachen
sind willkommen.
