# Installationsanleitung
{: #installation-instructions}

Auf dieser Seite wird die Installation von TinyCAD beschrieben.

## Installation unter Windows
{: #install-on-windows}

Unter Windows wird TinyCAD v4 vorzugsweise über den
[Microsoft Store](https://apps.microsoft.com/detail/9NZQ1M56NM3V) installiert.

Wenn Sie Windows verwenden, nutzen Sie die Version aus dem Microsoft Store, sofern Sie keinen
besonderen Grund haben, die Installation aus einer anderen Quelle vorzunehmen.

Die [GitHub-Releases](https://github.com/matt123p/TinyCADv4/releases) enthalten ebenfalls
 ein Installationsprogramm für Windows.

## Installation unter macOS
{: #install-on-macos}

Laden Sie TinyCAD v4 für macOS aus den
[GitHub-Releases](https://github.com/matt123p/TinyCADv4/releases) herunter.
Das macOS-Disk-Image (`.dmg`) ist für Apple Silicon (ARM64) erstellt.

## Installation unter Linux
{: #install-on-linux}

TinyCAD ist über den [Snap Store](https://snapcraft.io/tinycad) für 
gängige Snap-fähige Linux-Distributionen erhältlich, darunter Ubuntu, Kubuntu, KDE Neon, Pop!_OS, elementary OS,
Debian, Fedora, openSUSE, Manjaro, Arch Linux, CentOS und Red Hat Enterprise
Linux.

Unter Ubuntu und vielen darauf basierenden Distributionen ist die Snap-Unterstützung bereits vorhanden.
In diesem Fall können Sie TinyCAD direkt mit folgendem Befehl installieren:

```bash
sudo snap install tinycad
```
Wenn dies nicht funktioniert, enthält die TinyCAD-Seite im [Snap Store](https://snapcraft.io/tinycad)
Links zu distributionsspezifischen Einrichtungsanleitungen für alle unterstützten Linux-Distributionen.

Die [GitHub-Releases](https://github.com/matt123p/TinyCADv4/releases) enthalten ebenfalls
Linux-`.deb`-Pakete für x64 und ARM64. Das Snap-Paket ist für
x64 erstellt. Linux-Pakete für ARMv7 (32-Bit-ARM) werden nicht mehr bereitgestellt, da die aktuelle
Electron-Laufzeitumgebung diese Architektur nicht unterstützt.

## Verwendung unter ChromeOS und auf Chromebooks
{: #use-on-chromeos-and-chromebooks}

Verwenden Sie unter ChromeOS stattdessen [TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/),
anstatt die Desktop-Anwendung zu installieren.
