# Seitengröße
{: #page-size}

Mit **Seitengröße** legen Sie die Blattabmessungen für alle Blätter fest.

<img src="/v4/images/media/image4.png" alt="The page size dialog" />

## Änderbare Einstellungen
{: #what-you-can-change}

- **Papierformat**: Wählen Sie ein Standardpapierformat wie A4.
- **Ausrichtung**: Wählen Sie **Hochformat** für eine höhere oder **Querformat** für eine breitere Seite.
- **Breite** und **Höhe**: Geben Sie eine benutzerdefinierte Seitengröße in Millimetern ein.

Wenn Sie ein Standardpapierformat auswählen, trägt TinyCAD die Breite und Höhe
für Sie ein. Beim Ändern der Ausrichtung werden diese Abmessungen vertauscht.

## Typische Verwendung
{: #typical-use}

Verwenden Sie die Seitengröße passend zur gewünschten Ausgabe:

- Wählen Sie ein Standardformat für den Druck oder den PDF-Export.
- Verwenden Sie das Querformat für breitere Schaltpläne.
- Verwenden Sie eine benutzerdefinierte Breite und Höhe, wenn kein Standardpapierformat zu Ihrer Zeichnung passt.

Die ausgewählte Seitengröße wird als Teil der Zeichnung mit dem Blatt gespeichert.
