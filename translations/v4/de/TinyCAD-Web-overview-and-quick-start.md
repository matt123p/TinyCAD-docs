# TinyCAD Web-Schnellstart
{: #tinycad-web-quick-start}

## TinyCAD für das Web
{: #tinycad-for-the-web}

TinyCAD für das Web läuft direkt in Ihrem Browser, muss nicht installiert werden
und funktioniert auf Betriebssystemen, die einen kompatiblen Browser unterstützen. Die Dateiformate
sind mit TinyCAD für den Desktop kompatibel (Zeichnungen vom Typ `.dsn` und
Bibliotheken vom Typ `.tclib`).

## Bevor Sie beginnen
{: #before-you-start}

Stellen Sie sicher, dass Folgendes vorhanden ist:

- Chrome oder Edge (für den Modus mit lokalen Dateien)
- Für den Google-Drive-Modus wird Chrome empfohlen; Firefox kann ebenfalls funktionieren
- Lesen Sie die Nutzungsbedingungen: [Nutzungsbedingungen](https://www.tinycad.net/TCs)

TinyCAD ist für die Verwendung mit Windows, Mac, Chromebooks und Linux vorgesehen.

## Einstiegspunkte
{: #entry-points}

- Modus mit lokalen Dateien: <https://online.tinycad.net/fs>
- Google-Drive-Modus: <https://online.tinycad.net/ga>
- Support: <https://discord.gg/bdXnjhrSYQ>

## Erste Schritte (Zeichnungen auf dem lokalen Computer speichern)
{: #getting-started-saving-drawings-on-local-computer}

Dieser Modus basiert auf Browserfunktionen, die in aktuellen Versionen von Chrome oder Edge verfügbar sind.
Verwenden Sie die neueste Version eines dieser Browser und öffnen Sie dann:

- <https://online.tinycad.net/fs>

## Erste Schritte (Zeichnungen auf Google Drive speichern)
{: #getting-started-saving-drawings-on-google-drive}

Bevor Sie beginnen, benötigen Sie ein Google-Konto.

Ersteinrichtung:

1. Öffnen Sie <https://online.tinycad.net/ga>.
2. Wenn Sie einen Werbeblocker verwenden, deaktivieren Sie ihn für diese Website (er kann den
   Anmeldevorgang bei Google beeinträchtigen).
3. Wenn kein Popup erscheint, prüfen Sie, ob die Pop-up-Blockierung aktiviert ist, und erlauben Sie
   Pop-ups für die Website.
4. Melden Sie sich im Popup bei Ihrem Google-Konto an (falls erforderlich).
5. Aktivieren Sie **alle** Kontrollkästchen für die Einwilligung, um die vollständige Google-Drive-Integration zu erlauben.
6. Wenn die Google-Anmeldung nach dem Akzeptieren der Bedingungen fehlschlägt, laden Sie die Seite neu und versuchen Sie es
   erneut.

## Datenschutz
{: #privacy}

### Modus mit lokalen Dateien
{: #local-file-mode}

TinyCAD läuft vollständig in Ihrem Browser und speichert Ihre Arbeit lokal im Browser.
Nichts von Ihrer Arbeit oder anderen Dateien wird an TinyCAD-Server gesendet.

### Google-Drive-Modus
{: #google-drive-mode}

Zeichnungen werden in Ihrem Google Drive gespeichert. Bei der ersten Verwendung müssen Sie TinyCAD
Zugriff auf Ihre Google-Dateien gewähren, um die Integration zu ermöglichen.

TinyCAD läuft weiterhin im Browser und schreibt Daten in Ihr privates Google Drive; nichts von Ihrer
Arbeit oder anderen Dateien wird an TinyCAD-Server gesendet.

TinyCAD verwendet Google Analytics, um das Nutzungsvolumen der Website zu erfassen.
