# SPICE-Tutorial
{: #spice-tutorial}

In elf Kapiteln gelangen Sie von einem ersten DC-Ergebnis zu Quellen, Filtern, Gleichrichtern, Verstärkern und Untersuchungen zum Schaltungsentwurf. Die Schaltungen finden Sie unter **Beispiel öffnen (Open Example) → SPICE-Tutorial**; sowohl der Browser als auch die Desktop-Version können die Analogbeispiele ausführen.
