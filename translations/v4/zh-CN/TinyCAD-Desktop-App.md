# 安装说明
{: #installation-instructions}

本页介绍 TinyCAD 的安装方法。

## 在 Windows 上安装
{: #install-on-windows}

对于 Windows，安装 TinyCAD v4 的首选方式是通过
[Microsoft Store](https://apps.microsoft.com/detail/9NZQ1M56NM3V)。

如果您使用 Windows，除非有特定原因需要从其他来源安装，否则请使用 Microsoft Store 版本。

[GitHub releases](https://github.com/matt123p/TinyCADv4/releases) 也
提供 Windows 安装程序。

## 在 macOS 上安装
{: #install-on-macos}

对于 macOS，请从
[GitHub releases](https://github.com/matt123p/TinyCADv4/releases) 下载 TinyCAD v4。
macOS 磁盘映像 (`.dmg`) 适用于 Apple Silicon (ARM64)。

## 在 Linux 上安装
{: #install-on-linux}

TinyCAD 可通过 [Snap Store](https://snapcraft.io/tinycad) 获取，适用于主流的、支持 snap 的 Linux 发行版，包括 Ubuntu、Kubuntu、KDE Neon、Pop!_OS、elementary OS、
Debian、Fedora、openSUSE、Manjaro、Arch Linux、CentOS 和 Red Hat Enterprise
Linux。

在 Ubuntu 和许多基于 Ubuntu 的发行版上，系统已支持 snap。
在这种情况下，您可以直接通过以下命令安装 TinyCAD：

```bash
sudo snap install tinycad
```
如果此方法不起作用，[Snap Store](https://snapcraft.io/tinycad) 中的 TinyCAD 页面提供了
各个受支持 Linux 发行版的专用设置说明链接。

[GitHub releases](https://github.com/matt123p/TinyCADv4/releases) 还
提供适用于 x64 和 ARM64 的 Linux `.deb` 软件包。Snap 软件包适用于
x64。由于当前的 Electron 运行时不支持 Linux ARMv7（32 位 ARM）架构，因此不再提供相应的软件包。

## 在 ChromeOS 和 Chromebook 上使用
{: #use-on-chromeos-and-chromebooks}

在 ChromeOS 上，请使用 [TinyCAD Web](../TinyCAD-Web-overview-and-quick-start/)，
而不是安装桌面应用程序。
