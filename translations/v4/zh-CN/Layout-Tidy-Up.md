# 布局整理
{: #layout-tidy-up}

**自动布局 (Auto-layout)** 可通过调整元件位置、导线和标签来整理现有原理图。使用它可以让拥挤的电路更易于阅读、减少不必要的拐弯，或改善元件标号和值的间距。

它适用于**当前原理图页**，在浏览器和 Desktop App 中均可使用。它会保留现有电气连接；不会推断您原本打算绘制哪些连接，也不会从头创建电路。

## 打开自动布局
{: #open-auto-layout}

在任一产品中，选择工具栏上紧邻**仿真 (Simulation)** 的**自动布局 (Auto-layout)**。在 Desktop 中，也可以选择**工具 → 自动布局 (Tools → Auto-layout)**。

请先选择一个原理图页。在编辑库或查看仿真页时，此工具不可用。

## 选择要整理的内容
{: #choose-what-to-tidy}

对话框中的**应用范围 (Apply to)** 设置提供以下选项：

- **整页 (Whole sheet)** — 整理当前页上受支持的电路项目。
- **所选项目 (Selected Items)** — 仅整理所选电路项目，将选择范围以外的项目固定不动，并保留其边界处的连接。

若要处理较小区域，请在打开对话框之前，将该区域内要调整的元件、导线和标签一并选中。当所选内容包含受支持的电路项目时，默认选择“所选项目”。如果所选内容仅包含不受支持的对象（例如注释框或绘图形状），或者没有选择任何内容，则该选项会被禁用。

选择内容可以包含符号、导线、网络标签、电源符号、不连接标记和结点。选择范围外的元件不会仅仅因为与所选元件相连而移动。

## 选择整理强度
{: #choose-the-strength}

**强度 (Strength)** 控制元件布局可以改变的幅度：

| 强度 | 可以更改的内容 |
| --- | --- |
| **低 (Low)** | 固定大型元件；小型元件、导线和标签仍可移动。 |
| **中 (Medium)** | 最多允许两个大型元件移动，也可移动小型元件、导线和标签。这是默认设置。 |
| **高 (High)** | 允许所有符合条件的元件移动，同时也可移动导线和标签。 |

若要保留主要布局，请从“低”开始。如果电路需要更多空间来重新安排，请使用“中”或“高”。“低”并非仅调整标签的选项：它也可能更改小型元件的位置和导线路径。

“大型”是根据符号几何形状和引脚数确定的，而非根据其电气重要性确定。更改强度不会旋转、缩放或替换元件，也不会更改元件标号、值或模型设置。

## 运行并检查结果
{: #run-and-review-the-result}

1. 打开一个图纸，或打开一个[内置示例](../Bundled-Examples/)的可编辑副本。
2. 如果要限制操作范围，请选择要整理的区域。
3. 打开**自动布局 (Auto-layout)**，选择**应用范围 (Apply to)** 和**强度 (Strength)**，然后选择**执行 (Go)**。
4. 等待显示**正在排列布局… (Arranging layout…)**。成功后，结果会立即应用，对话框随即关闭。
5. 检查结果。如果您更喜欢原来的布局，可以使用**撤消 (Undo)** 一步还原整个整理操作。

**取消 (Cancel)** 会停止计算并关闭对话框，不应用任何更改。如果工具运行期间图纸发生变化，计算结果将被丢弃；请针对当前图纸重新运行。

**未发现布局改进 (No layout improvements were found)** 表示在所选范围和强度内，工具未找到可接受的更改。图纸将保持不变。您可以关闭对话框，选择其他区域，尝试不同的强度，或手动调整。

## 工具可以改进的内容
{: #what-the-tool-improves}

自动布局会尝试进行以下改进：

- 调整元件标号/值文本的位置，使其更易读、字段保持在一起，并避开附近的图形、导线和其他文本。
- 改善普通网络标签沿其连接导线的位置，并尽可能对齐相关标签。
- 简化正交导线路径、缩短不必要的绕行，并让元件引脚处的引出更清晰。
- 更紧凑地布置相连元件，并让重复元件保持规则间距。
- 在连接关系和可用空间允许时，为相关导线安排有序的平行路径。

它不会重新设计注释框、总线、形状端口标记、库图形或页面装饰。某些密集或形状特殊的符号仍需手动调整。如果较长的导线能为标签腾出空间，或能让连接更清晰，那么较长的导线也可能是更好的结果。

## 整理前检查连接
{: #check-connections-before-tidying}

自动布局将图纸的**现有连接关系作为起点**。在接受更改之前，它会检查电气网络归属和导线的物理连接。这些检查不会因网络标签名称相同而忽略断开的物理导线。

导线经过另一根导线的端点或插座时，即使没有可见的结点圆点，也可能形成电气连接。如果这种接触是意外的，请在运行自动布局之前先修正：该工具无法判断现有连接是否是绘图错误。它不会移动存在歧义的结点来连接原本分离的网络。

整理之后，请检查分支、引脚连接以及未使用插座周围的路径。请酌情使用[设计规则检查](../Design-Rules-Check/)，并将电路与您预期的连接关系进行比较。如果仿真图纸标记为已更改，请先[重新运行仿真](../Simulation/)，再将旧结果视为当前图纸的测量结果。

## 自动布局还是逐点连线？
{: #auto-layout-or-point-to-point-wire}

如果要整理原理图中已有的几何布局，请使用**自动布局 (Auto-layout)**。如果要在两个端点之间创建新的布线路径连接，请使用[逐点连线 (Point-to-Point Wire)](../Wires/#auto-routing)。普通的[导线工具 (Wire tool)](../Wires/#placing-wires)允许您自行选择各个拐角。

另请参阅[吸附到网格 (Snap to Grid)](../Snap-to-Grid/)、[标签 (Labels)](../Labels/)和[页面尺寸 (Page Size)](../Page-Size/)。
