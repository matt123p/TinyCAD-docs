# 设计详情框
{: #design-details-box}

每个设计都会存储文档元数据，例如标题、作者及相关
详情。您可以通过 **设计详情（Design Details）** 命令编辑这些值。

设计详情框可以显示在图纸的左下方：

<img src="/v4/images/media/image15.png" alt="Design details box displayed on the schematic page with title and document metadata fields" style="width: 4.65625in; height: 2.20833in;" />

## 编辑设计详情
{: #edit-design-details}

1. 打开原理图。
2. 从“文件”菜单/工具中打开 **设计详情（Design Details）**。
3. 更新所需字段（例如标题和作者）。
4. 保存设计。

从设置菜单中使用 **设计详情（Design Details）** 进行编辑：

<img src="/v4/images/media/image16.png" alt="Menu showing the Design Details command used to edit document metadata" />

保存设计时，这些详情也会随之保存。

## 显示详情框
{: #display-details-box}

**显示详情框** 选项用于控制是否在图纸上显示详情面板。

- 启用后，详情会显示在原理图上。
- 详情框会与设计一起打印。
- 详情框显示在图纸的右下区域。

## 注释
{: #notes}

设计详情按图纸页分别设置——在多页图纸中，每页都可以有自己的设计详情。

- 如果设计跨越多页，请参阅[多页图纸](../Multiple-Sheet-Drawings/)。
- 请参阅[页面尺寸](../Page-Size/)，了解如何控制详情框周围的图纸布局。
- 有关详情框在打印或 PDF 输出中的显示方式，请参阅[打印](../Printing/)。
