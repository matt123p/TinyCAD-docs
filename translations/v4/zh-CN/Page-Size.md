# 页面尺寸
{: #page-size}

使用 **页面尺寸** 设置所有图纸页的尺寸。

<img src="/v4/images/media/image4.png" alt="The page size dialog" />

## 可更改的设置
{: #what-you-can-change}

- **纸张尺寸**：选择 A4 等标准纸张尺寸。
- **方向**：选择 **纵向**，使页面较高；或选择 **横向**，使页面较宽。
- **宽度**和**高度**：以毫米为单位输入自定义页面尺寸。

选择标准纸张尺寸时，TinyCAD 会自动填入宽度和高度。
更改方向会互换这两个尺寸。

## 典型用法
{: #typical-use}

根据所需的输出类型设置页面尺寸：

- 打印或导出 PDF 时选择标准尺寸
- 对于较宽的原理图使用横向布局
- 标准纸张尺寸不适合图纸时，使用自定义宽度和高度

所选页面尺寸会作为图纸的一部分与该图纸页一起保存。
