# 标签
{: #labels}

标签是具有电气作用的网络名称。名称相同的所有导线都视为已连接，
即使它们之间没有绘制实体导线。

使用标签可以：

- 连接同一页上相距较远的点，
- 减少密集原理图中的视觉杂乱，
- 连接同一绘图中不同页上的网络，
- 将层次符号引脚连接到内部网络。

## 标签的工作方式
{: #how-labels-work}

- 标签连接到其下方的导线上。
- 连通性取决于**标签文本**，而非位置。
- 标签的**形状**仅是视觉样式，不会改变连通性、
	网表或 DRC 行为。
- 凡是要表示同一电气网络的位置，都使用相同的名称。

## 标签命名指南
{: #label-naming-guidelines}

- 使用清晰的网络名称，例如 `RESET`、`SCL`、`+5V`、`ADC_IN0`。
- 在整个设计中保持命名一致。
- 避免意外的名称变体（`GND` 与 `GN D`、`CLK` 与 `Clk`），因为这些名称会创建不同的网络。
- 如果名称中包含数字，重复放置时可使用“重复方向”（Repeat Direction）名称选项递增或递减数字后缀。

## 标签形状及其用途
{: #label-shapes-and-why-to-use-them}

TinyCAD 在标签工具选项中提供多种标签形状。根据可读性和绘图风格
选择形状；所有形状的电气作用都相同。

使用不同形状的常见原因：

- 将频繁重复使用的网络与仅使用一次的局部网络区分开，
- 在视觉上突出显示页外连接或跨块连接，
- 向读者表示信号方向或意图，
- 符合团队或公司的原理图风格。

实用原则：选定少量形状并保持一致使用，以便读者快速浏览图纸。

## 放置和编辑标签
{: #placing-and-editing-labels}

1. 选择“标签”工具。
2. 输入网络名称。
3. 按需选择方向和形状。
4. 将标签放置在目标导线上。
5. 在所有应连接到该网络的位置重复上述操作。


## 在多页绘图中使用标签
{: #labels-with-multi-sheet-drawings}

在多页绘图文件中，标签是连接不同页面网络的常用方式。

- 不同页面上名称相同的标签表示同一电气网络。
- 生成网表时会使用这种跨页连接。
- 为共享网络使用稳定且明确的名称（`+3V3`、`GND`、`I2C_SDA`、
	`I2C_SCL` 等）。

推荐工作流程：

1. 预先定义常用网络名称。
2. 在每一页上重复使用完全相同的名称。
3. 运行 DRC/网表检查，尽早发现命名错误。
