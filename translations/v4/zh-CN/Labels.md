# 标签
{: #labels}

标签是具有电气作用的网络名称。所有具有相同标签名称的导线都会被视为
已连接，即使它们之间没有绘制实际导线。

使用标签可以：

- 连接同一张图纸上相距较远的点，
- 减少密集原理图中的视觉杂乱，
- 连接同一绘图中的不同图纸上的网络，
- 将层次符号引脚连接到内部网络。

## 标签的工作方式
{: #how-labels-work}

- 标签连接到其下方的导线。
- 连通性取决于**标签文本**，而不是位置。
- 标签的**形状**仅是一种视觉样式，不会改变连通性、
	网表或 DRC 行为。
- 在所有需要属于同一电气网络的位置使用相同名称。

## 标签命名指南
{: #label-naming-guidelines}

- 使用清晰的网络名称，例如 `RESET`、`SCL`、`+5V`、`ADC_IN0`。
- 在整个设计中保持命名一致。
- 避免无意的差异（`GND` 与 `GN D`，`CLK` 与 `Clk`），因为这些
	会创建不同的网络。
- 如果命名中包含数字，重复放置时可以使用 Repeat Direction 名称选项递增或递减
	数字后缀。

## 标签形状及其用途
{: #label-shapes-and-why-to-use-them}

TinyCAD 在标签工具选项中提供多种标签形状。根据可读性
和制图风格选择形状；所有形状在电气上等效。

使用不同形状的常见原因：

- 将经常重复使用的网络与仅使用一次的局部网络区分开，
- 让页外或跨模块连接在视觉上更加醒目，
- 向读者指示信号方向或意图，
- 符合团队或公司的原理图样式。

实用规则：选用少量形状并保持一致，以便读者
快速浏览图表。

## 放置和编辑标签
{: #placing-and-editing-labels}

1. 选择 Label 工具。
2. 输入网络名称。
3. 根据需要选择方向/形状。
4. 将标签放置在目标导线上。
5. 在每个需要连接到该网络的位置重复此操作。


## 多图纸绘图中的标签
{: #labels-with-multi-sheet-drawings}

在多图纸绘图文件中，标签是连接不同图纸上网络的常用方式。请参阅[多图纸绘图](../Multiple-Sheet-Drawings/)，了解一个完整示例以及介绍图纸管理和跨图纸标签的视频。

- 不同图纸上名称相同的标签表示同一电气网络。
- 生成网表时会使用这种跨图纸连接方式。
- 为共享网络使用稳定、明确的名称（`+3V3`、`GND`、`I2C_SDA`、
	`I2C_SCL` 等）。

推荐工作流程：

1. 预先定义常用网络名称。
2. 在每张图纸上重复使用这些完全相同的名称。
3. 运行 DRC/网表检查，尽早发现命名错误。
