# 11. TinyCAD 如何实现 SPICE
{: #how-tinycad-implements-spice}

[上一节：设计调查](/v4/SPICE-Tutorial-10/) · [目录](/v4/Simulation-Tutorials/) · [XSPICE 课程](/v4/XSPICE-Tutorial-01/)

TinyCAD 提供原理图编辑器、仿真设置、仪器、图表和测量功能。**ngspice** 是其底层的电路求解引擎。你在 TinyCAD 中绘制并配置实验；TinyCAD 将其转换为 SPICE 电路文本，运行 ngspice，并呈现返回的结果。

本章中的示例已随 TinyCAD 一同提供。选择 **打开示例 → SPICE 教程**，选中 **divider** 或 **rc-ac**，然后选择 **打开图纸**。对于数字演示，选择 **打开示例 → XSPICE 和数字教程 → logic-buffer → 打开图纸**。无需下载教程或模型。

## SPICE、ngspice 和 XSPICE
{: #spice-ngspice-and-xspice}

SPICE 使用元件、连接节点和数学器件模型来描述电路。工作点分析会求解其直流方程。瞬态分析会跟踪电路在模拟时间内的行为。AC 分析会在电路偏置点附近对其线性化，以计算小信号频率响应。因此，选择分析类型也是定义实验的一部分。

ngspice 是一种开源混合信号电路仿真器，源自 Berkeley SPICE。TinyCAD 将其引擎打包在软件中，而无需你安装并运行单独的命令行仿真器。用于验证这些教程的引擎版本是 **ngspice 47**；运行的 **诊断**视图会标明其后端和构建版本。有关上游项目的背景，请参阅[官方 ngspice 概览](https://ngspice.sourceforge.io/presentation.html)。

**XSPICE 是集成在 ngspice 中的扩展**，不是另一个需要启动的应用程序。它增加了代码模型，包括功能性模拟模块，以及与模拟求解器协调事件的数字逻辑。因此，数字状态变化可以在同一次仿真中影响模拟电路。[官方 XSPICE 介绍](https://ngspice.sourceforge.io/xspice.html)说明了这种区别。

| TinyCAD 环境 | 引擎的运行方式 | 适用示例 |
| --- | --- | --- |
| 桌面版 | 单独的本机求解器进程，配有捆绑的 XSPICE 代码模型库 | 模拟 SPICE 和 XSPICE 课程 |
| 浏览器版 | 编译为 WebAssembly 的 ngspice，在单独的 Web Worker 中运行 | 模拟 SPICE 和兼容的模拟行为模型；此构建版本不包含 XSPICE |

TinyCAD 会根据运行环境选择后端。对于捆绑的示例，无需查找 ngspice 可执行文件或选择外部仿真器。XSPICE 图纸可以包含其模型定义，但仍需要桌面版随附的本机代码模型库。将图纸复制到浏览器中并不会增加该引擎功能。

## 从图纸到结果
{: #from-drawing-to-result}

主要阶段如下：

1. **确定电气连接。** TinyCAD 根据导线、接点和网络标签，确定哪些元件引脚共用一个网络。导线交叉处并不一定连接，除非图纸确实将网络接在一起。相同的网络标签可以连接相距较远的点；画在导线附近的文本则不行。
2. **展开元件定义。** 每个用于仿真的符号都提供一个 SPICE 模板。TinyCAD 会替换其中的元件代号、连接的节点名称和值，并包含所需的器件或子电路定义。
3. **添加实验设置。** 仿真工作表提供分析类型、温度、参数、模型附件和请求的信号。提交电路前，TinyCAD 会检查缺失的模型、未解析的引脚、重复的元件代号以及其他可检测的设置错误。
4. **运行 ngspice。** 求解器会计算电压、电流和其他请求的量。它会返回数据和诊断日志；TinyCAD 将它们收集到一个采集结果中，并关联该次运行的设置和引擎标识。
5. **查看和测量。** TinyCAD 会呈现图表、数值数据和计算得出的测量结果。例如，截止频率测量是根据 AC 数据推导出来的，并不是另行插入原理图的元件。

这说明为什么仅有看起来正确的图形还不够：晶体管需要模型和正确的引脚映射；而两根导线即使在当前缩放比例下看起来端点接近，也必须在电气上实际相连。

## 应该使用哪些符号？
{: #which-symbols-should-i-use}

打开工具栏上的**脉冲形图标**。悬停提示为**仿真**。下文中的 **仿真 → …** 指该图标的菜单。

| 所需内容 | 查找位置 | 检查事项 |
| --- | --- | --- |
| 电阻、电容、电感、二极管、LED、NPN/PNP 晶体管或 741 运算放大器 | **仿真 → SPICE 元件**，或 **SPICE 基础元件**库 | 数值、极性、电源和模型假设 |
| 独立电压/电流激励源 | **仿真 → SPICE → 插入源** | 源类型、信号形状、单位和连接方向 |
| 参考节点 | **仿真 → SPICE → 插入接地** | 进行电气连接；SPICE 的参考节点为 `0` |
| 电压观测 | SPICE 子菜单中的**插入探针**或**插入差分探针** | 单端电压相对于地测量；差分探针测量其端子之间的电压 |
| 支路电流观测 | **仿真 → SPICE → 插入电流探针** | 串联插入并检查正方向 |
| 受控源 | **仿真 → SPICE → 插入受控源** | 控制端子、输出端子和增益/跨导 |
| 台式仪器 | **仿真 → 实验室设备** | 示波器、万用表、函数发生器和台式电源的设置；其负载效应和限制都很重要 |
| 普通模型化逻辑 | **数字逻辑**库 | 这些可配置的便携式 SPICE 模型不同于事件驱动的 XSPICE 示例；检查电源引脚和模型属性 |
| 事件驱动的 XSPICE 逻辑 | 内置的 **XSPICE 和数字教程**示例 | 使用桌面版，并保留模型中的模拟/数字桥接器 |

SPICE 基础元件库提供了常见器件的即用型配置示例。通用晶体管或 741 风格的模型适合学习，但其仿真行为并不自动等同于特定制造商器件的规格。运算放大器章节明确说明了替代原始 `AMP.DSN` 器件的通用模型。

其他库中的符号可能仅供绘图使用。选中已放置的符号，并在其属性中检查 **SPICE** 选项卡。它需要有效的 SPICE 模板以及该模板所引用的所有模型定义。名称、封装或图案相匹配，并不会自动提供这些定义。同样，名为 `VCC` 的标签只是命名网络，并不会产生电源电压。请将实际的电源连接到该网络。

## 运行现有实验
{: #run-an-existing-experiment}

1. 选择 **打开示例 → SPICE 教程 → divider → 打开图纸**。
2. 选择其**仿真**工作表。在**设置**下，保存的分析为**测量直流 — 工作点**。该电路使用一个 5 V 电源和两个 1 kΩ 电阻。
3. 选择**运行**。如果图表面板处于隐藏状态，使用**仿真 → 显示图表**。
4. 检查 `in`、`out` 和 `v1#branch`。预期值分别为 **5 V**、**2.5 V** 和 **−2.5 mA**。电源电流的定义方向是流入正端，因此此处正在供电的电源电流为负值。
5. 在电路工作表中将 R2 改为 `2k`，然后重新运行。预期 OUT 变为约 **3.333 V**。先前保留的采集结果仍然对应旧电路；更改数值不会重写已有结果。

![TinyCAD 的仿真工作表，其中显示 RC AC 分析和截止频率结果](/v4/images/simulation-tutorials/spice/tinycad-ac-setup.png)

此应用程序截图显示的是另一个内置示例 **rc-ac** 的**设置**视图。其 1 kΩ/1 µF 滤波器的截止频率约为 **159.15 Hz**。打开它，可以将频域实验与分压器的单个直流工作点进行比较。

**运行**会根据所选分析开始一次有限时长的采集。**停止**会终止求解器，并保留已接受的采样点；这些采样点是部分结果，不能证明请求的时长已完成。这些构建版本不提供暂停/恢复或无限期运行的求解器。使用**历史记录**检查先前的运行，并通过**诊断**查看求解器日志。

观看[打开、运行并更改分压器](/v4/videos/simulation-tutorials/spice/first-run.mp4)以及[AC 响应和截止频率](/v4/videos/simulation-tutorials/spice/ac-response.mp4)进行演示。两段视频都展示了真实的桌面版控件、已完成的本机采集和数值结果，并附有字幕。

## 构建你的第一个仿真
{: #build-your-own-first-simulation}

从**仿真 → SPICE 元件**放置两个电阻，使用**插入源**放置一个电源，并使用**插入接地**放置一个接地符号。将它们布置成分压器：电源正端接 R1，R1 接 R2，R2 再接回电源负端和地。将两个电阻都设为 `1k`，将电源设为 5 V DC，并将电源网络标记为 `IN`、中点网络标记为 `OUT`。确保每个元件都有唯一的元件代号，例如 R1、R2 和 V1。

选择**仿真 → 仿真**以创建仿真工作表。在**设置**下选择**测量直流 — 工作点**，然后选择**运行**。你应得到与内置分压器相同的数值。如果运行失败，请对照该可正常工作的示例，检查连接、电源设置和 SPICE 属性。

若要进行瞬态实验，请选择**随时间变化 — 瞬态**，设置持续时间和最大步长，并配置随时间变化的信号源。若要进行 AC 分析，请选择**频率响应 — AC**，设置频率范围和每十倍频程的点数，并为输入源指定非零的 **AC 幅值**，通常为 1 V。其正弦频率和瞬态幅值不会设定 AC 扫频。TinyCAD 还提供直流扫描、噪声、传递函数和极点—零点分析；前面的章节介绍了各自的适用场景。

## 检查生成的 SPICE 并添加模型
{: #inspect-the-generated-spice-and-add-models}

运行分压器后，打开**诊断 → 生成电路文本**。重要的行如下所示；TinyCAD 还会添加温度和保存信号的指令：

```spice
R1 IN OUT 1k
R2 OUT 0 1k
V1 IN 0 DC 5 AC 0 0
.op
.end
```

`R1 IN OUT 1k` 表示一个连接在节点 IN 和 OUT 之间的 1 kΩ 电阻。`0` 是参考节点。此文本明确展示了连接和电源极性。若要单独检查或运行网表，请使用**导出电路**。TinyCAD 的仿真工作表负责 `.op`、`.tran`、`.ac` 和其他分析指令；不要将它们或 `.end` 粘贴到元件的 SPICE 属性中。

若要添加其他器件模型，请展开**设置 → SPICE 模型**。选择 `.lib`、`.cir` 或 `.mod` 文件，或者输入文件名和模型文本。无论哪种方式，都要选择**保存模型**以附加模型。使用简单的文件名，例如 `device.lib`。然后配置符号的 SPICE 模板，以实例化相应的器件或 `.SUBCKT`，并在需要时包含该附件，例如在其前导部分中使用 `.include device.lib`。仅附加文件并不会将其映射到符号上。

请根据模型的**引脚编号**检查其端子顺序，而不是根据这些引脚在页面上的表面位置。三端晶体管模型和制造商子电路可能采用不同的节点顺序。也要验证嵌套模型的引用：包含的文件也必须附加到仿真工作表。模型定义和附件会随已保存的图纸一起保存。

TinyCAD 支持嵌入式模型文本，不支持任意 ngspice 命令脚本或外部可执行模块。此工作流程不支持 `.control` 块、Shell 命令、外部模块加载以及基于文件的激励源/模型。请使用受支持的源控件和分析功能，或导出电路以进行单独的命令行 ngspice 仿真。为其他 SPICE 方言编写的厂商模型可能需要调整后才能被 ngspice 接受。

## 数字仿真的原理
{: #how-digital-simulations-fit-in}

在桌面版中打开 **XSPICE 和数字教程 → logic-buffer**。其 X1 模型包含一个模数桥接器、一个事件驱动缓冲器和一个数模桥接器。普通信号源驱动模拟输入；这些桥接器使逻辑状态能够以电压的形式显示在 TinyCAD 图表中。

![内置 XSPICE 缓冲器的输入和输出计算结果](/v4/images/simulation-tutorials/xspice/logic-buffer-results.png)

运行保存的瞬态仿真。预期得到周期为 1 µs 的 0–5 V 脉冲，以及延迟约 20 ns、边沿具有有限上升/下降时间的输出跳变。放大图表以检查延迟。此图绘制的是该示例中的实际求解器结果。

模型的数字节点不是普通电压节点。桥接器阈值以及对未定义状态的表示方式，都是有意选择的建模方法。由模拟 SPICE 表达式构建的行为门电路在图表上可能看起来类似，但使用的是不同的仿真方法。继续阅读 [XSPICE 概览](/v4/XSPICE-Tutorial-01/)，了解桥接器、时序、存储和混合信号电路。

## 保存、比较和排查问题
{: #save-compare-and-troubleshoot}

使用**另存为**保存实验，以保留可编辑的内置示例副本。TinyCAD 可以将采集结果与图纸一同保留；**不保存结果**会保留电路和设置，但省略存储的结果。若需进一步分析，可使用**数据**导出 CSV、JSON 或 SPICE raw 数据。请记录所用的采集结果、模型和测量窗口。

| 现象 | 首先检查 |
| --- | --- |
| 缺少 SPICE 信息 | 使用带模型的符号，或配置其 SPICE 选项卡 |
| 缺少模型或子电路 | 模型名称、附加文件、包含语句和端子顺序 |
| 电路浮空或缺少接地 | 已连接的 SPICE 地和适当的直流回路 |
| 有电源标签但无电源电压 | 将电压源或台式电源连接到带标签的网络 |
| AC 响应为空/为零 | 输入 AC 幅值和所选信号 |
| 浏览器中无法使用 XSPICE 模型 | 在 TinyCAD 桌面版中运行该示例 |
| 绘图与编辑后的数值不符 | 重新运行并选择新的采集结果 |
| 收敛错误或波形不完整 | 阅读诊断信息，简化电路，并检查激励边沿、时间步长和模型有效性 |

[ngspice 手册](https://ngspice.sourceforge.io/docs.html)是器件和模型语义的参考文档。TinyCAD 的控件决定了通过其集成工作流程可以使用其中哪些功能。
