# TinyCAD - 入门指南
{: #tinycad---getting-started}

如需根据文字说明和数据手册创建符号、库或电路方面的帮助，请参阅 [AI 助手](../AI-Assistant/) 指南，其中包括提供商设置和示例提示。

TinyCAD v4 提供两种使用方式：

## 桌面应用
{: #desktop-app}

如果您希望离线工作，或者想确保始终能够使用 TinyCAD，可能更适合使用已安装的 TinyCAD 版本。

请参阅[安装说明](../TinyCAD-Desktop-App/)，了解如何下载、安装和运行此版本的 TinyCAD。

## 在线应用
{: #online-app}

如果您不想或无法安装 TinyCAD，可能更适合使用在线版本。例如，在不允许安装应用程序的教育或工作环境中，您可以使用在线版本。

请参阅 [TinyCAD Web 快速入门](../TinyCAD-Web-overview-and-quick-start/)，了解如何直接在 Web 浏览器中开始使用 TinyCAD，无需安装。

## 浏览现成图纸
{: #explore-a-ready-made-drawing}

使用[捆绑示例](../Bundled-Examples/)浏览网络、传感器站、音频设置、实验室工作台或电机控制项目。在浏览器标题栏中，或在桌面版的“文件”菜单下，选择“打开示例”。

[捆绑库](../Bundled-Libraries/)位于左侧的 **标准** 分类下。选择一个集合，搜索所需内容，然后将预览图拖到图纸上。

如需计算电路行为，请从[仿真和 SPICE](../Simulation/)开始，或按照完整的 [SPICE 教程](../SPICE-Tutorial/)操作。这两款产品均包含集成引擎。要学习独立的 [XSPICE 数字课程](../XSPICE-Tutorial/)，请使用桌面版。
