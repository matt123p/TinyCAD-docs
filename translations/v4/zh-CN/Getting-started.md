# TinyCAD - 入门指南
{: #tinycad---getting-started}

TinyCAD v4 有两种使用方式：

## 桌面应用
{: #desktop-app}

如果您想离线工作，或者希望确保始终能够使用 TinyCAD，可能更适合使用已安装的 TinyCAD 版本。

请参阅[安装说明](../TinyCAD-Desktop-App/)，了解如何下载、安装和运行此版本的 TinyCAD。

## 在线应用
{: #online-app}

如果您不想或无法安装 TinyCAD，可能更适合使用在线版本——例如，在教育或工作环境中，您无权安装应用程序。

请参阅 [TinyCAD Web 快速入门](../TinyCAD-Web-overview-and-quick-start/)，了解如何直接在 Web 浏览器中开始使用 TinyCAD，无需安装。

## 浏览现成的图纸
{: #explore-a-ready-made-drawing}

使用[随附示例](../Bundled-Examples/)探索网络、传感器站、音频设置、实验台或电机控制项目。“打开示例”位于浏览器标题栏中，或在桌面版的“文件”菜单下。

[随附库](../Bundled-Libraries/)位于左侧的 **标准** 下方。选择一个集合，搜索并将预览拖到图纸上。

若要计算电路行为，请从[仿真和 SPICE](../Simulation/)开始，或参阅完整的 [SPICE 教程](../SPICE-Tutorial/)。两款产品均包含集成引擎。请使用桌面版学习独立的 [XSPICE 数字课程](../XSPICE-Tutorial/)。
