# TinyCAD - 入门指南
{: #tinycad-v4---getting-started}

TinyCAD v4 有两种使用方式：

## 桌面应用
{: #desktop-app}

如果您希望离线工作，或者希望确保始终能够使用 TinyCAD，可能更倾向于使用已安装的 TinyCAD 版本。

请参阅[安装说明](../TinyCAD-Desktop-App/)，了解如何下载、安装和运行此版本的 TinyCAD。

## 在线应用
{: #online-app}

如果您不希望或无法安装 TinyCAD，可能更倾向于使用在线版本——例如，在不允许安装应用程序的教育或工作环境中。

请参阅 [TinyCAD Web 快速入门](../TinyCAD-Web-overview-and-quick-start/)，了解如何
直接在 Web 浏览器中开始使用 TinyCAD，无需安装。
