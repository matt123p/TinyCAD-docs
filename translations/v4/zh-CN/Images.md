# 图像
{: #images}

向图纸添加图像，可用于放置徽标、参考图片或扫描的图表。在 TinyCAD Desktop 和浏览器应用中，均可从剪贴板粘贴图像，或使用 **文件 → 导入 → 图像…** 选择文件。

图像是图纸上的图形。它们不会创建元件、引脚或电气连接。若要将电路图像转换为可编辑的符号和导线，请改用 Desktop [AI assistant](../AI-Assistant/)。

## 复制和粘贴
{: #copy-and-paste}

1. 在其他应用程序中复制图像本身，而不是文件名或链接。例如，在浏览器中使用 **复制图像**，或在图像编辑器中复制选区。
2. 返回 TinyCAD，点击绘图区域，确保当前未在编辑文本字段。
3. 按 **Ctrl+V**（macOS 上按 **Cmd+V**）。
4. 选中粘贴的图像并将其拖动到所需位置。

支持 PNG 或 JPEG 格式的剪贴板图像。如果无法粘贴图像，请将其另存为文件，然后使用“导入”。也可以复制并粘贴 TinyCAD 图纸中已有的图像。

## 从文件导入
{: #import-from-a-file}

1. 打开 **文件 → 导入 → 图像…**。在浏览器应用中，使用工具栏上的文档图标打开 **文件** 菜单。
2. 选择图像文件并确认文件选择器中的选择。
3. 图像将显示在当前图纸上。选中图像即可移动、调整大小或裁剪。

PNG 和 JPEG 文件会直接嵌入。浏览器可解码的其他格式（如 GIF、WebP、BMP 和 SVG）会转换为 PNG。导入的图像仍为静态图片；动画不会保留。格式支持取决于浏览器，或 TinyCAD Desktop 所含的浏览器引擎。无法读取或不受支持的文件会导致错误。

也可以将 PNG 或 JPEG 文件拖到绘图区域，以放置在释放位置。

## 移动和调整大小
{: #move-and-resize}

点击图像将其选中。拖动图像主体可移动图像，拖动角部或边缘的控点可调整大小。

选中图像时，底部属性栏会显示 **图像** 部分。启用 **固定纵横比** 可在调整大小时保持当前宽高比例。禁用此选项可分别调整宽度和高度。移动图像不会改变其比例。

**重置纵横比** 会恢复可见图像的原始比例，并将裁剪部分计入考量。此操作会保留当前宽度和左上角位置，并调整高度。“固定纵横比”复选框会保持当前设置。可以撤销重置操作。

## 裁剪边缘
{: #clip-the-edges}

在“图像”属性中使用 **左侧裁剪 (px)**、**右侧裁剪 (px)**、**顶部裁剪 (px)** 和 **底部裁剪 (px)**，以隐藏不需要的边框或图片部分。

- 数值为整数像素，以原始图像为基准测量，与显示尺寸或图纸网格无关。
- 例如，将 **左侧裁剪 (px)** 设为 **20**，会隐藏源图像最左侧的 20 个像素。
- 裁剪会使剩余像素保持原有比例和位置；可见边界向内移动，而不会拉伸图片。
- 每个方向至少须保留一个像素。控件会相应限制各边的裁剪量。
- 将边缘值重设为 **0** 即可恢复。裁剪不会从嵌入的原始图像中移除像素。

图像插入和属性更改，以及移动和调整大小，均可使用 **撤销** 和 **重做**。

## 保存和输出
{: #saving-and-output}

图像会嵌入图纸文件，因此原始文件无需继续保存在导入位置。像平常一样保存图纸，即可保留其中的图像、固定纵横比设置和裁剪设置。重新打开文件后，这些设置仍会保留，压缩的 `.dzn` 图纸中也会保留这些设置。

裁剪设置属于每个已放置的图像，因此同一图片的不同副本可以显示不同部分。可见图像会包含在打印、PDF 和 SVG 输出中。
