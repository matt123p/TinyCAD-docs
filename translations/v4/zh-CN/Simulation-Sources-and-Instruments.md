# 信号源、探针和虚拟仪器
{: #sources-probes-and-virtual-instruments}

工具栏的 **Simulation** 菜单包含 **SPICE** 插入工具和 **Lab Equipment**。选择一个工具并将其放置在原理图上。右键单击或按 Escape 取消放置。从 Simulation 图纸中选择的工具会切换到原理图以供放置；其定义会嵌入到绘图中。

## 独立信号源
{: #independent-sources}

选择 **Simulation → SPICE → Insert Source**。放置前会打开其编辑器。选择电压或电流以及信号类型。选择已放置信号源的主体可重新打开其底部编辑器。

| 信号类型 | 适用场景 | 需要检查的设置 |
| --- | --- | --- |
| DC | 偏置和稳定电源 | DC 值和极性 |
| 正弦波 | 周期性模拟输入 | 偏置、峰值幅度、频率、相位、延迟和阻尼 |
| 方波/脉冲 | 开关和定时 | 低/高电平、延迟、上升/下降时间、脉冲宽度和周期 |
| 三角波 | 重复斜坡 | 电平、周期和斜坡定时 |
| 分段线性 (PWL) | 指定的序列 | 按递增时间排列的时间/数值对，每行一对 |
| 指数波 | 形状渐变 | 电平、延迟和时间常数 |
| FM | 频率调制 | 载波和调制设置 |

![正弦信号源编辑器和波形预览](../Images/simulation/source-settings.png)

预览会反映数值波形设置。运行前可用它检查是否存在意外的偏置、峰值或定时。设置无效会导致无法启动。信号源图标会随波形变化，电流信号源会保留其方向箭头。

**AC 幅度和相位是小信号频率分析的独立设置**。它们与瞬态正弦波幅度相互独立。信号源 DC 偏置和瞬态波形也必须谨慎选择。请参阅[分析](../Simulation-Analyses/)和[信号源教程](../SPICE-Tutorial-03/)。

新建信号源和探针使用紧凑的 8 mm 端子间距。旧版大型控件可在其底部编辑器中选择 **Use compact symbol**。转换会固定第一个端子，并将现有连接延伸至调整尺寸后的端子，整个过程可通过一次撤销操作还原。更改尺寸后请检查这些连接。

## 探针和接地
{: #probes-and-ground}

| **Simulation → SPICE** 中的工具 | 连接方式 | 含义 |
| --- | --- | --- |
| **Insert Probe** | 一个尖端连接到一个网络 | 相对于地 0 的电压 |
| **Insert Differential Probe** | + 和 − 分别连接到两个网络 | `V(+) − V(−)` |
| **Insert Current Probe** | 与支路串联 | 电流从 + 流向 − |
| **Insert Ground** | 连接到电路的参考网络 | 将 Earth 电源符号连接到值为 0 的节点 |

插入探针/接地时会吸附到导线上，并在连接点处分割导线。请检查尖端的实际位置和极性。电流探针是**理想的零伏电压源**：必须串联使用。将其并联在电源两端会造成短路。插入串联测量探针时，请移除或断开原有的并联导线。

探针面板用于选择采集和显示模式。工作点信号可显示标量读数；复数 AC 结果可显示实部、幅值、dB 和相位视图。如果所需结果缺失，或属于已编辑的电路，面板会说明结果不可用或需要重新运行的原因。

### 受控源
{: #controlled-sources}

**Insert Controlled Source** 提供压控压源（**E**）或压控流源（**G**）。输出引脚为 +/−，编号为 1/2；控制引脚为 C+/C−，编号为 3/4。连接控制输入的两端，并在编辑器中检查传输特性。控制端口不是输出电源端子。

## 虚拟实验室仪器
{: #virtual-laboratory-equipment}

从 **Simulation → Lab Equipment** 中选择这些工具。它们是带有采集控件的操作模型。**Standard → Test & Measurement** 中名称相似的图形用于绘制实体工作台布局，不会执行仿真测量。

对于已接线完成的电路，请下载 [Virtual laboratory.dzn](../examples/simulation/virtual-laboratory.dzn) 并使用 **File → Open** 打开。这是配套演示文件，不是捆绑示例浏览器中的命名条目。

### 示波器
{: #oscilloscope}

示波器有两个差分通道：**1 A+**、**2 A−**、**3 B+**、**4 B−**。正输入和负输入都必须连接。默认输入负载为 **1 MΩ**；它可能影响高阻抗电路。

使用 time/div 和 volts/div 控件以及十格水平、八格垂直的显示区域。触发模式为 **Auto**、**Normal** 和 **Single**。**Acquire** 会请求采集十格水平时间范围的瞬态数据，最大步长约为 time/div 除以 100。运行后更改显示比例不会生成新的采集数据，也不能补回缺失的边沿。

AC 耦合会从显示信号中去除按时间加权的平均值；它不是实际的模拟高通输入模型。GND 耦合会显示零，但仪器负载仍保持连接。示波器的时间/电平控件有助于检查数据；它们不能将欠采样的运行结果变为有效的定时测量。

### 万用表
{: #multimeter}

测量电压或电阻时使用 **VΩ 和 COM**，测量电流时使用 **A 和 COM**。电流测量必须串联。默认电压输入阻抗为 **10 MΩ**；电流模式使用 **1 Ω 负载电阻**和零伏检测源。因此，更改模式会改变电路负载，并需要重新运行。

DC 显示相应的稳态/平均值。AC 使用去除 DC 分量后的按时间加权 RMS。超出量程的值显示为 **OL**。这些是建模的仪器行为，不包括保险丝或热失效仿真。

电阻测试是单独进行的临时无电测试。测试期间会抑制独立信号源，并断开仪器连接。支持的网络包括 R/C/L 和探针：电容在 DC 下视为开路，电感视为短路。主动器件或不受支持的模板会导致电阻测试不可用。不要将其理解为对任意带电电子设备进行的在电路电阻测量。

### 函数发生器
{: #function-generator}

函数发生器提供正弦波、脉冲/方波、三角波和 PWL 波形，并可设置幅度、偏置、频率和定时。其预览显示的是**开路**波形。默认的 **50 Ω 输出电阻**意味着连接负载可能会降低端子幅度。

Output Off 会以 **1 TΩ** 泄漏电阻近似开路端口。小信号 AC 幅度与瞬态幅度仍然相互独立。将设定波形与测量值比较前，请确认所需幅度是峰值、峰峰值还是 RMS。

### 台式电源
{: #bench-supply}

设置电压、电流限制、输出电阻、使能状态和可选的斜坡时间。该模型使用平滑的行为级限流和有限电阻；面板会显示测得的 V/I 和 **CV/CC** 工作状态。将电流限制设得低于负载需求会降低所供电压。

它可在相同限制范围内供电或吸收电流。这不是厂商的开关电源模型，也不是热模型。禁用输出时采用 1 TΩ 泄漏近似。斜坡会影响瞬态分析；DC 工作点使用最终设定电压。

函数发生器和电源的数值属性可绑定到 [Circuit Explorer](../Simulation-Charts-and-Measurements/)，以便临时调整或设置测试条件。Desktop 可将仪器面板弹出到单独窗口；两款产品均支持弹出图表。

## 负载也是实验的一部分
{: #loading-is-part-of-the-experiment}

理想电压探针与带负载的示波器输入不会得到相同的电路结果。比较结果前，应考虑函数发生器阻抗、万用表负载、示波器输入负载和共用回路。如果信号两端都不是地，请使用差分测量。如果添加仪器后运行失败，请先检查接线和模式，再更改求解器设置。
