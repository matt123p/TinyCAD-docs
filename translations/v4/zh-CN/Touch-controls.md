# 触摸控制
{: #touch-controls}

在触摸屏上，您可以直接编辑图纸，也可以使用放大镜进行更
精确的定位。这些控制方式适用于浏览器和桌面编辑器。

## 直接触控
{: #direct-touch}

- 点按可使用当前工具选择或放置对象。
- 单指拖动可移动对象或进行选择，与使用鼠标时相同。
- 手指静止按住约一秒钟，可打开图纸的上下文菜单。
- 两指并拢移动可平移图纸；将两指分开或合拢，可围绕手势位置缩放画布。
- 将库面板中的符号预览拖到图纸上即可放置符号。

## 使用放大镜精确定位
{: #precise-placement-with-the-loupe}

放大镜会放大瞄准十字准线周围的区域，因此手指不会
遮住您要触及的连接点。

1. 如有必要，点按图纸以显示 **显示放大镜（Show Loupe）**，然后点按
   图纸底部的该按钮。
2. 用一根手指在画布上滑动以瞄准十字准线。十字准线的移动速度比手指更慢，便于精细控制；抬起手指后，瞄准位置会保持不变。
3. 使用镜头下方带标签的控件：

   | 控件 | 操作 |
   |---|---|
   | **单击（Click）** | 在十字准线位置单击，以选择对象或使用当前工具放置点。 |
   | **拖动（Drag）** | 从十字准线位置开始拖动。在画布上滑动手指以移动指针。 |
   | **放下（Drop）** | 结束拖动。拖动过程中，此控件会替代 **拖动（Drag）**。 |
   | **菜单（Menu）** | 在十字准线位置打开上下文菜单。 |
   | **关闭（Close）** | 关闭放大镜并返回直接触控。 |

4. 点按 **隐藏放大镜（Hide Loupe）** 返回直接触控。

![触摸放大镜显示了放大的连接区域、十字准线以及“单击”“拖动”和“菜单”控件。](../images/touch-loupe.png)

例如，要绘制导线，请选择 **导线（Wire）**，瞄准起始引脚，然后点按
**单击（Click）**。滑动手指以瞄准下一个点，然后再次点按 **单击（Click）**。
如果要结束或取消操作，请使用 **菜单（Menu）** 打开工具的上下文命令。

打开放大镜时，也可以使用双指平移和捏合缩放。更改视图前，请先使用 **放下（Drop）** 结束当前拖动。
