# 触控操作
{: #touch-controls}

在触摸屏上，您可以直接编辑图纸，也可以使用放大镜进行更精确的放置。这些控件可在浏览器和桌面编辑器中使用。

## 直接触控
{: #direct-touch}

- 点按可使用当前工具选择或放置对象。
- 用一根手指拖动可移动对象或进行选择，操作方式与鼠标相同。
- 将手指按住约一秒，可打开图纸的上下文菜单。
- 两指并拢移动可平移图纸；两指分开或捏合，可围绕手势位置缩放画布。
- 将库面板中的符号预览拖到图纸上即可放置。

## 两次点按自动布线
{: #auto-route-wires-with-two-taps}
{: #auto-route-wires}

使用工具栏中的 **点对点布线（Point-to-Point Wire）**，即可连接两个引脚，或连接一个引脚与现有导线，而无需逐个放置拐角。点按起始连接点，然后点按目标位置。TinyCAD 会选择布线路径并放置导线段。使用鼠标时这项功能也很有用，但在触摸屏上尤其方便，因为它减少了需要精确放置的位置数量。

如果端点较小或周围较拥挤，请在每个端点处使用放大镜的 **单击（Click）** 控件，而不是直接点按引脚。完整步骤和示例请参见[自动布线](../Wires/#auto-routing)
。

## 使用放大镜精确放置
{: #precise-placement-with-the-loupe}
{: #precise-placement-with-the-loupe}

放大镜会放大瞄准十字线周围的区域，因此手指不会遮住您要定位的连接点。

1. 如有必要，点按图纸以显示 **显示放大镜（Show Loupe）**，然后点按图纸底部的该按钮。
2. 用一根手指在画布上滑动，将瞄准十字线对准目标。十字线移动速度比手指慢，便于精细控制；抬起手指后，瞄准位置会保持不变。
3. 使用镜头下方标注的控件：

   | 控件 | 操作 |
   |---|---|
   | **单击（Click）** | 在瞄准十字线处单击，使用当前工具选择对象或放置点。 |
   | **拖动（Drag）** | 从瞄准十字线处开始拖动。用一根手指在画布上滑动以移动指针。 |
   | **放下（Drop）** | 完成拖动。拖动过程中，该控件会替代 **拖动（Drag）**。 |
   | **菜单（Menu）** | 在瞄准十字线处打开上下文菜单。 |
   | **关闭（Close）** | 关闭放大镜并返回直接触控。 |

4. 点按 **隐藏放大镜（Hide Loupe）**，返回直接触控。

![触控放大镜显示放大的连接区域、瞄准十字线以及“单击”、“拖动”和“菜单”控件。](../images/touch-loupe.png)

例如，要绘制导线，请选择 **导线（Wire）**，将瞄准十字线对准起始引脚，然后点按 **单击（Click）**。滑动手指，将瞄准十字线对准下一个点，再次点按 **单击（Click）**。需要完成或取消操作时，使用 **菜单（Menu）** 查看该工具的上下文命令。

打开放大镜时，两指平移和捏合缩放也可正常使用。更改视图前，请先使用 **放下（Drop）** 完成当前拖动。
