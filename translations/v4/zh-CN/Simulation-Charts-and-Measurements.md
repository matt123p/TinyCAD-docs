# 图表、测量与 Circuit Explorer
{: #charts-measurements-and-circuit-explorer}

完成一次[仿真运行](../Simulation/)后，可使用图表查看波形，并使用命名测量记录可重复的量。Circuit Explorer 还提供临时调参、重复运行、要求和研究报告。

打开 **Simulation sheet → Setup**，然后滚动到 **Circuit Explorer**。需要时，使用 **Add tools** 添加 Measurements、Tune / sweep、Requirements、DC overlay 或 Analysis lab。已配置的工具会显示在左侧列表中。**Hide tool** 会隐藏其控件，但保留已保存的设置。图表仍位于单独的右侧面板中。

## 显示和排列图表
{: #show-and-arrange-charts}

在浏览器版和 Desktop 中，都可在工具栏选择 **Simulation → Show charts**。Desktop 还提供 **View → Show Charts**。拖动右侧 **Simulation charts** 面板的左边缘可调整其大小。选择一个设置和采集，然后使用 **Run** 或 **Stop**，无需离开原理图。

探针图表会自动添加。若没有探针，设置会获得一个输出图表。使用 **Add chart** 添加另一个探针或自定义视图，然后选择 **Choose signals**。图表标题可以编辑。多曲线绘图分析（例如噪声分析）带有结果图选择器。

单击图例条目可隐藏曲线。电压、电流和其他量使用标注的坐标轴；不要根据电压刻度读取电流。复数 AC 数据可显示实部/虚部、幅值、dB 或相位。以 dB 为单位的输出幅值不会自动成为传递增益，除非输入经过适当归一化。

使用滚轮/捏合手势缩放，拖动以平移，使用 **Shift-拖动**选择区域，使用 **Fit** 恢复视图。数值游标可检查采样位置。为确保概览响应流畅，大型结果会使用缩减后的显示数据；缩放时视图会细化。兼容的固定基线会以虚线叠加显示。

### 弹出与导出
{: #pop-out-and-export}

**Pop out chart** 可在任一产品中打开独立窗口。可以分离多个图表。关闭弹出窗口会将图表放回面板；停靠图表上的 × 会移除该图表。分离的图表共享当前结果数据，不会启动单独的仿真。

**Download CSV** 会导出所选信号及其刻度的所有保留采样，包括虚部。导出内容不受显示缩放或采样影响。主图表还提供 **PNG** 下载。随报告保留所选设置、采集和单位，以便其他读者了解数据所描述的实验。

## 尝试预设的 RC 研究
{: #try-the-prepared-rc-investigation}

下载 [RC low-pass.dzn](../examples/simulation/rc-low-pass.dzn)，通过 **File → Open** 打开，然后运行。此配套文件与随附的教程示例 **rc-ac** 分开。它包含预设的测量、要求和调参定义。

当 R1 = 1 kΩ、C = 1 µF 时，标称拐角频率约为 159.15 Hz。**Measurements** 包含截止频率、100 Hz 处的增益以及理想拐角频率处的相位；**Requirements** 检查截止频率是否在 150–170 Hz 范围内。

![RC 配套图纸中的 Circuit Explorer 调参控件](../Images/simulation/explorer-tuning.png)

## 调参而不更改已保存的电路
{: #tune-without-changing-the-saved-circuit}

在 **Tune / sweep** 中，选择一个元件和数值属性，然后选择 **Add tuning control**。选择原理图元件会在选择器中预先选中该元件。也可以绑定受支持的信号源/仪器设置和命名设置参数。任意文本、表达式和模型文件内容不能作为滑块目标。

控件支持单位、边界、线性/对数刻度以及 E12/E24/E96 优选值吸附。更改后约 500 ms 即会安排一次运行。临时值与已保存的元件值相互独立。

- **Undo tuning** 返回到前一个临时覆盖值。
- **Reset** 恢复原始值和采集设置。
- **Apply** 将覆盖值作为一次可撤销的编辑写入图纸。

只有当元件的 SPICE 模板实际使用某个数值属性时，该属性才会影响电路。不要假定更改未使用的属性会改变模型。

### 单变量扫描
{: #one-variable-sweeps}

展开 **One-variable sweep** 并选择一个控件。可使用 2–100 个线性/对数点，或输入 1–100 个显式值，值之间以空格或分号分隔。**Run sweep** 会针对每个值运行所选分析。**Cancel** 会停止安排更多用例，并保留已完成的结果。

RC 配套文件预设了 1 kΩ、2.2 kΩ、4.7 kΩ、6.8 kΩ 和 10 kΩ。其理想截止频率约为 159.15、72.34、33.86、23.41 和 15.92 Hz。可比较叠加曲线，或比较某个命名指标与参数值。这不同于 [DC 扫描分析](../Simulation-Analyses/#dc-sweep)，它会在 DC 分析中改变独立信号源。

扫描定义、数值、单位、运行状态和捕获的指标均保存在 `.dzn` 中。**Saved sweep** 可重新查看一组扫描。移除原始结果会删除波形叠加，但捕获的标量表和报告元数据仍可能保留。最多保留 100 组扫描，但仍受常规采集和数据限制约束。

## 定义命名测量
{: #define-named-measurements}

在 **Measurements** 中添加名称，选择信号/元件并展开其设置。设置有意义的时间/频率窗口以及任何必需的电平或参考值。元件/探针绑定使用图纸身份和参考标号，因此重新打开后仍可保持绑定。

![预设的截止频率、增益和相位测量](../Images/simulation/explorer-measurements.png)

| 测量 | 解释 |
| --- | --- |
| Value、minimum、maximum、peak-to-peak | 某位置处的信号值，或所选窗口内的极值 |
| Mean、RMS、ripple RMS | 按时间加权的瞬态量；ripple RMS 会去除均值 |
| Integral | 时间积分；对瓦特积分可得到焦耳 |
| Rise/fall time | 在指定低/高电平之间首次完整的 10–90% 跃迁时间 |
| Period、frequency、duty cycle、pulse width | 使用明确阈值或窗口中点电平测得的首个完整周期/脉冲 |
| Delay | 输出首次上升越过阈值的时间减去参考信号首次越过同一阈值的时间 |
| Overshoot/undershoot | 相对于指定初始/最终电平和阶跃幅度的偏离量 |
| Settling time | 从窗口起点开始测量，信号最后一次进入最终值容差带的时间 |
| Time constant | 从窗口起点开始测量，信号首次达到 initial + (final − initial) × (1 − 1/e) 的时间 |
| AC gain/phase | 所选频率处的复数输出/输入比值 |
| Cutoff/bandwidth | 相对于所选增益参考值的半功率交点，即 −3.0103 dB |
| Resonance | 内部幅值峰值中的最大值；边界处的最大值不算已解析出的谐振 |
| Additional response metrics | 通带纹波、阻带衰减、端口阻抗幅值和群延迟 |

瞬态积分会考虑不等时间步长和插值后的窗口端点。RMS 包含 DC 分量；ripple RMS 会将其去除。若输出越过阈值的时间早于参考信号，延迟可以为负值。时序指标要求窗口内包含足够的相关跃迁或周期。

为阶跃指标指定初始/最终电平。最终电平错误会导致稳定时间和过冲结果产生误导。最终采样尚未稳定、缺少越限点、绑定不明确、单位不匹配或窗口无效时，结果会显示为 **unavailable**，而不会伪造一个零值。

对于截止频率，请使用明确的线性参考增益或 **peak**。对于简单 RC 滤波器，单位增益参考值适用；但增益为 20 的放大器需要不同的参考值。带宽需要两个有效交点；频率采用对数插值。扫描边缘处的任意峰值不能证明存在谐振。

## 要求和 DC 叠加
{: #requirements-and-dc-overlays}

使用 **Requirements** 将命名测量与 **at least**、**at most** 或包含端点的 **between** 范围进行比较。单位必须匹配。结果为 **pass**、**fail** 或 **unavailable**；不可用的指标不能算作满足要求。

![带有明确可接受范围的 RC 截止频率要求](../Images/simulation/explorer-requirements.png)

选择一个可用的测量以检查其依据和适用的原理图高亮显示。导出结果时保留测量定义、窗口和阈值。并非所有类型的信号或模型都支持完整的双向探针高亮显示。

DC 原理图叠加需要一次最新且已完成的工作点采集。电压以 0 为参考；电流方向遵循已配置的端子顺序。消耗功率为正，因此供电的信号源可能具有负功率。理想电阻的电流可由 V/R 推导；不支持的器件电流会被省略，而不会凭空生成。

## Analysis lab
{: #analysis-lab}

![Circuit Explorer 中的 Analysis lab 工作流](../Images/simulation/analysis-lab.png)

### 频率响应与放大器响应
{: #frequency-and-amplifier-response}

选择输入/输出、频率范围和读数频率。运行 AC 分析以检查增益、相位、截止频率、带宽、谐振、带通 Q 和群延迟。带通 Q 表示 `f₀ / half-power bandwidth`。传递函数计算使用明确命名的激励信号。端口阻抗需要有明确配置的电压/电流测试；任意节点比值不是环路增益测量。

### 容差与极限情况
{: #tolerance-and-corners}

蒙特卡洛研究会根据已配置的元件分布重复运行：有界的 ± 容差均匀分布，或以标准差指定的无界正态分布。设置一个无符号随机种子和 2–100 个用例。重复使用同一种子和设置可使抽样具有可重复性。完全正相关的组共享一个标准化抽样值，并且必须使用同一种分布类型。

抽样得到的电阻、电容、电感或频率物理值若不为正数，则属于失败用例。请检查这些失败，而不要悄然将其排除。均值、样本标准差和直方图描述的是抽样结果，而不是所有可能制造出的元件。

极限情况搜索最多枚举六个独立变量，即最多 64 个角点。该搜索会忽略蒙特卡洛相关组。报告的最差观测结果不能证明角点之间的全局最差情况。良率仅在所输入模型/分布假设下具有参考意义；若研究中没有可评估的要求，则不会估算良率。

### 测试用例
{: #test-cases}

将分析、参数、迹线/测量/要求定义及绑定捕获为一个用例。为不同用例设置不同的温度或参数、激励和负载覆盖值，然后运行测试套件。各用例共用**当前原理图和模型**；它们不是相互独立的历史电路版本。每次运行都会记录其输入身份。

JSON 报告包含条件、结果和研究历史。研究按顺序运行，并可取消；失败或未收敛的用例仍会显示。定义、种子、用例条件和组引用会保存在 `.dzn` 中。最近的 100 组研究会在常规结果限制内保留。

### 功率、效率与应力
{: #power-efficiency-and-stress}

选择受支持的元件功率信号，并明确设置电压、电流或功率峰值的限制。Mean/RMS/Integral 测量可提供平均功率、电流 RMS 和能量。效率计算需要正确确定符号的供电输入边界和消耗有用功率的负载边界。器件电流不受支持或存在歧义时，结果将不可用。

小信号 AC 不是大信号应力测试。在 TinyCAD 中输入数值限制不会添加封装热模型、脉冲额定值或保护机制。请使用适合所研究问题的瞬态条件和模型，并在报告中保留相关假设。

## 当前限制
{: #current-limits}

已实现的工作流不包括 FFT/谐波失真分析、自动故障注入、不受限制的多维扫描、自动优化或协同式 Live/Pause。查看结果时，请依据已完成/已停止/已失败的运行状态以及实际数据可用性。若某项指标或采集不可用，请参阅[故障排除](../Simulation-Troubleshooting/)。
