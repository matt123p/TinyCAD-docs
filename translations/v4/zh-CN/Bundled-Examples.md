# 内置示例
{: #bundled-examples}

内置示例是随 TinyCAD 提供的可编辑图纸。它们展示如何使用元件库、说明连接选择，并为[仿真教程](../Simulation-Tutorials/)提供电路。无需单独下载这些示例的符号。

## 打开示例
{: #open-an-example}

<div class="manual-tabset" data-tabset="product-mode" data-tabset-label="Choose your TinyCAD product" data-default-tab="Browser" markdown="1">

### 浏览器
{: #browser}

在深色标题栏右侧选择 **打开示例（Open Example）**。打开带有说明的示例后，旁边会出现 **说明（Explanation）**。使用该按钮显示或隐藏说明面板。

### 桌面应用
{: #desktop-app}

选择 **文件（File）→ 打开示例（Open Example）**，该选项位于 **打开最近使用的文件（Open Recent）** 下方。使用 **视图（View）→ 查看说明（View Explanation）** 显示或隐藏当前示例的说明。图纸没有关联说明时，此命令不可用。

</div>

1. 选择一个分组：**示例**、**SPICE 教程**或**XSPICE 和数字电路教程**。
2. 选择一幅图纸以查看其预览和说明。此选择尚不会替换当前图纸。
3. 选择**打开图纸**。如果有未保存的更改，请先响应保存提示，然后再继续。
4. 阅读说明，检查连接并修改可编辑副本。使用**另存为**保留您的版本。

使用 **搜索分组和示例（Search groups and examples）** 查找指定项目。清除搜索内容并选择 **所有分组（All groups）**，以显示被筛选隐藏的分组。

## 设备与布局示例
{: #equipment-and-layout-examples}

选择 **示例（Examples）** 分组，查看以下七张图纸。

| 图纸 | 展示内容 | 可尝试的操作 |
| --- | --- | --- |
| **晶体管放大器** | 原始 AMP.dsn 晶体管放大器原理图 | 沿着偏置和信号路径进行查看。若要使用经过建模且可运行的重建版本，请参阅 [SPICE 教程第 7 章](../SPICE-Tutorial-07/)。 |
| **小型办公室网络** | 机架中的路由器、PoE 交换机、配线架和空白面板，以及 ISP 终端、接入点和桌面交换机 | 跟踪机架上联和办公室布线；添加另一个匹配的 1U 面板。 |
| **ESP32 环境与显示站** | 控制器、传感器和显示模块的连接 | 按标注检查电源和信号引脚，然后改用所选模块。 |
| **家庭太阳能与电池规划** | A3 页面上的太阳能发电、储能和家庭能源设备 | 分别跟踪电力路径和监测/控制连接。 |
| **双人播客录音室** | 麦克风、调音台/音频接口、录音电脑和监听设备 | 跟踪麦克风输入、录音输出和耳机馈送。 |
| **直流负载与波形测试台** | 实体电源、负载、波形发生器、示波器和仪表连接 | 区分完整的仪器电缆与单根导线。 |
| **直流电机与限位控制测试台** | 电机驱动器、减速电机、控制连接和限位开关 | 分别跟踪电机电源与 PWM/方向信号和限位信号。 |

六种设备布局都附有关于连接、假设和可能扩展的说明。它们是实体/系统图纸，不包含 SPICE 模型。原始放大器也是一张图纸示例；打开它并不会自动将其转换为可运行的仿真。

开路插座可能是有意设置的。与其他端点或插座接触的导线会形成实际连接，因此改用布局时请仔细检查。嵌入的图形和引脚使这些示例便于移植，但不能代替实际设备的接线文档。

## 仿真示例
{: #simulation-examples}

### SPICE 教程
{: #spice-tutorial}

本组沿着[十一章 SPICE 课程](../SPICE-Tutorial/)展开。课程从一个分压器开始，随后介绍信号源、RC 充电、交流滤波器、二极管整流、重建的晶体管放大器以及设计探究。**从这里开始 — 使用教程**条目会打开第一个分压器，并说明工作流程。

图纸中嵌入了符号、模型文本、分析设置和保留的参考结果。因此，**首次运行之前**就可能已经显示波形。选择 **运行（Run）**，根据当前电路和设置进行新的采集。按照章节中的预期值操作，并尝试建议的更改，观察结果变化的原因。

### XSPICE 和数字电路教程
{: #xspice-and-digital-tutorial}

此分组请使用 **TinyCAD Desktop**。[六章 XSPICE 课程](../XSPICE-Tutorial/)涵盖逻辑真值表、传播延迟、冒险、触发器、计数器、模拟/数字桥接和未知状态。浏览器版本不支持 XSPICE。浏览器仍可打开包含已保存 XSPICE 结果的图纸以供查看。

两个教程分组中共有 28 张不同的仿真图纸。额外的“从这里开始”条目指向 SPICE 第一章使用的同一个分压器。每节课程都提供可下载的 `.dzn` 图纸及配套的 `.cir` 网表，作为打开内置副本的替代方式。在 TinyCAD 中打开 `.dzn` 文件；`.cir` 文件是文本，可供检查或与兼容的外部仿真器配合使用。

## 保存你的实验
{: #keep-your-experiments}

编辑已打开的副本不会更改内置原件。重新打开同一个内置示例即可获得一个全新的起点。将自己的图纸另存为新名称以保留更改；如需保留数值证据，请保存仿真结果。

**说明**面板和**仿真图表**彼此独立。关闭其中一个无需关闭另一个。在 Desktop 中，可通过**视图 → 显示图表**访问图表；在两款产品中，均可使用工具栏上的**仿真 → 显示图表**。

分发已保存的图纸时，请附上读者需要的任何单独说明。内置说明与打开示例的操作相关联；请勿依赖它在单独打开已保存的副本后仍会显示。图纸自身嵌入的文本注释仍是文件的一部分。
