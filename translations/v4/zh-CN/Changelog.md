# TinyCAD 更新日志
{: #tinycad-changelog}


## 即将发布
{: #unreleased}
{: #unreleased}

### 新增
{: #added}

- [集成仿真](../Simulation/)，使用浏览器和桌面版中的本地 ngspice，支持工作点、瞬态、交流、直流扫描、噪声、传递函数和极零分析。[事件驱动 XSPICE](../XSPICE/) 在桌面版中受支持。
- [信号源、探针和虚拟仪器](../Simulation-Sources-and-Instruments/)，包括示波器、万用表、函数发生器和台式电源。
- [电路浏览器](../Simulation-Charts-and-Measurements/)，用于调节参数、扫描、命名测量、要求、直流叠加图、公差研究、测试用例以及功率/应力分析。
- [压缩的 `.dzn` 电路图](../Simulation/#dzn-simulation-drawings)，将电路、模型、仿真设置和可选结果集中保存。运行历史记录和结果导出功能便于比较和共享；不保存结果即可创建更小的副本。
- [内置库](../Bundled-Libraries/)，涵盖网络布局、嵌入式开发板和智能家居模块、音频、实验室设备、电机/运动以及太阳能/电池规划，并提供模型化 SPICE、逻辑、功能和传感器集合。可在库选择器的 Standard 选项卡中选择这些库。
- [七个可编辑的电路图示例](../Bundled-Examples/)，涵盖原始晶体管放大器、办公室网络、ESP32 气候/显示站、太阳能/电池住宅、播客工作室、实验室工作台和电机控制工作台，并附有嵌入式符号和说明。
- [SPICE 和 XSPICE 教程](../Simulation-Tutorials/)：包含 11 个模拟章节和 6 个数字章节，共有 28 个不同的可运行电路图、模型定义、分析设置和保留的参考采集数据。
- [布局整理](../Layout-Tidy-Up/)，可用于整张图纸或所选项目，提供低/中/高强度选项、取消操作、连接检查和一步撤销。

### 更改
{: #changed}

- “打开示例”和“说明”位于浏览器标题栏中。桌面版提供“文件”→“打开示例”和“视图”→“查看说明”。
- 桌面版的“视图”菜单包含“显示图表”；工具栏的“仿真”菜单保留了图表切换项。
- “自动布局”位于工具栏的“仿真”旁边，也可从桌面版的“工具”菜单中使用。

### 修复
{: #fixed}

- 恢复“标准”、“我的库”和“在线”选择器结果中可拖动的元件图稿预览。
- 将嵌入式控制器、传感器和显示器图稿缩小到适合页面布局的尺寸，同时保留引脚标识和接线位置。
- 防止布局更改在导线端点、弯折处或插座处产生意外连接；改进引脚引出方式并移除不必要的绕行。
- 移除与实验室和运动控制符号中文字重叠的小型端子标签框，并更新受影响的示例。
- 改进仿真错误报告和诊断、浏览器中的放大器运行、图表弹出窗口以及独立的示例说明面板。

### 手册
{: #manual}

- 添加查找和使用内置库及示例的指南，并以集成仿真工作流程取代仅介绍导出的 SPICE 说明。
- 添加分析、模型、仪器、图表、测量和故障排除参考，并附上 ngspice 和 XSPICE 官方文档链接。
- 收录完整的现有课程、可下载的图纸/网表以及十个视频讲解，内容涵盖库、示例、布局整理、多页连接和 SPICE。
- 澄清[功能差异](../Feature-Differences/)，包括 `.dzn` 和 Markdown 文本框兼容性，以及浏览器版对 XSPICE 的支持。
- 更新全部八种受支持语言的手册，包括导航、新参考页面、教程文本和视频字幕。

## v4.0.11
{: #v4011}
{: #v4011}

此版本新增格式化 Markdown 备注、矢量 SVG 输出和导线路由控制。

- [Markdown 文本框](../Text/#markdown-text-boxes)：支持列表、任务列表和代码块的格式化备注；图纸、SVG 导出和 PDF 使用相同的矢量渲染器。
- 实时源文本格式化会显示可编辑标记，并遵循所选的基础字体，同时保持光标位置、选区和换行一致。
- [导线路由模式](../Wires/#wire-routing-modes)：提供 90°、45° 和自由路由的紧凑选择器，并保留当前预览。
- 只有在触摸绘图画布后才会显示放大镜按钮。

## v4.0.9 — 2026 年 11 月 4 日
{: #v409--4-november-2026}

### 新增
{: #added-1}

- [触控操作](../Touch-controls/)，包括直接编辑、双指平移
  和捏合缩放，以及带有“单击”、“拖放”、“菜单”和“关闭”
  控件的放大镜，便于精确放置。
- [可调整大小的库面板和符号排序](../Using-Symbol-Libraries/)，
  包括搜索结果的字母顺序排列。
- [临时隐藏所选对象](../User-guide/#temporarily-hiding-objects)，
  并提供在当前图纸上恢复所有隐藏对象的命令。
- 波兰语界面翻译，以及“替换符号”对话框中的翻译文本。

### 修复
{: #fixed-1}

- [网格可见性和吸附](../Snap-to-Grid/)可独立工作，
  键盘移动也会遵循已禁用的吸附设置。
- 放置的库符号可正确渲染位图图像。
- [Escape 可取消绘图和放置操作](../Shortcuts/)，即使
  工具栏控件处于焦点时也有效。
- 取消桌面版的未保存更改提示时，会清除待处理的退出操作。
- 画布捏合缩放不再与浏览器页面缩放叠加。
- 改进触控放大镜的位置、指针反馈、手势处理和拖动。
- 改进桌面版和 macOS“关于”对话框的行为。

### 打包和维护
{: #packaging-and-maintenance}

- 更新依赖项以修复安全漏洞。
- 移除 Linux ARMv7 软件包，因为 Electron 运行时支持 Linux x64 和
  ARM64。Snap 软件包面向 x64；Debian 软件包面向 x64 和 ARM64。

## v4.0.6 — 2026 年 3 月 29 日
{: #v406--29-march-2026}

此版本包含以 4.0.5 版本号进行的开发更改；没有单独的 4.0.5 标签或已发布的 GitHub 版本。

### 新增
{: #added-2}

- 自动导线路由。
- “替换符号”，可将现有元件更改为另一个库符号。
- 拖动对象靠近绘图边缘时自动滚动。
- 双击可选择整条导线，三击可选择跨越节点和 T 形接头的部分。
- 可关闭标签连接指示器的选项。

### 修复和改进
{: #fixed-and-improved}

- 默认打开库文件夹，搜索时自动展开。
- 改进绘图处于焦点时的文本编辑、剪贴板快捷键、导航键和键盘快捷键。
- 修复 Ctrl-单击选择、拖动多个选定对象以及微调控件。
- 可双向拖动绘图和选择矩形。
- 修复 macOS 上的退出问题，并减少 macOS 上重复加载库的情况。
- 修复标签位置、颜色选择器翻译和网表后台处理。
- 更正 Windows 安装程序和 AppX 构建名称。
