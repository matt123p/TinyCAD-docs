# TinyCAD 手册
{: #tinycad-manual}

TinyCAD v4 既可作为桌面应用程序使用，也可作为基于浏览器的在线应用程序使用。两个版本的功能差异
很少。

如果您想了解 TinyCAD 各版本之间的具体差异，请访问[功能差异](Feature-Differences/) 页面。

## 警告
{: #warning}

**TinyCAD** 是一个开源、由社区驱动的项目，以免费方式编写并提供。软件按“原样”提供，可能存在错误或功能不完整的情况。  

您有责任备份自己的工作并防止数据丢失。在构建电路或打印 PCB 之前，您有责任仔细检查。
