# 快捷键
{: #shortcuts}

使用键盘快捷键代替单击工具栏，可以加快绘图速度。

 **注意：** 这些快捷键与 TinyCAD v3 的快捷键不同，因为浏览器应用程序
无法以相同方式使用 F 键。

| 按键 | 操作 |
|---|---|
| `Esc` | 取消当前放置或绘图操作；否则清除选区 |
| `W` | 导线工具 |
| `N` | 无连接 |
| `P` | 电源 |
| `L` | 标签 |
| `T` | 文本 |
| `B` | 总线 |
| `S` | 图形（矩形/椭圆/直线） |
| `+` | 放大 |
| `=` | 放大 |
| `-` | 缩小 |
| `_` | 缩小 |
| Arrow Keys | 启用吸附时，按网格间距移动选中的项目；禁用时，按小步幅移动；未选中任何项目时平移视图 |
| `Ctrl` + Arrow Keys | 按小步幅移动选中的项目，或按更小步幅平移视图 |
| `Ctrl-F` | 查找 |
| `Ctrl-P` | 打印 |
| `Ctrl-C` | 复制 |
| `Ctrl-X` | 剪切 |
| `Ctrl-V` | 粘贴 |
| `Del` | 删除 |
| `Ctrl-Z` | 撤销 |
| `Ctrl-Y` | 重做 |

工具栏按钮获得焦点时，Escape 也会取消创建操作。在文本字段中输入内容，或使用菜单或对话框时，请先完成操作或关闭该控件。

某些快捷键可能会被浏览器拦截，从而触发浏览器操作。
