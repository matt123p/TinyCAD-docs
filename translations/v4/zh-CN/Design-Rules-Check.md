# 设计规则检查
{: #design-rules-check}

在 v4 中，**设计规则检查的工作方式与 v3 相同**。

在生成网表或 VHDL 等输出文件之前，使用设计规则检查来查找原理图中
明显的连接问题。

它会检查连线和引脚类型组合是否存在常见电气错误（例如，将相互冲突的输出端连接在一起）。它**不能**保证电路在功能上正确。

尽量将设计错误降至零，以提高对原理图正确性的信心。

## 运行设计规则检查
{: #run-design-rules-check}

1. 打开设计。
2. 从“特殊工具”菜单中运行 **检查设计规则 (Check Design Rules)**。
3. 在规则对话框中，启用或禁用所需的规则检查。
4. 选择 **确定** 以运行检查。

## 查看结果
{: #reading-the-results}

- 每个检测到的错误都会在原理图上用红色圆圈标记。
- 设计旁边会显示错误列表。
- 在列表中选择某个错误，会使绘图区域居中显示该位置。

## 清除并重新检查
{: #clear-and-re-check}

- 在错误列表中选择 **关闭**，以移除所有当前错误标记。
- 错误圆圈是临时的审查标记：它们不会随设计一起保存。
