# 仿真故障排除
{: #simulation-troubleshooting}

更改设置前，请先阅读采集状态和诊断输出。区分**运行失败**、**运行有效但行为异常**以及**所选结果中没有可用的测量值**。这三种情况需要进行不同的检查。

## 仿真无法启动
{: #the-simulation-will-not-start}

| 症状 | 检查项 |
| --- | --- |
| 缺少接地 / 电路浮空 | 连接电源符号，或连接值为 **0** 的标签。单独的 GND 标签不会自动成为节点 0。检查电源回路和隔离子电路。 |
| 缺少元件模型 | 使用带模型的库元件，或提供模板和模型。设备图片不是仿真模型。 |
| 缺少属性或引脚映射无效 | 检查元件的 SPICE 属性和模型实际端子顺序。实例覆盖设置可能会更改默认值。 |
| 未找到模型/包含文件 | 将模型文本及其依赖项附加到 Simulation 图纸，并使用匹配的逻辑文件名。不会自动获取本地绝对路径或 Web URL。 |
| 元件中含有分析指令 | 从元件属性中删除旧版 `.op`、`.tran`、`.ac`、`.end` 和运行控制文本。集成的 Simulation 图纸负责管理分析设置。 |
| 浏览器中无法使用 XSPICE 模型 | 在 Desktop 中打开图纸并重新运行原生仿真。仍可在浏览器中查看已保存的结果。 |
| 源或范围无效 | 检查波形字段、递增的 PWL 时间、起始/停止值、扫描方向以及正的频率/时间量。 |

## 结果有误或求解器不收敛
{: #a-result-is-wrong-or-the-solver-does-not-converge}

**首先检查电路。** 导线越过端点，或未使用的插座，都可能造成意外连接。检查 T 形交点、实际引脚端点、网络标签和隐藏电源。将电流探针或电表并联在电源两端可能会造成短路。使用生成的网表确认仿真器接收到的电路内容。

检查模型的方向和引脚顺序：二极管极性、BJT 集电极/基极/发射极、运算放大器电源引脚以及子电路引脚顺序。使用有意义且唯一的参考标号，并确认扫描/噪声/传递函数设置中的源参考标号指向预期的电源。

先使用工作点分析验证直流偏置，再调查交流问题。理想电源回路、浮空节点、突变的理想跃迁以及不合理的模型参数，都可能导致电路难以或无法求解。如果真实实验确实存在相应特性，可添加有物理依据的电阻或有限的边沿时间。在更改数值选项之前，先将复杂电路缩减到最小的故障部分。

检查数值后缀：**在 SPICE 文本中，1M 表示 1 毫单位，而不是 1 兆单位**；兆请使用 `1Meg`。分别检查温度、电源直流值以及瞬态/交流设置。电源的瞬态振幅不会自动成为其小信号交流振幅。

## 波形显示不完整
{: #the-waveform-looks-incomplete}

- 如果启动过程尚未稳定，或所需周期超出运行范围，请增加瞬态持续时间。
- 若要解析快速边沿或窄脉冲，请减小最大步长。显示缩放无法还原缺失的采样点。
- 检查所选设置、采集、结果图、图例可见性、单位和坐标轴范围。
- 对于交流分析，请在窄带谐振附近使用足够多的点，并确认输入/输出比正确。
- 如果运行已停止或失败，请检查实际数据是否可用；部分轨迹不代表实验已完成。

## 图表或探针读数已过时
{: #charts-or-probe-readings-are-stale}

编辑接线、数值、模型文本或设置后，需要再次**运行 (Run)**。已保存的采集数据反映的是其原始输入。选择历史记录不会还原图纸。教程文件可能会在打开时显示保留的参考结果，即使你尚未亲自运行仿真。

如果面板被隐藏，请使用 **Simulation → Show charts**，或 Desktop 中的 **View → Show Charts**。移除自动探针图表后，它会保持移除状态，直到你明确将其重新添加。关闭弹出的图表后，它会返回面板。

## 测量值不可用
{: #a-measurement-is-unavailable}

检查其信号绑定、单位、窗口、阈值以及明确指定的初始/最终电平。计时测量需要完整的交越/周期。稳定时间测量必须在声明的最终带内结束。截止频率需要所请求的交越点和增益参考；带宽需要两个交越点。如果谐振出现在扫描边界上，则无法确定其位置。不会猜测不受支持的器件电流/功率向量。

要求不可用并不代表通过。使用研究报告导出条件和失败状态，并确保容差分析中不收敛的情况仍然可见。如果某项研究没有可评估的要求，则无法估算良率。

## 保存并重现调查
{: #saving-and-reproducing-an-investigation}

将图纸、模型附件、分析设置、电源设置、温度和相关采集数据一起保存。如果保存时未包含数值结果，或为了减小文件大小而将其移除，请重新运行以恢复图表。保留的标量/报告快照无法重建缺失的波形数组。

可重现的报告应说明模型假设、引擎、测量窗口和条件。在排查仿真器语言问题时，请与[教程的预期值](../Simulation-Tutorials/)以及官方的 [ngspice 手册](https://ngspice.sourceforge.io/docs.html)进行比较。
