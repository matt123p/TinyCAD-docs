# 仿真故障排除
{: #simulation-troubleshooting}

更改设置前，请先查看采集状态和诊断输出。区分**运行失败**、**运行有效但行为异常**以及**所选结果中无法获取的测量值**。这三种情况需要进行不同的检查。

## 仿真无法启动
{: #the-simulation-will-not-start}

| 症状 | 检查项 |
| --- | --- |
| 缺少接地 / 电路浮空 | 连接电源符号，或将值为 **0** 的标签连接到电路。单独的 GND 标签不会自动成为节点 0。检查电源回路和隔离的子电路。 |
| 缺少元件模型 | 选择符号并检查 **SPICE**。使用带模型的库元件，或[附加捆绑定义或自定义定义](../Bundled-SPICE-Models/)。 |
| 没有匹配搜索条件的模型 | 清除搜索条件，或尝试使用元件别名或器件系列搜索。SPICE essentials 符号只显示经过验证的模型。 |
| 缺少属性或引脚映射无效 | 检查元件的 SPICE 属性以及模型端子的实际顺序。实例覆盖项可能会更改默认值。 |
| 未找到模型/包含文件 | 将模型文本及其依赖项附加到 Simulation 图纸，并使用匹配的逻辑文件名。不会自动获取本地绝对路径或 Web URL。 |
| 元件中包含分析指令 | 从元件属性中删除旧版 `.op`、`.tran`、`.ac`、`.end` 和运行控制文本。分析设置由集成的 Simulation 图纸管理。 |
| 浏览器中无法使用 XSPICE 模型 | 在桌面版中打开图纸，以重新执行原生仿真。在浏览器中仍可查看已保存的结果。 |
| 源或范围无效 | 检查波形字段、递增的 PWL 时间、起始/停止值、扫描方向以及正的频率/时间量。 |

## 结果错误或求解器不收敛
{: #a-result-is-wrong-or-the-solver-does-not-converge}

**先检查电路。** 导线越过端点或未使用的插座都可能导致意外连接。检查 T 形接点、实际引脚尖端、网络标签和隐藏电源。将电流探针或电表跨接在电源两端可能造成短路。使用生成的网表确认仿真器实际接收到的电路。

检查模型的方向和端子顺序：二极管极性、BJT 集电极/基极/发射极、运放电源引脚以及子电路引脚顺序。使用有意义且唯一的元件参考标号，并确认扫描/噪声/传递分析设置中的源参考指向预期的电源。

在研究 AC 之前，先使用工作点分析验证 DC 偏置。理想电源回路、浮空节点、突变的理想转换以及不合理的模型参数，都可能使电路难以求解甚至无法求解。如果这些情况符合实际实验，应添加有物理依据的电阻或有限边沿时间。调整数值选项之前，先将复杂电路缩减为导致故障的最小部分。

检查数值后缀：**SPICE 文本中的 1M 表示 1 毫单位，而不是一兆单位**；兆应使用 `1Meg`。分别检查温度、电源 DC 值以及瞬态/AC 设置。电源的瞬态幅度不会自动成为其小信号 AC 幅度。

## 波形显示不完整
{: #the-waveform-looks-incomplete}

- 如果启动过程尚未稳定，或所需周期不在运行范围内，请延长瞬态分析时间。
- 若要解析快速边沿或窄脉冲，请减小最大步长。显示缩放无法恢复缺失的采样点。
- 检查所选设置、采集、结果图、图例可见性、单位和坐标轴范围。
- 对于 AC 分析，应在窄共振附近使用足够多的点，并确认输入/输出比正确。
- 如果运行已停止或失败，请检查实际数据是否可用；部分波形不代表实验已完成。

## 图表或探针读数已过期
{: #charts-or-probe-readings-are-stale}

编辑导线、数值、模型文本或设置后，需要再次单击 **运行（Run）**。已保存的采集记录描述的是其原始输入。选择历史记录不会还原图纸。捆绑的教程在你自行运行之前，可能会打开一份保留的参考结果。

如果面板已隐藏，请使用 **Simulation → 显示图表（Show charts）**，或桌面版的 **View → 显示图表（Show Charts）**。移除自动探针图表后，该图表会保持移除状态，直到你明确将其重新添加。关闭弹出图表后，它会返回面板。

## 无法获取测量值
{: #a-measurement-is-unavailable}

检查其信号绑定、单位、窗口、阈值以及明确指定的初始/最终电平。计时测量需要完整的过零点/周期。稳定时间测量必须在声明的最终带宽范围内结束。截止测量需要所请求的交点和增益参考；带宽测量需要两个交点。若共振位于扫描边界，则无法确定其位置。不会猜测不受支持的器件电流/功率向量。

无法获取的要求不代表通过。使用研究报告导出条件和失败状态，并确保未收敛的容差案例仍然可见。如果一项研究没有可评估的要求，就无法估算其良率。

## 保存和重现调查
{: #saving-and-reproducing-an-investigation}

将图纸、模型附件、分析设置、电源设置、温度和相关采集一并保存。如果保存时未包含数值结果，或为减小文件大小而移除了结果，请重新运行以恢复图表。保留的标量/报告快照无法重建缺失的波形数组。

可重现的报告应说明其模型假设、引擎、测量窗口和条件。排查仿真器语言问题时，请与[教程中的预期值](../Simulation-Tutorials/)以及官方的 [ngspice 手册](https://ngspice.sourceforge.io/docs.html)进行比较。
