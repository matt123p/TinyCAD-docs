# 语言翻译
{: #language-translation}

TinyCAD 可以在多种界面语言之间切换。

## 可用语言
{: #available-languages}

当前提供以下语言选项：

| 代码 | 语言 |
|---|---|
| `en` | 英语 |
| `nl` | 荷兰语 |
| `fr` | 法语 |
| `es` | 西班牙语 |
| `de` | 德语 |
| `it` | 意大利语 |
| `ja` | 日语 |
| `pl` | 波兰语 |
| `zh-CN` | 中文（简体） |

## 翻译质量与反馈
{: #translation-quality-and-feedback}

这些翻译由 AI 维护。

如果您发现措辞不自然、技术术语有误或存在未翻译的文本，
欢迎提供反馈。也欢迎提出新增翻译语言的建议。
