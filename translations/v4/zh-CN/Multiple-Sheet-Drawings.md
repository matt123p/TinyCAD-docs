# 多页原理图
{: #multiple-sheet-drawings}

TinyCAD 图纸可以在**一个文件**中包含多个原理图页。每个页都有自己的绘图区，画布下方有一个选项卡。使用选项卡一次处理一个页；所有原理图页共同描述一个电路。

## 为什么使用多个页？
{: #why-use-multiple-sheets}

多个页可以让你将设计整理为易于理解的部分，而不必把所有内容缩小到拥挤的一页上。例如：

| 页 | 可能包含的内容 |
| --- | --- |
| **电源** | 输入连接器、保护电路、稳压器和电源轨 |
| **控制** | 处理器、时钟、复位和编程连接 |
| **传感器** | 测量输入及其接口电路 |
| **输出** | 驱动器、继电器、电机、显示屏或外部连接器 |

这样可以让每个部分更易于绘制、审阅，并以清晰易读的尺寸打印。你可以将相关元件放在一起，为每页明确指定用途，并按便于阅读的顺序排列页面。对于小型设计，单页可能仍然更清晰。

一个页属于当前图纸，而不是单独的文件或浏览器选项卡。打开两个互不相关的图纸文件并不会将它们连接起来，即使它们包含相同的标签也是如此。

## 创建和切换页
{: #create-and-switch-sheets}

1. 打开图纸，找到画布下方的页选项卡。
2. 选择选项卡旁边的 **+**。其工具提示为**添加新页**。
3. 输入**页名称**，例如 `Control`，然后选择**添加**。
4. 新页将成为当前页。在其中放置元件和导线，或使用剪切和粘贴将所选项目从其他页移过来。
5. 选择任意页的选项卡即可切换回该页。切换页面不会丢弃其内容。

请使用各不相同且描述性明确的名称，以便阅读原理图的人能够找到所需部分。

## 重命名页
{: #rename-a-sheet}

1. 选择该页的选项卡。
2. 打开其名称旁边的小箭头菜单。
3. 选择**重命名**，输入新的**页名称**，然后在对话框中选择**重命名**。

重命名会更改页名称，但不会重命名元件标号或网络标签，也不会更改电气连接。

## 更改页的顺序
{: #change-the-sheet-order}

将一个页选项卡拖到另一个选项卡上，即可将其移动到该位置。你也可以选择一个选项卡，打开其箭头菜单，然后选择**左移**或**右移**，每次移动一个位置。

重新排序会更改页面顺序，不会更改元件或电路连接。可以利用此功能将电源部分放在最前面、将相关功能分组，或将辅助页面放在主电路之后。要重新排序页面，请拖动**选项卡**；拖动元件会移动该元件。

## 在页面之间建立连接
{: #make-connections-between-sheets}

导线无法在物理上延伸到另一页。相反，请在需要连接的点使用**名称相同且具有电气连接作用的标签**。TinyCAD 会将图纸中所有原理图页上的这些点视为同一个网络。

例如，Power 页上标记为 `+3V3` 的稳压器输出，可以为 Control 页上标记为 `+3V3` 的处理器输入供电。标记为 `RESET` 的信号可以将一个页上的复位电路连接到另一页上的处理器。标签必须连接到预期的导线或引脚上。

### 放置共用网络标签
{: #place-a-shared-net-label}

1. 在第一页上，像平常一样绘制连接到元件引脚的局部导线。
2. 选择**标签**工具，并将其电气连接点放在该导线或引脚上。仅在附近绘制文本是不够的。
3. 将标签文本编辑为清晰的名称，例如 `RESET` 或 `I2C_SDA`。选择标签文本即可编辑；请替换默认的 `Label` 文本。
4. 切换到另一页，在应该接入同一网络的导线或引脚上放置另一个标签。
5. 输入**完全相同的名称**，包括拼写、空格和大小写。
6. 在需要该电气网络的其他页面上重复此操作。

请使用[标签工具](../Labels/)，而不是[文本工具](../Text/)。写着 RESET 的注释只是说明图纸；写着 RESET 的标签则会建立电气连接。

### 示例：跨两个页的分压器
{: #worked-example-a-divider-on-two-sheets}

将普通的 5 V 分压器拆分为电源部分和负载部分：

| 页 | 元件 | 共用连接 |
| --- | --- | --- |
| **Power** | V1 = 5 V，R1 = 1 kΩ | R1 的输出导线标记为 **OUT**；V1 的回路连接到地 **0**。 |
| **Control** | R2 = 1 kΩ | R2 的上引脚标记为 **OUT**，下引脚连接到名为 **0** 的接地电源符号。 |

OUT 将两个页上的 R1 和 R2 连接起来。名称匹配的接地连接将 R2 的回路接到 Power 页上的地 0。页面之间没有绘制导线，但电路仍然是 V1 → R1 → R2 → 回路。使用原来的元件值时，其工作点输出仍为 2.5 V。

视频使用**剪切和粘贴**移动 R2，保留其标号，而不是创建第二个 R2。添加更多元件时，请确保整个图纸中的标号唯一，以便网表和报告能够标识出预期元件。

## 标签名称适用于整个图纸
{: #label-names-apply-to-the-whole-drawing}

共用名称很有用，但也容易意外连接不相关的部分。在三个不同页上使用名为 `OUT` 的标签，会连接这三个位置；标签并非仅在各自页面内有效。如果信号应保持独立，请使用更具体的名称，例如 `SENSOR_OUT` 和 `AUDIO_OUT`。

页名称和选项卡顺序不会提供电气隔离。标签形状也只是视觉约定：名称相同的普通、输入、输出和双向标签都属于同一个网络。选择形状来帮助读者跟踪预期的信号方向，并通过名称定义连接关系。

[电源符号](../Power-symbols/) 也可以建立共用的命名电源连接。请保持名称一致：`+3V3` 和 `3V3` 是不同的名称。对于 SPICE，请使用与节点 **0** 的实际连接；名为 GND 的独立网络不会自动成为仿真的地参考。

## 检查跨页连接
{: #check-the-cross-sheet-connections}

使用下方列表面板的模式菜单，从**符号**切换到**网表**。找到共用标签，并检查已连接的元件标号和引脚编号。Sheet 列给出该行所代表的主要项目名称；Symbols 列可以包含同一网络上来自其他页的元件。在本例中，OUT 包含 R1 和 R2。

如果连接缺失，请检查标签的连接点，以及两页上的标签文本是否完全一致。如果不相关的元件共用了一个网络，请查找图纸其他位置是否重复使用了该标签名称。[设计规则检查](../Design-Rules-Check/) 可以帮助识别电气问题，但无法判断你是否有意让两个名称相同的网络保持分离。

有关详细信息，请参阅[网表编辑器](../Netlist-Editor/) 和[标签](../Labels/)。在仿真图纸中，更改电路后请重新运行分析，以使结果反映所有当前原理图页。

## 保存完整图纸
{: #save-the-complete-drawing}

**保存**会将所有页一起保存。普通图纸使用 `.dsn`；包含仿真内容的图纸使用 [`.dzn`](../Simulation/#dzn-simulation-drawings)。无需单独保存每个页。
